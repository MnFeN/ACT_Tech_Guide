# 0x6F：事件失败消息白名单

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

这不是通用 LogMessage 通道。p1 仅以下 20 条有效；参数依次来自 p2、p3、p4、Self p5，均以 uint32 加入模板参数。

| LogMessage | 内容 |
| --- | --- |
| 955 | **构造参数数**：0<br>**用途**：招募队员时不能进入任务战场<br>**实际参数**：无 |
| 1526 | **构造参数数**：4<br>**用途**：任务等级/人数不足<br>**实际参数**：p2=InstanceContentTextData 行；p3=InstanceContent 行（0 选泛称任务战场）；p4=最低等级；p5=所需人数 |
| 1528 | **构造参数数**：3<br>**用途**：任务重入冷却<br>**实际参数**：p2/p3 构造但当前模板不引用；p4=InstanceContent 行 |
| 1529 | **构造参数数**：2<br>**用途**：服务器繁忙<br>**实际参数**：p2=InstanceContentTextData 行；p3=InstanceContent 行（0 选泛称任务战场） |
| 1541 | **构造参数数**：3<br>**用途**：正在执行理符<br>**实际参数**：p2=Leve 行；p3=InstanceContentTextData 行；p4=InstanceContent 行（0 选泛称任务战场） |
| 1542 | **构造参数数**：2<br>**用途**：队员无法战斗<br>**实际参数**：p2=InstanceContentTextData 行；p3=InstanceContent 行（0 选泛称任务战场） |
| 1543 | **构造参数数**：2<br>**用途**：队员距离过远<br>**实际参数**：同 1542 |
| 1544 | **构造参数数**：2<br>**用途**：队员不满足开始条件<br>**实际参数**：同 1542 |
| 1597 | **构造参数数**：2<br>**用途**：组队或生活职业不能开始<br>**实际参数**：同 1542 |
| 1620 | **构造参数数**：0<br>**用途**：正在申请参加任务<br>**实际参数**：无 |
| 3718 | **构造参数数**：0<br>**用途**：组队或生活职业不能进入任务战场<br>**实际参数**：无 |
| 3719 | **构造参数数**：0<br>**用途**：正在申请参加任务<br>**实际参数**：无 |
| 3720 | **构造参数数**：0<br>**用途**：无法战斗<br>**实际参数**：无 |
| 3721 | **构造参数数**：0<br>**用途**：正在执行理符<br>**实际参数**：当前未构造参数，但资源有 Leve 模板占位；不能因此把 p2 标有效 |
| 3722 | **构造参数数**：0<br>**用途**：正在其他任务<br>**实际参数**：无 |
| 3725 | **构造参数数**：0<br>**用途**：正在招募队员<br>**实际参数**：无 |
| 7734 | **构造参数数**：0<br>**用途**：任务状态限制操作<br>**实际参数**：无 |
| 7751 | **构造参数数**：0<br>**用途**：区域切换限制操作<br>**实际参数**：无 |
| 7784 | **构造参数数**：0<br>**用途**：跨服队伍或团队状态限制<br>**实际参数**：无 |
| 9404 | **构造参数数**：0<br>**用途**：正在申请跨界传送<br>**实际参数**：无 |

资源条件宏用 InstanceContentId 是否 0 区分“进入任务战场”与“开始具体任务”；InstanceContentTextData 用于相应内容类型的文字。1526 的模板 localnum3 是等级，localnum4 是人数；不是按包字段顺序猜测的数量。1528 只有 localnum3 被当前模板引用，其他两参虽然入参队列但没有文字消费者。3721 反过来存在 Leve 占位却不构造参数，明确保留这个版本差异。

判断白名单前还可能请求 FadeBack/FadeMiddle 固定 24 帧过渡；不支持的 p1 不会打印日志，但不能笼统称整个分支无副作用。详细分支见 [0x6F](categories/006F.md)，原始宏见 [资源](resources-event-log-whitelist.json)。
