## 时间编码和选择

p4 完整 uint32 表示毫秒；原始 ASM 先用 EAX 零扩展，再以 RAX 转 float 乘 0.001 保存为秒，不能按 signed32 或 float 原始位解释。p4=0 写-1 哨兵。

p3=1 写共享对象+40h；p3=2..5 分别写+2B0h 显示类型 1..4，并把秒数写+2B4h。没有把这两处合为同一倒计时；更新某一路也不会自动清除另一路。p3 不在 1..5 时，本共享计时分支不写入。

141A419F0 在阶段 22 时对两处非负秒值减去逻辑帧秒数；减过 0 后可成为负数。140D5DCC0 显示时优先+40h：非负则用类型 0；否则若+2B4h 非负则使用+2B0h 类型。不是“最后收到的计时无条件覆盖当前提示”。

140D5ED60 将秒数按 `int(seconds+0.999f)` 取显示数字（不将其描述为对所有浮点输入严格等于 ceil），更新 NumberArray117[602/603]，再从五项表选择 Addon 行格式化，写 StringArray105[130]。已保存的类型越界时该格式化路径回退类型 0。

当两路秒值均负时，HUD 走无有效计时路径，数值槽置-1；若之前有类型，则仍可能格式化该类型的 0 秒文本。故 p4=0 能取消该计时源，但不能据此声称立即清空字符串或移除所有旧提示。

本类控制的是观战/共用 HUD 中的计时信息；没有在此路径直接生成火山、湍流或伤害，也没有由文字推断服务端机制触发。其他 0642 子命令仍待查。
