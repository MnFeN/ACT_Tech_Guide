# 无人岛探索队委托应答：0C86/0C87/0CAE

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

三者通过 MJI 模块包装访问 Agent425（MJIGatheringHouse），但效果不同。0C86 只读 p1，另两类全部控制参数未读。

## 0C86：先刷新主窗口，p1 非零再处理委托修改日志

最外层 140EA9730 case3206 先无条件调用 141A5E210→141C5EF00→140A13040；后者只有 Agent 激活且 AddonReady 才以掩码 6（2|4）更新主窗口 150 项 AtkValue，包含目的地、收集素材等。6 是数据更新掩码，不是第 6 种服务器操作。

仅当 p1 非零时，才追加 141A5E1F0→141C5EEB0→140A13280。只有本地 Agent+200h 待完成操作在 1..5 时显示对应日志，显示后清 0：

| 本地操作 | 内容 |
| --- | --- |
| 1 | **Log**：9940<br>**含义**：支付青船币并派出探索队<br>**本地模板值**：金额、目的地字符串 |
| 2 | **Log**：9994<br>**含义**：付费修改目的地<br>**本地模板值**：金额、目的地字符串 |
| 3 | **Log**：9993<br>**含义**：修改目的地<br>**本地模板值**：目的地字符串 |
| 4 | **Log**：9995<br>**含义**：延长探索天数<br>**本地模板值**：金额、目的地字符串 |
| 5 | **Log**：10244<br>**含义**：延长到最大天数<br>**本地模板值**：缓存总金额 |

1/2/4 金额来自 50*(Agent 选中天数+1F4h - 当前天数+1F3h)，目的地字符串来自+188h；5 金额来自+1FCh，均不是包内 p2/p3。p1=0 仍会尝试刷新主界面，但不追加该日志处理；它不是“是否刷新”或通用成功/失败码。

复核时必须保持两包装配对：5E210 对应 EF00（刷新），5E1F0 对应 EEB0（日志）。该顺序由外层分支验证，不能以孤立助手语义代替实际分支。

## 0C87：关闭或重建编辑子窗口

140A13080 若已有 Agent+1F8h 子 AddonId，则关闭子窗口并立即返回。否则仅 Agent 激活时，读取当前探索队槽目的地、天数；已有委托天数非零就复制当前选择；没有则默认 1 天，挑第一个当前素材解锁或专用功能允许的目的地。

随后以数据更新掩码 29（1|4|8|16）调用 140A15C50 构造 90 项 AtkValue，包含可选目的地、素材、青船币持有数和费用，刷新或打开 Addon837（345h）。29 也不是服务器操作码。没有回放请求配对，不强加一个唯一服务器请求名称。

## 0CAE：新增素材后关闭窗口

140A13640 只在 Agent 激活时显示 Log9936：“可以在探索中获得新的开拓素材了。请收下开拓素材后，再次派出探索队。”随后 Hide。未激活时不输出，也不打开界面。没有自动收取素材或重新派队的动作。
