# 0DF3：驾驶获选/地面参与与延后战斗对白

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

| 参数 | 已验证语义 |
| --- | --- |
| p1 | 未使用；目标为模块 CurrentEvent |
| p2 | full==1 为驾驶获选；所有其他值走地面参与初始化 |
| p3 | 地面分支非 0 时为 MassivePcContentBattleTalk 行号 |
| p4 | 上述表的子行号，完整 32 位传递 |

模块 141A2D7F0 要求 ready 及 CurrentEvent 非空，141A6B680 处理后直接 return1。不遍历各事件，不根据 p1 选择事件，也不经过事件层 Flags&3==3 门控。helper 另外要求全局机甲模块及 MassivePcContentDirector 存在，否则不更新。p5..p8、target 未用。

## 驾驶与地面分支

p2 恰 1：设模块 PilotApplicationAccepted bit2，清 IsJoined bit7。此路径不调用场景初始化、ScreenImage 或对白，不消费 p3/p4。它不在此处额外设置剧情进行位。

p2 不等于 1：设 IsJoined 并清 Accepted；141C55260 遍历场景注册对象，更新交互与两组选择器状态。按 WKSParam1016 的值 1421 显示 ScreenImage1421，置模块 bit13，并输出真实 Log10845：参加了机甲行动，此行动使用特殊热键栏专用技能。最后执行 internal3480(currentEventRow,0,0,0)。这些是已有当前事件的参与确认，不是用 p1 创建事件。

## p3/p4 是战斗对白资源键

只有地面分支且 p3 非 0 时，调用导演虚 337(p3,p4,5)。不是奖励/信用点数值，也不是 p4 指定延迟。

本机 141A24120 基类构造写 vt1423E2CB8。141A23590 按事件类型 800E 创建导演，派生 vt 为 1423E38A0/1423E4458/1423E5010；四张表的槽 337 都指向 141A26BA0。这里使用真实构造/factory 证据，没有按邻近地址猜虚表边界。

141A26BA0 先以 p3、p4 查 MassivePcContentBattleTalk。140842E40 ASM 将两者完整 DWORD 交表 1253 getter，没有在此截 p4 为 ushort。查表成功且 source 存在，才清旧对白计时、缓存新行/子行和本机 EntityId，并设置开始计时。查表失败保留旧链，不是无条件清空。

本包固定第五参数 5，调度函数收到 1000*5=5000 毫秒；140B58220 将毫秒乘 0.001 保存秒计时，因此这是名义 5 秒后开始。141A28B00 识别该起始计时器，设+4ED 及+4EE；141A25890 更新在+4EE 置位时不增加子行，直接播放本包指定的初始子行。后续对白结束计时再增加子行，逐条取同表，直至无下一行清链。

最终 141A27B20 读取资源的说话者、文本、图像/声音与+0F 时长，交既有战斗文本格式化/显示队列。显示时长来自表的秒值，与本包固定 5 秒开始延迟不同；p4 始终是子行号。

WKSParam1022 同时已核为 5，供 0DF6/0DFC 说明中的提前调查提示阈值使用；这是 WKSParam 表行，不是用户配置 ConfigOption 索引。本包采用 WKSParam1016=1421 的画面资源，ScreenImage 字段 Image=128378、Jingle162；未渲染时不臆造画面字样。

没有 0DF3 回放样本。全部参数、真实虚表、资源读取、延迟回调与后续文本消费闭合，转为已核对。
