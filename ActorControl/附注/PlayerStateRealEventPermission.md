# 038C.bit15：线下活动专用命令许可

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

PlayerState+537h.bit7，即全局 bit15，由 140BE2020 读取并返回 0/1。本轮用实际命令注册、处理函数和资源说明确认其至少控制线下活动专用命令；名称按已证功能，不宣称为通用 GM 权限或某一年活动标记。

| TextCommand 行 | 内容 |
| --- | --- |
| 322 | **实际命令**：//eventReset<br>**原生绑定和效果**：14090F1E0 将虚表 14219D9E8 注册给行 322；槽 1=14092C720。入口要求 bit15 为 1，否则返回 FFFFFFFF；后续重置部分配置、热键栏、闹钟等 |
| 32 | **实际命令**：//setGearset<br>**原生绑定和效果**：同一构造注册虚表 14219DA10；槽 1=14092D3F0。入口同样要求 bit15；随后调用 UI 装备套装模块方法 |

两行本机 Description 均明确“リアルイベント用コマンド”（线下活动用命令）。322 说明将游戏设置初始化为线下活动用途；32 说明根据兵装库物品自动生成战斗职业装备套装。不是只凭命令英文名猜测。完整行见 resources-playerflag15-shell-commands.json、resources-playerflag15-event-command32.json；后者是 32，不能误将相邻 323 的普通/crosshotbartype 当同一门控。

## 其他消费者与边界

1400F7010 的 JobHudNotice 相关流程在此位为 1 时走不同路径。140932E90（实际 TextCommand123 邀请小队）及 1409325E0 把此位作为额外开关交给目标名称解析器。1409BC450 还在特定身份/场地规则下读取其反值。上述额外用途按原分支保留，尚未把全部切换行为统一概括为 GM、试玩账号或调试权限。

140BE2020 的全部 8 个直接 call 站点保存在 client/playerflag15-command-bindings-and-contexts.json，其中 1409BC780 两个站点当前未得到反编译结果，保留了汇编上下文，没有因此更改栈帧。其他处理函数 C/ASM 已保存在 client/。

bit15 置 1 仅表示通过这里的许可检查，不能保证命令后续条件满足，更不能由此确定服务器何时或如何赋予该位。038C 已确认 16 项旗标作用，仍保留 bit12 以及第三 byte 其余高位的缺口。
