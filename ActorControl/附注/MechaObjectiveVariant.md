# 0DFF：机甲任务目标变体

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

这条包的 p2 不是 0DF4 子命令 1 切换的七阶段处理器编号，而是独立的目标变体字段 event+82B4。构造 141A69E90 和 Setup141A6A850 都初始化为 3；收包保存完整 DWORD，不取低 8 位。

## 目标文本与区域演出

141A2F840 要求目标 Todo 尚未有效、module Flags&8084 非 0、当前事件及处理器存在且其 GetStageIndex 为 5。Accepted bit2 决定使用资源+8 起的驾驶员三条文本，或资源+14 起的地面协助员三条文本，再用 event+82B4 作索引；值 3 特别回退到各自第一条。实际资源 WKSMechaEventData 行 8：变体 0 是驾驶重型机械清除重力块、地面清除重力畸变点；变体 1 改为双方清除巨大重力块。行 10 驾驶员变体 0 采伐有毒花粉植物、1 采伐攻击性花粉植物；地面两条都是焚烧小型植物并回收灰烬。行 1 只有首条非空，客户端仍保留三槽选择。不能给所有事件强行统一成同一套“第一波/第二波”名称。

141A6C0B0 还有独立消费者：通过资源+70 查 WKSMechaLivelyActorGroup 子行 0，在玩家位于对应场地区域内时选择演出项。传送开始后前 30 秒及阶段 7 走结束/准备项，阶段 1/2 和 3/4 各有独立项；只有阶段 5 按本字段选择驾驶员组 WORD[7+variant]或地面组 WORD[4+variant]。signed>=3 返回 0。ASM141A6C20A/211 是 signed 比较；负数仍进入带符号索引，不能声称所有不合法值都被过滤。本文只将正常 0..2 及初始化 3 作为业务取值，不把内存越界读取解释成合法目标。

## 收包直接副作用

公共门控：p1 完整事件行号匹配、事件 Flags&3==3、WKSMechaEventModule 存在。相同 p2 直接跳过以下字段变化副作用，但后续公共场景/阶段分发仍经过；已核对无该类别的额外动作。变化时写 event+82B4；若 MassivePcDirector 存在，141A23F40(director,0)给 Todo 槽 0 置 dirty bit1。

事件行 8 在新值非 0 时遍历现有标记，类型 3 标记的 MapMarkerData.Flags bit0 置 1（隐藏）；新值 0 不在本分支逐条恢复。创建/更新标记的 141A6C410 另行限制：事件 8 且目标变体既非 0 又非 3 时拒绝类型 3 标记。因而初始化哨兵 3 虽允许新标记，3 作为变化值仍满足非 0 并隐藏已有标记，两条条件不能擅自合并。

事件行 10 在新值恰 1 时，查 SharedGroup(type6) LayoutId0xC0F5D3，成功则 PlayTimeline(index1,0)。当前仅确认布局时间轴调用，不凭索引猜具体动画外观。此分支不直接创建角色，也不把 p2 当对象 EntityId。其他事件行不走这两个专属分支。

p3..p8 及 target 均未读。收包没有把 p2 钳制成 0..3，文本选择器也只有值 3 回退特例；不能把文档中的正常业务范围当作程序实际校验。

## 证据与覆盖

client/mecha-progress-status-consumers.json 保留全.text 精确位移扫描候选；仅上述已核对接收者用于语义，不把其他类同偏移当同一字段。WKSMechaEventData 行 1/8/10 及 WKSMechaLivelyActorGroup 行 1..4 子行 0 均为本机游戏资源导出。408 个回放未观测本类别；结论来自原生路径与独立资源/显示消费者，不虚报回放验证。
