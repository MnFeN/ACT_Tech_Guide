# 03F3：临时家具记录及布局模式收尾

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

只读 p1 完整 32 位的零/非零，其他 p2..p8 及独立 target 不用。主函数实际传给 140E19990 的是 p1==0，不能仅看 callee 的 if(!a2)反转网络条件。

140E19990 优先 Outdoor，没有时使用 Indoor。p1 非零先调用 1406F4660→14072BA10：遍历 LayoutWorld+40h 控制器+208h..+210h 实例指针 vector，以 1407989E0 注销/析构各实例，再清 vector 并置+188h 刷新 byte。p1 为零不做此额外销毁。

两条路径随后都 140E28750 处理固定临时家具记录 1461，偏移 70128=1461*48。首 ushort 非零时 140E27FD0 释放记录+24h 指向的场景对象，并把记录头、XYZ/朝向、对象索引等重置。再清特殊 key 的关联 map 记录以及 manager 内+12590h word。它不是遍历重建或删除所有已放置家具。

最后 1406F4290 将 Outdoor+12A80h 或 Indoor+12638h 缓存的布局模式送给 14072AAA0，第三参数固定零。后者在模式改变时执行模式切换并通知已注册对象。网络 p1 不是目标模式编号，也不总是退出到模式 0。

无回放样本。用“临时记录收尾并恢复缓存模式”描述实际消费者，不额外猜服务端失败原因。
