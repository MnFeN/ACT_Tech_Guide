# 512 / 0x200 CommitMapEventUpdate

[分类参数](../../README.md#category-0200) · [附注索引](../README.md)

提交地图事件更新

- 分支地址：`0x140b417a1`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：提交 01FF 开启的分组地图事件更新，启动异步资源解析并标记地图及推荐列表刷新。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 未读取 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：没有独立网络参数，使用 Map+1B38h 前一轮 mask。bit0 启动 Quest 队列解析，队列空时仍设置任务刷新状态；bit1 启动 GuildleveAssignment 异步行查找；bit3 调用 Agent109 RecommendList 刷新标记方法 140C9D140，只写 Agent+2A=1，无直接打开界面；bit4 处理 CustomTalk 关联对象刷新/异步资源；bit5 处理事件情境标记和 EventSituationIconTooltip 行查找。最后 Map+1B3Ch OR1 并清+1B38h 完整 DWORD。异步 Excel 查询尚可在返回后继续，不能称所有标记同步构建完成；不是单纯 OpenRecommendationGuide。bit2 行会令组已在 01FF 清理，不在此函数单独排表查找。无回放。

依据：`0x140C15E10 resourcequeues andpendingmaskclear`、`0x140C9D140 RecommendList dirtyonly`、`0x140C136B0 asyncsituationmarkers`、`FFCS Map listoffsets`、`FFCS AgentId.RecommendList109`、[MapEventUpdateGroups.md](../MapEventUpdateGroups.md)。
