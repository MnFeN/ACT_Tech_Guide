# 1310 / 0x51E VerminionHitEffect

[分类参数](../../README.md#category-051e) · [附注索引](../README.md)

萌宠命中表现

- 分支地址：`0x140b3909c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：对萌宠之王宠物播放普通 Hit 或 Critical 命中表现。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 要显示命中表现的宠物 EntityId；不存在对应 BattleChara 时不创建效果 |
| p2 | 完整 32 位恰等于 1 时选择 LOVM011 Critical 效果；其他任何值选 010 Hit；不是非零布尔 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140E77A20 按 p1 找实体，写 Character+0D00h float=0.5，再调用 1408580E0(localIndex,actor,1.0)。真实路径为 vfx/lovm/eff/010.avfx 或 011.avfx，不经通用 VFX 表 10/11 行。原始 010 引用 SE_Vfx_Monster_LOV_Hit.scd，011 引用 SE_Vfx_Monster_LOV_Critical.scd，并有不同粒子纹理；按资源名可确定普通 Hit 与 Critical 表现，但不把它扩大成该包计算暴击率或改变伤害。已纠正旧“VFX 寿命 1 秒”：helper 的 XMM2=1.0 用于构造统一缩放矩阵，再交 1403913F0；此函数拷贝 4x4 矩阵、按实例轴缩放后转交 14037A470，不是计时器。真正创建 140857200 的时长相关参数为-1.0，当前未从该路径推导具体秒数。+D00 的 0.5 固定侧效应保留原始字段，不猜全部时间语义。p3..p8 及独立 target 未读。现有回放无样本，未动态播放或修改伤害。

依据：`0x140E77A20 entitylookup andfixedD00=.5`、`0x1408580E0 path vfx/lovm/eff/%03d.avfx andfloat scale`、`0x1403913F0 transformmatrix /14037A470 forwarding`、`client/lovm-010.avfx /lovm-011.avfx actualgamebytes`、`client/lovm-short-effect-paths.json soundHit/Critical`、`client/lovm-short-effect-provenance.json hashes`、[VerminionHitAndCriticalEffects.md](../VerminionHitAndCriticalEffects.md)。
