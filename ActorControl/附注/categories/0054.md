# 84 / 0x54 SetTreasureMap

[分类参数](../../README.md#category-0054) · [附注索引](../README.md)

设置解读后的藏宝图

- 分支地址：`0x140b3d32a`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：EventItem 行号、固定任务道具槽与地图子键已核对。
- 用途：设置解读藏宝图事件道具并可打开地图。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 解读后获得的 EventItem 资源行号（如 TreasureHuntRank.KeyItemName=2001087）；0 清除该道具编号 |
| p2 | 低 16 位 TreasureSpot 子键；写 EventItemManager 首 ushort，供地图位置查询 |
| p3 | 非零且 p1 非零时打开藏宝地图并显示解读成功消息 |
| p4 | 此分支未读取 |

说明：1408918E0→140891E50 将 p1 作为 InventoryItem.SetItemId(itemId,true)实参写 KeyItems(2004)固定槽 123，先 Clear，再设 Quantity=1 并标脏；0x7B 是槽号 123，不是道具类型。藏宝图等级通过槽中 BaseItemId 与 TreasureHuntRank.KeyItemName/InstanceMap 对照；原 Item 来自同一行 ItemName。资源例 Rank1 Item6688 / EventItem2001087。p3 非零且 p1 非零才打开藏宝地图并显示 Log3750“解读成功，获得任务道具”，日志参数分别为原 Item 及 p1EventItem。其余参数未读。

依据：`0x1408918E0`、`EventItemManager.GetTreasureSpotSubKey`、`EventItemManager.GetTreasureHuntRank`、`LogMessage3750`、`0x140891E50 KeyItems2004 slot123 Clear/SetItemId(p1,true)/SetQuantity1`、`0x1408919C0 TreasureHuntRank.KeyItemName or InstanceMap match BaseItemId → ItemName`、`FFCS InventoryItem virtual4/5/7/13`、`resources-repair-treasure.json TreasureHuntRank1..5 and Log3750`。
