# 2 / 0x02 SetStatus

[分类参数](../../README.md#category-0002) · [附注索引](../README.md)

设置角色行为模式

- 分支地址：`0x140b396e3`。
- 回放观察：50257 次；包族 {"ActorControl": 50257}。

## 参数与行为

- 核对状态：已核对。
- 用途：设置 Character.Mode 与 ModeParam。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | CharacterModes 枚举；写 Character+0x2364 字节 |
| p2 | ModeParam，低 8 位写 Character+0x2365，意义依模式而异 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：不是 Status 状态效果列表。模式切换还更新动作、移动、武器与 UI。

依据：`0x140908790`、`FFCS Character.cs`。
