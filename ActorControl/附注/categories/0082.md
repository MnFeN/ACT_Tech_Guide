# 130 / 0x82 SetContentClearFlag

[分类参数](../../README.md#category-0082) · [附注索引](../README.md)

设置副本内容通关标志并刷新相关事件/UI

- 分支地址：`0x140b41f45`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：InstanceContent 表身份、分段位图、允许范围与共享刷新已核对。
- 用途：设置副本内容通关标志并刷新相关事件/UI。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | InstanceContent 资源行号；直接位图写入支持 1..104、10001..10014、20001..20109、30001..30163、40001..40047、41001..41007；额外支持 15001..15027 与 35001..35032 |
| p2 | 等于 1 置通关状态，否则清除 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：p2 恰为 1 置位，其余清位。每个编号段减对应起始 ID 形成 0-based bit 索引，以 1<<(index&7)写 PlayerState 分段位图。不是 ContentFinderCondition：例如 InstanceContent10001 关联 CFC42，InstanceContent104 关联 CFC1011。写入入口不读取 EXD 校验行是否存在，只依编号范围；无效段也仍执行主函数的事件/UI 刷新。开放经 LABEL1728 再到 1729，通关直接 1729；不消费 p3..p8。

依据：`0x1419AACC0`、`0x140B41F45`、`0x1419AACC0 completed range switch / 0x1419AA7D0 unlocked range switch`、`0x1419AAEB0 FFCS UIState.IsInstanceContentCompleted and 0x1419AA980 IsInstanceContentUnlocked`、`0x140BE5210 LSB-first bit writer`、`resources-content-flags.json InstanceContent10001→CFC42 /104→1011`、`ActorControl-reading.c LABEL1728/1729`。
