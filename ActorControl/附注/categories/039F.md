## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：接收 PvP 快捷聊天（旧 SetMountSpeed 不准确）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 发言者 EntityId |
| p2 | QuickChat 行号 |
| p3 | QuickChat.Addon 文本模板第 1 参数；QuickChat28 的 Addon11057 将其解释为 ClassJob 行号 |
| p4 | QuickChat.Addon 第 2 参数；QuickChat28 还将其作为集中攻击目标 EntityId 传给 Agent |

说明：使用 QuickChat.Addon 格式化文字并按队伍成员补发言人名；QuickChat28 集中攻击将 p4 另传给 Agent，29 停止集中攻击清该目标。无队伍时显示 LogMessage7529。
