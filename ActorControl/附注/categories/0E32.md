# 3634 / 0xE32 CompleteCosmicDeliveryObjective

[分类参数](../../README.md#category-0e32) · [附注索引](../README.md)

宇宙任务交纳目标完成

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：目标类型 5、交纳目标文本及进度布尔消费者已核对。
- 用途：将探索任务交纳至指定存放点目标置为完成并刷新任务进度。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 本消费者未读取 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：全部控制参数未读。WKSManager 存在时将+E99h 置 1，调用 140148C10(0)标记 Agent467 任务信息 dirty，再 141A73BD0 刷新任务追踪。后者当前 WKSMissionToDo+29h 类型为 5 时，把此 byte 转 bool 写目标条目+78h 进度；它与采集总数/个人数、物品库存计数及任务分数的类型 1..4 分支不同。当前本机所有类型 5 行的 WKSMissionText 均为 144“交纳至指定存放点”，关联 EObj2014616/2014618 均名“物资存放点”；任务示例 WKSMissionUnit512“制作工作所需的落脚台”第二阶段 ToDo520 使用此目标。故这是交纳目标完成状态，不是泛称收集阶段计数，也不直接修改库存或清除整项任务。任务切换/清理时清该 byte；无回放样本，默认模块须加载且链可达。

依据：`0x141A709C0`、`FFCS WKS/WKSManager.cs`、`0x141A73BD0 ToDooffset29 type5→ManagerE99 bool→tracker78`、`0x140148C10(0)→Agent467 dirtybit1`、`resources-wks-mission-todo-units-raw.json`、`resources-wks-mission-todo-type5.json`、`resources-wks-mission-delivery-text.json`、`wks-mission-delivery-type5-summary.json`。
