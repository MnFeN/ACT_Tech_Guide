# 2366 / 0x93E ItemGainResult

[分类参数](../../README.md#category-093e) · [附注索引](../README.md)

物品获得或背包已满提示

- 分支地址：`0x140b451c2`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：获得物品成功/背包已满提示，可额外显示获得徽章的物品提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位非零转成功 bool，显示获得日志；零显示 4658 背包已满 |
| p2 | 成功时完整 32 位恰 1 额外显示 Addon10360 获得徽章物品提示；其他值不额外显示，失败时未读取 |
| p3 | 完整 32 位 Item 标识，成功用于获得日志/徽章提示，失败用于 Log4658 物品名称 |
| p4 | 完整 uint32 获得数量，仅成功时用于共同获得日志；额外徽章提示数量固定 0，失败不使用 |

额外参数：p5..p8 及独立 target 未读取

说明：141780D00 要求 item 非 0，且 quantity 非 0 或 PlayerState.HasAddictionRestrictions(+78h)为真；当前 PlayerState 基址 142ADF3B8，故 byte142ADF430 对应此字段。quantity uint32<=1 用 Log2071，否则 2072；本地参数 1 为 Item 编号、参数 2 为数量（仅多件路径显式加入）。完整 SeString 边界已解码，普通 gnum51=0 为获得了 Item 及数量，gnum51=1 走防沉迷收益减半，其他走无法获得收益；此函数未将传入数量再除 2。HasAddictionRestrictions 门控与模板 gnum51 是独立存储，未声称它们始终数值相同。不是交付或扣除物品，不直接改变库存。 141781E80 接收到的是归一化 bool，因此其 a2==1 等价主收包 p1 非零，而非网络 p1 必须 1。成功 p2=1 调用 140BCBD40(item,10360,0,0)，标题本机明确获得徽章，不能叫未知内容 UI。失败 4658 是无法获取 Item，背包已满。没有写 FateContext.Progress，旧 FateProgress 不准确。无回放。

依据：`0x140B451C2 p1nonzero normalization`、`0x141781E80 itemresult`、`0x141780D00 gainlog`、`0x140BCBD40 itemnotice`、`resources-dynamic-event-reward-templates.json Addon10360/Log4658`、`resources-dynamic-event-reward-decoded.json`、[DynamicEventItemRewardNotices.md](../DynamicEventItemRewardNotices.md)。
