# 138 / 0x8A FreeEventPos

[分类参数](../../README.md#category-008a) · [附注索引](../README.md)

取消当前事件场景对包头角色的位置和朝向恢复

- 分支地址：`0x140b4263d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：完整 EventId 匹配、角色场景记录及位置/朝向恢复位末端已核对。
- 用途：取消当前事件场景对包头角色的位置和朝向恢复。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 EventId，必须等于 EventSceneModule 当前栈顶 EventHandler.Info.EventId(+20) |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：原“释放位置约束”解释撤回。EventFramework+1B0 为 EventSceneModule；140B53080 取当前栈顶 handler，p1 匹配其+20 EventId 后，1417D97E0 两次以 index0/1、enabled0 清该角色场景记录+0A8bit0/bit1。1417E1020 在 176byte 场景记录数组中按 GameObjectId 或 ClientObjectIndex 身份匹配；无对应记录则无变化。最终恢复函数 1417E1130 汇编以 bit0 控制保存 XYZ(+88..90)→移动控制/SetPosition，以 bit1 控制保存 Rotation(+94)→SetRotation。1417DB7E0 在场景清理并启用恢复模式时遍历这些记录调用它，故清位是取消后续位置/朝向恢复，不是立即移动、解除碰撞或把当前角色坐标改成 p1。p2..p8 未读。

依据：`0x140B4263D`、`0x1417D97E0`、`FFCS EventFramework.EventSceneModule+1B0;EventHandler.Info+20 EventId`、`0x1417E1020 sceneactorrecord arraystride176 identitymatching`、`client/1417E1130_raw.asm bit0 at12D1/19D5→savedXYZ;bit1 at1450→SetRotation`、`0x1417DB7E0 sceneactorcleanuprestoremodecalls1417E1130`、`client/event-scene-rollback-a8-candidates.json scopedreaders`、`client/event-scene-rollback-frame-repair.json HexRaysframefailure;trialreverted,rawasmused`。
