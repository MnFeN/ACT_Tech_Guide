# 2369 / 0x941 ClearFateObjectTracking

[分类参数](../../README.md#category-0941) · [附注索引](../README.md)

清空 FATE 关联对象

- 分支地址：`0x140b451ec`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：刷新并清空 FATE 关联对象跟踪列表。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FateId |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：Flags 某位未设时遍历关联对象，修正显示位并置刷新 bit3，最后清列表；不删除 FATE 本体。

依据：`0x141782900`。
