# 2356 / 0x934 FateAssignID

[分类参数](../../README.md#category-0934) · [附注索引](../README.md)

创建并登记 FATE

- 分支地址：`0x140b45009`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：创建注册、IsBonus 位及额外奖励完成图片消费者已核对。
- 用途：创建并注册 FATE 上下文，指定是否带额外奖励标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FateId |
| p2 | 全 32 位非零/零→新 FateContext+3C1h bit0，具名 IsBonus 额外奖励标记；不承载奖励数量或倍率 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：141780510 分配 29D0h(10704)字节并构造新上下文，p1low16 为 FateId；清 Flags+1Ch bit5，按 p2!=0 置/清+3C1h bit0，其他位保留。异步读取 sheet164 Fate 行，初始化 MotivationNpc/ObjectiveNpc=E0000000，最后按 FateId 检查列表，已有相同 ID 则不重复插入，也不在此函数更新已有上下文的 IsBonus。固定 FFCS 将+3C1 声明 IsBonus，实际消费者 14177C730 在 State7 结束分支将 ScreenImage34/38 切换为 522/525；本机前者 Image120082“危命完成！”，后者 Image120085 明确另有“额外奖励”。失败分支同样 35/39→523/526；Update14177B590 进入显示亦按此 bit 切换开始提示。141783FA0 的进度块更新会独立覆盖该位并标 dirty，说明创建初值不保证永久不变。此包不直接设置经验/双色宝石数量、改变角色等级同步或强制开始 FATE；其他网络参数未读，无回放样本。
