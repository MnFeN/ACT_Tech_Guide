- 分支地址：`0x140b3f9e5`。

## 参数与行为

- 核对状态：活动位消费者、次数恢复及 p2 实际地图标记作用已核对。
- 用途：终止 Type2/5 采集点的活动出现条件，恢复次数并可清感知标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 非零略过小地图感知标记清理；0 按 GatheringType0/1 清槽 1、2/3 清槽 2，其他类型不清 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：清 Flags+310bit0，RemainingCount=Count。140E8B830 对 Type2/5 检查该活动位，清除后不通过可见性判定；本函数并不清+304 缓存条件键。p2 只决定是否略过感知标记清理：0 对 GatheringType0/1 清 AgentMap 槽 1，2/3 清槽 2；其他类型不清。p3..p8 未读。

依据：`0x140E8B010`、`0x140FC03D0 clearsAgentMap.MiniMapGatheringMarkers record,not UI callback`。
