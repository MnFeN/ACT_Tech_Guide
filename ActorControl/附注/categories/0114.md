## 参数与行为

- 核对状态：ushort 写入、DawnMember 双消费者及 303 条 Self 回放取值已核对。
- 用途：同步副本助手槽的 DawnMember 编号及助手启用状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 DutyHelper 槽 0..6；>=7 无操作 |
| p2 | 低 8 位恰等于 1 则 DutyHelperInfo.HasHelpers=true；其他值 false |
| p3 | 低 16 位整体存 BuddyMember+0Ch；当前副本助手消费者把整个 ushort 作为 DawnMember.RowId，不能独立把高 byte 定义为等级同步旗标 |
| p4 | 此分支未读取 |

说明：目标全局 142AE2C40 即 UIState+42C0h=Buddy.DutyHelperInfo，首指针为 7 项 3F0h 的 BuddyMember 数组。140C22620 仅当 p1low8<7 时写 Info+9=(p2low8==1)，再将 p3low16 覆盖该槽+0Ch；值未变不重复写条目。两消费者 140C227E0/140C22830 先要求 Info+9，按槽取整个 WORD+0Ch，再经 140834660 查本机 sheet790 DawnMember，分别返回行首两个 byte；完整 ASM 明确 movzx eax,word ptr[...+0Ch]、movzx ecx,ax。固定 FFCS 通用 BuddyMember 把+C/+D 写成 DataId/Synced 并注释 Trust→DawnGrowMember，但不能照搬为本包网络参数的独立语义。本包与当前这两个副本助手消费者应按 DawnMember ushort 编号定义；不把高 byte 当可独立切换等级同步。ENpcIds 另由 05F5 设置，不与此值混淆。408 回放中本类 303 条全 ActorControlSelf，p3 只有 5(3)、13(98)、28(98)、31(6)、34(95)、35(3)，均能查当前 DawnMember；回放全部高 byte0，不能靠样本单独证明高 byte 旗标。DawnGrowMember13 不存在，作为负例另存 client 探测文件，不用不存在行作业务映射。
