# 1013 / 0x3F5 RestoreHousingItemTransform

[分类参数](../../README.md#category-03f5) · [附注索引](../README.md)

恢复家具位置与朝向

- 分支地址：`0x140b3d821`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：把家具缓存中的位置及朝向重新应用到对应场景对象。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low16 为已布置家具 InventoryType；bits16..23 为 OutdoorHouseUnit（普通地块/division 或 80h/81h 公寓），仅室外使用；最高 byte 未读 |
| p2 | low8 库存槽号。室内 25003..25014 映射 50*(type-25003)+slot；室外只接受 25001/25200，合并槽号按 byte 计算 slot+40*bank；当前入口无 slot<40 或 slot<50 检查 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取；不携新的 XYZ 或朝向

说明：140E19BC0 优先室外管理对象；室外 houseunit 普通/30 求 division、80h/81h 用低 7bit，需当前 division 一致，再用 word_142AF9140 地块基址或公寓基址 1460 加合并槽号。室外容器入口仅允许 25001/25200，27000/27200 备用分支已被入口排除。无室外对象时才尝试室内 25003..25014。终端 140E27330 仅 index<1462 处理 48byte 缓存 record，+24h 为场景对象索引；室内索引负则跳过，室外索引负改用 140E29570 按 FurnitureIndex 查对象。取得对象后从 record+10h/+14h/+18h 读 XYZ、+20h 读 float 朝向，141A46310 依次 GameObject.SetPosition/SetRotation，并通过 140E1A470 把 HousingManager+E2h 置 1；最后 141A45440 清全局 word1428D90C8 为 FFFF。没有删除家具、清库存或把新坐标写缓存的动作。旧 slot<40 注释不符当前函数，已撤回；与 03F9 从本地对象坐标提交至缓存的方向相反。无回放样本。

依据：`0x140E19BC0 outdoor/indoor routing and HouseUnit`、`0x140E234F0 indoor inventory index`、`0x140E27330 record stride30h XYZ+10 rotation+20`、`0x140E273B8 movss XMM2 rotation`、`0x141A46310 SetPosition thenSetRotation`、`0x140E1A470 HousingManager+E2=1`、`0x141A45440 word1428D90C8=FFFF`、[HousingCachedTransformApply.md](../HousingCachedTransformApply.md)。
