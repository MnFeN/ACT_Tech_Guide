- 分支地址：`0x140b3f546`。

## 参数与行为

- 核对状态：主处理与 Self 录制／回放外层参数已核对。
- 用途：通知 EventFramework 初始化/刷新控制器。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Director/EventId：通用主分支不读取；Self 录制及回放外层在高 16 位为 8003/8004/800C 时缓存完整 DWORD 到 ReplayManager+658h |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |

依据：`0x140B80E40`、[ReplayDirectorChapterSideEffects.md](../ReplayDirectorChapterSideEffects.md)、`client/replay-outer-catalog.json：0064实况及回放外层`、`1408494E0 category64 caches payload+4 DWORD /14084C9D0 recordA9同缓存`。
