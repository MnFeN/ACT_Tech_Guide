# 0 / 0x00 ToggleWeapon

[分类参数](../../README.md#category-0000) · [附注索引](../README.md)

收刀／拔刀

- 分支地址：`0x140b387c0`。
- 回放观察：86347 次；包族 {"ActorControl": 85957, "ActorControlSelf": 390}。

## 参数与行为

- 核对状态：分支与结构核对。
- 用途：收刀/拔刀，含本机武器状态特殊路径。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 等于 1 拔出，否则收起 |
| p2 | 等于 1 时传 isInstant=true；其他为 false。该布尔控制表情中断及武器切换时间轴处理 |
| p3 | 等于 1 时，本机路径保留 p2；否则本机路径强制第二布尔为 false。远端路径不依赖 p3 |
| p4 | 此分支未读取 |

额外参数：isRecorded 影响本机身份判断

说明：回放 85425 次，p2 非零 80483 次，p3 非零 12049 次；旧注释只列 p1 不完整。 固定 FFCS WeaponState 方法第三参名 isInstant；实际末端 true 时会取消正在执行/循环的表情并请求武器拔出/收起时间轴 1/2，本机还先重置时间轴槽。远端不依赖 p3。

依据：`0x140B387BD`、`0x140BDBA70`、`0x1408BF1E0`。
