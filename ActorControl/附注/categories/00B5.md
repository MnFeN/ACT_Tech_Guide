# 181 / 0xB5 SetMountTimeRemaining

[分类参数](../../README.md#category-00b5) · [附注索引](../README.md)

骑乘剩余时间

- 分支地址：`0x140b43f91`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：骑乘状态图标、时间文字与下坐骑归零已核对。
- 用途：同步骑乘状态的剩余持续时间。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 数值除 100 转换 float 秒，写 UIState+0x19FF0；0 表示无此倒计时 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：本机 HUD 的 14109DFA0/14109EB30 为坐骑状态构造特殊状态图标 0x40034C89、Addon179“骑乘状态”，将此 float 加 0.5 转整数秒后 FormatTimeSpan 显示。1408AB910 下坐骑路径对本机清零。1419F16A0/1419F1860/1419F1E10 在区域切换等流程中检查实例外非零骑乘时限。这里是持续时间秒，不是 float 位模式、移动速度或高度。没有根据当前函数声称客户端自动递减，服务器更新与具体坐骑类型可另查。p2..p8 未读。 本轮汇编复核：32 位 mov 写 EAX/ECX 后零扩展至 RAX/RCX，再 cvtsi2ss 以 64 位寄存器转 float，按 uint32 取数；已纠正旧伪码 signed 传播。见 FloatConversionAudit.md。

依据：`0x00B5`、`0x14109DFA0 /14109EB30 float+0.5→int seconds→RaptureTextModule.FormatTimeSpan`、`0x1408AB910 1408AC228 local dismount clear`、`resources-mount-time.json Addon179=骑乘状态`、`0x1419F16A0 /1419F1860 /1419F1E10 mount time nonzero gate`、`0x140B43F7D..89`、`client/main-float-conversion-instructions.json`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
