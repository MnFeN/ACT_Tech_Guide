# 555 / 0x22B SetGearsetMateria

[分类参数](../../README.md#category-022b) · [附注索引](../README.md)

套装魔晶石槽资料

- 分支地址：`0x140b42b3b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支及结构/资源已核对。
- 用途：同步套装中匹配装备的一个魔晶石槽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 基础 Item ID：在当前装备容器中查第一个数量非零的匹配物品 |
| p2 | 低 8 位魔晶石槽索引 |
| p3 | 低 16 位 Materia ID，写匹配套装条目的该槽 |
| p4 | 魔晶石等级 byte 的增量值；运算后截 byte，并非直接覆盖绝对等级 |

说明：当前装备容器由 InventoryManager.EquippedItemsInventoryType 选择；遍历可用套装的 14 个装备记录，要求带标志 Item ID 及五槽现有魔晶石 ID/等级都与物品匹配，再更新目标槽、标记套装界面 dirty。入口还触发固定 UI 消息 120903。

依据：`0x140875C10 / 0x140869340 / 0x1407F3190`。
