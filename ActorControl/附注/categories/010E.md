# 270 / 0x10E ToggleCompanion

[分类参数](../../README.md#category-010e) · [附注索引](../README.md)

设置跟随宠物/迷你宠物

- 分支地址：`0x140b38f31`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置跟随宠物/迷你宠物。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Companion 行号，0 通常表示移除；调用 CompanionContainer.SetupCompanion 时 fixed bool=true |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：此处 CompanionContainer 是跟随宠物容器，与战斗陆行鸟 CompanionInfo 不同；本机另通知 UI 虚函数 125。

依据：`FFCS CompanionContainer.SetupCompanion`、`0x140B38F31`。
