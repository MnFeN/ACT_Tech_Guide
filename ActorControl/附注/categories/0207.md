设置队伍成员过场/状态标志

- 分支地址：`0x140b3f214`。
- 回放观察：4470 次；包族 {"ActorControlSelf": 567, "ActorControl": 3903}。

## 参数与行为

- 核对状态：成员查找与标志逐位已核对。
- 用途：设置队伍成员过场/状态标志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 被更新队伍成员的 EntityId；不是包头 EntityId |
| p2 | bit1 映射到 PartyMember.Flags 的 bit4（InCutscene）；其他位不读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：通过 isRecorded 选择实况/回放 Group；callee 先清 Flags0x10，再按 p2&2 置位，其他成员 Flags 保持。

依据：`0x140B3F214`、`0x140B238A0`、`Client.Game.Group.GroupManager.GetGroup`。
