# 802 / 0x322 GearsetSlotError

[分类参数](../../README.md#category-0322) · [附注索引](../README.md)

套装装备槽错误

- 分支地址：`0x140b3c352`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：逐槽错误、全局错误白名单和消息模板参数边界已核对。
- 用途：套装更换过程的装备槽错误应答。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 仅 p2=0 路径使用：零基套装索引；100/254 特殊值遵循 0321 完成消费者 |
| p2 | 装备槽索引；写 InventoryManager+2444h+5*p2+2 的错误 byte=1。入口无边界检查；p2 非 0 直接结束 |
| p3 | 仅 p2=0 读取：LogMessage.RowId；固定八个全局操作阻止消息还会抑制套装结果附加处理 |
| p4 | 仅 p2=0 读取：作为 BattleLog.value1；意义由 p3 所选消息宏决定，未作为统一装备/槽 ID 解释 |

说明：本机/回放观察路由通过才处理。p2=0 时先清本地完成 byte142AD8444 低 byte，调用 14087B920(p1,0,逐槽数组,allowExtra)，再 BattleLog.AddLogMessage3Params(p3,本机,p4,0,0)。禁止附加结果 allowExtra=false 的集合精确为 689/708/730/1625/1626/9601/10969/10848：当前无法换武器、换装备、转职、场所禁止、等级不足、任务中限制 70 级以下战斗职业、职业/辅助职业锁定、机甲行动限制。上述八条本机资源均不插入 value1，故对它们 p4 虽然传入日志器但不呈现；其他 p3 按对应宏使用 value1。p5..p8 未读；p1 只在 p2=0 路径有效。

依据：`0x140B3C352 / 0x14087B920 / BattleLog.AddLogMessage3Params`、`resources-gearset-errors-pvp-currency.json eightglobalerrors`、`0x14087B920 completionfalse→1407F2AD0`、`0x20000080001 relative689 masks689/708/730`。
