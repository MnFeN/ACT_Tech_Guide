# 2100 / 0x834 ShowContentBattleTalk

副本战斗对白

- 分支地址：`0x140b44e5d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：显示当前 ContentDirector 提供的战斗对话文本，按毫秒指定显示时长。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位非零则省略说话者名；零使用路由角色的对象名称（角色存在时），不是文本类型编号 |
| p2 | 完整 32 位 ContentDirector 文本索引，经 Director 虚槽 354 取 Utf8String；不是通用 NpcYell 或 LogMessage 行号 |
| p3 | 完整 uint32 显示时长，单位毫秒；保存任务记录+ACh，回调以零扩展 uint32 转 float 并乘 0.001 后作为 ShowBattleTalk 的 duration 秒参数传 XMM3。不是 float 原始位模式 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：需当前 ContentDirector 存在。140B6D010 生成可选角色名，1417CE7D0 从 32 项 192byte 战斗文本任务中取空闲项，保存 p3 及 style0/showImage1，EventFramework140B85140 异步格式化文本。构造 14004E620 确认主任务 vtable1422D7E10 及+30h FormatStringCallback1422D7DF8，其 HandleCallback=141794B50。后者 ASM141794B8F..4BCC/4BD8..4C47 从+ACh 读 DWORD，经 64bit 零扩展 cvtsi2ss 乘 float0.001(14211BDD4 原字节 6F12833A)传 XMM3；showImage 选择虚槽 199 ShowBattleTalkImage，本包固定 image0/style0/sound-1/entityIdE0000000，无网络额外图像参数。FFCS UIModuleInterface198/199 提供方法与 duration 命名。旧伪码漏了 XMM3，已以原始 ASM 补证；p3=0 仍会覆盖构造默认 3000，不能假称零自动默认 3 秒。当前回放无样本。

依据：`0x140B44E5D ContentDirector gate/p1name`、`0x140B6D010 vf354 text/speaker`、`0x1417CE7D0 save+ACh andqueue`、`0x14004E620 taskctor/vtable/callback`、`0x1422D7DF8 HandleCallback141794B50`、`0x141794B50 XMM3 durationuint/1000`、`0x14211BDD4 raw6F12833A float0.001`、`FFCS UIModuleInterface virtual198/199 ShowBattleTalk/Image`、[DirectorBattleTalkDuration.md](../DirectorBattleTalkDuration.md)。
