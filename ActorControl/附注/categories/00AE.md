## 参数与行为

- 核对状态：Booster 表、冒险录道具与 Lua 读取后清除已核对。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 Booster 资源行号；0xFF 是脚本读取后清除时使用的哨兵值 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：140C509E0 写 UIState+17530 并将+18E8 的四个刷新 byte 置 1。141CAB410 读取 140C50A00 返回值，立即 140C50A10 清为 FF，然后以该值查 Excel 索引 0x3FD=Booster；回调 141CAB340 把行号及行数据交事件脚本。另 140B6A440 的 Lua 子命令 9 读取、10 清除该值。资源 Booster0 对应 Item13991 重生冒险录，1 骑士冒险录、2 武僧、3 战士。之前“可用 Action 列表附加字节”命名撤回；固定 FFCS 对附近 Emj 的注释不能替代实际 Booster 查询证据。p2..p8 未读。
