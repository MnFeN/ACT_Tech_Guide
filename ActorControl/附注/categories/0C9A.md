# 3226 / 0xC9A SetIslandCrop

[分类参数](../../README.md#category-0c9a) · [附注索引](../README.md)

无人岛作物状态

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛一块农田作物状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位农田槽 |
| p2 | 低 8 位 MJICropSeed 行号，0 无种子 |
| p3 | byte3 GrowthLevel；byte2 WaterLevel；byte0 GardenerYield；byte1 未读 |
| p4 | 低 8 位 FarmSlotFlags |

说明：更新作物及布局，按 20 块农田的 UnderCare(bit0)每块加 5 计算 FarmDailyCareFee（0..100）；并非把 ExpectedTotalYield 当费用。主 MJI switch 还重建农田布局。Self p5/p6 未被该槽更新使用；额外 mode 来自管理器。

依据：`0x140EA9730 / 注册模块0x141A60420 / 0x141A5FDB0 / FFCS MJIFarmState`、`0x141A5E990 逐槽费用计算`。
