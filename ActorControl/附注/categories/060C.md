# 1548 / 0x60C ClearTargetReferences

[分类参数](../../README.md#category-060c) · [附注索引](../README.md)

- 分支地址：`0x140b43b9c`。

## 参数与行为

- 核对状态：目标系统及各字段已核对。
- 用途：清除指定对象在 TargetSystem 中的各类目标引用。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 32 位 GameObjectId，0xE0000000 跳过 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：与指定对象相同才清：HardTarget、SoftTarget、PreviousTarget 及其他内部目标引用；SoftTarget 等清除时另将+312 置 0x40000000。该函数不清 FocusTarget。

依据：`0x140629BE0`、`Client.Game.Control.TargetSystem`。
