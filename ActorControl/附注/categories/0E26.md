## 参数与行为

- 核对状态：四槽存取、四阶段名称与＋整数百分比 UI 消费者已核对。
- 用途：同步四阶段宇宙研究数据分析效率的加成百分比。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 仅低 8 位，1/2/3/4 分别初级/中级/高级/最终计划；其他值不写入 |
| p2 | 仅低 16 位，无符号整数加成百分比原值，写 module+B8h+2*(slot-1)；直接显示为＋N％，不是浮点倍率也不是除 100 后的倍率 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：141A6D570 只写四槽，不直接刷新 UI。141A6DF60 在 Manager+1Dh 及 Research+ C0h IsLoaded 成立且槽 1..4 时原样返回 ushort。UI140A85680 构建 Addon939 WKSToolCustomize，从 1 到 4 调用 141A6DFC0 判断已有足够阶段的职业数，遇 0 停止，否则把对应槽百分比交 Addon16939“各职业到<阶段>为止的数据分析效率＋<数值>％”；四阶段名称 16952..16955 依次初级计划/中级计划/高级计划/最终计划。详情 140A86030 用同 getter 值交 16944“<阶段>的研究数据分析效率＋<数值>％”，确认百分比用途；显示还有工具阶段/界面资格门控。固定 FFCS 仅声明 B8 两槽，当前 native 写入和 getter 及 UI 均明确四槽，BC/BE 不覆盖 C0 IsLoaded，保留版本差异。p3..p8/target 未读，无回放样本；默认模块须加载且链可达。
