# 1604 / 0x644 SetSpectatorActorSlot

[分类参数](../../README.md#category-0644) · [附注索引](../README.md)

观战角色名单

- 分支地址：`0x140b43944`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：单槽更新、EntityId 身份及观战名单消费者已核对。
- 用途：更新观战名单中的 BattleChara EntityId 槽、有效位和有效槽计数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 列表槽索引；正常结构八槽，当前入口不检查边界 |
| p2 | 完整 uint32 BattleChara EntityId，写 InstanceContent.SpectatorIds[p1]；实际 AgentPvPSpectator 按有效位用 LookupBattleCharaByEntityId 解析并显示姓名，不是资源 Spectator 行号或 64 位 ContentId |
| p3 | 主收包函数先对完整 32 位做非零布尔归一；归一后为 1 置有效位，否则清；只在位改变时增减+59h 有效项数 |
| p4 | 此路径未读取 |

说明：真实存储为全局 InstanceContent142AF22D0，不是 SpectatorManager。FFCS InstanceContent+38h 八个 uint SpectatorIds 独立匹配；另一个具名 ProcessSpectatorListPacket140C2B3A0 一次拷贝同八个 DWORD，保存+58h 有效位图并 popcount 到+59h。ActorControl0644 通过 140C2B440 更新单槽。p3 在主入口被!=0 归一，不能把 callee 的 a4==1 误解成网络原值必须等于 1。观战管理器析构 141787FE0 调用 140C2B4A0 清列表，八槽写常量表且+58h/+59h 清零。ID 已由后续消费者确认是 BattleChara EntityId，有效位控制是否参与观战名单查找。 新闭环证据：140D63620 AgentPvPSpectator 更新在 140D636A6 将全局 142AF22D0 传 140C2DBF0，后者 ASM 仅返回 self+38h；复制同八 DWORD 及有效位信息。140D63707 把各有效槽 ID 置 EDX，140D6370A 调用 CharacterManager.LookupBattleCharaByEntityId，查到后取名称写 StringArray106 并缓存 EntityId，实际显示人数写 NumberArray119[0]。查不到本地角色的有效槽不显示，因此有效槽计数不一定等于已显示姓名数。详见 SpectatorListEntityIds.md。p4..p8 及独立 target 未读；正常八槽但入口不钳范围。

依据：`0x140C2B440`、`FFCS InstanceContent._spectatorIds+38h`、`0x140C2B3A0 ProcessSpectatorListPacket same8DWORD+bitmap/popcount`、`0x140B43944 boolean normalized p3`、`0x141787FE0 clears list on spectator destruction`、`0x140C2B4A0 clear8slots and validbits/count`、[SpectatorListEntityIds.md](../SpectatorListEntityIds.md)、`140D63620 C/ASM exact InstanceContent+38 table ->LookupBattleCharaByEntityId ->names StringArray106/count NumberArray119`、`140C2DBF0 ASM lea rax,[rcx+38h]`。
