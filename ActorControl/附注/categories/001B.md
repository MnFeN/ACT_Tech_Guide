# 27 / 0x1B SetMovementSpeedMultiplier

[分类参数](../../README.md#category-001b) · [附注索引](../README.md)

设置移动速度倍率

- 分支地址：`0x140b3afbc`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：全局覆盖、速度消费者与倍率单位已核对。
- 用途：设置移动速度倍率的全局整数覆盖值。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位整数倍率覆盖值；0 取消覆盖、使用正常状态计算；非零按 100*p1 计算百分比后除 100 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：1408D6110 先根据 StatusManager 算移动倍率、处理施法等修正，再以全局 p1 非零覆盖百分数。141829540 将返回倍率乘基础移动速度。正常小正整数 p1=1 即 1 倍，2 即 2 倍；不是百分比 2%，也不是布尔“逃跑”。实现为 32 位 imul 与有符号非负钳制，异常大值不能按无限精度整数外推；返回前 max(0,int32(100*p1))/100。无 StatusManager 时提前返回 1，不经过覆盖。p2..p8 未读。

依据：`0x140B3AFBC`、`0x1408D6110 ASM 1408D61C5..1408D61E3 imul100 / signed clamp / float divide100`、`0x141829540 movement speed * 1408D6110`、`0x1408A7D70 status-derived movement percent`。
