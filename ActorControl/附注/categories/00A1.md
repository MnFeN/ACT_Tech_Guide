# 161 / 0xA1 SetBGM

[分类参数](../../README.md#category-00a1) · [附注索引](../README.md)

设置/恢复区域 BGM

- 分支地址：`0x140b42dea`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置/恢复区域 BGM。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零交 BGM 切换方法；0 调用另一恢复/清理入口 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：过渡时间/优先级是否内置需继续追音频函数；本分支不读 a2–a4。

依据：`0x14085BB70`、`0x14085BC00`。
