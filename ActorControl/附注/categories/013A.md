# 314 / 0x13A ActivateType4GatheringPoint

[分类参数](../../README.md#category-013a) · [附注索引](../README.md)

启用特殊采集点

- 分支地址：`0x140b3fa19`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Type4 门控消费者与次数恢复已核对。
- 用途：激活 Type4 采集点的可见/可用状态并恢复剩余次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：Flags+310 设 bit1，RemainingCount=Count。140E8B830 对 Type4 明确要求该位，否则不可见/不可用；其他共同条件仍检查探知状态与等级。p2..p8 未读。当前资源 Type4 共 90 行（如 31436/31440），与 GatheringType 职业值不是一回事。

依据：`0x140E8B0B0`、`0x140E8B830 Type4 requires Flagsbit1`、`resources-gatheringpoint-all.json Type4 90 rows`。
