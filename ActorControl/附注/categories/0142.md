# 322 / 0x142 FishingTotalFishCaught

[分类参数](../../README.md#category-0142) · [附注索引](../README.md)

同步普通钓鱼成功次数累计值

- 分支地址：`0x140b3fda3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：PlayerState 字段、普通/刺鱼独立计数与原始消息标签已核对。
- 用途：同步普通钓鱼成功次数累计值。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 绝对累计钓鱼成功次数，写 PlayerState.NumFishCaught；不是增量或已发现鱼种数 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：PlayerState 基址 142ADF3B8，字段+4E0=142ADF898。FishRecord 界面 140F77ED0/781B0 将此值与刺鱼专用 142ADF8D0 按模式二选一，交 Addon3822：模式 0 显示“钓鱼成功次数”，模式非 0 显示“刺鱼获得鱼数”。故本类不含刺鱼数，也不是图鉴解锁 bitset 的种类统计；140F775C0 检测计数变化后安排 UI 刷新。p2..p8 未读。

依据：`0x140B3FDA3`、`FFCS PlayerState.NumFishCaught+4E0 vsNumSpearfishCaught+518`、`0x140F77ED0/781B0 Addon3822 withcount/mode`、`0x140F775C0 UI refresh whenabsolutecountchanges`、`resources-fishing-record-labels.json Addon3822 SeString branches`。
