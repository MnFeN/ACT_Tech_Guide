# 934 / 0x3A6 SetReplayLevel

[分类参数](../../README.md#category-03a6) · [附注索引](../README.md)

回放等级资料

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：408 次；包族 {"ActorControlSelf": 408}。

## 参数与行为

- 核对状态：Self 回放通用分发顺序、Level 字段与样本已核对。
- 用途：设置回放等级元数据。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位等级，写 ContentsReplayManager.Level |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：回放记录类型 A9 为 ActorControlSelf：14084CB92 先调用 HandleActorControl(...,isRecorded=1)，返回后按 payload.category 追加处理；03A6 于 14084CBBD 读 payload+4 low16，14084CBC1 写 ContentsReplayManager.Level+740h，再 return1。此前“不调用 HandleActorControl”说明已撤回。408 份回放各 1 条 Self；普通包与实况 Self 不据此等同此回放 Level 补写路径。详见 ReplayActorControlOuterPaths.md。

依据：`0x14084C9D0 ActorControlSelf类别0x3A6`、`Client.Game.ContentsReplayManager.Level`、[ReplayActorControlOuterPaths.md](../ReplayActorControlOuterPaths.md)：03A6 前后顺序纠正、`14084CB92 callHandleActorControl BEFORE14084CBC1 Levelstore`、`client/replay-outer-catalog.json actual recordtypeA9 ctree branch`。
