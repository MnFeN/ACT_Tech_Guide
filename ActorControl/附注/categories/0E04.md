# 3588 / 0xE04 SetProbeExtraEffects

[分类参数](../../README.md#category-0e04) · [附注索引](../README.md)

野外探查器附加效果

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：野外探查器三槽双层附加布局特效及开关边界已核对。
- 用途：启用或停用野外探查器的三槽附加布局特效。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint WKSMechaEventData 行号，外层匹配当前事件 |
| p2 | 完整 uint 只按非 0/0：覆盖第一组三槽控制器+BA 启用标志；已加入机甲活动时对资源类型 7 对象请求启用/停用附加效果 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：外层事件匹配与 Flags&3==3 仍适用，p5..p8 及 target 未读。141C54220 先无条件缓存 p2!=0 到 scene+193A（第一组控制器+BA），再检查模块 Flags80 已加入；未加入时不遍历对象，但已缓存的启用值仍有效。已加入时遍历 WKSMechaEventObject.Type7 对象：p2 非 0 调用 141C5B170(slotKind0)，若控制器+B9 已置再请求 slotKind1；p2 为 0 对两层调用 141C5B270。不是设置对象本体的轮廓色，也不直接切换其本体时间轴。141C5B170 在已有同 EntityId 槽或第一个 E0000000 空槽记录，最多 3 槽；已有附加布局请求开启，无句柄则置待创建，Update141C5A880 按真实第一组虚表 142458D28 读取 WKSMechaFieldSearcher。资源索引来自对象资源+0C；22 行中 4..21 均为 ExportedSG39981/40638，0..3 为 0。真实布局包含 b3441area1_j1.avfx 与 b3445pill1_j1.avfx（后者还有循环音效），当前未直接渲染观测颜色/几何。关闭只请求附加布局停用，不移除三槽 EntityId、不立即释放所有句柄，不清+B9，也不阻止 0E02 仍对槽内对象发 PlayTimeline。首次打开时已有句柄与待创建路径有各自生命周期门控。普通资源类型 7 本机构建 18 行、BaseId2014717 名称野外探查器。第二组虚表 142458D50 才读 WKSMechaTank，不混用。详见 MechaFieldSearcherEffectToggle.md。
