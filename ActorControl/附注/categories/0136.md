# 310 / 0x136 ActivateGatheringPoint

[分类参数](../../README.md#category-0136) · [附注索引](../README.md)

启用限时采集点

- 分支地址：`0x140b3f9aa`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：生成包选择键、启用标志与最终显隐/可选中消费者已核对。
- 用途：启用 Type2/5 采集点，并选择与对象生成键相符的采集点对象。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 低 8 位对象选择键；写 handler+304，与对象生成包 payload+2E 的 byte 完全相等时通过该项检查 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140E8AFF0 无条件置 Flags+310 bit0 并写+304=low8(p2)；真正使用该位/键的 140E8B830 分支限定 Type2/5。141757D50 从 GatheringPointObject.Impl+10 读取完整查询 DWORD，调用 handler 虚 278 作可用性检查，结果再控制对象 IsTargetable 和显示/隐藏路径。该 DWORD 由 140B49140 ObjectSpawn Kind6 传 payload+2C，经 141759180 写 Impl+10，所以 BYTE2(query)就是 payload+2E，属于对象实例携带的选择键，不能命名为时间戳/天气/时段枚举。Setup140E8B610 另外从 Impl+16 即 payload+32 给 handler+304 赋初值，从 payload+30/+31 设置活动 bit，收包随后可更新选择。p3..p8/target 未用。通用资格、状态、等级、次数仍按各自路径检查，不保证仅收本包就立即可见。详见 GatheringSpawnSelectorControls.md。
