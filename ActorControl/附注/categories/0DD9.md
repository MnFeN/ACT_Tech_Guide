## 参数与行为

- 核对状态：已核对。
- 用途：清理结束的宇宙任务，并在尚未观察到完成记录时显示功能解锁提示。

| 参数 | 读取与语义 |

| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：保存旧评级后清 CurrentMission 与任务显示缓存。旧评级!=5 且 JobStateModule+8 为 0 时，显示 Log10932..10937，分别为机甲行动、探索成果、探索轨迹的解锁提示与说明。+8 不是泛加载位：ctor141A6E960 清 0；整份完成位图接收 141A6EA60/141A70040、单字节更新 141A6F260 case0E2F/141A700F0 及扫描 141A703D0 发现 manager+ED1h 的 213-byte 任务完成位图任意 byte 非零，就将此位单向设 1，普通后续全零覆盖不回清。因此它表示本模块生命周期已观察到任意完成记录，不能当成严格同步的每次当前任务完成状态。最后 140148AD0 与 0DDA 的 140148A10 动作相同，均关闭任务信息/配方本、重置任务物品 UI 并按固定类型 1 刷新地图。本类只提示功能解锁，不在此设置 UnlockLink。所有控制参数未读。

依据：`0x141A709C0`、`0x140148AD0 compared with 0x140148A10 equivalent UI effects`、`resources-wks-mission-completion-messages.json Log10932..10937 exact feature notifications`、[WksMissionWindowAndCompletionControls.md](../WksMissionWindowAndCompletionControls.md)、`0x141A6E960 initialize latch0`、`0x141A6EA60/0x141A70040 bitmap receive -> anyCompletion latch`、`0x141A6F260 case0E2F /0x141A700F0 byteupdate -> anyCompletion latch`、`0x141A703D0 scan helper`、`client/wks-jobstate-completion-latch.json`。
