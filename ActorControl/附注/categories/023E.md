# 574 / 0x23E SetRetainerDialogueFlags

[分类参数](../../README.md#category-023e) · [附注索引](../README.md)

雇员对话与转职提示

- 分支地址：`0x140b3bf5b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：包宽度、当前记录选择、原生 Lua 名称及实际消费者已核对。
- 用途：覆盖当前雇员的探险对话／推荐转职标志（RetainerFlags）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位完整覆盖当前 Retainer+0x40 bitmask |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：14110D510 按 RetainerManager.LastSelectedRetainerId 匹配 10 个 0x48 字节记录，无选中或无匹配则忽略。141C9AA10 明确 IsRetainerFlagOn→141C9D260，对 Lua 第二参数低 byte 与 ActiveRetainer+40 按位 AND。注册常量 bit1=VENTURE_ACCOMPLISH_TALK（探险完成对话标志），bit2=RECOMMEND_JOB_CHANGE（推荐转职标志）；其他 6 位未注册语义，原样保存。UpdateRetainerFlagOn 使用 ServerRequestCallback9，callback9 亦写同字段。名称来自当前 EXE 注册字符串，不借用相邻 VentureId 字段。

依据：`0x14110D510`、`0x141C9AA10 nativeLua registration and flag constants`、`client/retainer-active-consumers.json`、`0x141C9D600 callback8/9`、`0x141C9D260 byteflag maskquery`、`0x141C9B870 UpdateRetainerFlagOn`。
