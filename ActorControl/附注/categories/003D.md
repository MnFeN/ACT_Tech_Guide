# 61 / 0x3D SetMovementRestriction

[分类参数](../../README.md#category-003d) · [附注索引](../README.md)

特殊移动许可限制

- 分支地址：`0x140b3af2a`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：双门控、uint32 转 float、跳跃可用性及实际请求消费者已核对。
- 用途：设置包括跳跃在内的 Permission98/别名阻断门控。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 0 同时清 byte 门控与 float 门控；非 0 按 p2 更新其中一个，另一个保留 |
| p2 | p1 非 0 时：p2=0 设置 byte 门控 1；p2 非 0 按 uint32 数值转 float 写第二门控；两种值均造成阻断 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：140E13870 HasPermission 对 98 及别名 1001/1007 在检查 Conditions 之前读取两个字段，byte1428C25FC 非 0 或 float1428C2600 非 0.0 直接 false。收包 p1 非 0 只更新其中一字段，不同时重置另一字段；p1=0 才全部解除。汇编 140B3AF43 先 MOV EAX,p2（零扩展至 RAX），140B3AF4E CVTSI2SS XMM0,RAX，因此是无符号 uint32 数值转换；原伪码(float)(int)p2 在高位为 1 时不准确。已找到的 float 消费者只检查非零，未发现倒计时递减、单位换算或数值大小比较，不能命名为秒数/时长。140C44F20/140C50780 初始化 UI/Condition 流程也设 byte1,float0。已继续核对 ActionManager 通用动作：1408E1860 的 GeneralAction2 请求调用 141836580，GetActionStatus 对 ActionType5/GeneralAction2 调用 1418366C0；两者均检查 HasPermission1001→资源 98。GeneralAction2 本机名称为“跳跃”，故明确至少阻断跳跃请求及其可用性；其他 Action 的 1007 别名仍按各自条件使用，不能称全部操作禁止。p3..p8 未读。

依据：`0x003D`、`0x140E13870 HasPermission ids98/1001/1007 directfalsegate`、`0x140B3AF43 MOV EAX then0x140B3AF4E CVTSI2SS XMM0,RAX unsigned32conversion`、`0x140C44F20/0x140C50780 initializebyte1,float0`、`client/permission98-call-candidates.json callers areleads,not confirmedbusinessnames`、`0x1408E1860 GeneralAction2→141836580 jump request`、`ActionManager.GetActionStatus ActionType5/GeneralAction2→1418366C0`、`resources-jump-gate.json GeneralAction2跳跃`。
