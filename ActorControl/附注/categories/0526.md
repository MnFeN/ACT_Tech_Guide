萌宠地面预兆

- 分支地址：`0x140b3909c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：槽、坐标、Omen 资源及尺寸已核对。
- 用途：萌宠之王持久地面预兆效果的创建或移除。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 效果槽索引，入口未检查边界 |
| p2 | 非零 Omen 行号创建；0 移除该槽旧效果 |
| p3 | uint32/100-2000 得到 X 米 |
| p4 | uint32/100-2000 得到 Z 米 |

额外参数：Self p5 按 uint32 转 float，作为三轴初始尺寸；p6 未读。

说明：Y 固定 0，句柄存 Director+1816+8*slot，绑定 Director 回调。Omen 路径 vfx/omen/eff/%s.avfx；Y 尺度还经过 max(4*p5,p5)、资源 flag 及上限处理，不是直接把原值写三轴。 本轮汇编复核：32 位 mov 写 EAX/ECX 后零扩展至 RAX/RCX，再 cvtsi2ss 以 64 位寄存器转 float，按 uint32 取数；已纠正旧伪码 signed 传播。见 FloatConversionAudit.md。

依据：`0x140E829D0 / GoldSaucerDirector类型0x800A且内容7 / 0x140E7A020`、`0x140B393FB..443`、`client/main-float-conversion-instructions.json`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
