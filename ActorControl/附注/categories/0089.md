# 137 / 0x89 SetProvisionJobLevels

[分类参数](../../README.md#category-0089) · [附注索引](../README.md)

军队筹备职业等级

- 分支地址：`0x140b41f11`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：11 职业等级打包、消费与筹备列表刷新已核对。
- 用途：同步军队筹备候选条目的 11 职业等级并刷新列表。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 四个等级字节，按从高到低分别对应 ClassJob8/9/10/11（刻木/锻铁/铸甲/雕金） |
| p2 | 四个等级字节，按从高到低对应 ClassJob12/13/14/15（制革/裁衣/炼金/烹调） |
| p3 | 从高到低三字节对应 ClassJob16/17/18（采矿/园艺/捕鱼）；最低字节保存但当前 11 职业循环未使用 |
| p4 | 此分支未读取 |

说明：140C1EBB0 按职业索引 i 提取 uint8(words[i>>2]>>(8*(3-(i&3))))，故 wire 按小端解码 DWORD 后再从最高字节开始，不能直接把内存字节顺序当职业顺序。等级非零上限 100；等级 0 会依该职业本机是否有等级回退为 0 或 1；候选任务行按等级相对偏移生成。0x89 写三 DWORD 后 140C1EA80 启动 GCSupply 刷新，0x81 种子随后选择候选。p4 与 Self p5..p8 未读。

依据：`0x0089`、`0x140C1EA80`、`0x140C1EBB0 v12=uint8(dword_142ADF6A8[i>>2]>>(8*(3-(i&3))))`、`0x140C1EBB0 ClassJob8+i / clamp level100 / candidate offset`、`0x140C1EA80 GrandCompany rank gate and GCSupply initialization`、`resources-gcsupply.json`。
