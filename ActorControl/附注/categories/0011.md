# 17 / 0x11 Cooldown

[分类参数](../../README.md#category-0011) · [附注索引](../README.md)

更新冷却总时长

- 分支地址：`0x140b3a184`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：汇编与被调函数已核对。
- 用途：更新匹配动作的冷却总时长。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 冷却组索引，不是固定 1 的未明字段 |
| p2 | ActionId，用来检查该组记录的动作；记录为 0 或等于 p2 才更新 |
| p3 | 冷却总时长/100 秒，即网络值单位 0.01 秒 |
| p4 | 未读取 |

说明：当前函数只改 Total，不直接写 Elapsed。

依据：`0x140B3A161–0x140B3A184`、`0x1408EE240`。
