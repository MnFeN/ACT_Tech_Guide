# 947 / 0x3B3 ShowCustomScreenLog

[分类参数](../../README.md#category-03b3) · [附注索引](../README.md)

自定义正文与数值飘字

- 分支地址：`0x140b44c8f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Addon 正文、int32 数值、最终组件与 GP 标签取值已核对。
- 用途：为本机显示 Addon 自定义正文、主数值及 GP 标签的 26 类飘字。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位数值放 ScreenLogEntry.Value1（+0C），最终写飘字 NumberArray 相应主数值槽 |
| p2 | Addon.RowId，放 Entry.ActionId（+08）；固定 ActionKind22 使消费者按 Addon 表取正文 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：Entry.kind 固定 26，DWORD+4=16000000h 拆为 SourceRelation0/TargetRelation0/Option0/ActionKind22。Character 基类 GetScreenLogManager 虚 83 返回 null；实际玩家 BattleChara 虚表 1421A48D8 的 83=140AFDDF0 返回 self+2370h 队列，避免误认基类空实现。140CD2F70 取队头 1409AF530 并向 140CD3900 派发；关系 0/0 走后者，type26 进入共享 LABEL15，经 140CD2AC0 处理 ActionKind22，明确 GetAddonText(p2)，图标保持-1。取 Value1=p1、Value2=0、Option0，写 NumberArray 主数值与 StringArray 正文。不是 Action 表技能 ID，不将 p2 套用 ActionType22；这里是 ScreenLog 消费者的内部类型约定。type26 最终组件现已核对，见后；包 p3..p8 及 target 未读。 最终 Addon 证据：1414A0D80 把 kind26 映射根节点 25，当前 FlyText.uld 根 25 对应 component1023。1414A1220 把该组件文本节点 3/4/5/6 分别绑 record+40/+16/+24/+32；CreateFlyText1414A0330 把 GetAddonText(p2)送节点 3，把 p1 的 int32 原样 SetNumber 到节点 4，第二正文节点 5 收到空字符串，节点 6 则经 14149E950 取 StringArray[2].StringArray[3]。固定 FFCS 将数组 2 声明 Hud、槽 3 声明 GpIndicator；因此是 GP 标签样式的自定义正文/数字飘字，不是完全任意格式，亦非 Action 表技能 ID。本机 ULD 节点 6 原始 TextId725“技力”会被上述动态 HUD 标签覆盖，不把旧模板静态文字当最终单位。该路径只显示，不直接加 GP 或经验值。具体本地化标签文本随 HUD 数组，不依未证的 Addon 同号常量硬绑定。

依据：`0x140B44C8F / FFCS ScreenLog.AddScreenLogEntry`、`client/battlechara-screenlog-vtable.json current1421A48D8`、`0x140AFDDF0 self+2370 queue`、`0x140CD2F70 queuefront→140CD3900`、`0x140CD3900 type26 LABEL15 numbersandstringarrays`、`0x140CD2AC0 ActionKind22→GetAddonText(p2)`、`0x1414A0D80 kind26→root25;ULD component1023`、`0x1414A1220 root25 node3text/node4number/node6suffix`、`0x1414A0330 node3=Addontext;node4=SetNumber int32;node6=dynamicHUDlabel`、`0x14149E950 kind26→StringArray2 index3`、`FFCS AtkArrayData.StringArrayType Hud=2;HudStringArray.GpIndicator=3`、`client/custom-addon-gp-flytext-uld-selected.json`、[CustomAddonGpFlytextTemplate.md](../CustomAddonGpFlytextTemplate.md)。
