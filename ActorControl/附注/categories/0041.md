元素等级或知见等级提升

- 分支地址：`0x140b3f452`。
- 回放观察：119 次；包族 {"ActorControl": 119}。

## 参数与行为

- 核对状态：等级提升通知、日志资源与参数消费已核对；旧等级仅样本推定。
- 用途：副本特殊等级提升通知：优雷卡元素等级或新月岛知见等级。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 提升后的等级，传给 Log9053（元素）或 10955（知见） |
| p2 | 作为第二个数值转交日志；本批 119 条均=p1-1，推定旧等级；当前两套模板不引用它 |
| p3 | 主分支及已定位实际处理器未读取 |
| p4 | 主分支及已定位实际处理器未读取 |
