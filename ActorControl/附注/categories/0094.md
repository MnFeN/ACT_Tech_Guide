# 148 / 0x94 PlayObjectVfx

[分类参数](../../README.md#category-0094) · [附注索引](../README.md)

对象间特效

- 分支地址：`0x140b42c4f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与字段已核对。
- 用途：按打包对象类型解析两个 GameObjectId 并播放 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 源 ID 低 32 位 |
| p2 | 目标 ID 低 32 位 |
| p3 | 低字节源类型、次低字节目标类型；类型==3 时在对应 ID 上加 bit32 |
| p4 | VFX ID |

说明：低 32 位 0xE0000000 且未加类型高位时为空；p1==p2 时复用源对象（不再按目标类型查一次）。

依据：`0x0094`、`ObjectArrays.GetObjectByGameObjectId`、`0x140857450`。
