# 539 / 0x21B LockTitle

[分类参数](../../README.md#category-021b) · [附注索引](../README.md)

移除称号解锁

- 分支地址：`0x140b3f305`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：清除称号解锁标志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位称号索引；894 表示清全部 0..893，其他<894 只清一个 bit |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：与 0x1F5 解锁相反。894 是当前本机边界，不泛化为永久固定枚举上限。

依据：`0x140C0E640 / 0x140C0E670`。
