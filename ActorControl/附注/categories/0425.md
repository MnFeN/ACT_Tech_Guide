# 1061 / 0x425 InteriorSizeUnlockResponse

[分类参数](../../README.md#category-0425) · [附注索引](../README.md)

装修规格权限购买应答

- 分支地址：`0x140b3e2ec`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：住宅装修规格权限购买申请应答：刷新小/中/大规格解锁 mask 或结束界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位非零：刷新规格解锁 mask 并重建列表；零：关闭主窗口。不是仅值 1 为成功 |
| p2 | 仅 p1 非零时使用 low8，bit0 小/bit1 中/bit2 大规格解锁；bits3..7 不影响 mask，高 24 位未读。基础规格 p3 旧缓存也无条件加入 mask |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：与 0423 的 Self p5 使用完全相同 141735B80/140E25370，已由 HousingRenovation/HousingIndoorTerritory 资源及购买流程证实是规格权限而非楼层。141735110 无条件清 Agent+A31h 等待标志并关闭+A20h 附属窗口；p1 零再关闭 Agent+20h 主窗口，非零用 p2 更新+A28h 可用 mask，141735C20(agent,-1)重建当前规格风格和已购买提示，列表选择值不指向具体风格。发起 141735900/141734B60 购买确认经 140E21290 发 1170(target,size)，不可把本包当更换风格本身的成功回执，后者 1169/0424 有独立路径。无回放样本。

依据：`0x140B3E2EC p1 full32 nonzero`、`0x140E21320 replywrapper`、`0x141735110 clearwait/closepopup/refreshmask`、`0x141735B80 originalsize ORlow3bits`、`0x140E25370 sizebit tester`、`0x141735C20 refresh(-1)`、`0x140E21290 command1170`、[HousingRenovationSizesAndUnlocks.md](../HousingRenovationSizesAndUnlocks.md)、`resources-housing-renovation-all-raw.json`。
