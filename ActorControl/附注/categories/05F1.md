# 1521 / 0x5F1 DeathWithAction

[分类参数](../../README.md#category-05f1) · [附注索引](../README.md)

带技能的死亡动作

- 分支地址：`0x140b39698`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：角色死亡状态与可选技能死亡动作。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 触发死亡表现的 Action 行号；0 走普通死亡动画 |
| p2 | 低 16 位压缩朝向，转-π..π供技能表现路径 |
| p3 | 死亡 ActionTimeline；0 自动选择，FFFF 及 4057 有特殊处理 |
| p4 | 此路径未读取 |

说明：清 HP、MP、采集/制作点、护盾、施法等状态；本机还处理自动攻击/界面。p3 作为 timeline，p2 仅 p1 非 0 并通过本机路由条件时用于朝向。更具体死亡分类仍需 Action 资源核对。

依据：`0x14090A420 / case0x5F1`。
