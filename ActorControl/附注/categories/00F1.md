# 241 / 0xF1 WarpWithAnimation

[分类参数](../../README.md#category-00f1) · [附注索引](../README.md)

带 ActionTimeline 的强制传送

- 分支地址：`0x140b447ff`。
- 回放观察：1035 次；包族 {"ActorControl": 1035}。

## 参数与行为

- 核对状态：汇编、函数与回放核对。
- 用途：带 ActionTimeline 的强制传送。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 高 16 位原生 X，低 16 位原生 Y 高度 |
| p2 | 高 16 位原生 Z，低 16 位压缩面向 |
| p3 | 低 16 位 ActionTimeline；bit16、bit17 分别设置移动状态标志 |
| p4 | 移动确认序号；状态受限时通过命令 611 确认 |

说明：启动移动状态 9，保存起点与终点。bit17 使一条播放分支跳过直接播放时间轴。

依据：`0x14181F830`。
