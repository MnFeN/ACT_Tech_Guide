# 3207 / 0xC87 IslandExpeditionEditResponse

[分类参数](../../README.md#category-0c87) · [附注索引](../README.md)

无人岛探索委托编辑应答

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：关闭或重建无人岛探索队委托编辑子窗口。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：141A5E1D0->141C5EE60->140A13080。若 Agent+1F8h 已有编辑子 AddonId，调用 1404836F0 关闭并立即返回；否则仅在 Agent 激活时读取当前探索队槽的目的地与天数。现有委托有天数则复制到编辑选择；没有则默认 1 天、选首个当前已解锁素材/功能允许的目的地；随后以更新掩码 29（1|4|8|16）调用 140A15C50，构造 90 项 AtkValue，刷新或 OpenAddon837（345h）子窗口，包含可选目的地、素材、持币及费用。29 不是服务器操作码，所有控制参数未读。这里按实际编辑状态分支定义，不在没有请求配对样本时给它强加唯一服务器请求名称。

依据：`0x141C5EE60 ->0x140A13080 close existing or rebuild selection`、`0x140A15C50 mask29 ->90 AtkValues and Addon837`、`FFCS AgentId.MJIGatheringHouse425`、[MjiExpeditionResponseControls.md](../MjiExpeditionResponseControls.md)。
