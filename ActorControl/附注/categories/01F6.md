# 502 / 0x1F6 SetTargetSign

[分类参数](../../README.md#category-01f6) · [附注索引](../README.md)

设置目标标记并可显示标记操作者日志

- 分支地址：`0x140b3f1ba`。
- 回放观察：2863 次；包族 {"ActorControlTarget": 2863}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置目标标记并可显示标记操作者日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 标记槽序号，写 MarkingController.Markers[p1] |
| p2 | 操作者 EntityId；0xE0000000 时跳过日志 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

额外参数：独立 targetId 为 GameObjectId；0xE0000000 表示移除标记。

说明：先从 17 个槽移除相同目标，再写所选槽。p2 用于查操作者并显示 LogMessage1291；目标来自独立 64 位 targetId，不能用 p2 替代。薄包装初始伪码漏掉全部参数，已以寄存器及实际 callee 核对。

依据：`0x140B3F1BA`、`0x140C0CAE0`、`0x140C0D6D0`、`Client.Game.UI.MarkingController`。
