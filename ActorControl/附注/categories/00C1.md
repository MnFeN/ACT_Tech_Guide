# 193 / 0xC1 SetQuestRedoContentAllowance

[分类参数](../../README.md#category-00c1) · [附注索引](../README.md)

新游戏加副本准入列表

- 分支地址：`0x140b442ee`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：CFC 表身份、关联重玩任务、批量分段协议及入口可用性消费者已核对。
- 用途：同步 New Game+ 当前任务下允许进入的 ContentFinderCondition 白名单。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 0 重建白名单并设置关联任务；非零追加 ContentFinderCondition 行号 |
| p2 | p1=0 时：关联 Quest 短编号→manager+80；p1 非零时：首个追加的 ContentFinderCondition 行号（低 16 位，含 0 也追加） |
| p3 | p1=0 时：低 16 位 reserve 容量；p1 非零时：非零才追加为下一 CFC 行号 |
| p4 | 低 16 位非零时追加 CFC 行号，两种模式均执行此项；0 不追加且跳过 p5/p6 |

额外参数：Self p5：仅 p4 非零且自身非零时追加 CFC；p6：仅 p4/p5/p6 均非零时追加 CFC；p7/p8 未读

说明：manager+68 是 ushort 向量，+80 为关联的已接受重玩 Quest 短编号。140EB2EC0 在 NG+ 激活且内容已解锁未通关时，要求当前 QuestRedo 中首个已接受任务等于+80，且目标 CFC 出现在向量中；已通关或非相应重玩条件则不施此限制。目标 ID 由 140C28710 从 ContentFinderConditionInterface+8 取得，FFCS 明确该字段是 CFC RowId；不能将向量误称任务列表或 InstanceContent 编号。141CADF40 也将匹配内容的 CFC 传入同一条件函数。初始化先清逻辑 end、可扩容量，p4..p6 尾部追加仍会执行；不是 p1=0 时其他字段全部忽略。

依据：`0x140EB27F0`、`0x140EB2EC0 current acceptedQuest vsmanager+80 /vector+68 contains target`、`0x140C28710 ASM target=word[ContentFinderConditionInterface+8],virtual14 unlocked /16 completed`、`FFCS ContentFinderConditionInterface.ContentFinderConditionRowId+8 /ContentInterface virtual14/16`、`0x141CADF40 content CFC+70 vs InstanceContent+72`、`0x140EB27F0 init reserve / nested trailing appends`。
