# 942 / 0x3AE UnlockPortraitDecoration

[分类参数](../../README.md#category-03ae) · [附注索引](../README.md)

解锁肖像装饰

- 分支地址：`0x140b44cf4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：解锁索引范围、置清及独立 Item 名称提示已核对。
- 用途：设置肖像装饰套件解锁并可显示提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 肖像装饰套件解锁编号/bit 索引，只有 0..351 更新；没有 FramersKit 同名 EXD 表，不能简单称行号 |
| p2 | 非零设解锁，0 清 |
| p3 | Item.RowId，用于 LogMessage5854 内 Item 表取名；非零即提示，不以 p2 为条件 |
| p4 | 此路径未读取 |

说明：140BE51C0 仅 p1<352 时按 UnlockedFramersKits+890h 置/清 bit，p2 非零置位、0 清位。其后 p3 非零时独立显示 5854：本机原始宏 Sheet("Item",lnum1,column0)直接证明参数是物品 ID，正文为“可以使用‘该物品’记载的设计样式了”。即使 p1 越界或 p2=0，通知也仍可发，不能称只有成功解锁才提示。p4..p8 未读；p1 的解锁编号与 p3 的 ItemID 属于独立编号空间。

依据：`0x140BE51C0 / FFCS PlayerState.cs`、`resources-framers-kit-notice.json Log5854 rawSheetItemlnum1`、`0x140BE51C0 p1<160h`、`sheet-map.json noFramersKit sheet`。
