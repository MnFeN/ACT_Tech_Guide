- 分支地址：`0x140b41fa0`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：行会令编号、基础职业位及首次奖励消费者已核对。
- 用途：同步行会令某基础职业的首次完成奖励标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 行会令索引 1..14，对应 InstanceContent10001..10014（索引=行号-10000） |
| p2 | ClassJob 行号，经 ClassJobParent 还原基础职业，再用 BattleClassIndex(0..13)索引该职业位 |
| p3 | 恰等于 1 置位，其他值清位 |
| p4 | 此分支未读取 |

说明：14 组×2 字节，PlayerState+0x547 起始。1419B5D50 按本机基础职业查询位；140C20FB0 用 1419AA0F0 将 InstanceContent10001..10014 转换 1..14，查询结果交 1419AA110 选择奖励。bit 未置时取首次奖励与通常奖励差值，置位后只取通常奖励；不只是普通技能解锁。越界组或无效 BattleClassIndex 不写。p3 恰 1 置位否则清位；p4..p8 未读。
