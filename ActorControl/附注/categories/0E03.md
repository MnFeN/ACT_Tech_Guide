机甲对象布局与束缚

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：EntityId 键、精确开关与束缚布局资源已核对。
- 用途：按 EntityId 切换对象布局状态，并维护束缚状态集合。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint WKSMechaEventData 行号；外层匹配当前事件 |
| p2 | 完整 uint 对象 EntityId；不是 LayoutId、EObj 或 ReactionEventObject 行号 |
| p3 | 完整 uint 恰等于 1：请求布局 Timeline5 并插入集合；其他值：请求 Timeline6 并移除集合 |
| p4 | 未读取 |

说明：外层 141A6ACC0 要求 p1 完整 uint 与当前 WKSMechaEventData.RowId 匹配、Flags 低 2 位均置位，且模块存在；转交 event+70 场景控制器。7 个当前阶段对象虚 9 均 return0，不另消费本包参数。p5..p8 及 target 未读。 141C590D0 从 scene+40 的 EntityId→record map 查对象；同一 map 的注册 141C555D0 与移除 141C540E0 都读 GameObject+78，record 构造 141C5C830 也写 EntityId 到+10，因而 p2 身份有双向独立证据。p3==1 集合位 scene+1A88 插入 p2，其他值移除；即使当前查不到对象也会变集合（含 0 键），不验证 ID 有效性、不按播放成败决定集合更新。有对象且 record 有效时请求 SharedGroup Timeline5/6；true 分支额外判 SharedGroup 非空，false 分支未在本层额外判空。资源 EObj2015370“攻击性花粉植物”→ExportedSG43947→w4_me_t003.sgb，本机 SGB handler 索引 5/6 实际映射 subId7 on_to_bind /8 bind_to_on，故束缚表现不是凭编号猜测；索引 4 为 subId6 bind，141C555D0 重绑定该 EObj 时若集合含 EntityId 则播放 4 恢复束缚表现，销毁 141C540E0 将该 ID 移出集合。没有直接附加战斗 Status。该函数返回 1 表示分支已处理，不保证对象或布局存在。MechaSelectedTimelineAndBindSet.md 保留全部边界。
