# 3101 / 0xC1D PortraitSaveResponse

[分类参数](../../README.md#category-0c1d) · [附注索引](../README.md)

肖像保存应答

- 分支地址：`0x140b45817`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：处理冒险者铭牌肖像保存响应。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 结果码，0 成功，非 0 失败 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：成功且 TempBannerData.HasData 时复制 0x34byte 至 CurrentBannerData、置 Flagsbit0，随后清临时数据并通知 UIModule 助手；失败仅清临时数据并通知错误。

依据：`0x140C48BD0 / FFCS CharaCard.TempBannerData,CurrentBannerData`。
