# 221 / 0xDD StartPendingGimmickJump

[分类参数](../../README.md#category-00dd) · [附注索引](../README.md)

启动延后机关跳跃

- 分支地址：`0x140b42300`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：恢复启动函数完整 ASM，延后启动与 DC 配对关系已核对。
- 用途：触发已缓存且要求延后启动的 GimmickJump 机关跳跃。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此分支未读取 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：MoveController+257==3（机关跳跃已经启动）则返回；否则按+258 缓存的 GimmickJump 行查表，要求行+16 bit0 为 1，调用 141806F70(self+16)。此前“结束移动段”解释撤回：完整 ASM 在 1418072C7 调用 141805630(mode3)激活跳跃状态，随后在 14180741E 调用 141819E90 建立目标轨迹，XMM2 为角色当前朝向。配对的 0xDC/14181F250 保存 GimmickJumpId、终点、确认序号，bit0=0 时当场调用同一启动 helper，bit0=1 时留待 0xDD 触发。DD 本身 p1..p8 均不读取，目标、配置与确认序号来自先前缓存，不是 DD 参数。未找到 DD 回放样本。

依据：`0x14181F540`、`EXD__GimmickJump__Row_14083D100`、`client/141806F70_raw.asm (HexRays returned None)`、`0x1418072C7 mode3 activation /0x14180741E trajectory start`、`0x141805630 state transition`、`0x14181F250 GimmickJump flags bit0 selects immediate/deferred start`。
