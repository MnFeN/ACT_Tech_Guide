钓鱼图鉴推荐应答

- 分支地址：`0x140b3fff1`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：真实虚表、参数转发及最终 UI 文本已核对。
- 用途：回复普通钓鱼图鉴的推荐鱼饵与提钩方式。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FishingBaitParameter 行号；164 显示未知，165 显示以小钓大；其他行由表映射 Item 并加载鱼饵名 |
| p2 | 提钩方式：0 未知，1 强力提钩，2 精准提钩；其他值显示空文本 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：只有普通钓鱼 Data 且等回复标志+903 成立才写入；刺鱼 Data 对应虚槽 5 直接返回。p2 存 Data+808，最终界面按 Addon14391/3853/3854 显示。wrapper 和 Data 尾调用都转交真实参数，初始伪码漏参。
