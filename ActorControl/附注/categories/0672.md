# 1650 / 0x672 SetCustomDeliverySeed

[分类参数](../../README.md#category-0672) · [附注索引](../README.md)

老主顾每周物品种子

- 分支地址：`0x140b43a6b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：老主顾模块、SupplySeed 字段及需求物品选择消费者已核对。
- 用途：同步老主顾交易的每周需求物品随机种子。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位写 SatisfactionSupplyManager.SupplySeed(+0) |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140B1DD00 只写一个 byte，不改+1 BonusGuaranteeRowId。140B1EBA0 把 SupplySeed 与 CurrentSupplyRowId 分别乘常数后异或，产生伪随机序列，按 SatisfactionSupply 子行类别与权重选定三类需求项。故不是总标志、剩余交付数或 NPC 索引。p2..p8 未读。

依据：`0x140B1DD00`、`FFCS SatisfactionSupplyManager SupplySeed+0`、`0x140B1EBA0 PRNG initialization consumes*a1 andCurrentSupplyRowId,weighted selection categories1..3`。
