# 3635 / 0xE33 SetCosmicItemEvaluation

[分类参数](../../README.md#category-0e33) · [附注索引](../README.md)

宇宙任务物品评价

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：普通/优质及鱼尺寸评价点、收藏价值四边界与三档提示文本已核对。
- 用途：同步宇宙任务物品的普通/优质评价点，或收藏价值分档边界与评价点。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 int32 子类型，0 普通/鱼一般尺寸评价点，1 优质/鱼大尺寸评价点；2..5 分别写收藏价值边界 T0..T3 及关联点数 S0..S3。仅 0..5 有写入，其余不写 |
| p2 | 低 16 位 WKSItemInfo 行号，截断后 0 直接忽略；有效资源行的首 DWORD ItemId 才是记录 map 的键，不是直接用 WKSItemInfo 行号作键 |
| p3 | 完整 32 位评价点数；类型 0/1 为普通/优质（鱼为一般/大尺寸）点数；类型 2..5 分别为收藏价值三档所用 S0/S1/S2/S3，不是累计数量或已发奖励 |
| p4 | 仅类型 2..5 读取低 16 位，分别作为收藏价值分档边界 T0/T1/T2/T3；0/1 不读 |

说明：141A75530 以 WKSItemInfo 首 DWORD ItemId 建立 40-byte 记录。141A716D0 以 ItemDetail 物品编号%500000 查同一 map，唯一直接调用 1410404E0 构造宇宙任务物品说明。若 T0/S0/T1/T2/T3 均非 0，显示 Addon16909 收藏价值并生成[T0,T1-1]=S0、[T1,T2-1]=S1、[T2,T3]=S2（S3>0 时末档显示 S2～S3）点的三条 16910；否则若普通/优质任一点数非 0 则显示 17011 评价。类型 0 点数用指示参数 1，类型 1 用 0；17012 SeString 明确 lnum2>0 显示普通、否则优质；FishParameterReverse(sheet928)有行则 17013 对应一般尺寸/大尺寸。优质行另需物品 HQ 资格 byte 或鱼资源存在。固定 Lumina 表达式源码核对 E1 为 GreaterThan、E8 为 LocalNumber 及 03 解码 2，未只用 literalText 丢失的条件字符串猜测。收包只更新说明所用缓存，不改库存、不直接发点数或报酬；不校验边界升序。p2 非 0 但资源 ItemId=0 的占位行未被此入口额外拒绝，可形成键 0 记录。p5..8/target 不读；无回放样本。
