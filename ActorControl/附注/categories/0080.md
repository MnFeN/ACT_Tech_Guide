# 128 / 0x80 SetProvisionDelivered

[分类参数](../../README.md#category-0080) · [附注索引](../README.md)

军队筹备职业交付记录

- 分支地址：`0x140b41e8d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：更新军队筹备某职业条目的当日已交付屏蔽位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 位索引 0..31；当前 11 职业消费者使用 0..10，对应 ClassJob8..18 |
| p2 | 恰等于 1 置位，其他值清位 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：UIState+3364=+0xD24=PlayerState+0x2EC，与 0x81 保存四字节位图相同；0x80 是单点更新。byte 索引 p1>>3、mask=0x80>>(p1&7)，p2 恰为 1 置位，其余清除。140C1E5C0 仅当 bit 清零且 ItemId 非零时将对应筹备条目标为可用。不能将其泛称独立解锁位图。 独立界面链已补齐：141003260 把 GCSupply 条目+27 的可交付 bool 取反写 Agent 列表条目+155；141001CD0 将+155 非零条目从显示列表跳过，141000E50 同样跳过它们来解析界面选择。当前标签页有已学职业条目但无可显示条目时，141001CD0 使用 Addon4588“今天的份额已经筹备完毕。”；没有相应职业条目则用 4604“还没有学会相应职业，无法获得筹备任务的经验值。”。结合位图的反向条件，可将这些已存在职业条目的网络位命名为当日已交付/筹备完成屏蔽位。ItemId 为 0 也会隐藏，但这是另一个条件，不等同网络完成位。现有 408 回放无 0080/0081，属于静态收包、界面与本机资源交叉核实，未实际交付。

依据：`0x0080`、`0x142ADE980+0xD24=0x142ADF6A4=PlayerState+2EC`、`0x140C1E5C0 reverse-bit 11-class consumer; see0081`、`0x141003260 source+27 -> AgentItem+155 inverted`、`0x141001CD0 excludes155 and chooses Addon4588/4604`、`0x141000E50 selection excludes155`、`resources-gcsupply-completion-ui.json`、[GrandCompanySupplyCompletionBitmap.md](../GrandCompanySupplyCompletionBitmap.md)。
