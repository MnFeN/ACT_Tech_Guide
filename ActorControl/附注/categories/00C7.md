刷新任务事件与标记

- 分支地址：`0x140b443be`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与字段已核对。
- 用途：按任务 ID 更新任务事件与地图标识。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 Quest 行号，0 走全部刷新路径 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：当前全局任务对象存在时调用；固定第二选项 1、第三 0，按 Quest|0x10000 寻找事件处理器。

依据：`0x140B826E0`。
