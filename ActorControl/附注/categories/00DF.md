## 参数与行为

- 核对状态：坐标打包、资源表与状态链已核对。
- 用途：远端角色的 ActionTimeline 动作及配套 ActionTimelineMove 移动。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 高 16 位压缩 X，低 16 位压缩 Y 高度 |
| p2 | 高 16 位压缩 Z，低 16 位压缩朝向 |
| p3 | 低 8 位 ActionTimelineMove 表行号；决定移动目标/相对偏移及旋转规则 |
| p4 | 低 16 位 ActionTimeline 表行号 |

说明：仅非本机路径执行；位置按 u16*2000/65535-1000，朝向按 u16*2π/65535-π。ActionTimelineMove=1 时使用包内终点，其他行号的入口位置取角色当前位置，后续按表计算目标。修正早期记录中 p1/p2 高低半字颠倒的问题；收包和本机回写 0xDF 两条路径相互核对。

依据：`0x140B43001`、`0x1408C1200`、`0x1418201D0`、`0x141808030`。
