# 142 / 0x8E MoveType

[分类参数](../../README.md#category-008e) · [附注索引](../README.md)

增强移动同步

- 分支地址：`0x140b42bd4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：全局开关、两类发送布局、预测与碰撞选项消费者已核对。
- 用途：切换本机增强移动同步模式，连同预测坐标和相关碰撞选项。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 恰等于 1 开启增强模式；任何其他值关闭 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：全局 byte142AB28A1，不是每实体独立状态，也不由 p2 选择 PvP。开启时 14062B500 通过 14181A910 额外算预测位置/朝向，发内部 ClientIPC938（头总长度 56，payload36：两份朝向 float、两 ushort 状态、两份 XYZ），关闭走 555（总长度 40，payload20：一份朝向、两 ushort 状态、一份 XYZ）。预测基于运动方向/速度，通常看前 0.3 逻辑秒，Character.IsInPvP 时用 0.45，再做碰撞修正；部分运动状态直接用当前位置。普通发送入口 14062AEF0 关闭时有 100ms 尝试间隔，开启绕过该门控；距上次发送>333ms 可追加 0x40 强制处理缓冲标志，仍不保证网络即时抵达。此 flag 也通过 141838300 写碰撞 options+10，141838610 令单步长度等于本次全距离，从而不按常规步长细分；141801A60 在位置移动后设置碰撞刷新半径时，普通+0.1 变增强+0.2。当前功能据实际消费者命名，不把它等同为进入 PvP，因为 PvP 是预测函数内部另行判断。p2..p8 未读。

依据：`0x140B42BD4`、`0x14062AEF0 send attempt timing /0x14062B040 forced send flag`、`0x14062B500 payload choose /0x14062B850 internal555 vs14062B900 internal938`、`0x14181A910 outPosition/outRotation forecast0.3 orPvP0.45`、`0x141838300 options+10=mode /141838610_raw.asm 141838743..49 segmentLength=wholeDistance`、`0x141801A60 collision refresh radius +0.1/+0.2`。
