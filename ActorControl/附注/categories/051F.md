# 1311 / 0x51F SetVerminionTimeRemaining

[分类参数](../../README.md#category-051f) · [附注索引](../README.md)

萌宠比赛剩余时间

- 分支地址：`0x140b3909c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步萌宠之王 HUD 比赛/准备阶段剩余秒数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 剩余秒数，数值转 float 写 Director+6BCh；HUD 拆为分钟与秒的四个十进制数字 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140E79C50 写+6BCh。140E73E30 在阶段!=6 时每帧减 Framework.FrameDeltaTime 并钳 0；此处没有乘 GameSpeedMultiplier。1410D1650 将该 float 截断为整数，以/60 和%60 拆成分秒，再写 NumberArray98[0..3]。0515 阶段 3 将同字段设 20 秒准备时间，阶段 5 由 p3 设置比赛剩余时间。因此可核定为 HUD 倒计时，不是召唤等待时间；召唤等待另在+65Ch。p2–p8 及 Target 独立 target 未读。

依据：`0x140E829D0 / GoldSaucerDirector类型0x800A且内容7 / 0x140E79C50`、`0x140B392FA..309`、`client/main-float-conversion-instructions.json`、[FloatConversionAudit.md](../FloatConversionAudit.md)、`0x140E73E30 update raw assembly`、`client/verminion-update-windows.json`、`0x1410D1650 NumberArray98 minute/second digits`、`0x140E77D20 summon eligibility wait`、`0x140E788F0 stage5 signed32 conversions`、[VerminionClocksAndSummonDelay.md](../VerminionClocksAndSummonDelay.md)。
