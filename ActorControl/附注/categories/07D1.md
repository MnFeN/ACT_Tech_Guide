# 2001 / 0x7D1 SetMahjongRecord

[分类参数](../../README.md#category-07d1) · [附注索引](../README.md)

麻将对战战绩

- 分支地址：`0x140b44ec3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：总场数、当前/最高积分、段位点数及 Self 段位参数已逐项核对。
- 用途：同步多玛方城战玩家对战战绩摘要。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位总场数，保存摘要+0，格式化为“n 战” |
| p2 | 低 16 位当前积分，保存摘要+2，显示于“当前”积分行 |
| p3 | 低 16 位历史最高积分，保存摘要+4，显示于“历史最高”积分行 |
| p4 | 低 16 位当前段位点数，保存摘要+6，格式化为“n 点”；下一段还差 EmjDani[段位]+6 的 ushort 门槛减本值 |

额外参数：Self p5 低 8 位为段位编号：0 新人，1..9 对应 9 级..1 级，10..19 对应初段..十段；保存摘要+8。p6..p8 及独立 target 不读。不是 EmjVoiceCharacterId。

说明：140C44DD0 保存四 ushort 及一 byte，再将摘要+9 置 1。1410B99B0 在该标志、金碟战绩子窗口及 EmjVoiceCharacter Agent 有效/就绪条件下构造 33 个 AtkValue。0=总场数文本、1=当前积分、2=历史最高积分、3=段位名、4=段位点文本、5=距离下一段文本。真实 Addon GsInfoEmj(704)的 LoadUld 虚槽 46 使用资源名 GoldSaucerEmj，不能按 Addon 名找同名 ULD。构造/析构证实 vtable1422C21C0；OnSetup49 将成员 71/72/73/74/76/75 分别绑定 Node16/23/24/7/9/11；OnRefresh51 保留 R8 values 尾跳 1416C63F0，逐项显示上述 AtkValue。实际 ULD 及 Addon 文本证明 23/24 对应“当前/历史最高”而非猜测积分顺序。段位 byte 先用于 Addon12396+rank 标题，当前 0..19 标签；rank>=19 时距离下一段用 Addon9689“---”，否则 EmjDani+6 门槛减当前段位点格式化 Addon12381。收包不 clamp、不计算最高积分、不按本地成绩递增，本包四 ushort 彼此独立。初始 0 场/1500 当前积分/新人会置一个 UI 标志，不能将所有 1500 输入当默认；无回放样本。
