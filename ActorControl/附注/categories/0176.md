库存操作应答 406

- 分支地址：`0x140b3b76c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：收包转发与库存命令关联已核对；回包 p1 具体身份仍待查。
- 用途：将结果转交 GameMain 命令 406。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位原样送命令第一数值参数，具体业务待查 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：当前分支仅将 p1 完整 32 位原样发送 GameMain 命令 406，其余三业务参数为 0。已核实 ExecuteCommand140B33690 是网络发送器，内部包号 565/大小 48，不是本地命令解释器。独立库存调用：140881440 对 20000..20004/22000/22001 容器请求使用 404；FFCS 签名匹配的 MoveItemSlot14086D570 跨这些特殊库存移动前使用 405(sourceInventoryType,destinationInventoryType)，140870250 和 1408815C0 错误/受限路径使用 406。由此确立库存容器流程关联，但这些正常请求有时带两个容器参数，本 ActorControl 只透传一个 p1，尚不能排除服务端让客户端回送令牌/特殊值，不把其他调用者的 InventoryType 直接强套到本包 p1。继续保留待查。

依据：`0x140B386F0`、`0x140B33690 ExecuteCommand sends565`、`0x140881440 command404 containerrequest`、`0x14086D570 MoveItemSlot command405`、`0x140870250 command406 restrictedmove`、`0x1408815C0 command406 errorroute`、`client/unresolved-command-immediate-candidates.json`。
