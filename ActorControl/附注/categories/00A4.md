# 164 / 0xA4 UnlockAetherCurrentMsg

[分类参数](../../README.md#category-00a4) · [附注索引](../README.md)

风脉解锁位与完成表现/状态更新

- 分支地址：`0x140b42e67`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：完整事件 ID、p3 三段打包及全部模式/飞行许可副作用已核对。
- 用途：风脉解锁位与完成表现/状态更新。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 AetherCurrent 事件 ID（通常 0x2B0000+ 短编号）；低 16 位索引用于风脉位图，同时完整值用于 EventHandler 查找 |
| p2 | 恰等于 1 表示本次同时完成区域风脉，触发完成位、飞行许可、教程与横幅路径 |
| p3 | 打包：bit24..31 为 AetherCurrentCompFlgSet 的 1-based 行号；bit8..23 为 ScreenImage 行号；低 8 位未读 |
| p4 | 低 8 位交 CanFly setter；恰等于 1 设 true，其他 false，仅 p6=1 或(p6=0 且 p2=1)时调用 |

额外参数：Self p5 恰 1 时在区域完成路径显示 HowTo205；p6 模式 0 解锁风脉、1 撤销，其他值不写这组状态；p7/p8 未读

说明：风脉位图 PlayerState+5C1 按 p1 低 16 位索引、LSB 优先；区域完成位+5F9 按 p3 高字节减 1。140BE2600 支持 1..32，0 不写；FFCS 实际资源 BitCount31 不能替代本机入口范围。p6=1 清风脉位、清区域完成位并设置 p4 CanFly；p6=0 置风脉位，仅 p2==1 才设置区域完成位、处理教程/CanFly/ScreenImage 并 Refresh ZoneSharedGroup。任何模式末尾仍刷新相关 UI 并用完整 p1 查事件处理器，不能将 p6 非法值说成整个包无操作。

依据：`0x140B42E67`、`0x140BE26D0`、`0x140BE2600`、`0x140BE2600 CompFlgSet index1..32→PlayerState5F9 LSB bits`、`0x140BE26D0 AetherCurrent bitmap5C1 byte setter`、`0x140BE2A90 byte==1→CanFly611`、`main A4 full p1 GetEventHandlerById / p3>>8 &FFFF ScreenImage`。
