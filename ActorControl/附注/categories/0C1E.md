# 3102 / 0xC1E AdventurerPlateSaveResponse

[分类参数](../../README.md#category-0c1e) · [附注索引](../README.md)

冒险者铭牌保存应答

- 分支地址：`0x140b45835`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：保存结果、类型 1..5 发起侧与刷新已核对；静默类型 0 名称待查。
- 用途：处理冒险者铭牌资料保存响应。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 保存结果码：0 成功，非 0 失败；失败值作为 LogMessage5878 的数字参数选择错误文案 |
| p2 | 完整 uint32 操作类型：1 肖像应用，2 个人信息，3 铭牌样式，4 可见范围，5 更新搜索备注时补建/重建铭牌资料；0 无成功日志且发起侧未具名，>=6 不查成功日志表；成功助手刷新时 1 用肖像标志，其余用一般标志 |
| p3 | 成功且临时资料首 byte 非零时写 CharaCard+1E4h 的 Timestamp；此入口不转换单位 |
| p4 | 此路径未读取 |

说明：成功且临时资料首 byte（资料版本标记）非零时，将当前程序+68h 起 192-byte 临时块复制到+128h 当前块；Flags bit1 置位，按 bit2 保留旧当前 Data32.Timestamp（+1B0h）或置 0，随后写外层 Timestamp+1E4h=p3 并清临时块。失败清临时块后输出 Log5878；成功但临时首 byte 为 0 时不走助手通知。助手 140BC4320 将 p2=1/2/3/4 分别映射 Log5864/5867/5866/5868。0 及 5 成功日志为 0，>=6 也无该日志，但仍调用 AgentCharaCard 刷新；Agent 已激活、界面与资料条件允许且没有等待中请求时，p2==1 设置刷新标记 1，其他值 2，再 RequestCharaCardUpdate。固定 FFCS TempCharaCardData 写 6Ch，而本机 ASM 为 68h；Current+128h、外层 Timestamp+1E4h、Flags+1E8h 相符，文档保留版本差异，未套用错误临时偏移。p4 及其余参数未读。 新增发起侧闭环：BannerHelper.SendCharaCardData140BC4210→140C48120 将 reason 原样写内部 448 号 216 字节请求首 DWORD，并缓存 192 字节临时资料。140DBEA80 事件 5 先调用 InfoProxyDetail(10)的 14096EB90 设置 SearchComment(+100h)，再 SendUpdateData；仅 Current 资料 Version=0 或 Data8.Flags bit0（幻想药重置）置位时初始化默认铭牌 Version4 并以 reason5 发送，因此 5 不是单独传送备注文本的包。当前 9 个直接发送调用点均已检查：肖像 1、资料 2、样式 3、可见 4、备注补建 5，没有发现 reason0 直接发起点。固定 FFCS CharaCardDataChangeReason 写 Design=2/Profile=3，与本机成功日志及实际写字段相反：140DC7920 发 2 且更新个人活动时段/资料，140DC6220 及 140DC2E20 发 3 且更新边框背景/装饰；保留当前本机 2 个人信息、3 样式，不直接套上游枚举。

依据：`0x140C48CB0 save result and current native offsets`、`0x140BC4320 operation->log mapping / ASM six-entry local array`、`resources-characard-save-response.json Log5864/5866/5867/5868/5878`、`0x140DBFA60 Agent refresh portrait1 vs other2`、`FFCS CharaCard.cs current offsets and Temp6C discrepancy`、[CharaCardSaveOperationResults.md](../CharaCardSaveOperationResults.md)、`0x140C48120 reason→internal448 request/payload216/cache192`、`0x140DBEA80 event5 InfoProxyDetail.SearchComment andconditionalreason5`、`0x14096EB90 writesUtf8String+100h and193bytecomment buffer`、`0x140DC7920 reason2 profilefields /0x140DC6220 reason3 designfields`、`FFCS BannerHelper.cs ChangeReason2/3 differsfromcurrentCNnative`。
