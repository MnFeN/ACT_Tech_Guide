# 245 / 0xF5 StopClientPath

[分类参数](../../README.md#category-00f5) · [附注索引](../README.md)

停止布局路线移动

- 分支地址：`0x140b4490b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：ClientPath 布局路线生产者、模式 4 子状态 2/3 及终止收尾已核对。
- 用途：终止本机 ClientPath 布局路线移动（模式 4，子状态 2 或 3）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：路由 BattleChara 存在仅为入口门控，实际 140630A10 从全局输入控制器 142AB28B0 取+150h 子对象，141809AA0 再取其+30h MoveController；不是对任意路由角色停止移动。要求 MoveController+3F0=4 且+3F1=2 或 3。141809660/141809760 明确以优先级 4 清理后置模式 4、子状态 2、优先级 4，再 14180DB60 读取 GetLayoutInstanceStatic(type65=ClientPath,layoutId,0)及其+60h 路径对象，按路径长度/速度建立路线。141809860/141809980 必须 IsFlying，置模式 4/子状态 3/优先级 4，再 14180E760 读取同一 ClientPath、记录起始位置/路径进度/朝向选项与回调指针+350h。故子状态 2 是标准 ClientPath 轨迹，子状态 3 是飞行 ClientPath 轨迹，不是泛自动跑或所有强制移动。00F5 对子状态 3 先在+350h 回调存在时调用其虚 2，然后 1418168A0(controller,4)终止/清理；对子状态 2 直接该清理。1418168A0 第二参是清理优先级，不能把该调用解释为重新设模式 4；原模式 4 已由调用前比较确认。无 p1..8 及独立 target 读取，不改变 ClientPath 布局资源本身；无回放样本。

依据：`0x140630A10`、`0x141809AA0`、`0x141809660 /141809760 write mode4 subtype2 priority4→14180DB60`、`0x141809860 /141809980 IsFlying thenmode4 subtype3→14180E760`、`0x14180DB60 /14180E760 GetLayoutInstanceStatic65=ClientPath layoutId androute+60`、`FFCS ILayoutInstance.cs InstanceType.ClientPath65`、`0x141809AA0 subtype3 callback+350h virtual2 then priority4cleanup`、`client/movement-mode4-methods.json`、[ClientPathMovementStop.md](../ClientPathMovementStop.md)。
