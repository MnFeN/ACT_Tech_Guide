# 524 / 0x20C ChallengeEntryUnlockMsg

[分类参数](../../README.md#category-020c) · [附注索引](../README.md)

提示挑战笔记开放新内容或追加新项目，并刷新解锁列表

- 分支地址：`0x140b42990`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：两条完整日志及解锁列表刷新已核对。
- 用途：提示挑战笔记开放新内容或追加新项目，并刷新解锁列表。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零=Log3781“开放了新的内容”；0=Log3782“追加了新的项目” |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：两条日志均无格式参数，其他网络参数不读；Agent0x88 存在时调用 140F57E00(agent,true)，可见时除通常进度刷新 140F58650 外额外调用 140F58720 刷新解锁项目。旧“结束/清理提示”描述撤回，资源明确是解锁/追加通知。

依据：`0x020C`、`resources-notebook-messages.json Log3781/3782 full text`、`0x140F57E00 a2=true adds140F58720 refresh`。
