# 1039 / 0x40F SetCustomizableFurniture

[分类参数](../../README.md#category-040f) · [附注索引](../README.md)

可定制家具资源

- 分支地址：`0x140b3dd7c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：34 件可定制家具及模型/双资源状态已核对；各子品类状态枚举待查。
- 用途：同步花瓶、画框、空白隔离墙及鱼拓框等可定制家具的部件资源。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位部件资源模型编号；byte3 部件槽，byte2 未读；当前 UsageType12 即时绘制只处理槽 0 |
| p2 | byte1 为第一 SGB 状态选择，byte0 为第二 SGB 状态选择；byte2 附加缓存值，byte3 未读；本路径缓存覆盖，不套用 0407 的 FF 保留规则 |
| p3 | 低 16 位家具对象索引 |
| p4 | 此路径未读取 |

说明：HIWORD(BaseId)==3 且 HousingFurniture 行+0F UsageType==12 才即时更新。当前全表 34 件：UsageParameter1 为 11 件花瓶，2 为 5 件画框/画架，3 为 14 件空白隔离墙/隔板门，4..7 为四档鱼拓画框；不是单一花盆或水族箱协议。141C6B630 对 UsageType12 只接受 slot0 进行绘制，其他 byte 槽仍可能写外层缓存，不能混同入口拒收。模型经 1406FF990 直接改 SGB 资源编号，未查 GardeningSeed；两个状态交 1406FFC40 分别改 SGB 扩展名前第 7/第 4 字符（以十进制字符串首字符），不是直接调用染色接口。模型及状态字段在 140E28EA0 无 FFFF/FF 哨兵分支，缓存全部覆盖；即时绘制的 Type12 路径也不采用转轮台分支的跳过写入判断。p2byte2 保存至缓存+4，但第六形参未被此绘制末端读取，各品类额外语义仍待查。p3 低 16 位对象索引，p4..p8 未读。

依据：`0x140E20B10 ->141AC32D0 ->140E28EA0`、`0x140E24DE0 UsageType12 and141C6B630 slot0-only path`、`0x1406FF990 /1406FFC40 resource variant consumption`、`resources-housing-furniture-all-raw.json`、`housing-customizable-furniture-map.json 34 nameditems`、`resources-housing-special-furniture-schema.json`、`client/scripts-furniture fivecustomtalk bytecodes andmodernoutput`、[HousingSpecialFurnitureParts.md](../HousingSpecialFurnitureParts.md)。
