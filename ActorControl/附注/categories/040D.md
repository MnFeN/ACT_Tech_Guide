## 参数与行为

- 核对状态：已核对。
- 用途：设置住宅室内的幻卡游戏区资格开关。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位按 0/非 0 转 bool，写 IndoorTerritory+128E9h；非零允许该室内通过幻卡区域附加资格，0 禁止通过 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140E1D610 仅在 Indoor 对象存在时写 byte+128E9。getter140E1ECB0 在无 Indoor 时返回 0。全.text 字段追踪与八个 getter 调用者核实其业务为幻卡：140C40CD0 在 TerritoryType.IntendedUse==14 时返回该 flag；140C40F60 的挑战请求路径若室内该 flag 为 0，显示 Log4752“当前区域无法进行幻卡挑战”并拒绝。140C3F840/3F910 用于幻卡交互资格，还要求已解锁、区域/事件资格、未在禁止状态等；140C40630/40710 在相同门控下使用 Log4764 离开/4763 进入幻卡游戏区。固定 EventHandler0x230001 明确为 TripleTriad，与 FFCS EventHandlerModule 吻合。p1 为 true 只开启室内附加门控，不绕过其他挑战条件、不直接发起对战、不发卡或改牌库。资源另有 BaseId197003 Item12110 九宫幻卡对战台，UsageType9，可作为房屋功能关联证据，但本收包没有指定家具索引，也未独立证明每次 false 必等于家具被移除。p2..p8 及独立 target 未读，现有回放无样本。
