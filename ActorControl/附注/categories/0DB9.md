# 3513 / 0xDB9 SetCosmicCommendationDeadline

[分类参数](../../README.md#category-0db9) · [附注索引](../README.md)

旧星球影像展示截止时间

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Unix 秒单位、旧星球截止比较及名单匹配切换消费者已核对。
- 用途：同步旧星球赞誉全息影像展示名单的截止时间。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 Unix 秒截止时间，写 module+320h；旧星球按 ServerTime<p1 保持 EntityId 名单匹配，否则改用固定 DataId 映射 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：141A79C40 直接保存 p1 到 module+800(320h)，不立刻应用或刷新。141A795B0/141A796F0 与更新 141A78FB0 在当前星球==最新星球，或 ServerTime<该截止时间时，按记录 EntityId 匹配 7 个影像；旧星球截止后改用固定 DataId 表 14241C2C0 匹配。等于截止已进入后者。141A79A10/141A7A9F0 仅在当前星球!=最新星球时将该原始时间复制到显示时间字段+688(2B0h)；最新星球按服务器时间和统计期标志本地推算 09:00 UTC 边界。星球字段为 WKSManager.State+15/+16，即 manager+65/+66。p2..p8/target 未读。不能把 p1 当通用状态码或相对秒数。仅默认委派模块加载且链可达时生效。

依据：`0x141A79C40`、`resources-wks-hologram-controls.json`、`resources-wks-hologram-quest.json`、`0x141A79A10 PlayerState.ContentId and shared96byte records`、`0x141A7A7D0 / table14241C300 sevenActionTimeline rows`、`0x141A795B0 / 0x141A796F0 serverTime<module+320h`、`0x141A79F30 / 0x141A7A9F0 statistics-state and09UTC boundary`、`FFCS WKSManager.State+50 CurrentPlanetIndex+15 LatestPlanetIndex+16`。
