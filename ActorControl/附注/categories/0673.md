# 1651 / 0x673 SetCustomDeliveryProgress

[分类参数](../../README.md#category-0673) · [附注索引](../README.md)

老主顾进度与交付次数

- 分支地址：`0x140b43a90`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：老主顾业务、NPC 行与零基索引映射、三字段及剩余次数消费者已核对。
- 用途：同步指定老主顾的当前档位进度、爱心档位及已用交付次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 零基 NPC 索引 0..11，对应 SatisfactionNpc 行 p1+1；越界忽略 |
| p2 | 低 16 位当前爱心档位的 Satisfaction 进度，不是累计总好感 |
| p3 | 完整 int32 等于 0 时写档位 1，否则取低 8 位写 SatisfactionRanks；正常档位 1..5 |
| p4 | 低 8 位已用交付次数 UsedAllowances，不是剩余次数 |

说明：进度写+2+2*index，档位写+1A+index，已用数写+26+index。仅档位 byte 发生变化才通知 EventFramework。140B1D0E0 通过 SatisfactionNpc.RowId-1 读取这三项：进度夹到当前档位上限、rank 复制到 NpcInfo.RankCur、used 复制到 NpcInfo.UsedAllowances；剩余量受单 NPC 上限-used 及全局 12-sum(12 项 used)双重限制。此包本身不把 rank 夹到 1..5，p3=0x100 将写 0 而非 1。p5..p8 未读。

依据：`0x140B1DD10 / 0x140B81910`、`FFCS SatisfactionSupplyManager Satisfaction+2,SatisfactionRanks+1A,UsedAllowances+26`、`0x140B1D0E0 buildsNpcInfo,index=RowId-1,progress clamp andremaining allowance calculation`、`0x140B1D440 sumsall12 UsedAllowances`、`resources-effects-custom-deliveries.json SatisfactionNpc0/1/11/12`。
