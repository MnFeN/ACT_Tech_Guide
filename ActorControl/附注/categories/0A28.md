# 2600 / 0xA28 SetFieldRecordRegistration

[分类参数](../../README.md#category-0a28) · [附注索引](../README.md)

战果记录登记状态

- 分支地址：`0x140b44f33`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步战果记录界面的登记状态位图。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | bits1..31 对应 MYCWarResultNotebook 行 1..31；bit0 未读 |
| p2 | bits0..23 对应 MYCWarResultNotebook 行 32..55；高 8 位未读，当前 51..55 为无名称占位行 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140D8AEF0 将两 mask 写 Agent383 的 55 个登记 bool：记录行 r 写 Agent+14303+r，并设+210 dirty。140D8C3E0 按资源行 r 将记录保存在初始槽 r-1，并保留该零起始 ID；之后虽会排序，140D8B940 仍按保留 ID 寻找行，并按 r-1 读取登记标志写 UI 布尔，因此位号与资源行号映射已闭环。当前有效记录 1..50，51..55 为资源占位。与 0B54/55 的道具登记查询缓存不同，不直接写 UIState 那份 bool。

依据：`0x140D8AEF0 bit expansion`、`0x140D8C3E0 resource rowId-1 identity`、`0x140D8B940 indexed UI bool output`、`0x140D8BF70 registered count`、`resources-myc-war-notebook-raw.json`、`client/myc-notebook-flag-reads.json`、[FieldRecordRegistrationFlags.md](../FieldRecordRegistrationFlags.md)。
