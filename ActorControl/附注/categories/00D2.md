# 210 / 0xD2 InstanceSelectDlg

[分类参数](../../README.md#category-00d2) · [附注索引](../README.md)

显示分线选择窗口及人数信息

- 分支地址：`0x140b40ca8`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分线数量、uint32 人数数组及 Self 尾参消费已核对。
- 用途：显示分线选择窗口及人数信息。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | TerritoryType 行号 |
| p2 | 分线数量 |
| p3 | uint 第 1 条分线的玩家人数；不再拆分半字/字节 |
| p4 | uint 第 2 条分线的玩家人数 |

额外参数：Self p5/p6 分别为第 3/第 4 条分线人数。p7/p8 未读取。实际构造 8 项 uint32 数组，前 4 项来自 p3..p6，后 4 项清零。

说明：140C33FB0 逐项 mov ecx,[r14]、add r14,4，明确 32 位元素；长度参数固定 8，分线数量 p2 决定 UI 条目数，索引>=8 时用 0。每项交 Addon2092 格式化地区、分线号、人数。不是四个 uint 打包八个 ushort，也不是八个网络参数。SelectString 窗口 60 秒关闭倒计时。

依据：`FFCS PublicInstance.ShowInstanceSelection`、`0x140B40CA8`、`140C33FB0 ASM 140C340F4 DWORD读取 / 140C34129指针+4`、`主函数instancePlayerCounts[4]+相邻清零__int128构成8项`。
