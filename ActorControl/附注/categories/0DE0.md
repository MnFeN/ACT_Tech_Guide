# 3552 / 0xDE0 SetCosmicEmergencyProgress

[分类参数](../../README.md#category-0de0) · [附注索引](../README.md)

宇宙紧急情况累计进度

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：两个任务区域的累计进度、资源目标与 HUD 百分比及提示对白已核对。
- 用途：同步宇宙紧急情况两个任务区域的累计进度，并可提示紧急任务邀请及请求对白。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 区域 0 累计进度，写 EmergencyModule+134h，AgentWKSAnnounce.Data+0Ch；不是百分比也不是另一参数的当前值 |
| p2 | 完整 uint32 区域 1 累计进度，写 EmergencyModule+138h，AgentWKSAnnounce.Data+10h；其目标值独立来自第二个 WKSEmergencyProblem 行 |
| p3 | 完整 uint32 MassivePcContentBattleTalk 行号；仅非 0 且 module 阶段+128h==3 时显示 Log11335 邀请提示，并以 subrow0/队列种类 2 请求该行对白；0 不做此提示/对白 |
| p4 | 此路径未读取 |

说明：141ACED30 始终先写两个 DWORD，不改变阶段。140A6FAA0 及 140A6F510 从 manager+1120h 取得同一模块，把+134h/+138h 分别同步到 Announce.Data+0Ch/+10h；模块阶段 3..5 且 HUD 状态 2 等条件满足时，按各自+80h/+84h 目标值生成百分比并通过 140A70860 更新 HUD。140A701A0 按 WKSEmergencyInfo 当前 row/subrow 前两个 ushort 取得两个 Problem 行，各取+0Ch DWORD 作为两个目标值；不是把 p2 作 p1 的最大值。140A70B70 ASM 先 unsigned 比较 progress>=required 则 100，否则将两个 uint 零扩展到 64 位后转 float，做 progress/required*100 并截断；required0 直接走 100。两结果分别打包到 Data.StateProgress+94h 的 low8 和 bits8..15。固定 FFCS AgentWKSAnnounce 独立具名这两组 EmergencyProgress/Required。p3 分支 Log11335 本机正文为紧急情况中收到紧急探索任务参加邀请；141ACF340 另有本机角色/Director/功能 8/权限 198/对白节流门控，可能排队、清队列或不播放，不保证收包立即出对白。当前函数不把 p1/p2 夹紧，只有显示百分比到 100 封顶；无回放样本。p4..8/target 不读。
