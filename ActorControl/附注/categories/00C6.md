# 198 / 0xC6 SetQuestEligibility

[分类参数](../../README.md#category-00c6) · [附注索引](../README.md)

任务附加资格状态

- 分支地址：`0x140b44381`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Quest 键、uint64 拼接、全部 getter 引用与整体零值资格判定已核对。
- 用途：同步任务短 ID 对应的 64 位附加资格状态，值为 0 才通过专用资格检查。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Quest 短 ID（低 16 位），作为附加资格表键 |
| p2 | 64 位资格状态的高 32 位；与 p3 合成后做整体是否为 0 判断 |
| p3 | 64 位资格状态的低 32 位 |
| p4 | 此分支未读取 |

说明：map<ushort,uint64>键为 Quest 短 ID，值=p3|((uint64)p2<<32)，存在覆盖，不存在新增。141977500 返回 true 的充分必要条件是该 Quest 键已存在且 value==0；缺键与任意非零值均 false。因此两 DWORD 都有效，但当前消费者不分别解释各 bit 或把值当 ContentId/EntityId。全部 9 个 getter 引用位于 Quest 可用性/剧情分支：141C66150 针对未接受任务读取此资格；部分特殊任务如赠予幻卡收藏家的礼物、为了民众与近邻、两个孤儿的故事、感谢艰险之路的陪伴、强梁霸道终覆灭等，在资格不通过且未接受时产生限制 bit0x100000000000。71053 前往魔之塔还把它与已接受/任务进度/组队检查结合。服务器非零状态可能有更细错误编码，但当前本机只消费整体 0/非 0，不能凭客户端分出未读取的 bit 名。p4..p8 未读；只在 singleton 存在时更新。

依据：`0x1419773D0`、`0x141977500 key exists AND value==0`、`all 9 direct callers of141977500: Quest gates`、`0x141C66150 quest shortId+2E0 /IsQuestAccepted`、`0x141C672F0 /141C693C0/694B0/695A0/69690/69970/69A70/6AA50`、`resources-quest-extra-gates.json current Quest names`。
