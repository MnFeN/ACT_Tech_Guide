# 1010 / 0x3F2 SetHousingCrest

[分类参数](../../README.md#category-03f2) · [附注索引](../README.md)

住宅家具部队队徽

- 分支地址：`0x140b3d745`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步住宅/工房及相关家具显示的部队队徽图案 CrestData。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | 低 8 位 HouseUnit，仅 Outdoor 分支使用：普通地块 0..59 或公寓编码 80h/81h，并按当前显示分区筛选 |
| p3 | 队徽 CrestData 高 32 位；当前纹理生成器取其 bits0..3 与 4..7 为两个 Ordinary 配色编号；与 p4 拼 64 位 |
| p4 | 队徽 CrestData 低 32 位：Charge 低 8、Ordinary bits8..13；盾形取右移 14 后的 byte、图案色取右移 22 后的低 4 位；全 64 位 FFFFFFFFFFFFFFFF 表示清除 |

说明：纠正此前“住宅关联标识”：此 64 位是部队队徽图案编码，不是 HouseId、角色 ContentId 或 FreeCompanyId。140E19800 拼 p3 高/p4 低：Outdoor 存 PlotDetail+8 并 1406F3730 刷新；Indoor 存 12720h 并遍历前 40 个 Housing 对象，对 Kind12 调用 141A46290；后者仅 HousingFurniture+15h bit1 置位时将布局传 1407006F0。当前 1793 行家具表只有 196627/Item6559 部队储物柜置此 bit，不能泛称所有家具或旗帜。Workshop 存+0B8B8h，140E481D0 找各城市工房固定 Layout 后同样套用队徽纹理并更新本地编辑预览。1407006F0 非全 F 时调用 RaptureAtkModule1400F9980，以 raw64 数据向 AtkModule+5C20h AtkCrestManager 请求纹理；140648D20 将 raw64 存纹理任务+10h 作为缓存键，再 140649260/3F0/9FD0 按图案部件与配色生成。独立 DrawDataContainer1408B3CD0 原样写+258h FreeCompanyCrestData，1408B3BD0 也将它传同一生成器，身份形成闭环。全 F 释放/清贴图；0 不是该清除哨兵。当前 native 两底纹色在 bits32/36：14064949C shr32、A7 shr4、AB/AF andF；固定 FFCS BitField 元数据的 29/33 与本机不符，不能直接套用。入口不校验部件/颜色资源范围，按实际读取宽度记录，未被该生成器取用的其余位仍作为 raw64 缓存键保留。p5..p8 及 target 未读，无回放样本。
