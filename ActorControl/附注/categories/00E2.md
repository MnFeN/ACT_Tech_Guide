# 226 / 0xE2 ForcedMovement

[分类参数](../../README.md#category-00e2) · [附注索引](../README.md)

向绝对位置强制移动，含额外移动参数

- 分支地址：`0x140b42595`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：入口、选项传递及逐帧消费已核对。
- 用途：向绝对位置强制移动，含额外移动参数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位压缩原生 X |
| p2 | 低 16 位压缩原生 Y 高度 |
| p3 | 低 16 位压缩原生 Z |
| p4 | 低 16 位压缩面向 |

额外参数：uint32 p5/10000 为平移与旋转持续时间（游戏逻辑秒）；p6 模式：0 传控制 0，1 传 3，2 传 2。p7/p8 未见读取。

说明：共享后缀还调用 MoveController 函数。不能只定义四个参数后丢弃 Self 尾部。

依据：`0x140B42592–0x140B42630`、`0x14090ABB0`、`0x14181A450`、`0x14181B6D0`、[Movement.md](../Movement.md)、`0x140B425C8..ED zero-extended p5 conversion`。
