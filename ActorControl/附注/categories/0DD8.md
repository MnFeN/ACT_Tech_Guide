宇宙任务目标阶段

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：切换当前宇宙任务的目标阶段，并按旧阶段资源追加时间。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位新阶段索引，最后写 CurrentMission+2；不是额外时长 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：141A74D70 先清理任务追踪/显示条目的阶段相关缓存，但保留类型 13 条目；然后用当前任务和尚未更新的旧阶段索引，查旧 WKSMissionToDo+24h 指向的 WKSMissionToDoRecover。该行+0 ushort 非零才将其作为秒数加到 manager+E84h 绝对 deadline，并将相应追踪计时器的剩余量先按当前 ServerTime 钳到 0..旧 duration，再追加同秒数，重写 start/finish/duration。之后才写 p1 低 8 位新阶段、UI 原因 1 刷新、清 manager+EBBh 阶段显示抑制位并刷新条目。当前 Recover22 行，例 row4+0 为 60 秒；该行其余字段不是本控制的 p2/p3。没有入口阶段合法性检查；任务资源有三个 ToDo 槽，未宣称异常阶段会被本地拦截。p2..p8 及 Target 独立目标未读。

依据：`0x141A74D70 order: oldToDo/Recover then newstagebyte`、`0x141A74D70 deadline and tracking timer add same ushort seconds`、`resources-wks-mission-stage-recover-raw.json 22 rows`、`0x140148C10 reason1 UI refresh`、[WksMissionStageAdvance.md](../WksMissionStageAdvance.md)。
