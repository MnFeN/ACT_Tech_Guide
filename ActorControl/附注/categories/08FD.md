天工纪念碑造型

- 分支地址：`0x140b452b1`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：缓存苍穹街天工纪念碑的造型时间轴选择，随重建阶段刷新应用。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 取低 8 位的纪念碑时间轴索引；0..9 有效，分别映射 SGB step1..step10／SubId12..21；消费时>9 不应用新值 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：140EA7BF0 只将低 byte 存模块+60h，必要时创建+58h 的 24-byte 纪念碑记录，记录当前轴初值 FFh、处理阶段 4；收包本身不立刻播放。140EA7370 在重建阶段转换、资源就绪的刷新块中消费：pending<=9 且与记录+8 当前轴不同时更新、标脏；随后清 pending 为 0。变更时标脏 BaseId2011353 EObj+9Bh bit3，重置场景处理状态；等 Layout ready 后对 SharedGroup 实例 8498226 调用 PlayTimeline(index,0)。EObjName2011353 本机名为“天工纪念碑”。当前 bg.lgb实例8498226确认为zosh_r1hx_00_poi18.sgb，planlive.lgb 的 EObj 实例 8550635 绑定同 ID。SGB 有 10 条 step 轴，实际索引表 12..21，0 对应 pil1b，1..8对应pil1a加clf1a..clf8a，9 对应 pil1a 加 fre2a 共享组；完整绑定、C019命令原始字节与模型路径见hwd-monument-timeline-map.json。未将 clf 数字直接套为职业中文名。
