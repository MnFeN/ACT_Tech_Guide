确认无人岛庭具位置

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：确认无人岛庭具的本地编辑位置、旋转与放养区域编号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位庭具索引 |
| p2 | 低 8 位 MJIMinionPopAreas 行号，写槽+38h；0 为空/不可放置区域，1..15 为资源区域；16 为特殊旁路值，不查区域资源且使用特殊对象索引 90 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：slot<90 且记录+39h 未置时，从当前本地编辑对象取得 XYZ 及 rotation 复制到槽（+10h/+14h/+18h/+20h），置+36h ushort=12；区域 byte 变化置模块+29C0h dirty，再将已生成对象同步到此位置/旋转，最后请求 HousingMenu 刷新。坐标和角度不是包内 p3/p4，来自本地编辑对象。字段+38h 的独立消费者 1418EA5A0 明确查 MJIMinionPopAreas：16 直接通过；处于需要 MJI 检查的状态时，其他值要求非 0、资源存在且行+9bit0 允许，再执行场景放置判定。141C142E0/143F0 等还以 16 选择特殊对象索引 90；不是染色或模糊区域标志。当前资源 0..15 完整中文名、Function 与坐标已写映射；原文行 16 不存在，与特殊值分支相符。p3..p8 及独立目标未读。

依据：`0x141C13480 local edit transform and area byte commit`、`0x141C14AB0 area ->1418EA5A0 placement check`、`0x1418EA5A0 MJIMinionPopAreas row lookup and16bypass`、`0x141C142E0/143F0 area16 ->objectindex90`、`resources-mji-furnishing-areas-raw.json 16 rows`、`resources-mji-furnishing-area-schema.json /names.json`、`mji-furnishing-area-map.json`、[MjiFurnishingEditResults.md](../MjiFurnishingEditResults.md)。
