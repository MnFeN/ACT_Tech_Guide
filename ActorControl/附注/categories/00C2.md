# 194 / 0xC2 SetCrystariumDeliveryProgress

[分类参数](../../README.md#category-00c2) · [附注索引](../README.md)

水晶都工艺馆交货状态

- 分支地址：`0x140b44341`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：工艺馆列表、全局任务完成位区别与刷新已核对；目标完成粒度待查。
- 用途：更新水晶都工艺馆交货任务的附加完成状态列表，并刷新任务事件。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 Quest ID，事件键会 OR 0x10000 |
| p2 | 非零将 p1 短 QuestId 加入 PlayerState+868 向量（已存在则不重复）；0 删除（不存在则无变化） |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：FFCS 将 PlayerState+868 命名为 CompletedCrystariumDeliveryQuests，实际列表与 QuestManager 的全局完成位图分开。140BE4B30 按 Quest 短编号查成员；141C64A70 将缺少该成员转为任务可用性错误 bit0x100000000000，141CA2E20 针对 CustomTalk B0237..B023B 及 Quest3227..3241 交叉检查列表成员和真正 QuestManager.IsQuestCompleted；本机资源这些任务为伊奥拉/黑铁工房等工艺馆任务。故不能把 p2 简单说成修改全局任务通关。列表变化才按 p1|10000 查 handler 并调用多项刷新虚函数。附加完成状态与具体交货目标的对应含义还需任务状态机核对。p3..p8 未读。

依据：`0x140B44341`、`0x140B81BE0`、`0x140BE4900`、`FFCS PlayerState.CompletedCrystariumDeliveryQuests+868 /StdVector<ushort>`、`0x140BE4B30 membership /0x141C64A70 quest availability errorbit`、`0x141CA2E20 CustomTalk B0237..B023B /Quest3227..3241 vs actual completion`、`resources-delivery-teleport.json Quest68763..68767`、`0x140B81BE0 changed-only handler refresh`。
