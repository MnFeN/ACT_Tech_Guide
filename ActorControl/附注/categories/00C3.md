# 195 / 0xC3 SetIshgardQuestEligibility

[分类参数](../../README.md#category-00c3) · [附注索引](../README.md)

苍穹街特殊任务资格

- 分支地址：`0x140b44361`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：HWD 结构、七任务逐 bit、资格消费者及任务刷新已核对。
- 用途：同步苍穹街复兴七个特殊任务的附加资格标志，并刷新任务事件。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Quest 短 ID，仅映射 7 个苍穹街任务；进入事件表时 OR0x10000 |
| p2 | 非零设置该任务附加资格位；0 清位 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140EA6BC0 返回 142AF93C8 管理器；其结构+11 DevelopmentLevel、+12 TerritoryType 及+40 HwdDevEventHandler 与 FFCS HWDManager 一致，初始化 140EA6BD0 检查 Territory886 苍穹街。当前 FFCS 静态签名在本机构建未匹配，身份由结构与实际任务资源共同核对，不套用上游地址。Quest 完整 ID→bit：69296 无名众人广场→0、69377 新巢居住区→1、69261 为大家带去温暖的家→2、69508 落羽商业区→3、69491 与森都的贸易交涉→4、69578 升歌文化区→5、69535 富足的生活→6。140EA7210 读同一映射；141C64E10 等在资格位未设置时返回任务限制 bit0x100000000000，另有进度检查结合 DevelopmentLevel，不是修改 QuestManager 全局完成位。未映射编号不改缓存，但管理器存在时仍会尝试任务 handler 多项刷新。p3..p8 未读。

依据：`0x140B81CC0`、`0x140EA7110`、`FFCS HwdManager.cs offsets +11/+12/+40; StaticAddress no current match`、`0x140EA6BD0 Territory886 lifecycle`、`resources-quest-special-state.json seven current quest names/IDs`、`0x140EA7210 flag getter matching writer`、`0x141C64E10 availability errorbit0x100000000000`、`0x141C65010/141C652C0 DevelopmentLevel gates`。
