位移或传送请求失败

- 分支地址：`0x140b40529`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：控制流及四参作用明确，模式枚举待查。
- 用途：处理位移/传送请求失败或取消。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 移动请求模式/操作码 |
| p2 | 非零时跳过部分失败动画并采用对应状态路径 |
| p3 | 完整理由值：2 目的地区域暂停进入；3 静默但收尾；4 无法移动下一区域；5 直接返回不收尾；6/8 用 p4 作日志行号；7 主线任务条件不满足；其他无法离开区域 |
| p4 | 仅 p3 为 6/8 时用作 LogMessage 行号 |

说明：可能取消布局预取、结束传送动画并更新移动请求状态；p1 不同值的完整玩法含义继续追发送侧。 已独立读取本机 Log912/4000/1320/727 正文，保留 p3=5 提前返回与 3 静默收尾的区别。p2 在主入口按完整 DWORD!=0 归一；p2 非零跳过失败时间轴及通常 WarpInfo 回滚，仅 p1=3 有专用角色恢复路径。细节见 WarpFailureReasonLabels.md，模式枚举仍未完整确认。 后续追到 14085F980 从区域准备 payload+Ah byte 缓存 WarpInfo 类型，但失败 p1 仍完整 DWORD；旧 Sapphire Login16/Housing19 与当前 17/20 冲突，不跨版本补名，见 WarpModeProducerBoundary.md。 具名 Lua 注册 IsEnterTerritoryEventLogin→140B693F0 独立确认 WarpInfo+Ch==17；其他含 Warp 的查询分别读事件/Leve/WKS 文本，不能给 6/23 补名。最新 FFCS 该文件 blob5863f37 与固定快照一致，见 WarpModeProducerBoundary.md 后附。
