# 3230 / 0xC9E ShowIslandAnimalResult

[分类参数](../../README.md#category-0c9e) · [附注索引](../README.md)

无人岛动物捕捉与放生

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：显示无人岛牧场动物捕捉或放生结果日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | LogMessage 行号；9975/9976/9977/9978/10149 有专用模板参数，其余行号按无参数日志显示 |
| p2 | 上述五个专用日志均为 BNpcName 资源行号，显示捕捉／放生的动物名；其他日志不传此值 |
| p3 | 仅 p1==9975 时作为 Item 资源行号，显示无效的捕捉道具；其他日志未读 |
| p4 | 此路径未读取 |

说明：141A660A0 先检查 MJIManager+28h 可编辑岛屿标志。9975 按[p3,p2]传两项整数，实际宏为 Item(lnum1)、BNpcName(lnum2)，意为道具对动物没有效果；9976 逃走、9977 失败但未警惕、9978 成功捕捉、10149 放归大自然，均只传 p2 作 BNpcName(lnum1)。其他 p1 仍调用 ShowLogMessageTextParameters 但参数列表为空。原宠物放养结果日志定义不符这些文本，应修正为牧场动物捕捉／放生；本控制只输出提示，不能当成直接捕获/删除动物数据。p4 及额外参数未读。

依据：`0x141A660A0 editable-island gate and argument ordering`、`0x140EA9730 MJI delegation`、`resources-mji-pet-and-wks-response.json rawSeString Log9975..9978/10149`、[MjiAnimalCaptureResultMessages.md](../MjiAnimalCaptureResultMessages.md)。
