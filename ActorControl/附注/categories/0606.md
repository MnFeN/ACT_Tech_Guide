## 参数与行为

- 核对状态：AreaObject 路由、AVFX 触发编号及实例消费已核对。
- 用途：更改 AreaObject 的 AVFX 触发编号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位触发编号；与缓存相同则无操作，不同则缓存并通知现有 VFX |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：要求包头 EntityId 对应 ObjectKind11 AreaObject。0x141758790 写对象+0x1B4；VFX 指针+0x1A8 非空时调用 0x140391030。后者写共享上下文+140 触发编号、+136 累计触发位图；有效实例同步写+8274/+8275 编号及+8278 位图。没有入口范围检查。不能把所有编号解释为启动/停止布尔值；具体视觉效果取决于该对象的 AVFX 资源。

依据：`0x141758790`、`0x140391030：trigger编号与位图写入`、`VFXEditor固定49012104303caae373ac4b37b385a3affedca472 AvfxScheduler.Triggers仅作资源结构佐证`。
