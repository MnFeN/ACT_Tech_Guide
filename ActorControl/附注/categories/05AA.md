冒险者分队公告进度

- 分支地址：`0x140b3e7e2`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分队公告进度、脚本资格读者及参数宽度已核对。
- 用途：同步冒险者分队公告用进度，刷新相关场景对象的事件资格。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位为 GcArmyGetProgressForAnnounce 返回的公告用进度编号，写 GcArmyData+52Bh；脚本将该编号作为 GcArmyProgress 行号使用。当前表 0..19，无写入范围验证 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：需 GcArmyManager 及 Data 存在。新值与 Data+52Bh 字节不同才写入，并枚举 140 槽，对存在对象的 byte+9Bh OR 1Ch；相同值不触发本次刷新。原生 141A91080 明确注册 GcArmyGetProgressForAnnounce=141A916C0，后者直接返回本字节，缺少管理器/数据/事件对象时返回 0；不是依赖相邻模块推测。六份本机 CustomTalk 脚本已提取、反编译并保存字节码：教官 Officer.IsAnnounce 在编号 3/5/10/13/16/17 返回真；训练 Training.IsAnnounce 恰 8，招募 Interview.IsAnnounce 恰 4 且存在新候选。Training/Interview.IsTargetingPossible 再通过 GcArmyGetProgressValue 比较当前编号和 8/4 的资源进度值。原生 141A91750→140B18F00 按编号读取 GcArmyProgress 首 ushort，当前 20 行分别 100..119，证明本字段是可用于公告/可选资格的进度编号，不是布尔或 NPC 服装开关。包本身不立即播放通知、不直接推进招募/训练，也不把某个进度值直接等同分队军衔；具体剧情对白另由场景参数控制。p2..p8 及独立 target 未读，无回放样本。
