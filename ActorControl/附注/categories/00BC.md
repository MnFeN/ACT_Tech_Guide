# 188 / 0xBC SetCustomTalkIcons

[分类参数](../../README.md#category-00bc) · [附注索引](../README.md)

对话事件地图与姓名牌图标

- 分支地址：`0x140b441f7`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：地图图标、名称牌图标、Level 键及 CustomTalk 事件已核对。
- 用途：分别设置 CustomTalk 事件的地图图标及对象名称牌图标。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 地图 IconId：非 0 排队添加/更新标记，0 移除该事件在 p3 LevelId 下的地图标记 |
| p2 | 对象名称牌 IconId，完整 uint；按(LevelId,CustomTalkId)保存，0 删除该关联。CustomTalk 虚 209 按 GameObject.LayoutId 查询并直接返回图标 |
| p3 | Level 资源行号；地图坐标/半径来源，也是名称牌图标按 GameObject.LayoutId 匹配的键 |
| p4 | 完整 CustomTalk 事件 ID/资源行号，用于事件处理器查找及 CustomTalk 资源查询 |

说明：140C17480 维护 CustomTalk 地图标记与独立的名称牌图标关联 map+3F40。p2 非 0 保存(LevelId→deque(CustomTalkId,p2))，0 删除对应关联；140C12980 以事件 ID 及对象 LayoutId 精确查回 p2，无项返回 0。实际 CustomTalk 虚表 14241C5A0 槽 209=141A82E40，与固定 FFCS EventHandler.GetNameplateIconForObject 吻合：handler+460 bit7 且+461 bit0 未置时，虚方法直接以自身 EventId 和 GameObject.LayoutId+7C 取关联值。没有把 p2 当 bool、计数或任务进度。若+461 bit0 置则改走另一关联 map+3FE8，其他普通路径使用 handler 默认图标及条件；因此不能声称 p2 无条件覆盖所有 CustomTalk 对象。141CADA40 同虚方法的重写在特定内容已解锁时返回 61395，其他情况回落 141A82E40，独立支持图标身份。140B891B0 将虚 209 结果（有时经虚 228 重写）写交互选择界面图标项。p1/p2 分别控制地图和名称牌两类图标，p1=0 并不强制删除非 0 p2 关联。地图异步 CustomTalk 资源+F8 非空门槛、+F4 标签、Level 坐标/半径/地图与 territory，以及 Icon60483 额外隐藏位均保留原核对。handler 存在时 slot279=141A84090 按 LayoutId 置 GameObject.UpdateFlags bit3；slot280=141A84160 置 bit2，不把两个槽混同。p5..p8 及 target 未读，无回放。详见 CustomTalkMapAndNameplateIcons.md。

依据：`0x140C17480`、`0x140C17480 ASM EDX=0x72 CustomTalk sheet; queue=[p1,p3,p4]`、`sheet-map.json CustomTalk=114`、`0x140C13320 CustomTalk+F8 prerequisite/+F4 label;Level(p3),MapMarkerData.SetData Icon=p1`、`FFCS Map.CustomTalkMarkers+3ED0`、`0x140C17480 map[p3] list of(p4,p2) update/remove`、`client/customtalk-level-state-readers.json direct+3F40 scan`、`0x140C12980 returns p2 by CustomTalkId and GameObject.LayoutId`、`0x141A82E40 CustomTalk slot209 nameplate icon path`、`client/nameplate-slot209-consumers.json vtable14241C5A0 slot209/279/280`、`FFCS EventHandler.GetNameplateIconForObject virtual209`、`0x141CADA40 override returns Icon61395 otherwise calls base`、`0x140B891B0 slot209/228→SelectIconString item integer`、[CustomTalkMapAndNameplateIcons.md](../CustomTalkMapAndNameplateIcons.md)。
