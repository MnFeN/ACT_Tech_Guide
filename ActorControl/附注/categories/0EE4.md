## 参数与行为

- 用途：设置割草玩法的流程旗标并更新任务条目。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 0 设 flags bit2；非 0 设 bit3 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：flags 位于对象+41648；随后在任务类别 0 查类型 6 条目，写+120 为对象+96，+124 为 LiveMinigamesDynamicDefine7 值 4，标记 dirty。状态位对应成功/失败仍需发起端和 UI 消费者。 本机 LiveMinigamesTerritoryType[1,1]明确场地 1336，地名 5445“睡莲湖附近”；配套 Action45127/42039/42038 分别转圈割草/突进割草/大转圈割草，可确认为割草玩法。结果 Addon795 原生名 EasterMowingResult，仍不凭名称推定具体运营活动年份。 新增横幅消费者：初始化按 bit2 缓存 Agent+41，剩余倒计时回调在该值==1 时显示 ScreenImage1605“失败……”，否则 1603“时间结束！”。0EE4 本身不直接同步 Agent+41，也不清相反 bit；这些旗标亦用于初始化/流程交握，撤回仅称“结果状态”的过窄解释，不据同位关系强定每个 p1 值的场景模式名。
