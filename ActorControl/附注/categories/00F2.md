# 242 / 0xF2 StartPackedTargetMove

[分类参数](../../README.md#category-00f2) · [附注索引](../README.md)

启动目标点受控移动

- 分支地址：`0x140b4482d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与字段已核对。
- 用途：以打包目标点进入受控移动状态 7。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 高 16 位压缩 X，低 16 位压缩 Y 高度 |
| p2 | 高 16 位压缩 Z；低 16 位当前 callee 未使用 |
| p3 | 命令确认/序号，写 MoveController+1004 |
| p4 | 此分支未读取 |

说明：满足优先级时设状态 7、bit0x20 并设置目标；被更高状态阻止且为本机时发送命令 613(p3)。

依据：`0x14181F080`。
