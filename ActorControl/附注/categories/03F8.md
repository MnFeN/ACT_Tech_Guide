# 1016 / 0x3F8 ReopenHousingSettings

[分类参数](../../README.md#category-03f8) · [附注索引](../README.md)

住房设置菜单重开控制

- 分支地址：`0x140b3d88d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：零非零锁存、Outdoor 门控及部队住房菜单重开已核对。
- 用途：控制住房设置菜单重开的抑制锁存，必要时重开部队住房设置菜单。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 零/非零：0 置 Agent+268h 抑制锁存；非零清锁存，并仅在旧锁存 0 时重开部队住房设置菜单 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：只读取完整 32 位 p1 的零/非零，不区分任何非零结果码；p2..p8 与 target 均未读取。Housing Agent(120)的+268h 是这两路共享的抑制锁存：p1=0 写 1 并返回；p1 非零仅在原值 0 时执行菜单重开，随后无条件写 0。因而不能把 0 简单叫成功或等待，也不能把非零简单叫失败。主分支仍受住宅系统门控。 此类别额外要求 Outdoor 存在。141722F50 非零且旧锁存 0 时明确调用 141725C80(agent,8,1)。第三参数 1 选择 141725D70，标题 Addon6470 部队房屋；打开原生 Addon266 HousingSubmenu，正文 Addon6230 住房设置。8 进入该菜单 AtkValue[4]，菜单内部选项标识 8 的文案为 Addon6234 放弃土地，但未沿 ULD 消费验证 AtkValue[4]的最终焦点效果，故只记录固定 UI 参数 8，不声称此包直接放弃土地或弹出确认。原所谓 UI 回调 8 应修正为普通函数第二参数 8。

依据：`0x140E1C140 / 0x141722F50`、`client/housing-settings-addon-names.json`、`resources-housing-menu-response-text.json`、`resources-housing-other-settings-menus.json`、`0x141722F50 / 0x141722FA0 +268h byte`、`0x1417246C0 ASM preserves EDX/R8D/R9D and stack byte`、`0x141725C80 ASM tail arguments EDX saved selection / R8B local eligibility`。
