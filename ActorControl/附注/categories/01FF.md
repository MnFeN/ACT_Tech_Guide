# 511 / 0x1FF BeginMapUpdate

[分类参数](../../README.md#category-01ff) · [附注索引](../README.md)

开始地图事件更新

- 分支地址：`0x140b4177f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：开始分组重建未接任务/理符/行会令/幻卡/CustomTalk 及事件情境地图标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位保存为本轮更新 mask；bit0 未接任务，bit1 理符发布，bit2 行会令向导，bit3 幻卡，bit4 CustomTalk，bit5 事件情境标记（当前资源含广域交易商）；bits6..31 未选择其他已见分组 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：140C15430 保存 Map+1B38h，然后分别清理六组已存地图标记、取消未完成 Excel 查找，并对 CustomTalk/情境队列保留对象刷新请求。固定 FFCS Map 精确偏移 1B40 未接任务、1B88 理符发布、1BD0 行会令、3EC0 幻卡、3ED0 CustomTalk、3F78 GemstoneTrader，与当前原生各位选中列表一致。提交 0200 又以表索引 32 Quest/76 GuildleveAssignment/114 CustomTalk 互证 bit0/1/4，bit3 通知 Agent109 RecommendList+2A=1，而非直接 OpenAddon。bit5 当前使用 EventSituationIconTooltip991，只有 row3 有广域交易商文字；泛化定义为情境标记，不能把旧前置任务猜测或 FFCS GemstoneTrader 名称当成所有未来用途。140B7E510 只在 bit0 重置任务相关状态并写 QueryPerformanceCounter 毫秒计时。主伪码传给清理函数的 v17/v18 是未归一化寄存器临时量，不是网络 p3/p4。无回放。

依据：`0x140C15430 sixmaskgroups`、`0x140B7E510 bit0 timestamp`、`0x140C15E10 commitmask`、`0x140C9D140 RecommendList dirtybyte`、`FFCS Map offsets1B40/1B88/1BD0/3EC0/3ED0/3F78`、`sheet-map.json32 Quest/76 GuildleveAssignment/114 CustomTalk/991 EventSituationIconTooltip`、`0x140C136B0 situationmarkercallback`、`resources-map-event-situation-tooltips.json`、[MapEventUpdateGroups.md](../MapEventUpdateGroups.md)。
