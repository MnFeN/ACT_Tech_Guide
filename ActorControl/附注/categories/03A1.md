# 929 / 0x3A1 ShowActionEffectNumber

[分类参数](../../README.md#category-03a1) · [附注索引](../README.md)

技能追加效果飘字

- 分支地址：`0x140b43ea4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：两种飘字最终组件、数值与技能/状态日志参数已核对。
- 用途：显示技能追加效果数值飘字，选择普通或附感叹号样式，并可附带技能/状态百分比日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 必须等于 1 才处理 |
| p2 | 全 32 位非零选 ScreenLogKind55 数字样式；零选 Kind56 数字带感叹号样式，并额外显示 LogMessage3595 |
| p3 | p2 为零时作为 LogMessage3595 的 Action 行号（lnum1） |
| p4 | p2 为零时作为 LogMessage3595 的 Status 行号（lnum2） |

额外参数：p5 作为两种飘字的主数值（int32 显示）；p2 为零时也作为 LogMessage3595 的 lnum3，日志显示为百分比。p6..p8 及 target 未读。

说明：需要路由角色对象有效且 p1==1；不改 MountContainer 或 MountId，旧 Dismount 不符当前客户端。p2 只按全 32 位零/非零分支，未读其他位含义。p2 为零时 p3 为 Action 行号、p4 为 Status 行号，p5 为日志百分比；非零时 p3/p4 未用于这条飘字。140CD3900 对 kind55/56 都取 ScreenLogEntry+0Ch 主数值进入 NumberArray，不取技能名或状态名作为飘字正文。最终 AddonFlyText.CreateFlyText1414A0330 将该 int32 交 AtkTextNode.SetNumber，无除 100 或乘 100。初始化 1414A0D80：kind55 使用根节点 11，kind56 使用根节点 12；1414A1220 分别取组件内数字文本节点 4。实际 FlyText.uld 根 11 对应 component1011，仅数值与空正文；根 12 对应 component1009，另有文本节点 5 固定 Addon982“!”。所以可精确描述为普通数值/带感叹号数值的显示分支，不凭共用模板把 p2 附会为伤害、治疗、暴击或下坐骑类型。日志 3595 明确百分比，但飘字本身未加百分号，不将两种格式混同。该类别没有回放样本；结论来自当前原生分支、队列消费者、最终 Addon 和本机 ULD。
