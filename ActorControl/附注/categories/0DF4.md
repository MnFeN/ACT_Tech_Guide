# 3572 / 0xDF4 CosmicMechaProgressControl

[分类参数](../../README.md#category-0df4) · [附注索引](../README.md)

宇宙机甲进度与标记

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：九项子命令、显示消费者及跨区序列事件门控已核对。
- 用途：宇宙机甲：进度、贡献与地图标记子协议。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | WKSMechaEventData 行号 |
| p2 | 子命令 1..9 |
| p3 | 按 p2 解释：1 低 8 位阶段键；2 完整 DWORD 为跨区完成后自动序列请求抑制值（0 尝试，非 0 跳过）；3 进度当前值；4/9 标记键；5 贡献；6/7/8 目标文本格式参数，详见子命令表 |
| p4 | p2=3 进度上限；4/9 低 8 位标记类型；6/7/8 目标当前值；其它子命令未读 |

额外参数：p5 仅子命令 4/6/8 读取；p6 在已核对的此层未读取。

说明：命令 1：p3 低 8 位切阶段；2：p3 写 event+0x8280；3：p3/p4 写 EventProgress/Max；4：p3 标记参数,p4 低 8 位类型,p5==1 布尔；5：p3 写 Contribution；6：p3/p4/p5 写+0x8290/+0x8294/+0x8298；7：p3/p4 写+0x829C/+0x82A0；8：p3/p4/p5 写+0x82A4/+0x82A8/+0x82AC；9：按 p3 及 p4 低 8 位定位并移除地图标记。 机甲模块还会把未提前返回的事件向各 WKSMechaEvent 转发；对应事件要求 p1 匹配行号且 Flags&3==3。共用场景对象层/阶段槽已另导出。 WKS 默认链仅在相应模块加载时可达。 进一步显示消费者：141A2FA90 将 EventProgress/Max 经 141A6B580 换算后写类型 5 Todo 当前值，上限 FFFFFFFF；141A2FB40 把 Contribution 写类型 2/子类型 0 Todo 当前值，子类型 2/3 则把+829C 作为文本格式参数、+82A0 作为当前值。141A301E0 给类型 6 Todo 按子类型 1/4 选+8290/+82A4 作为文本参数，+8294/+82A8 作为当前值，+8298/+82AC 作为上限。不能仅因 FFCS 把+829C 声明 bool 就将完整 DWORD 网络值截成 bool；实际格式读者取完整 DWORD。+8280 的实际用途进一步闭合：WarpInfo.Update 区域收尾 140860060→140604DE0→140ECE800→141A2E3B0，在区域切换 byte 非 0 及模块／事件／阶段 5/6/7 门控满足时，值 0 才请求当前事件的角色 SequentialEvent，任何非 0 均抑制本次自动请求。采用客户端用途描述，不将该字段命名为剧情已播放或服务器完成状态。详见 MechaAreaTransitionSequenceGate.md。详见 MechaProgressDisplayConsumers.md。
