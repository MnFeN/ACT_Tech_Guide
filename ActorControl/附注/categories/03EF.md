# 1007 / 0x3EF RemoveExteriorHousingItem

[分类参数](../../README.md#category-03ef) · [附注索引](../README.md)

移除庭具应答

- 分支地址：`0x140b3d6e8`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：索引打包、零/非零结果及布局轮廓高亮和选择收尾已核对。
- 用途：庭具移除结果：成功清除缓存和场景对象，失败清除操作高亮与选择状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low8 为合并庭具槽号，bits16..23 为 OutdoorHouseUnit；bits8..15 及最高 byte 未读。不能把 bits16..23 写成第二个 byte |
| p2 | 完整 uint32 结果；0 清理该家具缓存及场景对象，非 0 保留记录/对象并清除临时轮廓高亮及当前操作选择；客户端不细分非 0 原因 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：Outdoor 存在且 division 匹配才处理。HouseUnit 普通/30 求 division、80h/81h 用低 7bit。零值分支经 140E23270 映射全局缓存索引，index<1462 才清记录；本分支没有 slot<80 检查。非零分支另要求 HouseUnit 普通<60 或 80h/81h 且 slot<80，再 140E280B0(this,houseUnit,slot)取家具；该 helper 旧原型漏了第三参数，已据 140E1BBEC 显式 R8D=slot 修复。布局对象存在则 1406F4560(0,layout)清临时状态，继而 1406F45E0 结束当前布局操作；不是从服务器重新生成模型。140E26540 清待处理指针队列、场景对象和缓存记录，置 HousingManager+E0h；对于记录首 ushort54..56，先额外从索引关联 map 清项。 本轮向图形对象核对：1406FE730 将 SharedGroupStainInfo+C0 置 0、+C4 bit1 置脏；1406FE7E0 确认资源已加载才调用 ILayoutInstance vf59(0,1)，未就绪则置 LayoutManager+106h 延后处理。SharedGroup 构造 1406FC730 写 vtable14217FFA0，vf59=140703010 递归子实例；BgParts 实际 vtable142181C00（140737340 分配 0x68 并写入）vf59=14073F400，将 GraphicsObject+89h 高 4 位清零，保留低 4 位 LoadState，同时将+88h bit5 设 1。固定 FFCS DrawObject 明确+89h 高 4 位为 OutlineColor，ObjectHighlightColor.None=0，因此这是轮廓高亮复位，并非把实际染料索引清 0。14072AFD0 还通知注册对象、清+3h 选择/锁定位及 controller+18h 当前操作对象指针，并重置控制器内部 vector 尾；不是删除家具重建。非 0 在本消费者没有独立错误码分支，故文档只给“未移除并收尾”，不补不存在的错误原因枚举。
