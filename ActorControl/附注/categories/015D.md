# 349 / 0x15D SetMateriaMeldPose

[分类参数](../../README.md#category-015d) · [附注索引](../README.md)

魔晶石镶嵌姿态

- 分支地址：`0x140b3c0a3`。
- 回放观察：28 次；包族 {"ActorControl": 28}。

## 参数与行为

- 核对状态：寄存器、64 位拼接及武器加载已核对。
- 用途：进入/恢复采集职业镶嵌相关姿态与武器模型。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 第 1 个 64 位 WeaponModelId 低 32 位 |
| p2 | 第 1 个 64 位 WeaponModelId 高 32 位 |
| p3 | 第 2 个 64 位 WeaponModelId 低 32 位 |
| p4 | 第 2 个 64 位 WeaponModelId 高 32 位 |

说明：按 p1|(p2<<32)、p3|(p4<<32)拼接。Character.Mode 设 7/1；满足 ClassJobCategory33 且非潜水等条件时分别向武器槽 2 和 1 加载模型，并使用时间轴 236/237。初始伪码误把两个模型截成 int，隐藏了 p2/p4。

依据：`0x140B3C087..0x140B3C0C1`、`0x1418EF420`、`Client.Game.Character.DrawDataContainer.LoadWeapon`。
