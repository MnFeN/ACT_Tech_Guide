# 318 / 0x13E SelectType8GatheringPoint

[分类参数](../../README.md#category-013e) · [附注索引](../README.md)

选择特殊采集点对象

- 分支地址：`0x140b3fa7e`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Type8 生成键、signedbyte 禁用边界与次数恢复已核对。
- 用途：选择 Type8 采集点对象并恢复剩余采集次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | low8 写 handler+305，按 signedbyte 与 ObjectSpawn payload+2E 的 unsignedbyte 比较；0..127 可匹配，128..255 不能匹配任何对象键 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140E8B160 只有 Type8 才写+305 并将 RemainingCount 恢复为 Count；其他 Type 无操作。141757D50 传入 Impl+10 查询 DWORD，来自 Kind6 ObjectSpawn payload+2C，故 BYTE2=payload+2E，不是已证实的天气/时段枚举。ASM140E8B894 movsx EAX,[handler+305]，140E8B89E movzx ECX,BL，再 cmp EAX,ECX：p2 低 byte 最高位置位时为负，query 键永远 0..255，必不匹配；特别 FF 保留禁用/无选择效果。即便不能匹配，setter 仍恢复次数，不把它简写为删除对象。Setup 按 Impl+16 即 payload+32 初始化+305，初值先设 FF。Type8 本机 12 行全 Territory901 是资源范围事实，不根据所在地给键贴天气名字。p3..p8/target 未用，其他资格仍需通过。详见 GatheringSpawnSelectorControls.md。
