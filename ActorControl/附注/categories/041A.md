## 参数与行为

- 核对状态：已核对。
- 用途：住宅交流簿子协议：房主留言、访客留言、页面失败、删除、默认公开设置、单条公开状态及点赞应答。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位子命令：0 编辑房主留言应答；2 发表访客留言；3 取页失败应答（本路由数据指针固定 null）；4 删除留言；5 得到批准前非公开的默认设置；6 切换单条留言公开状态；7 点赞。其他值无分支 |
| p2 | 完整 32 位结果，0 成功；非零不执行对应原生数据更新。UI 并非所有操作都同样处理：通用错误 2 触发关闭，其他码通常保留窗口；子 6 无论结果先翻转行公开标记，子 7 始终显示现有缓存 |
| p3 | 子 0：房主留言日期时间 Unix 秒时间戳，非 0 才用 Addon6896 显示；子 2：新访客留言 Index；子 4：完整 32 位非零转 bool，可否再次发表当天留言（成功写缓存，UI 回调也接收）；其他子命令未读 |
| p4 | 子 2：访客留言 Timestamp，完整 32 位写记录；其他子命令未读 |

额外参数：子 2 读 Self p5/p6 完整 32 位非零转 bool，分别 HasData 和 IsInSameFreeCompanyAsOwner；p7/p8 及独立 target 未读。其他子命令不读 Self p5/p6

说明：已打通发起 Agent、事件处理、GameMain1155..1158、应答和 UI 资源。子 0 发独立 219 包更新 192byte 房主留言文本，p3 经 SetTime 宏 07 按 Unix 秒格式化；子 2 发独立 220 包，成功仅 CurrentPage0 时插入本机姓名/ContentId/HomeWorld 与既有编辑文本。子 4 删除目标 Index 来自既有待删除缓存+7ACh 而非 p3；成功标记六条中匹配记录 WasDelete 并显示 6906 留言已删除，p3 存+6E9h 并转 Agent+617，false 阻止再留言并提示 7137 每日只能 1 次。子 5 发 1156 的 bool 来自交流簿设置 6916/6918/6919，设置在发起时已本地修改，回包不再直接写 bool。子 6 发 1157(index,newPublic)，UI 无论结果先翻转选中行 bit0 再调用错误处理，不能写成仅成功翻转。子 7 成功 Likes+1、+6EAh 剩余点赞次数非 0 才减 1，UI6911 明确剩余点赞次数。子 3 函数在结果 0 时会解引用数据指针，但此 ActorControl 固定传 null，故只可确认非零错误应答；完整页数据来自另一收包路径，不能把 0/null 描述为有效空页。通用错误 2 仅有关闭行为证据，不猜服务端原因。新 Lua 扫描 5402 Quest/952 可读 CustomTalk 未命中 GuestBook 名称，不作为无脚本证明。
