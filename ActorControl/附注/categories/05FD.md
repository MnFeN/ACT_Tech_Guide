# 1533 / 0x5FD RemoveTargetHudStatus

[分类参数](../../README.md#category-05fd) · [附注索引](../README.md)

移除目标 HUD 补充状态

- 分支地址：`0x140b3a1e8`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：删除 HUD 按目标实体补充显示的状态缓存项。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 Status 表 RowId |
| p2 | 目标 EntityId；与 p1 一起精确匹配十槽缓存，不作通配 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：140BE3BA0 匹配 StatusId 及目标 EntityId 后清 StatusId 与剩余 float，将目标 EntityId 置 E0000000；只删除首个匹配，不直接更改角色 StatusManager。缓存由 HudStatus.Status.ProcessStatuses 合并到界面状态列表。常规状态移除逻辑 1408A65E0/66F0/6820 也可调用此清理器；具体调用条件包括 StatusManager 找不到相应条目或针对本机／资源条件的分支，不能将该包描述为对所有来源的状态驱散。E0000000 在本清理器中也是精确比较值，不是自动通配。

依据：`0x140BE3BA0 exact pair match and clear`、`0x140FDBA60 HUD extra status merge`、`0x1408A65E0 / 0x1408A66F0 / 0x1408A6820 status-removal fallback consumers`、[ExtraStatusHudCache.md](../ExtraStatusHudCache.md)。
