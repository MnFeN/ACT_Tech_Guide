## 参数与行为

- 核对状态：对象虚表、SharedGroup 索引及毫秒快进补偿已核对。
- 用途：对包头事件对象播放通用时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | SharedGroup 本地时间轴选择索引 0..15，经 TimelineIndices 映射；不是 ActionTimeline 资源 ID |
| p2 | uint 播放后的快进补偿时长，单位毫秒；非 0 时换算 p2*30/1000 到调度器帧数并推进 |
| p3 | 非零时受 EventFramework 状态检查抑制 |
| p4 | 此路径未读取 |

说明：ObjectKind7 EventObject 与 12 HousingEventObject 共用 GameObject 虚槽 20=140898830；要求场景/布局就绪并索引有效。SharedGroup.PlayTimeline 1407060B0 经 TimelineIndices 与 TimeLineContainer 定位实例，尚未创建时缓存索引与 p2，已创建时 1407520F0 播放后将 p2 转 float 乘 30 除 1000，交 1418CB010→SchedulerTimeline.UpdateBanner 推进，最终命令将帧数截成 int。零不额外推进。并非 float 位模式、秒数或时间轴 ID。p3 非 0 时 EventFramework 门控可抑制操作；对象不存在不执行。详 EventTimelines.md。
