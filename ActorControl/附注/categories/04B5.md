# 1205 / 0x4B5 SetTripleTriadNpcDefeated

[分类参数](../../README.md#category-04b5) · [附注索引](../README.md)

幻卡 NPC 胜利记录

- 分支地址：`0x140b40bac`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：设置是否曾在幻卡中战胜指定 NPC 的记录位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 TripleTriadResident 行号，入口 2293762..2293905；行内 Order ushort 映射到 17-byte 胜利位图，FFFF 及超范围位索引跳过 |
| p2 | 完整 32 位按 0/非 0 转 bool；非零置曾获胜位，0 清位 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：当前 getter140C4BE20 由固定 FFCS IsTripleTriadNpcBeaten 签名唯一匹配，实际使用与 setter140C4BD90 完全相同的行号范围、Order、17-byte 边界和 LSB 位序。固定源码说明为“beaten once”。独立 NPC 图标消费者 140E68580：资格/开放时段通过后，未曾战胜返回图标 71101；曾战胜再检查最多 4 个掉落卡牌是否已解锁，仍有未获得卡返回 71102，全部卡已解锁返回 0。因此该位不是全部奖励收集标志，也不是可挑战资格位。140E687F0 也直接封装此 getter。当前本机 TripleTriadResident 有 146 行，其中 133 个有效 Order0..132；17bytes 原生容量可覆盖 0..135，不能套固定 FFCS 旧 BitCount132 删掉最新位 132。setter 完成后仍通知 EventFramework20000h，即使 key/Order 无效而未改位，也不能称完全无副作用。p3..p8 及独立 target 未读，现有回放无样本。

依据：`0x140C4BD90 setter`、`0x140C4BE20 currentFFCS signatureunique match`、`FFCS UIState.IsTripleTriadNpcBeaten commentbeatenonce`、`0x140E68580 icons71101/71102 andindependent cardunlock loop`、`0x140E687F0 getterwrapper`、`resources-tripletriad-resident-all-raw.json`、`resources-tripletriad-resident-schema.json`、`tripletriad-resident-win-bit-map.json`、[TripleTriadNpcWinsAndRoomFlag.md](../TripleTriadNpcWinsAndRoomFlag.md)。
