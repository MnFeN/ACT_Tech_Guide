# 256 / 0x100 SetMountBardingModel

[分类参数](../../README.md#category-0100) · [附注索引](../README.md)

坐骑鸟甲模型

- 分支地址：`0x140b39ca0`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与结构/资源已核对。
- 用途：设置陆行鸟坐骑的一件鸟甲模型。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 槽选择 0 头、1 身体、2 脚，其他忽略 |
| p2 | 装备模型基础 ID，经 EquipmentModelId 构造后加载 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：须 Mount.MountId==1，MountObject 存在。映射 DrawData 槽 0、1、4，染色等构造参数固定 0；并非一般玩家身上的装备更新。

依据：`0x140B386F0 / FFCS MountContainer.cs`。
