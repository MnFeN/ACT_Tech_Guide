# 192 / 0xC0 SetQuestRedoChapterNotice

[分类参数](../../README.md#category-00c0) · [附注索引](../README.md)

新游戏加章节解锁提示

- 分支地址：`0x140b442c4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：任务 ID 匹配、一次性章节开放提示及未被模板引用的附加值已核对。
- 用途：登记 New Game+ 新章节开放提示的触发任务。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 Quest 短编号；后续任务收尾收到同编号时触发“追加新章节”提示 |
| p2 | 低 16 位提示附加值，保存+62 并作为 Log1647 参数；当前本机模板无占位，文字不消费该值 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：写 manager+60/+62。140DF36F0 的任务事件收尾路径调用 140EB3B30(QuestId)，只有与+60 匹配才用+62 构造 Log1647 并清这两个 ushort，避免重复提示。Log1647 是“昔日重现模式追加了新的章节。”且当前 SeString 没有参数占位，所以不能把 p2 无依据称为章节 ID。此包只登记提示触发，不直接把全部章节解锁。p3..p8 未读。

依据：`0x140EB27E0`、`0x140EB3B30 manager+60 compare questId; +62 logparam; thenDWORD+60=0`、`0x140DF36F0 Quest handler+2E0 QuestId→140EB3B30`、`resources-questredo-fields.json Log1647 raw has no macro`、`0x140EB27E0 ushort pair setter`。
