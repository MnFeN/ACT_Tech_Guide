# 3216 / 0xC90 SetIslandVillageAppearance

[分类参数](../../README.md#category-0c90) · [附注索引](../README.md)

无人岛村落外观

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛小屋并统一村落外观。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 CabinLevel |
| p2 | 低 8 位 CabinGlamour，同时写 Paths/Grounds/SlopesGlamourId |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：不等于 0xC8F：本条把三个村落外观 byte 也改为 p2。

依据：`0x140EA9730 / case3216 / 0x140EADF10 / 0x140EACFE0`。
