# 3638 / 0xE36 SetCosmicMissionFlags

[分类参数](../../README.md#category-0e36) · [附注索引](../README.md)

宇宙任务旗标

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：本机分支与结构已核对。
- 用途：宇宙探索：更新任务 MissionFlag。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位职业索引 |
| p2 | 低 16 位 WKSMissionUnit ID |
| p3 | 32 位 MissionFlag |
| p4 | 本消费者未读取 |

说明：依次查该职业 Provisional/Sequential/Critical 列表，再全 11 职业各 3 个 MasterMissions；匹配后写记录+4。 路由：WKSManager 默认模块链，需对应模块已加载。

依据：`0x141A6F260`、`FFCS WKS/WKSManager.cs`。
