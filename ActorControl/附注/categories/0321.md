# 801 / 0x321 GearSetEquipMsg

[分类参数](../../README.md#category-0321) · [附注索引](../README.md)

完成套装装备响应，按本地逐槽结果提示并更新套装状态

- 分支地址：`0x140b3c2d7`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：零基索引、100/254 特殊值、本地结果来源、日志及缓存消费者已核对。
- 用途：完成套装装备响应，按本地逐槽结果提示并更新套装状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 套装索引，普通索引为零基；100 为恢复原装备，254 为最强装备特殊结果 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：只对本机/回放观察角色处理。14087B920 还接收本地 142AD8444 的低 byte 与 142AD8445 开始的 14×5 逐槽结果数组；不是从 p2/p3 读取两个 byte。普通套装按 GetGearset 索引取得名称，显示编号 p1+1；依据逐槽标志优先选择缺必要装备 761、不可装备 1906、魔晶石/以太属性差异 1908、投影差异 1900、染色差异 1901 或成功 755。p1=100 使用恢复原样的独立日志 764/1907/1909/1910/1902/758；p1=254 在本地完成 byte 非 0 时根据逐槽失败标志提示 7985，否则 7980“换上了…最强装备”，随后通知 1407F2820。完成 byte 为 0 且 p1=254 直接返回。普通/100 再进入 1407F2AD0：有效普通索引须小于可用套装数，100 特殊处理，更新本地套装/槽结果、相关头部武器面罩耳朵设置及 GearSet Agent98 刷新；不是单纯显示消息。p2..p8 未读。

依据：`0x14087B920`、`0x14087B920 allbranches andlocal14x5flags`、`0x1407F2AD0 indexvalidation/cache/config/GearSetAgent98`、`resources-gearset-apply-messages.json`。
