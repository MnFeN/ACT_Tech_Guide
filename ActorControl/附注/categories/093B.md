# 2363 / 0x93B ShowItemGainWithTreasure

[分类参数](../../README.md#category-093b) · [附注索引](../README.md)

物品与宝物提示

- 分支地址：`0x140b45188`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：显示获得物品日志并按类型显示触媒、水晶或宝物提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位选择额外 UI：0 无标题物品提示；1 已获得触媒；2 获得水晶；3 获得宝物且不带数量；4..6 获得宝物并传数量。其他值仅走共同获得日志 |
| p2 | 完整 32 位物品 ID；共同日志按 Item 取名，额外 UI 经普通 Item/特殊 EventItem 分流，不是统一的任意奖励资源行 |
| p3 | 完整 uint32 获得数量；先用于共同日志，0 时不显示任何额外物品 UI。类型 0/1/3 的额外提示数量强制 0，2/4..6 普通 Item 提示保留数量；EventItem 专用提示忽略数量 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：141780D00 要求 item 非 0，且 quantity 非 0 或 PlayerState.HasAddictionRestrictions(+78h)为真；当前 PlayerState 基址 142ADF3B8，故 byte142ADF430 对应此字段。quantity uint32<=1 用 Log2071，否则 2072；本地参数 1 为 Item 编号、参数 2 为数量（仅多件路径显式加入）。完整 SeString 边界已解码，普通 gnum51=0 为获得了 Item 及数量，gnum51=1 走防沉迷收益减半，其他走无法获得收益；此函数未将传入数量再除 2。HasAddictionRestrictions 门控与模板 gnum51 是独立存储，未声称它们始终数值相同。不是交付或扣除物品，不直接改变库存。 141781CE0 先无条件调用共同日志，然后 quantity 非 0 才 switch。类型 0 用标题 0，1 经 140BCBE70 标题 8370 已获得触媒，2 标题 8348 获得水晶，3..6 映射 140BCBEF0 类型 1..4，两种宝物标题 13872/16675 当前同文。不能将 p1=4/5/6 强分三种业务奖励，当前客户端显示相同；本包只做表现。

依据：`0x141781CE0 commonlog beforetypeswitch`、`0x140BCBE70 Addon8370`、`0x140BCBEF0 treasuremodes`、`0x140BCBD40 Item/EventItem`、`0x140BCC080 asyncquantity`、`0x140BCBB80 itempopup`、`resources-dynamic-event-reward-titles.json`、`resources-dynamic-event-reward-decoded.json`、[ContentTreasureItemNotice.md](../ContentTreasureItemNotice.md)、[DynamicEventItemRewardNotices.md](../DynamicEventItemRewardNotices.md)。
