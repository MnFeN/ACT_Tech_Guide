# 316 / 0x13C SetSpearfishingSpecialPoint

[分类参数](../../README.md#category-013c) · [附注索引](../README.md)

海洋之相特殊刺鱼点

- 分支地址：`0x140b3faf3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Type6 限制、全部资源种类与海洋之相探知消费者已核对。
- 用途：设置海洋之相可发现的特殊刺鱼点总/剩余次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 低 8 位同时写 Count 及 RemainingCount |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：只有 GatheringPoint.Type==6 写 Count 和 RemainingCount 为 p2low8，其他类型忽略。已枚举本机全部 5857 行，Type6 仅 12 行、8 种 Base，所有 Base.GatheringType=5；140E8B830 对此类要求 Status1173 海洋之相，而常规刺鱼用 1166 鱼群测定。故明确为特殊刺鱼点，不是所有采集点通用恢复。p3..p8 未读。

依据：`0x140E8B140`、`resources-gatheringpoint-all.json all12 Type6 rows`、`resources-gathering-special-types.json all8 bases GatheringType5,Status1173/1166`、`0x140E8B830 Type6 picksStatus1173`。
