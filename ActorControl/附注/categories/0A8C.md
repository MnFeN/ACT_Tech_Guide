## 参数与行为

- 核对状态：动态事件对象、结果分支及报酬提示已核对。
- 用途：动态事件成功/失败结果横幅与贡献不足提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint DynamicEventContainer.Events 槽索引；数组 16 项，入口无范围检查 |
| p2 | 非零显示完成结果横幅，0 显示失败结果横幅 |
| p3 | 仅 p2 非零时判断：0 追加 Log9633 贡献不足无法取得报酬；非零不显示该提示 |
| p4 | 主分支及本消费者未读取 |

额外参数：Self p5..p8 未读取。

说明：141AB9790 选择 DynamicEventScreenImage 或容器按 EventType 配置的 ScreenImage，p2 非 0 取结果槽 1，0 取结果槽 2。不是修改动态事件状态字段；本批 38 条 p2/p3 均 1。slot+92 的资源可覆盖默认横幅，缺表行会提前返回。
