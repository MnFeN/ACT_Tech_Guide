角色经验获得提示

- 分支地址：`0x140b38b8c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：角色路由、经验值及 p3 百分比模板条件已核对。
- 用途：显示指定角色获得经验的提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 获得经验角色的 EntityId，须能找到 BattleChara |
| p2 | 经验值；0 时第三模板参数固定 0 |
| p3 | 经验加成百分比的显示值；p2 非零且此值非 0 时模板显示(+n%)，p2 为 0 时强制传 0 |
| p4 | 此路径未读取 |

说明：按 p1 EntityId 查 BattleChara，找到才 AddLogMessage3Params(588,角色,0,p2,p2? p3:0)。本机 Log588 raw 宏中 E4 E804 01 表示第三局部整数==0，此时显示空串，否则显示“(+n%)”；顶层另按防沉迷状态选择收益文本。这里是经验获得提示，不负责实际修改角色经验或计算加成。p4..p8 未读。

依据：`0x140B386F0 / LogMessage588`、`resources-notebook-messages.json Log588 E804 third lnum /(+n%) conditional`、`https://github.com/NotAdam/Lumina/blob/master/src/Lumina/Text/Expressions/ExpressionType.cs E4=Equal;E8=LocalNumber; verified 2026-11-16`。
