# 1600 / 0x640 InitializeSpectator

[分类参数](../../README.md#category-0640) · [附注索引](../README.md)

初始化观战

- 分支地址：`0x140b438ae`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：模块与构造字段明确，参数业务待查。
- 用途：初始化观战管理器。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Spectator 资源行号 |
| p2 | 观战告警基准总时长，uint32 逻辑秒，写+98h；除 60 选择阈值组，阈值<=总时长/2 时才输出分钟提示 |
| p3 | 低 8 位初始阶段状态，写 SpectatorManager+90h；0648.p2 随后覆盖同一字段。20/21、22、23 分别有音乐/计时消费者，完整阶段枚举仍待查 |
| p4 | 32 位写管理器+148 |

说明：已有管理器先析构，新建 1248byte 对象并初始化观战子对象；p2/p3/p4 业务命名尚需 Spectator 字段/虚函数核对。 本轮由 Update 和 LogMessage1532 确认 p2 为秒单位的总时长基准；0643/0647 另同步剩余秒。p3 模式 byte 与 p4 属性仍需独立核定。 进一步确认 p3 为 0648 同一阶段 byte 初值。p4 除了非零抑制进入 21 时的开战提示，还由事件 handler 的 141787DB0 按非零查询，并由 141787DE0 以完整 DWORD 作为一个参数送事件场景 0 初始化，0xF8438EFB 为 SceneFlag 而非函数 hash；不能将 p4 仅定义为 bool 提示开关。真实 handler 构造 141787CB0 安装 1422D5C30，事件 ID 高 16 为 003F。详见 SpectatorInitialStateAndScriptValue.md。 实况 Self 成功录制后，回放外层另对 Header.Flags 所在+70h 作 QWORD OR 8，不读额外参数；这不替代主观战初始化处理。 详见 ReplayDirectorChapterSideEffects.md。

依据：`FFCS SpectatorManager.Initialize / 0x1417889F0`、[SpectatorTimeAndWarnings.md](../SpectatorTimeAndWarnings.md)、[SpectatorInitialStateAndScriptValue.md](../SpectatorInitialStateAndScriptValue.md)、`client/spectator-small-accessors.json 67 methods`、`141787CB0 ctor /141787DB0 bool query /141787DE0 fullDWORD scene argument C and ASM`、`140B573F0 forwards sceneId/SceneFlags/uint args to EventFramework.ProcessInitializeScene`、`140B54150 sets EventType15 EnterTerritory /EventHandler virtual20`、[ReplayDirectorChapterSideEffects.md](../ReplayDirectorChapterSideEffects.md)、`client/replay-outer-catalog.json：0640附加作用`。
