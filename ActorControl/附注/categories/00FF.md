# 255 / 0xFF EquipBarding

[分类参数](../../README.md#category-00ff) · [附注索引](../README.md)

设置陆行鸟装甲槽

- 分支地址：`0x140b39c93`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置陆行鸟装甲槽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 部位索引：0 头、1 身体、2 脚；原生要求<3 |
| p2 | BuddyEquip 行号，低 8 位保存，要求<112 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：走共享 UI 刷新标签，不在此主分支直接给角色重建模型。

依据：`0x140C217A0`、`FFCS CompanionInfo.BuddyEquipRowIds`。
