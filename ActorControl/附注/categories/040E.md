# 1038 / 0x40E HousingOrchestrionControl

[分类参数](../../README.md#category-040e) · [附注索引](../README.md)

住宅管弦乐琴控制

- 分支地址：`0x140b3dd3b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：住宅管弦乐琴播放/停止子协议。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low16 管弦乐曲 ID；high16 子命令 0 界面结果、1 播放、2 停止 |
| p2 | 子命令 1/2 操作者 EntityId |
| p3 | 子命令 1：high16 X、low16 Y，均 u16*2000/65535-1000 米 |
| p4 | 子命令 1：low16 Z；bits16..19 播放模式（0 无列表上下文、1 顺序、2 随机、3 单曲）；bits20..23 通知类型；byte3 为当前播放列表零基槽号，正常 0..7，非播放 mode |

说明：子命令 0 按曲 ID 是否非 0 处理 UI，不读其余参数；子命令 2 只使用曲 ID 与操作者。播放可暂存到 Indoor 后延迟执行；无 Indoor 时仍处理子命令 2 停止。坐标经 float 数组送异步曲目加载。 新增 UI 独立消费已纠正旧命名：bits16..19 写 142AF9124，由 140E49850 读取，是播放模式 1 顺序/2 随机/3 单曲；byte3 写 142AF910A，由 140E49930 读取，141071DB0 以该值和 0..7 槽号比较、同时匹配曲 ID，为当前播放条目置高亮掩码 0x04。因此两个字段不能倒置，也不是列表 ID/列表大小。模式 0 在列表 UI 中抑制当前播放高亮；当前无曲目或无列表上下文时，UI 将槽按 FF 处理，不表示收包只允许 FF。通知类型 2 使用 Log3433，其余类型再按操作者是否本机/有效以及播放模式选择 3463/3474/3471 等提示。

依据：`0x140E1D630 / 0x140E38B80 / 0x140E499A0 / 0x140E49DA0`、`0x140E499A0 fixedprototype playbackMode/playlistSlot`、`0x140E49850/140E49930 globalreaders`、`0x141071DB0 slot0..7 andsongmatch ->highlight4`、`0x141070080/14106F6F0 playbackmode text enum`、`resources-orchestrion-playlist-modes.json`、[OrchestrionPlaybackModeAndSlot.md](../OrchestrionPlaybackModeAndSlot.md)。
