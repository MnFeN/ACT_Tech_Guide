# 3586 / 0xE02 PlayMechaIndicatorTimeline

机甲指示器时间轴

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：三槽 EntityId 来源、布局时间轴及全部参数已核对。
- 用途：对机甲场景三槽指示器所引用的对象播放布局时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint WKSMechaEventData 行号；外层匹配当前事件 |
| p2 | 完整 uint GameObject.PlayTimeline 索引；EObj 路径为 SharedGroup 布局时间轴索引，不是 ActionTimeline 资源行号 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：外层 141A6ACC0 要求 p1 完整 uint 与当前 WKSMechaEventData.RowId 匹配、Flags 低 2 位均置位，且模块存在；转交 event+70 场景控制器。7 个当前阶段对象虚 9 均 return0，不另消费本包参数。p5..p8 及 target 未读。 场景控制器+1880 为三槽指示器，每槽 56 字节，+1890 起的三项 EntityId 由 141C5B170 从 record+10 复制；record+10 由 141C5C830 直接取 GameObject.EntityId+78，map+40 也以该 EntityId 为键（141C555D0 注册、141C540E0 移除）。0E02 遍历三槽，键非 0 且 map 匹配、record+22 有效、对象非空时调用 GameObject 虚 20(p2,0)，不按 p2 截 16、不用 p3/p4、不选择单个槽。固定 FFCS GameObject.PlayTimeline 亦为虚 20(uint,uint)，ReactionEventObject 具体实现 141C42E20 转 SharedGroup.PlayTimeline；本构建资源类型 7 共 18 行、BaseId2014717“野外探查器”，其第一组指示器虚表 142458D28 读取 WKSMechaFieldSearcher，第二组 142458D50 才读取 WKSMechaTank。调用结果被忽略，分支固定返回 0 并不代表播放失败。完整补证 MechaSelectedTimelineAndBindSet.md。

依据：`0x141C54220`、`client/141C5C830_sub_141C5C830.asm EntityId+78→record+10`、`client/141C555D0_mecha_scene_selection.c EntityId map insertion and bind restore`、`client/141C540E0_mecha_scene_selection.c EntityId map removal`、`client/141C5B170_sub_141C5B170.c recordEntityId→three slots`、`client/141C590D0_sub_141C590D0.asm Timeline5/6 and set update`、`client/wks-mecha-pollen-plant-timelines.json handler indices5/6`、`resources-wks-mecha-object2015370.json EObjName and ExportedSG43947`、`resources-wks-mecha-selected-object-and-overlays.json EObj2014717野外探查器`、[MechaSelectedTimelineAndBindSet.md](../MechaSelectedTimelineAndBindSet.md)、`client/mecha-selection-vtables.json actual first FieldSearcher and second Tank tables`。
