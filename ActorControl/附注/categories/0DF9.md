# 3577 / 0xDF9 SetCosmicMechaEntryWindows

[分类参数](../../README.md#category-0df9) · [附注索引](../README.md)

机甲报名与支援传送窗口

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：完整子命令、报名/地面传送时间与资格消费者已核对。
- 用途：更新当前机甲事件的报名预告、报名开放及地面支援传送窗口。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 不用于选择模块当前事件；后续事件层比较但此类别无附加动作 |
| p2 | 完整值 1/5：报名预告起止；2/6/7：开放报名；3/8：开放地面支援传送；4 及其他值无相应模块字段操作 |
| p3 | 1/5 写 PilotRegistrationStartTimestamp+8268 完整 DWORD；3/8 写 TeleportStartTimestamp+8270 完整 DWORD；其他子命令未读 |
| p4 | 仅 1/5 写 PilotRegistrationEndTimestamp+826C 完整 DWORD；其他子命令未读 |

说明：模块 141A2D7F0 要求 ready，直接更新 CurrentEvent，不受 p1 行号筛选；全部 p2 按完整 int 先匹配 1..8，257 不能当 1。1/5 OR 事件 Flags80，写报名起止；2/6/7 OR PilotRegistrationOpen100，其中 2/7 在 WKS 功能 8 解锁且 manager+EC8 bit6 为 1 时显示 Log10830，6 不显示；该日志门控不要求 CurrentEvent 存在，重复包可再次提示。3/8 OR GroundSupportTeleportOpen200 并写+8270；4 及其他无此层动作。只 OR 不清旧旗标，不校验时序。报名截止由 141A6B4F0 按 now<+826C 判定；地面窗口 141A6B530 要求+8270<now<+8260，flag 只是门控之一。p3 报名开始字段与固定 FFCS 命名匹配，当前未发现直接显示消费者，保留存储字段边界；不影响完整参数确定。默认事件转发中的 scene default/7 阶段虚 9 无新增读取，p5..p8/target 未用。另有 141A30E40 接受 byte 子命令的独立路径，但不能把其截断规则套到本包完整 int 外层。详见 MechaRegistrationAndTeleportPhases.md。
