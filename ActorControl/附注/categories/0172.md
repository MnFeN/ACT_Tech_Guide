# 370 / 0x172 MarkTemporaryInventoryItem

[分类参数](../../README.md#category-0172) · [附注索引](../README.md)

标记临时库存物品

- 分支地址：`0x140b3b6bd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与结构已核对。
- 用途：标记与指定 Item ID 匹配的临时库存记录。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位 Item ID，与 InventoryManager.UnkInventoryItem0/1 的+8 字段比较 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：匹配第一条设+0x36B4 低 byte，匹配第二条设其高 byte；两条 Item 副本在+0x3620/+0x3668。

依据：`0x140B386F0 / FFCS InventoryManager.cs`。
