# 1049 / 0x419 HousingStoreroomStatus

[分类参数](../../README.md#category-0419) · [附注索引](../README.md)

刷新家具/庭具仓库状况，以及搬迁和内部整装空间条件

- 分支地址：`0x140b3df40`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：刷新家具/庭具仓库状况，以及搬迁和内部整装空间条件。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | byte0 庭具容量（已布置/仓库两行分母共用）；byte1 庭具仓库内数量；byte2 庭具已布置数量；byte3 非零转 bool：庭具搬迁空间条件通过 |
| p2 | low16 家具已布置数量；byte2 非零转 bool：家具搬迁空间条件通过；byte3 非零转 bool：内部整装空间条件通过 |
| p3 | low16 家具已布置容量；high16 家具仓库内数量 |
| p4 | low16 家具仓库容量；高 16 位未读 |

额外参数：p5..p8 及独立 target 未读

说明：140E1E270 转 AgentHousing120，141721570 向 HousingWareHouseStatus 推 11 个 AtkValue；来源窗口可为 Housing 或 HousingInteriorPattern462。已由该 Addon 名称函数 14161A3F0、构造 14161A3A0 及 vtable1422A9970 定位 vf51=14161A490，并与本机 ULD 逐节点对应。主 node5 的 component1007：node3/7 为仓库内/已布置，node4/8 为家具列、node5/9 为庭具列。Atk0 庭具已布置、1 庭具仓库、2 家具已布置、3 家具仓库。主 node9 的 component1008：5/6 为家具/庭具能否搬迁，10 为家具能否内部整装，分别读 Atk5/4/6；Atk8/9 布尔联合控制搬迁图标，Atk10 控制整装图标。搬迁庭具合计=两数量之和，临时上限 cap0 非 0 时 80、否则 0；搬迁家具合计与临时 600 比较显示；整装家具合计使用当前仓库容量。三个通过 bool 是包字段，UI 不按数量自行重新判定。cap0=0 提示公寓与个人房间不支持功能；其余空间不足提示按三个 bool 组合。具体资源文案已保留 rawHex，非凭邻接类别猜测。408 回放无样本。

依据：`0x140E1E270 11argumentwrapper`、`0x141721570 11AtkValues`、`0x14161A3F0 HousingWareHouseStatus name`、`0x14161A3A0 vtable1422A9970`、`0x14161A490 vf51 AtkValue-to-node mapping`、`client/housing-warehouse-status-uld.json`、`client/housing-capacity-ui-vtables.json`、`resources-housing-capacity-labels.json`、`resources-housing-capacity-row-labels.json`、[HousingWarehouseSummary.md](../HousingWarehouseSummary.md)。
