## 参数与行为

- 核对状态：下一次重置时间计算、缓存失效及已打开界面关闭提示已核对。
- 用途：更新日常成果轮次时间基准并使当前星球缓存重新查询。

| 参数 | 读取与语义 |

| p1 | 完整 uint32 轮次基准 Unix 秒，写 module+8Ch；界面重置截止时间按 uint32(p1+86400)计算 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：Manager 存在时以 CurrentPlanetIndex&3 定位或新建查询状态 map 项，设状态 0，module+88h 日常成果点数清 0，再写 p1 至 8Ch。141A76190 返回 uint32(8Ch+86400)，140A80480 和 140A7FCA0 以该值及 ServerTime 交 Addon16923“重置时间”，140A7EE10 按差值计算剩余小时和分钟，独立确认单位是 Unix 秒。不是直接把 p1 当截止时间，也不猜每天哪个时区整点。1401493F0 只在 Agent471 已激活时 Hide 并 Log11153“日常成果已更新，界面关闭，请通过探索触控板重新打开”；未激活不显示此日志。只使当前星球查询状态无效，不在此清整个成就记录 map。p2 起不用，默认模块须加载且链可达，无回放样本。
