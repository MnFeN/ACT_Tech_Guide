# 184 / 0xB8 TargetVFX

[分类参数](../../README.md#category-00b8) · [附注索引](../README.md)

对象间特效

- 分支地址：`0x140b44054`。
- 回放观察：141 次；包族 {"ActorControl": 141}。

## 参数与行为

- 核对状态：入口、记录及逐帧回收已核对。
- 用途：副本控制器管理的对象间 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | VFX 行号 |
| p2 | 源 entityId，必须能找到普通 GameObject |
| p3 | 目标 entityId，也必须能找到 |
| p4 | uint32 毫秒数，数值转 float×0.001 得到强制回收倒计时（游戏逻辑秒）；0 不启用该倒计时 |

说明：p2/p3 按 EntityId 查普通 GameObject，两个对象都有效才创建角色间 VFX；使用与 0xB7 相同的记录和回收更新，见 VfxLifetime.md。 网络整数先零扩展再转 float，不能发送 FFFFFFFFh 作为负寿命禁用；只有 0 关闭本项计时。内部 float 管理器仍以 remaining>0 决定是否扣减。

依据：`0x140B44054–0x140B44093`、`0x140B6CEE0`、`0x140B52120`、`0x140B51EE0`、[VfxLifetime.md](../VfxLifetime.md)、`0x140B4406A..8D`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
