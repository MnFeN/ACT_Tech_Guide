## 参数与行为

- 核对状态：已核对。
- 用途：同步个人房间入口的条件性可选中开关，并请求入口对象刷新交互状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位非零转 true、零转 false，保存到 Indoor+128E8h；在非自有/共享住宅且室内类型不为 2 时决定个人房间入口是否可选中 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：纠正原先无参/隐藏门描述：140E1FB20 是尾调用包装，旧 prototype 漏 EDX；主分支 140B3D9F4 比较入口保存的 R8D 即 p1，不是 entityId。140E394A0 保存 bool 后在前 140 个 Housing 对象中寻找 Kind7 且 BaseId 为 2004624..2004626、2008126、2011571 的首个对象，将 GameObject+9Bh UpdateFlags OR8，要求刷新 TargetableStatus；不是直接改 RenderFlags。资源名称均为移动到其他房间。脚本注册 141A84230 明确命名 IsTargetablePersonalRoomEntrance=141A87910，调用 140E1FC30 读取该 bool；与独立 IsVisiblePersonalRoomEntrance 路径区分。该 predicate 对 Indoor 不存在或室内类型 DWORD+125D8h 恰 2 返回 false；普通非入口对象返回 true；入口在 140E39170 匹配既有自有/共享住宅 HouseId 时返回 true，其余读取本包保存值。该住宅身份判断与 0418 未定名的 p3 类型是环境门控，不是本包额外参数。现有 408 回放无样本，结论为原生静态双向消费核对。
