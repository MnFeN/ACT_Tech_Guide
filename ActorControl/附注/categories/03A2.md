# 930 / 0x3A2 DismountWithPositionCorrection

[分类参数](../../README.md#category-03a2) · [附注索引](../README.md)

下坐骑与位置校正

- 分支地址：`0x140b43f52`。
- 回放观察：4325 次；包族 {"ActorControl": 4325}。

## 参数与行为

- 核对状态：下坐骑坐标及三个抑制标志消费已核对。
- 用途：下坐骑并按条件纠正角色坐标（旧 BeginReplayAck 不符当前程序）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位压缩 X |
| p2 | 低 16 位压缩 Y 高度 |
| p3 | 低 16 位压缩 Z |
| p4 | 低 8 位标志；bit3 抑制坐骑对象的离开运动请求；bit4 抑制常规分支骑手落差探测/修正；bit5 同时抑制上述两项及下坐骑声音 |

说明：坐标 u16*2000/65535-1000，按本机/模式/移动状态选择是否应用。0x1408AC730 构造四 byte 选项：mode，!(p4&16)，!(p4&8)，true；p4&32 清后三项。远端坐标校正路径强制第二 byte=0，飞行时 mode5，且另行执行骑手落差修正，因此 bit4 不是所有分支的全局禁止。0x1408AB910 的 byte3 控制 Mount 资源 sound/battle/etc/%s.scd；byte1 控制 ObjectKind1 骑手 0x141814C80 高度探测，成功走 0x1408AD0F0，否则固定下坐骑 Timeline33；byte2 控制坐骑实体的 0x14090AB10 或 0x14181C470 离开运动请求。其余 p4 位不参与这些选项。

依据：`0x1408AC730`、`0x1408AB910`、`Client.Game.Character.Character.Mount`、`Client.Game.Character.MountContainer`。
