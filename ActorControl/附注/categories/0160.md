# 352 / 0x160 MateriaMeldRequestUi

[分类参数](../../README.md#category-0160) · [附注索引](../README.md)

镶嵌委托窗口

- 分支地址：`0x140b3c161`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：八 DoH 等级、对方实体、禁忌许可及 UI 最终条件已核对。
- 用途：打开/更新魔晶石镶嵌委托窗口（不是单纯失败消息）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 委托窗口对方角色 EntityId；必须能找到 BattleChara 才处理 |
| p2 | 非零允许超出普通魔晶石孔数继续镶嵌（对方禁忌镶嵌许可）；0 受普通孔数限制 |
| p3 | 按高到低四 byte 为 ClassJob8..11 等级：木工、锻铁、铸甲、雕金 |
| p4 | 按高到低四 byte 为 ClassJob12..15 等级：制革、裁衣、炼金、烹调 |

说明：1418F07E0 要求包路由身份是本机，将 p3/p4 高位优先解为 8byte，AgentMateriaAttach+0xC8..CF 保存；p2bool 存+142。1410461D0 进入委托模式 2 并保存对方 EntityId，可能因已有窗口/占用状态而关闭或拒绝，不保证一收到就打开。14104B950 在通常本机模式用 PlayerState.GetClassJobLevel(8+i)生成同样 8 级，禁忌许可取 UIState.UnlockLink12；委托模式改用这次网络提供的等级/许可，证明八字节含义。14104D390 核对物品 Meld 级别：八个等级至少一个达到要求才通过（否则 Addon4454），不是只按装备标记职业那一项判断；普通孔已满且 p2false 返回 Addon4455，p2true 允许继续，但最多 5 颗及物品禁忌限制仍独立检查。两 DWORD 按大端字节顺序装入等级数组，不是 uint64 ID。p5..p8 未读。

依据：`0x1418F07E0`、`AgentId.MateriaAttach=45`、`0x1410461D0 mode2 stores+C8..CF/+142/entityId+120`、`0x14104B950 local fallback GetClassJobLevel(8+i),UnlockLink12`、`0x14104D390 any of8 levels meets Item+4E;overmeld allowance`、`0x14104D4F0 currentMateriaCount>=Item+67 normal slots`、`resources-reset-materia.json Addon4454/4455 actual requirements text`、`client/materia-request-field-readers.json consumer references`。
