## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：角色出现/生成表现。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零时播放 BNpcBase.SEPack 对应出现 VFX 及敌我通用出现 VFX；0 跳过该段 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：实体存在时解除 RenderFlags bit10，并将 Alpha 速率设+1/1 逻辑秒；不强制 Alpha 设 1 或重置起点。p1 非 0 另播放出现 VFX。实体不存在时可修改待生成缓存。逐帧 Alpha 积分、夹紧与透明度末端参见 CharacterRendering.md。 角色不存在时共享 LABEL_354 清待生成包 CommonSpawnData.DisplayFlags bit0x20（Invisible），不会缓存 p1 所要求的出现 VFX。

依据：`0x140B3A6B7`、`0x140909F00`、`Character构造0x1408D9B30→vtable0x142197100`、`虚槽39=0x140907490→0x14089AD50；虚槽41=0x1409075B0→0x14089ADF0`、`0x14090A010 / Alpha逐帧更新与DrawObject.SetTransparency`、`0x140B4E200 / 0x1408CEA20生成缓存DisplayFlags→RenderFlags10`。
