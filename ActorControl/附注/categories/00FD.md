# 253 / 0xFD UpdateBuddyData

[分类参数](../../README.md#category-00fd) · [附注索引](../README.md)

陆行鸟搭档资料

- 分支地址：`0x140b39881`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：更新陆行鸟搭档 UI 数据（旧名 CompanionUnlock 过窄）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位写 BuddyMember.DataId，并清相邻 Synced 字节；非零可触发 HowTo109 |
| p2 | 是否更新剩余时间的开关 |
| p3 | p2 非零时除 100 写 CompanionInfo.TimeLeft |
| p4 | CompanionInfo.CurrentXP 绝对值 |

额外参数：p5 低 8 位 Rank，非零可触发 HowTo108；p6 低 8 位 SkillPoints；不是只解锁一次。

说明：原生字段地址与 FFCS CompanionInfo 布局相符；共享 LABEL_1369 刷新相关 UI。

依据：`FFCS UI.Buddy/CompanionInfo`、`0x140B39881`。
