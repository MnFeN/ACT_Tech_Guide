# 903 / 0x387 SetMountBitmask

[分类参数](../../README.md#category-0387) · [附注索引](../README.md)

设置坐骑解锁位并提示新获得坐骑

- 分支地址：`0x140b42158`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置坐骑解锁位并提示新获得坐骑。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 坐骑解锁位索引（Mount.Order），要求<360 |
| p2 | 非零解锁，零撤销 |
| p3 | Mount 行号，用来检查是否已解锁及显示 LogMessage610 |
| p4 | 此分支未读取 |

说明：位图索引 p1 与资源行号 p3 分开；解锁会加入未查看坐骑，撤销还会从收藏中移除。

依据：`0x140BE1430`、`Client.Game.UI.PlayerState.IsMountUnlocked`、`LogMessage610`。
