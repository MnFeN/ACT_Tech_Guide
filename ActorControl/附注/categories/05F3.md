# 1523 / 0x5F3 FadeOutAndHide

[分类参数](../../README.md#category-05f3) · [附注索引](../README.md)

角色渐隐后隐藏

- 分支地址：`0x140b3a061`。
- 回放观察：746 次；包族 {"ActorControl": 746}。

## 参数与行为

- 核对状态：特殊渐隐结束抑制已核对。
- 用途：角色以 0.2 秒完整行程速率渐隐，归零后施加渲染抑制。

说明：设置 Character+0x236C bit2，AlphaRate=-1/0.2；初始 Alpha>0 时解除 RenderFlags bit23。逐帧 Alpha 降至 0 后设置 RenderFlags bit23，区别于普通渐隐到透明仍保留绘制对象的路径。时长指完整 1→0 行程，未强制起始 Alpha 为 1。
