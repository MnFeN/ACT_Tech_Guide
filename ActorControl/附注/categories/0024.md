# 36 / 0x24 PlayEntranceTimeline

出入场演出

- 分支地址：`0x140b3a61b`。
- 回放观察：15799 次；包族 {"ActorControl": 15799}。

## 参数与行为

- 核对状态：特殊演出门控、渐显、时间轴及生成缓存 Invisible 位已核对。
- 用途：锁定角色特殊出入场时间轴表现，可选择渐显与指定时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零启动+1/1 秒 Alpha 速率；不重置初始 Alpha，0 不设置速率 |
| p2 | 非零时低 16 位作 ActionTimeline，播放指定演出 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：符合角色门控时置 GameObject.UpdateFlags(+0x9B) bit7；0x1408BB420 使远端角色跳过常规默认时间轴替换，避免特殊演出被默认姿态覆盖。不是直接隐藏/删除。BNpcBase8784 还给 MountObject 置该位。p1 控制从当前 Alpha 按+1/逻辑秒渐显，p2 非 0 播放低 16 位 ActionTimeline。资源及样本说明不能专称退场：常见 Timeline142 specialpop/specialpop，4562 mon_sp/[SKL_ID]/show/mon_sp002，也有 4575 hide/mon_sp003。对象不存在时与 0x25 共享 LABEL_354，按生成缓存类型清 CommonSpawnData.DisplayFlags bit0x20（Invisible）；待生成路径不缓存 p1/p2 演出参数。详 CharacterRendering.md。

依据：`0x0024`、`0x140909F00`、`0x1408BDCB0`、`0x1408BB420 / +0x9B bit7阻止常规时间轴替换`、`0x140B4FDE0生成缓存返回值 / 0x140B4E200 CommonSpawnData定位`、`0x1408CEA20 CommonSpawnData.DisplayFlags&0x20→vf41(10)`、`resources-spawn-timelines.json / ActionTimeline142,4562,4575`。
