# 3100 / 0xC1C SetAdventurerPlateTimestamp

[分类参数](../../README.md#category-0c1c) · [附注索引](../README.md)

冒险者铭牌时间

- 分支地址：`0x140b44e0f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与末端字段已核对。
- 用途：同步当前冒险者铭牌数据时间戳。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | CurrentCharaCardData.Data32.Timestamp，32 位 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：设 Flags bit2。目标偏移 0x1B0，区别于外层 Timestamp+0x1E4（0xC1E 保存应答写入）。

依据：`0x140C48F70`、`FFCS CharaCard+0x128+0x88`、`CharaCardFlags.HasCurrentCharaCardDataTimestamp`。
