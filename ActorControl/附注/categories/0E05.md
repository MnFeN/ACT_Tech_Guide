# 3589 / 0xE05 SetMechaExitConfirmation

[分类参数](../../README.md#category-0e05) · [附注索引](../README.md)

机甲范围离开确认许可

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：事件 ID 门控、离开范围确认窗口及一次性重发消费者已核对。
- 用途：机甲行动离开范围确认流程的再次同步许可。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | WKSMechaEventData 行号 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：p1 完整 uint 为 WKSMechaEventData 行号筛选；外层事件要求同号且 Flags&3==3，再由场景对象控制器 141C54220 核对所属事件+8258h 行号并置 controller+623Dh=1。p2..p8/target 未读；七个当前阶段对象的槽 9 对此类均返回 0。新定位 141C58660：事件阶段类型 4/5/6 选取场景圆柱区域，v9==2 且本机在该区域外、模块 bit2 及 bit4 允许时，走离开任务范围确认流程。controller+623Ch 为 0 或角色+4B6h 非 0 的分支中，还须本标志非 0、global142AF9091 byte 为 0、controller+38h 确认窗口 ID 非 0，才发送 Execute3483(所属事件行号,1,0,0)，随后清 623Dh，故是一次性再次同步许可。另一分支首次发送同命令并打开 Addon16876“确定要离开任务范围，退出机甲行动吗”确认框，同时清 623C/623D 两 byte。此包本身不关闭窗口、不脱离机甲、不重置贡献度；区域和提示资源独立支持离开范围业务，未擅自给两个未知门控 byte 命名。无回放样本；默认模块及所属事件需已加载。

依据：`0x141C54220`、`0x141C58660 outsidearea v9==2 → 623D latch → Execute3483(event,1,0,0) then clear`、`client/wks-mecha-refresh-users.json`、`resources-wks-mecha-outside-warning.json`、`0x140B33690 ExecuteCommand internal565 size48`。
