# 932 / 0x3A4 EndReplayAck

[分类参数](../../README.md#category-03a4) · [附注索引](../README.md)

副本回放结束应答

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：实况 Self 外层、结束请求配对及区域恢复参数已核对。
- 用途：结束副本回放的应答，执行挂起的播放收尾并可重新初始化区域。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32!=0 归一后交 14084C600；结束挂起 bit1 存在时总执行本机收尾，非零才在最后以缓存 ZoneInitPacket 调用 HandleZoneInitPacket(...,3)。0 也会结束本机播放，不是 0 时完全不处理 |
| p2 | 结束应答处理未读取 |
| p3 | 结束应答处理未读取 |
| p4 | 结束应答处理未读取 |

额外参数：Self p5..p8 未读取；路由 EntityId 不用于选择另一个角色，区域恢复使用本机缓存的实体编号/ZoneInit

说明：140847DA0 仅在 InPlayback 且无开始/结束挂起时置 bit1 并发送 1981；14084951A 对 payload+4 作 DWORD 零比较，SETNZ 后调用 14084C600。helper 未挂起则无收尾；挂起时清 bit1、解除暂停/播放、恢复音量及 HUD/本机视觉/目标等，p1 非零增加缓存区域初始化。另有本机强制收尾调用传 false，不是另一 category。931/932 不写录制白名单，408 回放无样本。详见 ReplayActorControlOuterPaths.md。

依据：[ReplayActorControlOuterPaths.md](../ReplayActorControlOuterPaths.md)、`client/replay-outer-catalog.json：实况Self外层，非主分发默认链`、`1408494E0 C/ASM category931/932 before recording whitelist`、`140847C80 command1980 startpending bit0 /140847DA0 command1981 stoppending bit1`、`14084BEA0 excludes931/932 from recorded Self whitelist`、`14084951A DWORD p1!=0 /140849524 call14084C600`、`14084C600 pendingbit1,clearInPlayback,SoundManager.SetReplayVolume,conditionalcachedZoneInit`。
