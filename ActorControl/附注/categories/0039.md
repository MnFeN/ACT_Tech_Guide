# 57 / 0x39 SetGlamourErrorSlots

[分类参数](../../README.md#category-0039) · [附注索引](../README.md)

投影错误装备槽

- 分支地址：`0x140b3a4ff`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：FFCS 字段与逐装备槽投影消费者已核对。
- 用途：同步当前装备的投影错误槽位掩码。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位写 UIState.CurrentGlamourErrorsBitmask(+0x19FD2)；bit n 对应装备槽 n |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：UIState 基址 142ADE980+19FD2=142AF8952。140C7AD20 逐槽读取掩码，存在错误 bit 时忽略该槽 GlamourId 并使用原始装备模型；CharaViewCharacterData.ImportLocalPlayerEquipment、装备校验和、物品比较与预览也读取该值。不是单一错误码。其余参数未读。

依据：`0x0039`、`FFCS UIState.cs CurrentGlamourErrorsBitmask+0x19FD2`、`0x140C7AD20 v12=mask&(1<<equipmentSlot); !GlamourId||v12 selects original`、`0x1409C34D3 CharaViewCharacterData.ImportLocalPlayerEquipment`、`0x140CAD0D0 equipment comparison`。
