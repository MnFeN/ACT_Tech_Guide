# 915 / 0x393 DismountResponse

[分类参数](../../README.md#category-0393) · [附注索引](../README.md)

下坐骑应答

- 分支地址：`0x140b431d4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：处理下坐骑请求应答，并按匹配序号清除待应答状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位下坐骑请求序号；仅与 UIState+1A3F5 当前序号相等时，才将该序号及+1A3FA 位置请求标志清零；不是物品类别 |
| p2 | 完整 32 位结果：0 不进入失败副作用；1 按路由角色/本机坐骑状态显示 Permission101 限制日志；2 显示 Log850 飞行跳下条件提示；其他非零值仍执行公共失败清理 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：主动纠正早期“物品动作类别”误名。140C4CD40/140C4CDA0/140C4CE30 在下坐骑请求时递增 UIState+1A3F5 的 byte 序号，255 回绕跳过 0 为 1，并携带该序号发 GameMain command101；普通请求将+1A3FA 置 0，带落点/角度的位置请求置 1。140C4D4B0 返回序号非 0，调用者 1406303C0 在其为 true 时避免重复发下坐骑请求。应答 0393 最后以 low8(p1)比较当前序号；匹配才清两个字段，过期不匹配应答不会清掉后续请求。注意 p2 非零的失败副作用发生在匹配判断之前，不能说过期应答完全无作用。p2=1 在路由角色不存在、不是本机或本机仍有坐骑 ID 时，按 Permission101 选当前最高优先级限制日志；本机已无坐骑时跳过这条日志。p2=2 使用 Log850：飞行时必须静止且在离地允许高度内才能跳下。任意 p2 非零均清 EventFramework+4738h 相关交互占用，相关管理器存在时对激活条目调用 virtual40 清理。p2=0 只进行末尾序号匹配清理，未给它添加本分支没有的强制卸载坐骑效果。p3..p8 及独立 target 未读。现有回放无此类，结论为静态请求/应答及资源互证。

依据：`0x140B431D4 /case0393 p2before-sequence-check`、`0x140C4D490 exact byte matching andclear`、`0x140C4CD40 increment skip0 command101`、`0x140C4CDA0 position request sequence andflag1`、`0x140C4CE30 Mount/GetIsAirDismountable/MoveController.IsFlying`、`0x140C4D4B0 pending getter ->1406303C0 duplicate gate`、`0x140BAB640 normal/flying dismount path`、`0x140E13AB0 Permission101 selects Condition log`、`0x140B819D0 /140B8D0A0 commonfailurecleanup`、`resources-dismount-request-results.json`、[DismountRequestAcknowledgement.md](../DismountRequestAcknowledgement.md)。
