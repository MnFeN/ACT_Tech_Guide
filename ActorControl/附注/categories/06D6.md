# 1750 / 0x6D6 SetTrapChestTimer

强欲陷阱倒计时

- 分支地址：`0x140b4446b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步宝箱及强欲陷阱界面的剩余倒计时和初始时长。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 宝箱 EntityId；用于匹配 Loot+458h 缓存及 ObjectKind==4 的 Treasure 对象 |
| p2 | uint32 毫秒剩余倒计时；乘 0.001 转秒，写 Treasure.CountdownTime(+1A4h)及匹配 Loot 缓存+258h，并限制不大于 p3 秒值 |
| p3 | uint32 毫秒初始时长；乘 0.001 转秒，写 Treasure.CountdownStartTime(+1A8h)及匹配 Loot 缓存+25Ch；大于 0 时设置 Treasure.Flags 的 40h 位，否则清除 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读取。

说明：142AE32E0=UIState+4960h 的 Loot。140C3BB30 先按 p1 匹配 Loot+458h 的一条 648-byte 缓存（不是 16 项 LootItem 数组），写相对缓存+600/+604 秒；再由 140C392A0 查实体并要求 GetObjectKind()==4，只操作 Treasure。141757090 将 CountdownStartTime 写为总值，并将 CountdownTime 钳在此值以内。141756D20 逐帧按 14089CCB0 返回的帧秒递减 CountdownTime，负值钳 0。Loot 更新 140C391C0 逐帧递减缓存剩余值；16 项 LootItem 则从对应 Treasure 同步剩余时间，找不到对象才自行递减。140CF69B0 对缓存剩余/总秒数 ceil 后写 NumberArray123[0/1]及 10[175]；1419D2510/2B90 也以 min(total,remaining+0.99)提供文本参数。补充追到 140118F50：Treasure.Flags 的 20h 与 40h 均置时进入名牌计时/进度分支，以 CountdownTime/CountdownStartTime 计算四舍五入百分比写 NumberArray 索引+7，并设置附加显示位。40h 因而是该附加分支的计时显示门控。缓存的界面消费者为 Agent279 TreasureHighLow（强欲陷阱），NumberArray123 同名；不是 NeedGreed 的 Agent41。未打开宝箱归零的完整后果仍未证明，不能定义为销毁包。uint32 转 float 已以主函数机器指令核验，见 FloatConversionAudit.md。
