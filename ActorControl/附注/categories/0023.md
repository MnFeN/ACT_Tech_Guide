# 35 / 0x23 Tether

[分类参数](../../README.md#category-0023) · [附注索引](../README.md)

创建/更新指定槽的连线

- 分支地址：`0x140b3a531`。
- 回放观察：14443 次；包族 {"ActorControl": 14443}。

## 参数与行为

- 核对状态：槽、Channeling、EntityId 及 Polyline 宽度最终消费已核对。
- 用途：创建/更新指定槽的连线。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位连线槽索引；FFCS 数组 2 槽，原生入口不检查范围 |
| p2 | 低 16 位 Channeling 行号；为 0 则取消指定槽 |
| p3 | uint32 对端 EntityId，零扩展到内部 64 位 GameObjectId；不是 Target 包独立 target64，也不与 p4 拼接 |
| p4 | 低 8 位宽度值/100，覆盖 AVFX Polyline 粒子 Wd 宽度；入口不钳制 0..100。FFCS 缓存旧名 Tether.Progress |

说明：槽内 Channeling 及对端不变、p4 变化且 VFX 存在时即时更新宽度；重建后亦应用缓存宽度。0x140391580→0x14037B140(handle,float,bool)→Apricot 根实例虚槽 9→子实例链；Polyline 虚表 142160610 槽 9=1403F9A50。逐帧 1403F9410 将覆盖值写渲染记录+320，取代资源 Wd 曲线。资源解析 1403A2020 的 tag0x5764(Wd)明确映射子资源+32，1403A7400 的 ParticleType6 调用该解析器；运行时 1403CF4B0 的 type6 创建 1403F8860 实例，建立同一资源字段关系。14,443 条回放均 p1=0、p4=15 即宽度 0.15，不能据样本恒定判未用。该值只对实现对应虚槽的粒子类型产生效果，最终外观仍受资源宽度分布/模型缩放影响。见 VfxControls.md。

依据：`0x1408CCD60`、`0x1408CCE80`、`Client.Game.Character.VfxContainer.Tether.Progress`、`0x140391580`、`0x1403A7400 ParticleType6→0x1403A2020 Wd→resource+32`、`0x1403CF4B0 ParticleType6→0x1403F8860 / vtable142160610 slot9=1403F9A50`、`0x1403F9410 resource+32曲线与覆盖值同写render+320`、`0x1403F2C70 render+320乘begin/center/end宽度`。
