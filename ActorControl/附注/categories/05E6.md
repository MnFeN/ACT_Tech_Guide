# 1510 / 0x5E6 PlaySequencedAction

[分类参数](../../README.md#category-05e6) · [附注索引](../README.md)

带来源序号的技能动作

- 分支地址：`0x140b43488`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：为路由角色启动技能动作表现，并关联 16 位动作来源序列号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Action 行号，同时作为动作原始 ID |
| p2 | 目标 64 位标识高 32 位 |
| p3 | 目标 64 位标识低 32 位 |
| p4 | 低 16 位动作来源序列号：与 CastInfo.ResponseSourceSequence 低 16 位匹配，并写入 Timeline 播放请求；不是 GlobalSequence、延迟或模式 |

说明：动作类型固定 1，p1 同时作为原始 ActionId 和表现使用的 Spell/ActionId；使用路由角色当前位置与旋转，p2 高 32/p3 低 32 拼 64 位目标 GameObjectId。14090B4D0 第 8 参 ushort 即 p4：若与 GetCastInfo()+50h 低 16 位不同，且+4Ch ResponseGlobalSequence 非 0，则调用 140900F50 清理旧 GlobalSequence 的相关动作表现；随后写动画请求+40h。独立同函数调用者 ActionEffectHandler.Receive140901C00 从 Header+18h SourceSequence ushort 取同一形参，写 CastInfo+50h，并作为第 8 参传入，原始 ASM140902662 写 r12w 到该栈实参。Timeline1406068F0 把请求+40h DWORD 复制到 Sequencer+50h，与来源序列用途相符。不能把 p4 等同服务器全局序列号；0 也按普通值比较，不是无条件通配。公共 Receive 在特定本机无来源序列的事件中可自行补序列，但 05E6 本分支直接使用 p4 低 16 位，不能把另一调用者的补号规则套过来。p5..p8 及独立 target 未读，现有回放无此类，未动态启动技能。

依据：`0x140B43488 maincall parameter8=p4 ushort`、`0x14090B4D0 CastInfo+50 compare vs+4C andrequest+40`、`FFCS CastInfo.ResponseSourceSequence50 /ResponseGlobalSequence4C`、`0x140901C00 ActionEffectHandler.Receive Header+18 sourceSequence`、`0x140902662 r12w->callee argument8`、`0x1406068F0 request+40 ->Sequencer+50`、`FFCS ActionEffectHandler.Header.SourceSequence18`、[ActionPresentationSourceSequence.md](../ActionPresentationSourceSequence.md)。
