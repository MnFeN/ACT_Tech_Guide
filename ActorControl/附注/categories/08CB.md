# 2251 / 0x8CB UnlockMcGuffin

[分类参数](../../README.md#category-08cb) · [附注索引](../README.md)

收藏品解锁

- 分支地址：`0x140b4521e`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：设置收藏品 McGuffin 解锁并刷新收藏界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | McGuffin 行号，资源首 byte 非 0 才处理；存储只用低 8 位 |
| p3 | 非零插入解锁 set，0 删除 |
| p4 | 此路径未读取 |

说明：主函数确实使用 p2/p3，不能将其错写 p1/p2。同步后通知 AgentMcGuffin，第三参数取 p3==0。

依据：`0x140BE4B60 / 0x1400FDA70 / FFCS PlayerState.UnlockedMcGuffins`。
