体力恢复飘字

- 分支地址：`0x140b433b2`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：恢复资源、源目标及四参已核对。
- 用途：显示体力恢复的 ScreenLog 并可播放 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 源角色 EntityId |
| p2 | 恢复数值 |
| p3 | 目标角色 EntityId；E0000000 或与 p1 相同则复用源 |
| p4 | 非零 VFX 行号；0 不播 |

说明：须主分支路由角色存在，再按 p1 查源。分别使用日志 519/521/522；0x5DE 仍为当前客户端显式分支，但旧技力不代表目前战斗资源仍使用。
