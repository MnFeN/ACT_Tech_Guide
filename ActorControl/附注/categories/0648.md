# 1608 / 0x648 SetSpectatorPhase

[分类参数](../../README.md#category-0648) · [附注索引](../README.md)

观战阶段状态

- 分支地址：`0x140b439be`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：写入及路由明确，模式值待查。
- 用途：写入观战状态 byte，并按两个状态参数决定显示战斗即将开始提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位传虚槽 13 作第一个状态值；值不等于 21 才可能提示 |
| p2 | 低 8 位先写管理器+90h，同时 R8B 保留作为虚槽 13 的第三实参；等于 21 且 p1 低 8 位不等于 21 时，若管理器+94h 为零，输出 LogMessage1621 战斗即将开始 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 均未读取

说明：1417887D0 仅 mov[rcx+90h],r8b 再 jmp[vtable+68h]，并未清 R8，所以旧两参虚调用伪码漏了第三实参。实际派生虚表 1422D6540 虚槽 13=14178A1C0，ASM 以 DL 比较 21、R8B 比较 21，且+94h DWORD==0 才输出 1621；先调用的 nullsub_215 无作用。不能把 p1 称为自动读取的旧状态，它仍是服务器传入值。0640 p4 初始化+94h，但其完整业务身份、状态 21 以及其他状态值的完整枚举仍待查。

依据：`0x1417887D0 preserves R8B across tailjmp`、`0x1422D6540 slot13=14178A1C0`、`0x14178A1C0 DL!=21 R8B==21 field94==0`、`resources-spectator-state-notice.json`、[SpectatorVirtualEndpoints.md](../SpectatorVirtualEndpoints.md)。
