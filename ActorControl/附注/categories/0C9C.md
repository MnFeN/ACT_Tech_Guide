无人岛农田操作反应

- 分支地址：`0x140b45719`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：无人岛农田操作的角色反应效果。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位农田槽 0..19 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：本条在主分发器将包头 entityId 插在网络参数前，子模块按完整 EntityId 找角色，再按 p1 低 8 位取该田地对象位置。播放 mji_frmreac_0h.avfx；四参中只有 p1 使用。当前伪码错误将角色 ID 窄化为 byte，汇编 R8D→EDX 确认完整 32 位。

依据：`0x140EA9730 / 特殊路由entityId插入 / 注册模块0x141A60420`。
