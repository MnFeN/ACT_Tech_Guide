采集点感知消失提示

- 分支地址：`0x140b3f6cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：名称引用表、两种标记槽选择与完整记录清除已核对。
- 用途：提示无法继续感知指定采集点名称，并清除对应小地图感知标记槽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | GatheringPointName 资源行号，Log3502 直接取该名称 |
| p2 | 非零清 MiniMapGatheringMarker 槽 1；0 清槽 2 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：Log3502 raw 宏引用 GatheringPointName(lnum1,column0)。随后 140FC03D0 清 AgentMap+3BD0 起的 6 个 0xA8 记录中的槽 1 或 2：清 TooltipText、MapMarker、RecommendedLevel 及 ShouldRender，并设更新 dirtybit。原“Map 模式 1/2”不是切换整张地图模式，是定点清理小地图采集感知标记。p3..p8 未读；没有足够证据将两个槽进一步命名为具体采集职业。

依据：`0x140B3F6CB`、`resources-messages.json LogMessage3502`、`resources-notebook-messages.json Log3502 GatheringPointName(lnum1,0)`、`0x140FC03D0 record168*slot+3BD0 clear`、`FFCS AgentMap.MiniMapGatheringMarkers /MiniMapGatheringMarker sizeA8`。
