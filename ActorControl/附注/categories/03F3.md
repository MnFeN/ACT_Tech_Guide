## 参数与行为

- 核对状态：已核对。
- 用途：结束住宅临时家具状态并恢复缓存布局模式；非零另清临时布局实例。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位仅零/非零使用；主函数传 p1==0。p1 非零时额外 1406F4660 销毁布局控制器临时实例列表；零跳过此步。两者均清临时家具记录并恢复缓存模式 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：撤回泛称刷新所有家具布局。140E19990 优先 Outdoor，否则 Indoor。140E28750 处理固定 record1461（70128=1461*48），首 ushort 非零才经 140E27FD0 释放其场景对象并重置 record；再 140E51700 清索引关联 map 中的特殊 key，清 manager 内+12590h word。p1 非零额外经 1406F4660->14072BA10 遍历 LayoutWorld+40h 控制器+208h..+210h 实例指针列表，1407989E0 注销并析构实例，再清 vector/置控制器+188h=1。末尾 1406F4290 取 Outdoor+12A80h 或 Indoor+12638h 缓存模式，转 14072AAA0(controller,cachedMode,0)，必要时向注册对象广播模式并处理状态切换；不是把网络 p1 当目标模式，也不一概强制模式 0。无网络坐标/库存槽/物品 ID，不删除全部已放置家具。无回放样本。
