结束无人岛庭具槽编辑

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：结束无人岛庭具槽编辑，并保留或清除对应槽记录。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位庭具索引；清槽路径只处理<90，保留路径还可按场景对象索引回退查找 |
| p2 | 完整 32 位非零：保留槽、清理当前编辑预览并解除目标布局编辑标记；0：清除对应庭具槽与已生成对象 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：1418EDE90 caseCA6：p2 非零先 141C137F0 取槽关联对象或回退 HousingObject 索引查找，再 141C13D70 清+2970h 当前编辑预览记录及其临时对象；目标布局存在时 1406F4560(0,layout)清布局运行字段 byte+3 的 0x10 位（bit4），1406F45E0 更新相关状态。p2==0 的 141C13630 仅 slot<90 时移出活动记录列表，清动态对象/布局绑定，重置槽 ID/位置/旋转等字段，未走保留路径。两者最后都标记 HousingMenu 刷新。这里按实际保留/清槽效果定义，不把 p2 简单叫成功/失败，也不声称 p2 为 0 必因网络错误。p3..p8 及独立目标未读。

依据：`0x1418EDE90 case0CA6 exact branches`、`0x141C137F0 associated object/fallback`、`0x141C13D70 clears edit-preview record+2970`、`0x141C13630 clears selected slot and object`、`0x1406F4560 bool0 /0x1406F45E0 layout editing state`、`0x1418E85A0 HousingMenu dirty`、[MjiFurnishingEditResults.md](../MjiFurnishingEditResults.md)。
