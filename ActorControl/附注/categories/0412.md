## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：显示室内花盆收获结果。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 收获 Item ID |
| p2 | 收获数量 |
| p3 | 低 16 位 GardeningSeed 行号 |
