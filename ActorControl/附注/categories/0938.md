# 2360 / 0x938 SetFateDeliveryNpc

FATE 交付目标 NPC

- 分支地址：`0x140b45091`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步 FATE 交付目标 NPC。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FateId |
| p2 | ObjectiveNpc EntityId，E0000000 清目标 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：Flags bit7 且 ID 变化才处理，构造交付目标资料并刷新同 FATE 实体。

依据：`0x141780A20 / FFCS FateContext.ObjectiveNpc`。
