# 2101 / 0x835 ShowTreasureItem

[分类参数](../../README.md#category-0835) · [附注索引](../README.md)

获得宝物提示

- 分支地址：`0x140b44e53`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：显示获得宝物的物品图标/名称提示，可附数量。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位只接受 1..4；1 使用 Addon13872 并将数量置 0，2..4 使用 Addon16675 并保留 p3，其他值不处理；两种当前标题均为获得宝物 |
| p2 | 完整 32 位物品 ID；0 不显示。2000000..2003843 走 EventItem 行及图标路径，其他值走异步 Item 查询队列，不是副本 ID 或奖励类型表行 |
| p3 | 完整 32 位数量位模式：p1=1 强制 0；p1=2..4 普通 Item 路径保留并用于名称数量格式化，最终以 uint32>1 选择带数量文本。EventItem 分支固定不传该数量，因此在此分支无显示作用 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：140B6C870 为保留 EDX/R8D 的尾跳包装，已恢复三参数类型。140BCBEF0 选择两种标题及数量，再 140BCBD40 分流：EventItem 从+18h 取 icon 直调 140BCBB80(icon,item,title,0,0)；普通 Item 将[item,title,option0,quantity]写 UIModuleHelpers+30h 的提示队列，140BCC080 异步回调用已解析 Item+88h 图标及缓存 quantity 调用同 140BCBB80。后者 quantity uint32>1 时用 Addon579 构造带数量名称，否则取单个物品名；设置十个 AtkValue，type 固定 26、icon、name、option0、标题，sub1400F0D40 提交屏幕提示。两个当前标题资源字节完全相同，不据 p1=2/3/4 编造三种不同副本或奖励模式；此包不直接增加库存。无回放样本。

依据：`0x140B6C870 full32 filter/tailjump`、`0x140BCBEF0 title/quantity branches`、`0x140BCBD40 Item/EventItem route`、`0x140BCC080 asynchronous Item/icon/quantity consumer`、`0x140BCBB80 quantity >1 unsigned and10AtkValues`、`FFCS UIModuleInterface.vf36 GetUIModuleHelpers`、`resources-content-reward-notice-templates.json`、[ContentTreasureItemNotice.md](../ContentTreasureItemNotice.md)。
