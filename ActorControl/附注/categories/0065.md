# 101 / 0x65 DirectorClear

[分类参数](../../README.md#category-0065) · [附注索引](../README.md)

清理内容控制器

- 分支地址：`0x140b3f565`。
- 回放观察：574 次；包族 {"ActorControlSelf": 574}。

## 参数与行为

- 核对状态：EventId、DirectorList 及角色事件清理已核对。
- 用途：按 EventId 清理 Director 及等待队列，并解除本机角色的对应事件关联。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint EventId，精确匹配 Director.EventHandlerInfo.EventId 或等待队列中的 EventId |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：0x140B80E70 遍历 EventFramework.DirectorModule.DirectorList（EventFramework+0xC0+0x40）；Director+0x2D8 指向 EventHandlerInfo，首 DWORD 即 EventId。匹配后调用虚槽 273，按返回结果/模块状态处理活动项或等待项；source.EventId 匹配时置 0 并清理相关事件。不是布尔开关，也不是独立 ContentId。 回放 Self 外层另在 p1 等于 ReplayManager+658h 缓存 EventId 时，清+743h.bit6 并把缓存置 0；不是清+742h ContentStarted 位。 详见 ReplayDirectorChapterSideEffects.md。

依据：`0x140B80E70`、`FFCS DirectorModule.DirectorList+0x40 / Director.EventHandlerInfo+0x2D8 / EventHandlerInfo.EventId+0`、[ReplayDirectorChapterSideEffects.md](../ReplayDirectorChapterSideEffects.md)、`client/replay-outer-catalog.json：0065附加作用`。
