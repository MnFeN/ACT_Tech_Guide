# 1522 / 0x5F2 InterruptActionCast

[分类参数](../../README.md#category-05f2) · [附注索引](../README.md)

打断动作并保留已打断施法条

- 分支地址：`0x140b40161`。
- 回放观察：168 次；包族 {"ActorControl": 168}。

## 参数与行为

- 核对状态：动作取消、打断施法条保留逻辑秒及 UI 消费者已核对。
- 用途：打断指定动作，并在施法条中保留该动作的已打断显示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Action 行号，亦以低 16 位保存到 CastInfo 相关结构+348 |
| p2 | uint32 无符号整数转 float：已打断动作/施法条状态的保留时间，单位逻辑秒；不是 float 位模式或百分秒 |
| p3 | Action 表标志允许时作为日志来源角色 EntityId |
| p4 | 此分支未读取 |

说明：固定 ActionType1 取消，p1 低 16 位写 CastInfo+0x15C 的 DWORD，p2 写+0x160。逐帧 0x14090D180 取 0x14089CCB0 有效帧秒（角色+0xD7E bit1 时再乘全局倍率），由 0x1408DEDD0 递减；严格<0 后同时清动作 ID 与计时器，恰 0 保留到下帧。无活动施法且记录 ID 非 0 时，0x140104A00 填 NumberArray6 CastBarEnemy 的动作名称与 IsInterrupted=true；0x140FECF20/0x140FEE070 也填相应目标信息施法条状态，0x1410F2AB0 保留动作名称并置中断标志。Action 资源显示门控仍适用。p3 仅在 Action 资源允许时作为 Log1472 的来源，另显示 Log540。不是沉默/封技持续时间。 本轮汇编复核：32 位 mov 写 EAX/ECX 后零扩展至 RAX/RCX，再 cvtsi2ss 以 64 位寄存器转 float，按 uint32 取数；已纠正旧伪码 signed 传播。见 FloatConversionAudit.md。

依据：`0x14090C270`、`0x05F2`、`0x1408DEDD0 CastInfo+0x15C/+0x160扣时及清零`、`0x14090D180→0x14089CCB0有效帧秒`、`0x140104A00 NumberArray6 / CastBarEnemyNumberArray.IsInterrupted`、`0x140FECF20 / 0x140FEE070 / 0x1410F2AB0 CastInfo+0x15C消费`、`FFCS Character virtual80/81重复CastInfo getter；只搜索81会遗漏UI消费者`、`0x140B401A6..B5`、`0x140B401C2..D1`、`client/main-float-conversion-instructions.json`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
