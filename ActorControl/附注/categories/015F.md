# 351 / 0x15F MeldSuccessMsg

[分类参数](../../README.md#category-015f) · [附注索引](../README.md)

执行镶嵌动作，并可播放分档的 cft_matng 特效

- 分支地址：`0x140b3c12f`。
- 回放观察：28 次；包族 {"ActorControl": 28}。

## 参数与行为

- 核对状态：表现与阈值已核对，p2 业务量待查。
- 用途：执行镶嵌动作，并可播放分档的 cft_matng 特效。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零允许可选 VFX；还要求 p2 非零 |
| p2 | 控制 VFX 档位：1–15=947、16–30=948、>30=949；确切代表数值待核对 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：无论是否播 VFX，都会选择一对制作/镶嵌时间轴并可将 Mode7 参数设为 2。 新查询 VFX947/948/949 分别为 cft_matng1/2/3（NG 命名），不是成功专用特效；Timeline239 为 craft/action_normal、4684 为 non_crafter_materia_melding。p2 可能与批量损失数量相关，但当前只有全零回放，不能将此假设填成已证实字段。

依据：`0x1418EFAE0`、`resources-event-materia-vfx.json：VFX与ActionTimeline真实资源键`。
