## 参数与行为

- 核对状态：已核对。
- 用途：同步队伍职业构成加成的五位职能掩码。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位保存 Group+7FDDh；当前五类职能：bit0 防护、bit4 治疗、bit1 近战、bit2 远程物理、bit3 远程魔法。高三位保存但不参与已核对的加成显示；p1 高 24 位未读 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：网络字段按 isRecorded 选择 Group 后保存。1400E45F0 把网络位[0,4,1,2,3]重排为 UIbit0..4；140FE6390 写 PartyList NumberArray4[5]，以 popcount 经 Addon1618 输出+N%。本轮不再只靠回放推定位名：140521BE0 使用 1421753A8 表[1619,1620,1621,1622,1623]作为 Addon56 PartyMemberList 的 AtkValue0..4 文本，资源依次为防护/治疗/近战/远程物理/远程魔法职业；141626120 OnSetup 将同五项文字绑定 node22/21/20/19/18，存 self+14528 起五个 component；141626D70 OnRequestedUpdate 读同一 NumberArray4[5]，按 UIbit i 对同 component 切换 timeline7/101。故位身份已有独立原生界面绑定闭环。回放 435 个本类别、2117 个 UpdateParty，既有 190 个 2 秒内完整名单配对中 143 符合、47 不符的记录保留；这些近邻名单并非同步快照，47 条时间/名单来源尚未逐条归因，不再用它们承担位映射推断。没有宣称客户端在此修改实际属性值。
