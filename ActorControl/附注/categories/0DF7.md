# 3575 / 0xDF7 CosmicMechaObjectControl

[分类参数](../../README.md#category-0df7) · [附注索引](../README.md)

机甲场景对象与反应对象

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：五项对象命令、EObj 参数、选择器及临时对象毫秒寿命已核对。
- 用途：按 EntityId 更新机甲场景对象参数/显隐/附加效果，或创建限时附属反应对象。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整机甲事件行号；外层事件匹配且 Flags&3==3、模块存在才转场景 |
| p2 | 完整 uint 子命令 1/2/5/6/7；其他值无处理 |
| p3 | 完整 uint 既有注册对象 EntityId；场景 map 按此查记录，0/不存在/记录未 valid 均不处理 |
| p4 | 命令 1：完整 EObj.Arg，恰 FFFF 为注销/停用哨兵；2：完整值恰 1 显示，其余隐藏；5/6：恰 1 开启第二层附加布局，其余关闭；7：新 ReactionEventObject 的 EObj BaseId |

额外参数：Self p5 仅命令 7 消费：完整 uint 毫秒存活时间，零扩展转 float 后除 1000 存秒，更新用 FrameDelta*GameSpeed 递减；p6..p8 及 target 未用

说明：141C57090 以 p3 查 EntityId map，要求记录+22 valid；141C5C830 注册以 GameObject+78 EntityId 作 key，资源 BaseId/LayoutId 分别匹配+84/+7C，不能将 p3 叫 LayoutId。命令 1 非 FFFF 写对象+1B4，即固定 FFCS EventObject.Arg，非 SharedTimelineState；FFFF 先清 IsTargetable，记录状态 4 时清记录并移 map，否则置状态 5，不直接销毁实体。命令 2→141C52060 控制 SharedGroup 启用与 GameObject 显隐虚方法，不直接改 IsTargetable。命令 5/6 分别控制 WKSMechaFieldSearcher/WKSMechaTank 选择器第二层，设置+B9 并添加/停用；6 关闭还清 scene+1A00 关联指针。命令 7 要求资源/对象及 SharedGroup 存在、10 槽未满，位置/旋转来自原对象 SharedGroup，以 p4 作 BaseId、资源首 DWORD 作 LayoutId 创建反应对象，启用状态 1；p5 是 uint 毫秒，ASM141C5443E mov EAX,p5→64 位 cvtsi2ss RAX，非 signed32，旧 C(float)(int)不可采用。场景 Update141C53670 从 10 槽秒值减 FrameDelta*GameSpeed，<=0 调用 14198A120 销毁并清槽/计数；p5=0 仍先创建，下次更新销毁。与 E01/DF8 的 80 条动态对象 vector 及 30 倍秒退场计时是两套容器/单位，不混用。p5 仅命令 7 读，p6..p8/target 未用。详见 MechaSceneObjectCommands.md。
