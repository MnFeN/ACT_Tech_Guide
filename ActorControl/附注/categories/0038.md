# 56 / 0x38 SetAllianceDebuffIndicator

[分类参数](../../README.md#category-0038) · [附注索引](../README.md)

联盟负面状态提示

- 分支地址：`0x140b3a444`。
- 回放观察：12872 次；包族 {"ActorControl": 12872}。

## 参数与行为

- 核对状态：联盟 HasDebuff 界面末端已核对。
- 用途：同步联盟成员的负面状态提示开关。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 联盟成员 EntityId，非包头实体的隐式替代 |
| p2 | 非零显示 HasDebuff 提示，0 清除；存入 PartyMember.Flags bit1 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：仅有效联盟/有效成员可写。0x140FE8960 取 Flags(+0x484)>>1&1，写 AllianceList 每成员数值块+4；固定 FFCS AllianceListMemberNumberArray 将此槽命名 HasDebuff。该包只更新提示布尔，不添加/移除具体 Status 或剩余时长。12872 条样本均来自同一份 7.55a 温达斯回放，未将样本覆盖误称跨全部版本。

依据：`0x140B25030`、`Client.Game.Group.PartyMember.Flags`、`0x140FE8960 AllianceList member header+2，HasDebuff在+6（成员内+4）`、`FFCS Client/UI/Arrays/AllianceListNumberArray.cs HasDebuff`、`client/alliance-flag-references.json`。
