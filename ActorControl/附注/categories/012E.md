# 302 / 0x12E SetGatheringAttempts

[分类参数](../../README.md#category-012e) · [附注索引](../README.md)

剩余采集次数

- 分支地址：`0x140b3f5e7`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：剩余次数宽度、与总次数区分及可用性消费者已核对。
- 用途：设置采集点剩余采集次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 低 8 位 RemainingCount，写 handler+0x30A |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：p1 低 16 位 OR30000 查 GatheringEventHandler，只写 RemainingCount(+30A)低 byte，不改 Count(+30B)。140E8B7E0 在共同可见性资格通过后，要求 RemainingCount 非 0 或 virtual280 特殊豁免才视为可用；因此该字段是剩余次数，并非资源表等级。p3..p8 未读。

依据：`0x140B386F0 / FFCS GatheringEventHandler.cs`、`0x140E8B7E0 RemainingCount nonzero availability gate`、`0x140E8B610 Setup loadsRemainingCount fromGatheringPointObject vsCount resource`。
