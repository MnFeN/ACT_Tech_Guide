# 2351 / 0x92F FateNpc

[分类参数](../../README.md#category-092f) · [附注索引](../README.md)

FATE 对象交互资格

- 分支地址：`0x140b44f65`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：EntityId 键、两个交互资格位、选择列表消费者及等级提示已核对。
- 用途：按 EntityId 同步 FATE 对象的交互选择资格及等级超限拦截标志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 全 32 位对象 EntityId，作为 8 字节条目的键；消费者与 GameObject+78h EntityId 直接比较 |
| p2 | 低 8 位标志：bit0 允许非 BattleNpc 对象的 FATE 交互进入选择列表；bit1 在对应职业且模式等级超过 FATE 上限时显示 2074 并拒绝该交互。其余位保存但当前读者未使用 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：141781660 按条目首 DWORD=p1 查找，不存在则追加 8 字节条目，再覆盖+4byte=p2low8；不是 p2=0 就删除。141784FC0 按目标 GameObject.EntityId 匹配；匹配后若 bit1 为 1 且 FATE 上下文存在、本机存在、RequiredClassJobCategory 匹配且 14177FCA0 确认该模式等级>MaxLevel，则 Log2074 并 false；其他情况返回 bit0 非零且对象 Kind!=2(BattleNpc)。有 bit1 但等级/职业条件不满足，仍回落 bit0，不是无条件禁止。FateDirector 构造 14177A670/14177AEC0 写 vt1422D4EC0，虚 7=14177AB80→该查询；EventFramework140B8BD00 在汇集交互选项时要求 Handler 虚 7 为 true 才追加 Selector 条目，完成真实消费者闭环。固定 FFCS 将 FateManager 首 vector 声明 GameObjectId，但当前 native 读者将+4 按 bit0/1 测试，键仅比较 EntityId；不将 p2 解释成 GameObjectId.Type 或按其类型改变 p1 编号空间。未匹配条目时查询另有 EventObj/FateRule 默认处理，不属于本包显式条目的 p2 含义。其他控制参数和 target 未读，无回放样本。
