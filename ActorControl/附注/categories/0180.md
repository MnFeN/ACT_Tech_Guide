# 384 / 0x180 ReplaceGatheringPointDetails

[分类参数](../../README.md#category-0180) · [附注索引](../README.md)

替换采集点次数与加成

- 分支地址：`0x140b3fd31`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与结构已核对。
- 用途：替换采集点基础配置、独立次数与 bonus。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 |
| p2 | 32 位 GatheringPointBase 行号 |
| p3 | 低 8 位 GatheringLevel，高 16 位非零置 handler+0x312 布尔 |
| p4 | 低 8 位 RemainingCount |

额外参数：p5 低 8 位 Count；p6 高 16 位 GatheringPointBonus0，低 16 位 Bonus1。

说明：保存旧配置后写新值；与 0x17C 不同，RemainingCount 和 Count 来自两个参数；两个 bonus 打包在同一 p6 中。

依据：`0x140E8B510 / FFCS GatheringEventHandler.cs`。
