# 236 / 0xEC SetMovementReportFlags

[分类参数](../../README.md#category-00ec) · [附注索引](../README.md)

移动上报附加标记

- 分支地址：`0x140b43a9f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：出站移动标记字节、普通/扩展包路径及本地位 5/6 消费已核对。
- 用途：设置后续本机移动上报的服务器附加标记字节，并影响相关回放/发送模式分支。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low8 原样保存 142AF8D78，供后续移动包附加 flags 低字节；不是 bool。各位先保留后 OR 本机 0x10/0x20/0x100；扩展移动还可 OR0x40。bit5 在本机记录路径请求追加 00EF，bit6 在扩展发送中选择 SendPacket 第五参数 1 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：当前全局直接读取及覆盖目标 byte 的相邻 word/dword/qword 引用核对，仅有主分支写和 14062BBC0 读取，没有由该地址出发的具名逐位模式表。14062BBC0 返回 low8 加本机状态：controller+710 非 0 OR20h、子状态码 2..4 OR10h、子状态码非 0 且+249 byte 非 0 OR100h。其全部四个直接调用点位于 14062B170/14062B500，构造普通 20 字节业务体或扩展 36 字节业务体；附加 flags 分别在 body+6/+10 的 ushort，8 位网络输入不会截掉之后 OR 出的 bit8。普通内部消息 555 声明大小 40，扩展 938 声明大小 56，不当作当前线上 opcode。扩展重同步路径或前一 flags 字 0x4700 条件另可 OR40h。14062B900 读附加 flags.bit6，选择 140481E80 或 140481EA0，最终 ZoneClient.SendPacket 第五参数分别 0/1；没有证据把该模式命名可靠传输或强制 flush。140631E30/140632010 在本机回放记录开关有效且 source 存在时读该附加字节 bit5，构造 category00EF 四参数全 0，经 140849420 尝试写入记录器；该位也可由本机状态产生，不能将所有 00EF 回放归因本包。收到 00EC 只存标记，不立即发移动、不改变 XYZ、不强制本机移动模式。正常周期 14062B500 仍有位置/朝向未变的跳过条件。这里完成的是本版客户端对整个输入字节的传递、合并和全部已识别消费，不为仅转交服务端的位编造走路/飞行枚举名。无本类回放样本。
