# 1206 / 0x4B6 SetTripleTriadRoomFlags

[分类参数](../../README.md#category-04b6) · [附注索引](../README.md)

幻卡对战室解锁资格

- 分支地址：`0x140b40bd0`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：bit0 对战室解锁及挑战/锦标赛门控已核对；其余高位待查。
- 用途：同步幻卡对战室解锁相关旗标字节并刷新界面资格。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位覆盖 UIState+1A1F9h；bit0 为 IsTripleTriadRoomUnlocked 查询的资格位，高 7 位仍保存但尚未命名 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：原生 140B9F5D0 注册 IsTripleTriadRoomUnlocked→140B9F040，后者仅对本机角色返回 byte142AF8B79&1。140C3F840/3F910 把 bit0 纳入幻卡交互资格；140E65CF0/68370/68580 在已完成任务 65973“决斗！九宫幻卡”后，允许教程 NPC 事件 2293771 例外绕过 bit0，其他 NPC 要 bit0；不能把所有 NPC 都描述成该 bit 无条件控制。141C672F0 对任务 69566“新幻卡对局锦标赛开赛！”以 bit0 未置产生资格错误。140C28C90 和 140C291E0 也将其纳入相关内容可用判定。此 byte 与 040D 的室内附加资格是独立层次，不能相互替代。收包仍通知 EventFramework40000h 与 HUD 指令资格重建；没有动态挑战验证。p2..p8 未读。

依据：`0x140B40BD0 bytewrite`、`0x140B9F5D0 IsTripleTriadRoomUnlocked registration`、`0x140B9F040 localcharacter andbit0`、`0x140E65CF0/68370/68580 tutorialNPC exception`、`0x141C672F0 Quest69566 prerequisite`、`0x140C28C90/140C291E0 content availability`、`resources-tripletriad-unlock-and-quests.json`、[TripleTriadNpcWinsAndRoomFlag.md](../TripleTriadNpcWinsAndRoomFlag.md)。
