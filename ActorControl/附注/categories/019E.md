# 414 / 0x19E SetRenderVisibility

[分类参数](../../README.md#category-019e) · [附注索引](../README.md)

角色显示与渐显

- 分支地址：`0x140b4182f`。
- 回放观察：148 次；包族 {"ActorControl": 148}。

## 参数与行为

- 核对状态：渲染掩码方向与渐显末端已核对。
- 用途：按 p1 解除或施加角色渲染抑制位 16，并可渐显。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 恰等于 1 清 RenderFlags bit16；其他值设置 bit16 |
| p2 | 仅 p1==1 且非零，Alpha 设 0 并按 p2*0.1 逻辑秒渐显 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：条件 16 的最终显隐含义仍须核对；不是直接把 p1 写成 Alpha。 统一校正：虚槽 39 清 RenderFlags(+0x118)指定 bit，虚槽 41 设置 bit；这是渲染抑制掩码，不是 Conditions 数组。清一位不保证可见，其他抑制位仍可能生效。 渐变单位依据 0x14090A010 及 0x14089CCB0：FrameDeltaTime，通常乘 GameSpeedMultiplier；到 0/1 清速率并夹紧。

依据：`0x019E`、`0x140909E00`、`0x140909F00`、`Character构造0x1408D9B30→vtable0x142197100`、`虚槽39=0x140907490→0x14089AD50；虚槽41=0x1409075B0→0x14089ADF0`、`0x14090A010 / Alpha逐帧更新与DrawObject.SetTransparency`。
