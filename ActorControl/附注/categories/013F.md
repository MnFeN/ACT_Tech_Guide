# 319 / 0x13F ClearGatheringState

[分类参数](../../README.md#category-013f) · [附注索引](../README.md)

清除采集活动状态

- 分支地址：`0x140b3fabb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：剩余次数、特殊条件键无效化及 p2 地图标记清理开关已核对。
- 用途：清采集剩余次数/辅助状态并可通知界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 非零略过小地图感知标记清理；0 按 GatheringType0/1 清槽 1、2/3 清槽 2，其他类型不清 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：RemainingCount=0，+305 特殊条件键置 FF（signed-1）。p2=0 时按 GatheringType0/1 清 AgentMap 感知槽 1，2/3 清槽 2；p2 非 0 略过此标记清理，字段清零仍执行。140E8B7E0 通常要求 RemainingCount 非 0；特殊 virtual280 可豁免。p3..p8 未读。

依据：`0x140E8B190`、`0x140FC03D0 clearsAgentMap.MiniMapGatheringMarkers record,not UI callback`。
