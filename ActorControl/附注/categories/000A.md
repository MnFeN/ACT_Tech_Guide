# 10 / 0x0A LevelUpEffect

[分类参数](../../README.md#category-000a) · [附注索引](../README.md)

升级表现

- 分支地址：`0x140b38c69`。
- 回放观察：22 次；包族 {"ActorControl": 22}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：逐级播放升级表现并刷新本机等级。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ClassJob 编号 |
| p2 | 新等级，循环上界 |
| p3 | 旧等级，循环从 p3+1 开始 |
| p4 | 可选当前等级；非零且本机当前职业匹配 p1 时写 Level 并更新 UI |

说明：不是只用 a1 的一条特效包；可一次补播多个等级。

依据：`0x141AAA320`、`0x140BE5D20`。
