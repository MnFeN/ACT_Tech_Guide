## 参数与行为

- 核对状态：Category 七种制作物、模型字段、部件索引及初始化布局演出已核对。
- 用途：初始化部队工房制作物的场景类型、单个部件模型及初始演出。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 CompanyCraftSequence.Category：1 转轮台、2 小型房屋、3 中型房屋、4 大型房屋、5 飞空艇、6 以太转轮、7 潜水艇；0/其他落默认布局路径 |
| p2 | 低 8 位部件模型编号，写该部件 model ushort；与 CompanyCraftPart.Unknown1(+8h)在完整预览构造中的用途相同，不是物品 ID 或制作次数 |
| p3 | 低 8 位部件索引；正常 0..7，初始化路径没有独立范围检查。2..4 经双表转换，合法范围结果仍为同号槽 |
| p4 | 此路径未读取 |

说明：要求住宅系统有效、HousingManager.IsInWorkshop 且 Workshop 指针可用。140E47650 保存 p1 到 Workshop+50h，并置演出阶段+54h=0；构造 36 字节配置，全部 8 个部件 model=FFFF/state=0，仅指定 p3 槽 model=p2/state=1；配置尾 DWORD 为 p1。按 Workshop+61h/+62h 状态缓存至+2Ch/+8h 或提交布局，不直接修改物品或物资进度。场景根+58h 存在且+60hready 时，仅若 timeline2 尚未播放才启动。14071CE70 布局加载器按配置尾 Category 分派：1 为 craft/aet 资源、2/3/4 为 bil_s/m/l_house.sgb、5 构造飞空艇样式 8 部件布局、6 为 craft/hol 资源、7 构造潜水艇样式 4 部件布局；业务名称通过 140E47BF0 读取 CompanyCraftSequence+8 Category 与产物资源交叉核对。p4..p8 及 target 未读。

依据：`0x140E47650`、`0x140E47BF0 CompanyCraftSequence+8 Category andCompanyCraftPart+8 model`、`0x14071CE70_workshop_loader.c Category1..7 actualasset paths`、`client/workshop-loader-frame-repair-audit.json`、`resources-companycraft-all-sequences-raw.json`、`resources-companycraft-sequence-sample.json`、`resources-companycraft-part-layout-identity.json`、`resources-companycraft-first-result-item.json`。
