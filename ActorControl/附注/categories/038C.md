# 908 / 0x38C SetPlayerFlags

[分类参数](../../README.md#category-038c) · [附注索引](../README.md)

玩家功能与资格旗标

- 分支地址：`0x140b42cf4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对位索引与十六项旗标；其余位待查。
- 用途：按字节同步安全令牌、陆行鸟寄养、导师及新人频道等玩家状态旗标。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 零基 byte 索引；0..2 读写 PlayerState+536h..538h，其他索引旧值按 0 且不写，但完整 p2 非 0 仍会进入 EventFramework 通知分支 |
| p2 | 低 8 位覆盖目标 byte；高 24 位不保存为旗标，但主分支以旧 byte 零扩展值与完整 p2 DWORD 比较，决定刷新，因此低 8 相同而高位非 0 仍刷新。全局 bit 号=8*p1+byte 内 bit，已命名位见专项表 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |
