探索笔记完成记录

- 分支地址：`0x140b42e3d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：探索笔记位图、章节编号与 p2 额外完成横幅布尔条件已核对。
- 用途：设置探索笔记完成位及获得消息。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 探索笔记 Adventure 的短编号低 16 位；完整 EXD 行号带 0x210000 前缀 |
| p2 | 恰等于 1 时额外显示该章节全部完成的 ScreenImage 横幅；其他值不触发此额外横幅 |
| p3 | 结果：1 置完成位并提示，0 清完成位，其他值跳过 |
| p4 | 此分支未读取 |

说明：1419F3B90 保留 ASM：EDX→R14D，只有 p3==1 成功路径尾部比较 R14D==1 才显示额外横幅。章节 0/1 分别 ScreenImage213/341，后续章节从 AdventureExPhase.AllVistasCompletedScreenImage 取非零值。成功路径始终设置 CompletedAdventures 位、显示 Log1274（编号在章节内格式化为 3 位数字）、调用 UIModule 虚 218 探索笔记发现表现（特定事件 0x906C5 时跳过）；p2 不是经验/数值。p3==0 清位并刷新 EventFramework 掩码 2000；其他 p3 跳过。p4..p8 未读。

依据：`0x1419F3B90.asm`、`PlayerState.CompletedAdventures`、`1419F3B90_raw.asm 1419F3BB6 EDX→R14D;1419F3CF8 cmp R14D,1`、`0x140BE2540 AdventureExPhase+12 screen /+16 expansion; 0x140BE25A0 chapter offset`、`resources-sightseeing-notice.json Log1274/ScreenImage213,341/AdventureExPhase`。
