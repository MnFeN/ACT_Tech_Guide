# 92 / 0x5C ItemRepairMsg

[分类参数](../../README.md#category-005c) · [附注索引](../README.md)

通知缺少修理暗物质，并列出指定物品容器所需材料数量

- 分支地址：`0x140b3c700`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：容器与 9999 背包组、修理材料计数及消息模板已核对。
- 用途：通知缺少修理暗物质，并列出指定物品容器所需材料数量。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | InventoryType 容器编号；9999 特殊选择背包四页 Inventory1..4（0/1/2/3） |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：本机门控通过后先显示 Log1392“没有修理所必需的暗物质”。非 9999 由 14088CE00 仅扫描 p1 指定容器；9999 由 14088C850 类型 5 读取 1421956C0+5*16 的四 DWORD [0,1,2,3]，不是全容器/已装备列表。按可自行修理条件（职业、等级、耐久等）筛选物品，按 ItemRepairResource1..8 累计件数；对每个非零项显示 Log1393“所需暗物质：[道具]×[数量]”。当前函数只统计并提示，不修改耐久、消耗材料或执行修理；9999 不是耐久阈值。p2..p8 未读。

依据：`0x140B3C700`、`0x14088CE00`、`0x14088CE00 InventoryManager.GetInventoryContainer(p1) → count eligible items`、`0x14088C850 group5 table142195710=[0,1,2,3]`、`0x14088C050 self-repair eligibility / GetCondition<30000`、`resources-repair-treasure.json Log1392/1393 and ItemRepairResource1..8`、`FFCS InventoryType.cs`。
