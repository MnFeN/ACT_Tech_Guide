# 225 / 0xE1 KnockBack

[分类参数](../../README.md#category-00e1) · [附注索引](../README.md)

按绝对方向启动强制位移/击退

- 分支地址：`0x140b42538`。
- 回放观察：279 次；包族 {"ActorControlSelf": 279}。

## 参数与行为

- 核对状态：入口、选项传递及逐帧消费已核对。
- 用途：按绝对方向启动强制位移/击退。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位压缩绝对朝向，解码为弧度 |
| p2 | 无符号整数/10000，距离（米） |
| p3 | 无符号整数/10000，为平移与旋转持续时间（游戏逻辑秒） |
| p4 | 未读取 |

说明：目标 X=当前 X+sin(angle)*distance，目标 Z=当前 Z+cos(angle)*distance，高度不变。持续时间由逐帧 progress+=effectiveDeltaTime/duration 证明，见 Movement.md；当前 279 条均为 Self，不能当作所有技能击退的唯一来源。

依据：`0x140B4253E–0x140B42588`、`0x14090AC70`、`0x14181A450`、`0x14181BD90`、`0x14181BE50`、`0x14181B6D0`、`0x14089CCB0`、[Movement.md](../Movement.md)。
