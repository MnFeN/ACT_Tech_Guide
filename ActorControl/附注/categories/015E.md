# 350 / 0x15E MateriaMeldResult

[分类参数](../../README.md#category-015e) · [附注索引](../README.md)

魔晶石镶嵌结果

- 分支地址：`0x140b3c0e8`。
- 回放观察：1 次；包族 {"ActorControl": 1}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：魔晶石镶嵌结果（不是精制）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 目标装备 Item 引用，非零时允许输出结果消息；不是魔晶石 Item |
| p2 | 魔晶石 Item 引用；LogMessage1201 使用 Item(lnum2) |
| p3 | 非零成功，选择 LogMessage1201；零失败，选择 1202 |
| p4 | 结果消息第三数值，失败模板用于损失魔晶石数量 |

说明：会停止制作/镶嵌相关动作状态，播放对应结束动画，刷新 MateriaAttach Agent；结果文字要求本机对象与接收者距离<5。 第二轮解析原始 SeString 宏后修正 p1/p2 顺序；只看去宏后的文字不足以判断。

依据：`0x1418EF570`、`resources-materia.json`、`resources-raw-templates.json：1201的Item(lnum1/lnum2)`。
