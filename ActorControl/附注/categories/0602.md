# 1538 / 0x602 MoveAndTurnLocalActor

[分类参数](../../README.md#category-0602) · [附注索引](../README.md)

本机移动后转向

- 分支地址：`0x140b3a216`。
- 回放观察：221 次；包族 {"ActorControlSelf": 221}。

## 参数与行为

- 核对状态：XYZ、弧度朝向、移动速度及两阶段状态机已核对。
- 用途：让本机角色先移动到目标位置，再转到指定朝向。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | IEEE-754 float 位模式 X |
| p2 | IEEE-754 float 位模式 Y 高度 |
| p3 | IEEE-754 float 位模式 Z |
| p4 | IEEE-754 float 位模式，目标朝向（弧度） |

额外参数：Self p5 为 IEEE-754 float 位模式的水平移动速度（世界坐标单位/逻辑秒）；p6..p8 未读取。

说明：控制器全局 1428B8560，setter0x140631CA0 写 XYZ+16/+20/+24、朝向+48、p5+96，挂子状态机+80。每帧 0x140631B90 调用虚槽 0=0x1406315A0：状态 0 按水平距离>0.001 持续请求移动，p5 装入移动 options+8，经 0x14181BD90 复制到 MoveController+472；0x14181B840 将该值乘 0x141815FE0 受限逻辑帧秒数，产生本帧可走距离；到达后清移动目标并进入状态 1。状态 1 按 wrap(targetFacing-GameObject.Rotation)绝对值<=0.098174773（π/32）结束，否则原地请求转向。完成由 0x140631A30 发内部 ClientIPC764 并解除状态机。不是摄像机插值，也不能把 p4/p5 都叫时间。

依据：`0x140631CA0`、`0x140631B90 / 0x1406315A0 / 0x140631A30`、`0x14090AA60 XMM坐标参数已按汇编恢复`、`0x141819E90原始汇编`、`0x14181BD90 options+8→targetRecord+24=MoveController+472`、`0x14181B840 ASM 0x14181B9EB..0x14181B9F3 speed*deltaSeconds`、`0x14181AD10 按本帧可走距离/水平剩余距离裁剪XYZ位移`。
