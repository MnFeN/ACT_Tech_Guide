# 1603 / 0x643 SetSpectatorTimeRemaining

[分类参数](../../README.md#category-0643) · [附注索引](../README.md)

观战剩余时间

- 分支地址：`0x140b43900`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步观战管理器的剩余逻辑秒数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 剩余逻辑秒数，数值转 float 写 SpectatorManager+88h；不是毫秒或 IEEE754 位模式 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：141788170 在 remaining>0 时每帧减 FrameDeltaTime*GameSpeedMultiplier，负值钳 0。141788660 在旧 remaining==0、告警序号==0 且 DAh.bit0 未置时，按初始化总时长+98h 除 60 选择告警阈值，并跳过已经达到的阈值。后续阈值触发 LogMessage1532，数字参数为 threshold/60 分钟。DAh.bit0 只抑制这段阈值告警初始化/输出，不抑制最前面的剩余时间递减，不能直接命名为暂停计时位。其余参数均未读。主函数 uint32 转换以汇编为准。

依据：`0x141788170 SpectatorManager.Update decrements seconds`、`0x141788660 stores timer and skips already-passed warnings`、`0x1419AB8F0 selects threshold arrays`、`0x14233BE58 / 0x14233BE60 threshold int32 seconds`、`0x1417888B0 ShowLogMessageUIntUInt1532`、`resources-spectator-time-warning.json`、[SpectatorTimeAndWarnings.md](../SpectatorTimeAndWarnings.md)、[FloatConversionAudit.md](../FloatConversionAudit.md)。
