# 13 / 0x0D HpSetStat

[分类参数](../../README.md#category-000d) · [附注索引](../README.md)

更新 HP、MP、GP 或 CP

- 分支地址：`0x140b38ea2`。
- 回放观察：305916 次；包族 {"ActorControl": 305916}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：按属性编号更新 HP/MP/GP/CP 及小队对应数据。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 属性编号：1/105=当前 HP，3/12/51=当前 MP，7=当前 GP，8=当前 CP |
| p2 | 新的绝对数值；GP/CP 只保存低 16 位 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：会更新当前 HP 与 MP 及小队相关字段，但不更新最大值。不能笼统称“血量相关未知状态”。

依据：`0x14090D020`、`FFCS CharacterData.cs`。
