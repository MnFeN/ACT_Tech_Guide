- 分支地址：`0x140b399cf`。
- 回放观察：5908 次；包族 {"ActorControlSelf": 5908}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：同步宠物类型、命令、姿态和 UI 数据。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 Pet 数据 ID；变化时通知事件/UI |
| p2 | PetInfo.Order，低 8 位，通常为 PetAction 编号 |
| p3 | PetInfo.Stance，低 8 位 |
| p4 | PetInfo+0xA 及小队字段的低 8 位附加状态 |

额外参数：p5 是否非零写 PetInfo+0xB；p6–p8 未读取。

说明：isRecorded=1 时跳过实际 PetInfo 写入，仍写录像小队对应字段。

依据：`0x140C221D0`、`FFCS UI.PetInfo`、`0x140B399CF`。
