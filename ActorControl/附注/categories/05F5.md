## 参数与行为

- 核对状态：DutyHelperInfo.ENpcIds 结构已核对。
- 用途：设置副本助手列表的一个 ENpcId。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 DutyHelperInfo.ENpcIds 数组索引；定义 7 项，入口无范围检查 |
| p2 | uint ENpcId |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：UIState+17100=0x42CC，即 Buddy(+0x1EF0).DutyHelperInfo(+0x23D0).ENpcIds(+0xC)。原生直接按 byte 索引写 uint；不能与 BuddyMember.DataId byte 或 EntityId 混淆。

依据：`0x05F5`、`FFCS Client/Game/UI/Buddy.cs DutyHelperInfo.ENpcIds`、`0x1EF0+0x23D0+0xC=0x42CC`。
