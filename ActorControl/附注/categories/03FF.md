# 1023 / 0x3FF OpenEstateSettingsUI

[分类参数](../../README.md#category-03ff) · [附注索引](../README.md)

住房设置菜单控制

- 分支地址：`0x140b3d9c4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：零非零锁存、当前类型路由及 HousingSubmenu 重建已核对。
- 用途：控制住房设置菜单重开的抑制锁存，并按当前住宅类型重建菜单。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 零/非零：0 置 Agent+268h 抑制锁存；非零清锁存，并仅在旧锁存 0 时按当前类型重建住房设置菜单 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：只读取完整 32 位 p1 的零/非零，不区分任何非零结果码；p2..p8 与 target 均未读取。Housing Agent(120)的+268h 是这两路共享的抑制锁存：p1=0 写 1 并返回；p1 非零仅在原值 0 时执行菜单重开，随后无条件写 0。因而不能把 0 简单叫成功或等待，也不能把非零简单叫失败。主分支仍受住宅系统门控。 140E1F7C0 本身无 Outdoor 存在检查。触发时 141722FA0 调用 1417246C0(agent,7,0,7,0)，按 Agent+A734h 选择：类型 2→141726600(agent,7)，类型 3→141723DF0(agent,7)，类型 4/5→14172B5C0(agent,-1,0)，其他→141725C80(agent,0,type==1)。这些路径均打开原生 Addon266 HousingSubmenu；2/3 标题为 Addon6465/6761 房间设置；type1 选择部队房屋，其他常规分支选择个人房屋 Addon6538。共享房屋分支传-1，保留 Agent 现有 HouseId 而非来自网络。本包不直接写房屋名称、权限或 HouseId。

依据：`0x140E1F7C0`、`0x141722FA0`、`client/housing-settings-addon-names.json`、`resources-housing-menu-response-text.json`、`resources-housing-other-settings-menus.json`、`0x141722F50 / 0x141722FA0 +268h byte`、`0x1417246C0 ASM preserves EDX/R8D/R9D and stack byte`、`0x141725C80 ASM tail arguments EDX saved selection / R8B local eligibility`。
