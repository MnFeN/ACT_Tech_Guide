# 143 / 0x8F SetActionRequestSubmission

动作请求提交控制

- 分支地址：`0x140b42bfd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：动作白名单、网络模式实参与强制缓冲处理逻辑已核对。
- 用途：控制动作请求是否强制提交并处理连接发送缓冲。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零保存 true 到 ActionManager+7F4(全局 1428BC6B4)，0 保存 false |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：1408E72A0 返回此 flag || ActionId 属于{2259,2261,2263,18805,18806,18807}，所以这些忍术动作无论此开关都走强制路径。UseActionLocation 传给 140B353F0/140B35500 等，最终 ZoneClient.SendPacket 第五布尔→141D70640→141D70A80 第三布尔。false 需连接缓冲对象 virtual4 允许才尝试写入；true 绕过该允许检查，写入 141D6E670 后若 buffer+40 非零立即调用 virtual1(buffer,connection)处理缓冲。满缓冲/写入失败仍可能回退到待处理链表，不能承诺包必然立即到达网络或服务器。以该控制流将其解释为强制提交/处理发送缓冲，不称加密、重试或可靠性标记。p2..p8 未读。

依据：`0x008F`、`0x1408E72A0 ActionManager+7F4 vs fixed Ninja action whitelist`、`0x1408E0640 UseActionLocation call sites`、`0x140B353F0 /140B35500 send selection`、`0x140481EA0→141CFAB30→ZoneClient.SendPacket(...,true) vs141CFAB00 false`、`0x141D00A10 →141D70640`、`0x141D70A80 !force && !buffer.virtual4 gate /force&&buffer+40→virtual1 process`、`0x141D6E670 append packet to bundle buffer / capacity guard`、`0x141D70640 normal connected-state path forwards a4; failed writes queue fallback`。
