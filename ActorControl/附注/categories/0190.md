- 分支地址：`0x140b38f0a`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：当前乘客数组、实际移动/交互消费者与区域转移快照分组已核对。
- 用途：更新本机多人坐骑乘客槽的 EntityId。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 槽号 0..6，超范围忽略 |
| p2 | 32 位 EntityId 写 RidePillon+4+4*slot |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：UIState.RidePillon+4 为 7 个当前乘客 EntityId，140C32160 按槽取值，E0000000 空槽返回 null，否则 LookupBattleChara。该 getter 用于飞行/交互允许性判断，以及 MountContainer 逐帧同步乘客与坐骑位置，不是仅邀请者名字缓存。14085F980 开始区域转移时调用 140C31FA0，把这 7 槽快照复制到+20 另一组并清当前槽；后续接收 190 填新当前组。第二组用于区域切换乘客对象就绪/缺失确认，191 只条件清该快照组，不能把两类理解为写/清同一数组。p3..p8 未读。
