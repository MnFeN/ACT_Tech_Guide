# 1045 / 0x415 OrchestrionModeResponse

[分类参数](../../README.md#category-0415) · [附注索引](../README.md)

管弦乐播放模式应答

- 分支地址：`0x140b3de96`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：确认管弦乐琴播放模式状态并刷新播放列表界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位按 0/非 0 转 bool；非零时更新 p2 播放模式；0 时保留旧模式，仍通知相关 Agent |
| p2 | p1 非零时完整 32 位覆盖播放模式：1 顺序播放、2 随机播放、3 单曲播放；0 也走单曲提示但在列表 UI 按无列表模式处理，不与 3 合并 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：仅有 IndoorTerritory 时生效。140E1D680 按 p1 的入口 bool 条件写全局 142AF9124，再通知 Agent228 OrchestrionInn 虚+136 和 250 OrchestrionPlayList 的 14106F590。原先“p1 低 8 位、p2 列表值”均已修正：主收包对完整 p1!=0，p1=0x100 同样为真。getter140E49850 的 Agent 消费者 141070080 与 14106F6F0，将模式 1/2/3 分别映射 Addon7065 顺序播放、7066 随机播放、7067 单曲播放，修改确认用 7074“房屋内的其他人也会受到影响”。值 0 在确认提示中也映射单曲，但 141071DB0 在其为 0 时清当前列表播放高亮并把槽号视为 FF，不等同 3。14106F590 只在窗口 active 且 AddonReady 时刷新，p1true 还可能重置该 Agent 的操作状态；不承诺未打开窗口会被弹出。p3..p8 未读。

依据：`0x140B3DE96 main full32 p1!=0`、`0x140E1D680 /1400FCF70`、`0x140E49850 getter andglobal142AF9124`、`0x141070080 value1/2/3 ->Addon7065/66/67;0 shares7067`、`0x14106F6F0 UIcallbacks32/33/34`、`0x141071DB0 mode0 listcontext gate`、`0x14106F590 active/ready update`、`resources-orchestrion-playlist-modes.json`、[OrchestrionPlaybackModeAndSlot.md](../OrchestrionPlaybackModeAndSlot.md)。
