# 1503 / 0x5DF ShowStatusProc

[分类参数](../../README.md#category-05df) · [附注索引](../README.md)

状态触发提示与特效

- 分支地址：`0x140b433e2`。
- 回放观察：2 次；包族 {"ActorControl": 2}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：显示状态效果触发日志及对应特效。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Status 行号 |
| p2 | 状态 param，传 BattleLog |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：由 Status 表决定日志 550/551 与 VFX73/40，且有状态标志/角色条件过滤；没有在此增加 StatusManager 状态槽。

依据：`0x1408A5DB0`、`0x1408A5F00`。
