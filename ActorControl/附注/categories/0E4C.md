- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：字段明确，数值业务待查。
- 用途：宇宙探索：更新或插入大师任务附加数值。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位职业索引 |
| p2 | 低 16 位 WKSMissionUnit ID |
| p3 | 32 位写 WKSMasterMissionState+0xC |
| p4 | 低 8 位大师槽位 |

说明：先全 11 职业各 3 槽查 ID，找到只更新+0xC；未找到则按 p1、p4 插入 ID 和数值。+0xC 可能最高分，尚未证实，不能直接命名 Score。 路由：WKSManager 默认模块链，需对应模块已加载。 进一步核对当前 UI：140A72BD0 AgentWKSMission.GetMasterMissions 从 Manager+80h+328*job+296h（即 Manager+376+328*job）遍历 3 个 16 字节大师记录，读取 ID、+4 奖牌、+A 锁定及 JobStateBonus 任务 ID，没有读取本包写入的+C。140A72060 大师分支也沿同一数组构造列表，未消费+C。141A702C0 虚接口写入与收包同构，141A70780 初始化批次复制完整 16 字节记录；存在复制不证明+C 最高分。全 text 精确 imul148h 候选索引与导出已保存，涵盖 UI、模块和无关同 stride 结构，未将候选全部认作 WKS。当前继续保留数值业务待查。

依据：`0x141A6F260`、`FFCS WKS/WKSManager.cs`、`0x140A72BD0 GetMasterMissions ignores record+C`、`0x140A72060 master list branch ignores record+C`、`0x141A702C0 virtual writer same semantics as0E4C`、`client/wks-job-stride148-candidates.json`、`client/wks-jobstate-master-candidates.json`、[WksMasterExtraValueReadAudit.md](../WksMasterExtraValueReadAudit.md)。
