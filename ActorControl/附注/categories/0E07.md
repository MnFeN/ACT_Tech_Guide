## 参数与行为

- 核对状态：GetLotteryCost 具名接口、两种费用单位及库存资格比较已核对。
- 用途：同步宇宙好运道信用点费用及宇宙好运爆票券费用。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 普通宇宙好运道所需星球信用点数，写 module+F8h |
| p2 | 完整 uint32 特殊宇宙好运爆所需好运票数量，写 module+FCh |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：141A780C0 按 selector0/非 0 读取这两值；141CB1920 原生 Lua 注册 GetLotteryCost→141CB1A10，独立确认是抽奖成本。141A781C0 按星球索引 0..3 选择普通信用点 Item45691/48146/48147/48148，或特殊票 48092..48095，以 cost<=库存且背包有空位判断资格。普通模式 140A83A40 把 p1 作为 Addon16915 的消耗数量，特殊模式 16934 模板只显示票券名称但资格仍使用 p2。各星球物品名称由本机 Item 资源确认；没有在这里按固定费用钳制，也不由收包扣款。p3..p8/target 未读，仅默认链模块已加载且可达时使用。
