# 3512 / 0xDB8 BeginCosmicStatisticsPeriod

[分类参数](../../README.md#category-0db8) · [附注索引](../README.md)

宇宙探索统计期开始

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：统计期文案、Quest 门控、时间参数与统计状态消费者已核对。
- 用途：通知宇宙探索开始进入数据统计期，并设置统计期状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 原始 uint32 统计截止 Unix 时间戳，作为 LogMessage10792 的日期时间格式参数；本路径不缓存该值 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：141A79C40 检查 QuestManager 完成位 0x1485（资源 Quest70789 重逢与新的计划！）及 UIModule 存在后显示 LogMessage10792，正文明确开始进入数据统计期及截至月/日/点数据计入统计结果。不满足显示条件仍将 module+0Ch 设 1。141A79F30 在当前星球==最新星球时返回该状态；141A79A10/141A7A9F0 计算+2B0h 时间时，状态 1 取下一次 09:00 UTC，状态 0 取再下一次 09:00 UTC。p1 只用于公告，不直接作为+2B0h 的写入来源。p2..p8/target 未读。仅默认委派模块加载且链可达时生效。

依据：`0x141A79C40`、`resources-wks-hologram-controls.json`、`resources-wks-hologram-quest.json`、`0x141A79A10 PlayerState.ContentId and shared96byte records`、`0x141A7A7D0 / table14241C300 sevenActionTimeline rows`、`0x141A795B0 / 0x141A796F0 serverTime<module+320h`、`0x141A79F30 / 0x141A7A9F0 statistics-state and09UTC boundary`、`FFCS WKSManager.State+50 CurrentPlanetIndex+15 LatestPlanetIndex+16`。
