# 1524 / 0x5F4 SetActorTransparency

[分类参数](../../README.md#category-05f4) · [附注索引](../README.md)

设置角色半透明

- 分支地址：`0x140b3a07f`。
- 回放观察：746 次；包族 {"ActorControl": 746}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置角色半透明并停用 Alpha 渐变。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此分支未读取 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：先调用虚函数 39(10)，设置渐变速率 0 及 alpha0.5；有别于 5F3 的 0.2 秒渐隐。 统一校正：虚槽 39 清 RenderFlags(+0x118)指定 bit，虚槽 41 设置 bit；这是渲染抑制掩码，不是 Conditions 数组。清一位不保证可见，其他抑制位仍可能生效。 渐变单位依据 0x14090A010 及 0x14089CCB0：FrameDeltaTime，通常乘 GameSpeedMultiplier；到 0/1 清速率并夹紧。

依据：`0x140909FC0`、`0x140909E00`、`Character构造0x1408D9B30→vtable0x142197100`、`虚槽39=0x140907490→0x14089AD50；虚槽41=0x1409075B0→0x14089ADF0`、`0x14090A010 / Alpha逐帧更新与DrawObject.SetTransparency`。
