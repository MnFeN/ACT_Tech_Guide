设置事件对象共享时间轴状态

- 分支地址：`0x140b418e9`。
- 回放观察：9093 次；包族 {"ActorControl": 9093}。

## 参数与行为

- 核对状态：备用 LayoutId 键及状态路由已核对。
- 用途：设置事件对象共享时间轴状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 状态值，传 EventObject.SetSharedTimelineState 或类型 12 的对应函数 |
| p2 | 此分支未读取 |
| p3 | 非零时按 p4 LayoutId 查找；0 按包头 EntityId 查找 |
| p4 | 仅 p3 非 0 时用作 GameObject.LayoutId（+0x7C） |

说明：0x14196CD40 遍历 140 项事件角色/对象表，最终比较对象+124，即固定 FFCS GameObject.LayoutId；不是 BaseId(+0x84)或另一套状态值。仅 ObjectKind7 和 12 调用共享时间轴状态消费者。

依据：`0x140B418E9`、`0x14196CD40`、`Client.Game.Object.EventObject.SetSharedTimelineState`。
