# 257 / 0x101 SetCompanionEntity

[分类参数](../../README.md#category-0101) · [附注索引](../README.md)

召唤物与搭档对象

- 分支地址：`0x140b39d9a`。
- 回放观察：26256 次；包族 {"ActorControlSelf": 26256}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：同步召唤物/搭档 EntityId 与九槽目标缓存。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 拥有者/队伍成员 EntityId |
| p2 | p5==2 时的槽索引，最终槽=p2+2 |
| p3 | 召唤物或搭档 EntityId |
| p4 | 非零才同时更新九槽缓存 |

额外参数：p5 选择映射类型 0/1/2；isRecorded 选择实况或回放 Group。

说明：p5=0 写小队成员 CompanionEntityId，p5=1 写 PetEntityId，p5=2 将缓存槽改为 p2+2；缓存槽<=8 才更新。缓存变化时重置其 HP/附加状态。

依据：`0x140C23370`、`Client.Game.Group.PartyMember.PetEntityId`、`Client.Game.Group.PartyMember.CompanionEntityId`。
