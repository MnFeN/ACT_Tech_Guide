# 1700 / 0x6A4 ResetNpcAppearanceOverride

[分类参数](../../README.md#category-06a4) · [附注索引](../README.md)

恢复 NPC 默认外观

- 分支地址：`0x140b43db5`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：将指定 NPC 外观覆盖缓存置为默认外观状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ENpcBase／ENpcResident 共享的 NPC 基础 ID；是缓存键，不是场景 EntityId |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：14196F840 只查已有 map 项，不存在则不创建；将 node+E8h 即 value+C0h 状态置 3，不清旧外观数据。旧状态 4 时将 value 地址传 141A177B0，加载对应 ENpcBase 并对跟踪实例应用；旧状态不是 4 则此入口只更新缓存状态。141A17B20 在状态 3 时忽略覆盖的武器、十槽装备、捏脸及相关覆盖值，改用 ENpcBase 与 NpcEquip 默认值，因此状态 3 可定义为使用默认外观，而不是未知 UI 状态。实例应用另按 NPC 基础 ID／跟踪 GameObjectId 匹配，特殊基础 ID1016925 亦可进入该流程。不能把此包当删除 NPC、改变服务器 NPC 装备或通用 StatusManager 控制。

依据：`0x14196F840 exact key state3 / lea rcx,[node+28h] tailcall ASM`、`0x14196FFC0 visible EventNpc scan and request2300`、`0x14196F7B0 normal appearance data response / 0x141A172E0 state2`、`0x141A177B0 ENpcBase load and apply`、`0x141A17B20 state3 selects default weapons/equipment/customize`、`0x141A178C0 sheet784 ENpcDressUp / 0x141A18310 sheet783 ENpcDressUpDress`、`resources-enpc-dress-up-tables.json`、[NpcAppearanceCacheControls.md](../NpcAppearanceCacheControls.md)。
