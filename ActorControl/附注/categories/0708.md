# 1800 / 0x708 SetGlamourDresserSlot

[分类参数](../../README.md#category-0708) · [附注索引](../README.md)

投影台物品槽

- 分支地址：`0x140b44650`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：投影台物品及两染色数组已核对。
- 用途：同步投影台一个物品槽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 投影台槽 0..799 |
| p2 | 物品值 uint，存+4+4*slot |
| p3 | 低 8 位 PrismBoxStain0Ids；套装条目也可作为部分套装 bit 数组 |
| p4 | 低 8 位 PrismBoxStain1Ids |

额外参数：Self p5 非零强制清缓存 flag；p6 未读。

说明：仅 PrismBoxRequested/Loaded 均非 0 才更新；空槽变有物品亦清缓存 flag。Stain0 数组在 7.4 起还用于套装部分部件 bit，不能对所有条目都解释成染料行号。

依据：`0x140893E30 / AgentMiragePrismPrismBox`。
