# 235 / 0xEB CancelControlledMovement

[分类参数](../../README.md#category-00eb) · [附注索引](../README.md)

取消受控运动

- 分支地址：`共享标签；见下方 goto 和完整函数`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：共享标签、受控运动取消及 GimmickJump 缓存复位已核对。
- 用途：取消当前受控运动并清除缓存的 GimmickJump 目标与确认序号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：与 0xE2 收尾共享标签，以 true 调用 141814B70。当前机关跳跃模式 3、路径模式 2 或受控状态 3/7/8 满足时，先调用 14181E910(self,3)取消。随后无条件清 GimmickJumpId+102、缓存目标 XYZ+B0..B8、轨迹参数+C0、确认序号+104 以及+108bit3。这些字段由 DC/14181F250 建立；不是释放任意角色对象。p1..p8 未读，仍需角色路由存在。此定义限于实际状态清理，不指定没有样本支持的单一玩法。

依据：`0x141814B70`、`0x141814B70 ASM conditional14181E910(mode3),then clear+102/+B0..B8/+C0/+104/+108bit3`、`0x14181F250 cached GimmickJump fields producer`。
