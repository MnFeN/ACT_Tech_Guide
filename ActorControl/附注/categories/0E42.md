# 3650 / 0xE42 SetCosmicRelicTarget

[分类参数](../../README.md#category-0e42) · [附注索引](../README.md)

星球遗物探索目标

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：目标子行资源、开始/恢复/场景挂起及秒计时消费者已核对。
- 用途：设置星球遗物探索目标子行并选择延时或恢复显示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 仅低 8 位，零扩展存 module+20h ushort；WKSTreasureInfo 当前组的目标 subrowId，0 仅清当前目标且不启动后续 |
| p2 | 完整 32 位按零/非零：在非事件挂起状态下，非零显示开始横幅并设置延时，零排入恢复目标显示 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：先 141AD5750 撤销现有 ReactionEventObject 并清目标 ID、地图标记和描述，再存 p1low8；该 reset 不清 F4 全部状态位。非 0 目标若 EventSceneModule+0D0h bit10 置位，则仅 OR 模块 F4 bit4 暂缓，p2 不参与；否则 p2 非 0 使用 WKSParam6001=ScreenImage1591，并将 WKSParam6000 的 signedint 转 float 写 F0 计时，OR F4 bit2；p2 零 OR F4 bit1。141AD4B20 按 Framework+16C0 FrameDeltaTime 秒逐帧扣减，计时<0 且 F4bit0 资源就绪才触发 141AD5280(1)；恢复路径须低两位均 1 才触发 141AD5280(0)。当前 6000=5，即 5 游戏逻辑秒，不保证墙钟 5 秒。141AD5280 读取 sheet1353 WKSTreasureInfo，以 module+E8 当前组作 rowId、p1 存储值作 ushort subrowId。141AD5380 取该子行首 DWORD 作为场景 layout instance ID，第二 DWORD 作为 ExportedSG 行，创建目标 ReactionEventObject 与地图标记。由此 p1 是目标索引而非泛称探索状态；本机有效组 1/2 来自 WKSTreasure 对应星球 2/3。p3..p8 及 target 不用；默认模块须加载且链可达；没有回放样本。

依据：`0x141AD48A0`、`0x141AD48A0 ASM low8zeroextend→ushort20; p2full32`、`0x141AD4B20 Framework16C0 seconds; completion deferredcleanup`、`0x141AD5280 WKSTreasureInfo1353 rowE8/subrow20`、`0x141AD5380 targetLayoutInstance and ExportedSG from subrow`、`0x1400F19A0 ScreenImage lookup`、`resources-wks-treasure-all-raw.json`、`resources-wks-treasure-params-log.json`、`resources-wks-treasure-screenimages.json`、`resources-wks-treasure-target.json`。
