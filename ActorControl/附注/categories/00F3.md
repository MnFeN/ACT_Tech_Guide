# 243 / 0xF3 MoveAndPlayPairedTimeline

[分类参数](../../README.md#category-00f3) · [附注索引](../README.md)

相对角色定位与双方动作

- 分支地址：`0x140b448b5`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：相对定位、步行/跑步及到位后双角色 ActionTimeline 消费者已核对。
- 用途：按参考角色朝向相对定位，步行或跑步到位后为双方播放指定动作时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 参考 BattleChara EntityId；查不到则不建立本次移动 |
| p2 | low24 三个 unsignedbyte 偏移：byte2=X、byte1=Y、byte0=Z，各除 10 米；按参考角色收包时朝向旋转；最高 byte 未读 |
| p3 | low16 相对角度=(value-180)*π/180，再加参考角色朝向并规范化；high16 整体非零为步行、0 为跑步 |
| p4 | low16 到位后 ActionTimeline ID：写入路由角色及参考角色的两份动作槽；不是确认序号 |

说明：141820DD0 按 p1 查参考 BattleChara，将 p2 三个无符号 byte 按/10 解码；141820A40 在优先级允许时清旧状态，设外层模式 10/子状态 9/优先级 7，内部轨迹记录类型 11。终点仅此时按参考角色坐标、朝向及偏移计算并保存；不是逐帧跟随。high16 布尔为真速度 2、假速度 5，时长为水平距离/速度，<0.0166 置 0；并存+351h walk 标志。原生初始化 141834440 在 InputController+520h 建立十项对象 vector，14180CDC0 索引 8 写 vtable1422DCE20，虚 1=141810C50 逐帧更新、虚 2=141810E60 取动画。动画在移动阶段按 walk 标志选 13/22，141822990 可能按角色外观标志作重映射；本机 ActionTimeline13=normal/walk、22=normal/run，独立证实步行/跑步。141810C50 按 delta 累积时间并线性插值 XYZ、朝向；控制器+438h bit1 置位时保留当前 Y。自然到位后 141810F10 置最终位置和朝向，再从+34Ch/+34Eh 读取 p4low16，分别 TimelineContainer_PlayResolvedActionTimeline 给路由角色、仍可找到的参考角色播放；阶段 1 等待双方动作不再播放才返回完成。故撤回此前 p4“确认序号”解释，已将 IDA 形参 sequence 改为 actionTimelineId。独立 target 及 p5..8 未读，无回放样本。

依据：`0x141820DD0`、`0x141820A40`、`0x141820A40 writesmode10/subtype9/priority7 anduniontype11`、`0x141834440 InputController+520h→14180CDC0 index8vtable1422DCE20`、`0x141810C50 vf1 updates/snap then playsrecord+34C/+34E timelines onbothactors`、`0x141810E60 vf2 walkflag→13 else22 withappearance resolver141822990`、`resources-relative-move-walk-run-timelines.json 13normal/walk22normal/run`、`0x141810F10 finalposition/rotation nofollowtargetrefresh`、[RelativeActorMoveAndPairedTimeline.md](../RelativeActorMoveAndPairedTimeline.md)。
