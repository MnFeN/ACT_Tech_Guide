# 3218 / 0xC92 RemoveIslandMinion

[分类参数](../../README.md#category-0c92) · [附注索引](../README.md)

收回无人岛宠物

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：移除无人岛放养宠物记录，并按 Companion 行号显示收回提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位放养槽号；<50 时在 50 条记录中按槽字段查首匹配并清理，未匹配不删除 |
| p2 | 完整 uint32 Companion 资源行号，仅用于 Log9999“收回了某宠物”的名称模板及界面响应；不是移除对象的查找键 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：141A67950 category3218 按 p1 低 byte 查记录，不是直接 records[p1]。取记录原 Companion ID 更新 RoamingMinions 资格状态，清记录 CompanionId 与区域 byte，将槽设 50（空哨兵）、EntityId 设 E0000000，再整理 50 项记录。UI 路径与移除是否找到独立：当前可编辑岛屿时取 Agent429 MJIMinionManagement，调用 140A1D6E0(p2)，刷新 UI、把 p2 作为唯一整数传 Log9999；原始 SeString 明确查 Companion。因而 p2 只确定提示名字，不以它校验或挑选被删记录；p1 无效/未匹配时也可继续提示路径。p3..p8 及独立目标未读。与 0C9E 牧场动物 BNpcName 捕捉日志不同。

依据：`0x141A67950 category3218 slotbyte search /record clear`、`0x140A1D6E0 p2 ->Log9999 one integer`、`resources-mji-minion-recall-message.json Companion(lnum1)`、`FFCS AgentId.MJIMinionManagement429`、[MjiRoamingMinionRecall.md](../MjiRoamingMinionRecall.md)。
