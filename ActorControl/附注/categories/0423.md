# 1059 / 0x423 SetHousingInteriorStyle

[分类参数](../../README.md#category-0423) · [附注索引](../README.md)

内部装修风格与规格

- 分支地址：`0x140b3e272`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：初始化住宅内部装修风格/规格及已解锁规格权限，并保留后续申请目标键。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位非零才接纳信息并刷新；零重新尝试查询 GameMain1168，无法查询则关闭窗口 |
| p2 | low16 当前 HousingRenovation 行号；0 归一为 1。资源关联 HousingIndoorTerritory 取得当前装修规格 0 小/1 中/2 大；高 16 位未读 |
| p3 | low8 住宅基础规格 0 小/1 中/2 大；无条件加入可用规格 mask，不是楼层编号；高 24 位未读 |
| p4 | low8 后续请求目标键，缓存 Agent+A1Eh，申请变更 GameMain1169 及购买规格权限 1170 时原样发送；查询 1168 的同位置室外为 HouseUnit，室内为 FF；高 24 位未读 |

额外参数：Self p5 仅 low8 读取，其中 bit0/1/2 分别为小/中/大型规格解锁，bits3..7 未影响此 mask；p6..p8 及独立 target 未读

说明：141734F70 将 p3 存+A29h，141735B80 循环 0..2，基础规格相等或 140E25370 测试 p5 对应 bit 成立时设置+A28h 可用 mask。不是三层楼层选择。141735C20 用当前风格关联的 HousingIndoorTerritory byte0 选规格，过滤 HousingRenovation1..21 同规格风格，发送 AtkValue7 可用 mask 与 10 购买权限提示，16411 有已购买/16412 无未购买；未解锁规格购买流程 140E253A0 对应 0/1/2 费用 10/20/30 亿 gil，GameMain1170(target,size)，变更 1169(target,renovationRow)。基础规格自动加入 mask，不代表 p5 对应 bit 必然为 1。独立资源 HousingRenovation1/2/3 为小/中/大型海雾村风格，关联 282/283/284，HousingIndoorTerritory byte0 恰 0/1/2；普通五地住宅及两种简装均重复此对应。p4 不擅自解释为权限 byte 或额外布尔，入口仅缓存并后续原样回送，不附加未见范围校验。408 回放无该类样本。
