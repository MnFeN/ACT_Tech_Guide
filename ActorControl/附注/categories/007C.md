# 124 / 0x7C UpdateDirectorEventItem

[分类参数](../../README.md#category-007c) · [附注索引](../README.md)

副本道具选择与数量

- 分支地址：`0x140b41e3d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：子命令、EventItem 表、四项缓存、DirectorTodo 计数与获得日志已核对。
- 用途：选择 Director 事件物品、更新其数量缓存或显示获得物品提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 子命令：0 选择当前 EventItem；1 更新最多 4 项 EventItem 数量缓存；2 显示获得日志；其他值忽略 |
| p2 | EventItem 行号/物品引用；子命令 0 选定，1 作为缓存键，2 作为 Log1804 物品参数 |
| p3 | 子命令 1 为该物品数量绝对值；子命令 2 为获得数量；子命令 0 不读 |
| p4 | 入口转交，但当前 sub_140B816E0 及最终调用不读取 |

额外参数：p5/p6 也仅在入口转交，当前 callee 未读。

说明：从 Director 列表中选择虚槽 281 返回非空附加对象的第一项，只处理该项。141AAB8C0 命令 0 写 CurrentItemKey+0C0，命令 1 按键查四个 16byte 缓存项或第一个空键，并写数量（四项全满且无匹配时只刷新、不插入）；两者刷新 141AABBF0。只有选定键非 0、缓存存在且数量非 0 时设置 Director.EventItemId(+458)并在首个空 Todo 槽显示物品名与 CurrentCount；否则清 EventItemId 并禁用对应备用 Todo。140B6B750 按原始物品引用异步查询本机 sheet124 EventItem，本表行号 2000000..2003843，不应强行减 2000000。命令 2 仅将 p2/p3 交 Log1804，原始宏读 EventItem 与数量，不走 HUD 刷新；其他子命令返回。p4..p6 虽由上层继续放栈，但实际末端函数未读；p7/p8 未读。

依据：`0x140B816E0`、`0x141AAB8C0`、`0x141AAB8C0 commands0/1/2;0ignoresp3`、`0x141AABBF0 selectedkey/nonzerocount→DirectorTodoType2 CurrentCount+78`、`0x140B6B750 ASM EDX124 EventItemsheet,Director.EventItemId+458`、`resources-director-item-control.json Log1804 EventItem macroandAddon2021 Itemmacro`、`resources-eventitem-all-raw.json rowIDs2000000..2003843`、`0x140B816E0 ASM passesp4..p6 stack;141AAB8C0 ignores`。
