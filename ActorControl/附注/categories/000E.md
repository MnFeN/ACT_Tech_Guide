# 14 / 0x0E DeathAnimation

[分类参数](../../README.md#category-000e) · [附注索引](../README.md)

死亡表现启动

- 分支地址：`0x140b3966d`。
- 回放观察：29620 次；包族 {"ActorControl": 29620}。

## 参数与行为

- 核对状态：死亡时间轴及起始时间消费已核对。
- 用途：死亡表现启动。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 死亡 ActionTimeline；0 自动选择，FFFF 走特殊消失/收尾，其他为指定时间轴 |
| p2 | 仅 p1=0 且非特殊骨架路径：按 int32 转 float，正值作为死亡时间轴起始 Timestamp，单位 30Hz 时间轴帧；0/负值保持默认 0 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：与 0x5F1 共用 0x14090A420，但此类别 Action 固定 0、angle 固定 0。p1 非 0 直接使用指定时间轴；FFFF 或 4057 走清附属武器/视觉及设置死亡状态 3 的路径。p1=0 根据坐骑、骨架选择死亡时间轴，部分分支构造请求并使用 p2。29620 条回放中 p2 始终 0，不能据此判未使用。 起始值经请求+40、SchedulerTimeline+0x23C 送 0x1418FC790 写 CurrentTimestamp(+0x34)。常规 Scheduler 更新 0x140470710 将帧时长乘 30，再沿 140471C00→1418CAB30→1419900C0→141BFD130 推进；不是毫秒或 Alpha 持续时间。 完整调用和单位证据见 DeathTimeline.md。

依据：`0x14090A420`、`0x140608790→0x1419904B0→0x1419905A0→0x141BFC150`、`0x141BFBBE0 XMM1从SchedulerTimeline+0x23C读入→0x1418FC790写CurrentTimestamp+0x34`、`0x140470710 float delta×30 / 0x1418FC790 CurrentTimestamp`、`0x14090A842 movd xmm0,r15d / 0x14090A847 cvtdq2ps xmm0,xmm0 confirms signed32`。
