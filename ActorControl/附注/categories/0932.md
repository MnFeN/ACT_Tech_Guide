# 2354 / 0x932 FateReceiveItem

[分类参数](../../README.md#category-0932) · [附注索引](../README.md)

显示获得物品消息

- 分支地址：`0x140b44fb1`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：显示获得物品消息。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 物品/模板第 1 参数 |
| p2 | 数量/模板第 2 参数 |
| p3 | LogMessage 行号；0 自动选择 2010 单件或 2011 多件，0xFFFFFFFF 抑制日志 |
| p4 | 模板第 3 参数 |

额外参数：p5 为模板第 4 参数；a1..a5 均来自 Self 路径才能完整表达。

说明：本函数只构造日志参数，不改背包或 FATE 收集数量。

依据：`0x141781880`、`LogMessage2010`、`LogMessage2011`。
