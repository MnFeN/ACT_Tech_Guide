# 401 / 0x191 ClearMountPassengerSnapshot

[分类参数](../../README.md#category-0191) · [附注索引](../README.md)

清除转移中的乘客记录

- 分支地址：`0x140b38f24`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：转移前快照生产、就绪/缺失确认与匹配清理已核对。
- 用途：按槽号和 EntityId 匹配，清除区域转移时保留的多人坐骑乘客快照。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 槽号 0..6 |
| p2 | 仅当前槽 EntityId 等于此值才清为 0xE0000000 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：操作 RidePillon+20 起的 7 槽快照，区别于 190 写的+4 当前组。14085F980 区域转移前 140C31FA0 把当前组复制到快照并清当前组。140C32010 逐个检查快照对象存在且渲染未抑制；140C320C0 对缺失快照对象发内部 cmd108(槽,EntityId)，随后清一次性处理标志；191 应答只有 EntityId 仍匹配才将该快照槽设 E0000000，避免旧确认误清新条目。此类不直接请求登骑/弹出邀请。p3..p8 未读。

依据：`0x140C32140 / FFCS RidePillon.cs`、`0x140C31FA0 snapshot producer at14085F980`、`0x140C32010 snapshot availability/render check`、`0x140C320C0 missing snapshot sendsinternalcmd108`、`0x140C32140 exact slot/entity compare thenE0000000`。
