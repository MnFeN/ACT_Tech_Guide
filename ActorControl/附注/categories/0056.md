# 86 / 0x56 SetWeeklyRewardFlags

[分类参数](../../README.md#category-0056) · [附注索引](../README.md)

副本周奖励领取记录

- 分支地址：`0x140b3d51d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：位图与 ContentsFinder 已领取数量消费者已核对。
- 用途：同步副本周奖励已领取位图。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位奖励领取位图；bit n 表示奖励索引 n 已领取，不是领取次数整数 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：写 UIState.Loot+0x454。FFCS 签名定位的 AgentContentsFinderInterface.GetReceivedRewardCount 读取所选内容的 4 个 sbyte 奖励索引(+874..877)，跳过负值，对 p1 位图中相应置位项计数。最大领取数另由有效索引数量计算；因此 p1=3 不能直接当作已领 3 件。具体哪个 bit 分配给哪项内容来自所选内容奖励配置。p2..p8 未读。

依据：`0x0056`、`0x140C2E780 FFCS AgentContentsFinderInterface.GetReceivedRewardCount`、`FFCS AgentContentsFinderInterface+874 four signed reward indices`、`0x142AE3734=UIState.Loot+454`。
