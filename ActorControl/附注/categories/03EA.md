外部装潢申请应答

- 分支地址：`0x140b3d5f9`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：房屋外部装潢编辑申请应答：使用地块缓存进入外装编辑，或重取资料。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low8 OutdoorHouseUnit，与请求缓存比较；普通 0..59 含 division，80h/81h 为公寓编码。高 24 位未读 |
| p2 | 完整 32 位结果：0 进入成功处理，非零结束等待且不发 1104 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：p1 身份由请求端闭环：Outdoor+125D8h 为当前选中 HouseUnit，复制到+125DAh 请求缓存后，1100/1101 原样发送。原生 140E1C2B0 明确接受普通 0..59 或 80h/81h 公寓编码；普通值包含 division，不是 UI 显示的 1..30 地块号。回包只比较低 byte 与请求缓存，不在此处重新做范围校验。p2 完整 32 位只判断零/非零，不存在已证实的详细错误码枚举。无回放样本。 140E1C2B0 检查选中 HouseUnit、土地已有房屋及权限后，将其缓存并发送 1101，mode2。140E1BD30 要求 Outdoor 存在、p2=0、HouseUnit 匹配及 mode2；先 1406F3580 以 p1 索引读取 40byte 场地外装记录到缓存（该 helper 对>=60 返回错误，本调用不检查返回值，不能承诺公寓同样有效），再 141722E40(agent,0)->14171F150 打开 Addon258 HousingEditExterior。其他情况清请求缓存为 FF/mode0、参数 1 结束等待；仅 p2=0 时再发 1104 请求资料。当前包不携外装 ItemID 或染色值，不直接更换外装。

依据：`0x140E1C2B0 selectedunit validation/mode2/1101`、`0x140E1BD30 reply gated flow`、`0x1406F3580 60records stride40 cached exterior`、`0x141722E40->14171F150 openAddon258 HousingEditExterior`、`client/housing-response-addon-names.json`、`resources-housing-exterior-request-results.json`、[HousingExteriorRequestResponses.md](../HousingExteriorRequestResponses.md)。
