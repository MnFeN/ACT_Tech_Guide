# 34 / 0x22 TargetIcon

[分类参数](../../README.md#category-0022) · [附注索引](../README.md)

从接收者向另一对象播放头顶标记 VFX

- 分支地址：`0x140b3a50e`。
- 回放观察：12881 次；包族 {"ActorControl": 12881}。

## 参数与行为

- 核对状态：分支与被调函数核对。
- 用途：从接收者向另一对象播放头顶标记 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 标记/VFX 编号，0 时不播放 |
| p2 | 另一个 GameObjectId；0xE0000000 或对象不存在时不播放 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：项目注释只列 p1 漏了实际读取的 p2；常规样本 p2 可能为自身。是否所有头标需 ID 归一化仍须按包版本处理。

依据：`0x1408CC160`。
