[分类参数](../../README.md#category-03a5) · [附注索引](../README.md)

陆行鸟竞赛与麻将资格

- 分支地址：`0x140b44793`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：竞赛入口、可参赛陆行鸟与麻将初段三项资格位及条件文案已核对。
- 用途：同步陆行鸟竞赛开放、已登记可参赛陆行鸟及麻将初段资格位，并刷新搜索界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位覆盖 PlayerState+738h：bit0 陆行鸟竞赛入口开放资格，bit1 已登记能参赛的竞赛陆行鸟，bit2 麻将段位初段或更高；高 24 位丢弃，低 byte 高 5 位保留但当前已定位消费者未使用 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140C28E00 作为 GoldSaucerContent.IsUnlocked 虚 14，先通过 CFC 基础资格，再对 GoldSaucerContent 行+4=1 返回 bit0，本机行 4→CFC481 竞赛教学；140C2CC30 及 140C291E0 也以 bit0 处理竞赛筛选/可用性。ContentRoulette 虚 71 的 140C272E0：行+37h=4 且 selector0 时返回 bit1==0，即该项条件未满足；同表虚 70=140C272A0 返回 Addon10828，原文已登记能参赛的竞赛陆行鸟。已枚举本机全部 ContentRoulette，+37h=4 的 21 行全部是陆行鸟竞赛各赛道/随机赛道及无报酬变体（行 18..38）。GoldSaucerContent 虚 71 的 140C284A0 对 CFC644/767 且 selector0 返回 bit2==0；对应虚 70 的 140C28460 返回 Addon10831 段位初段或更高。因此 bit2 是有段桌的初段资格缓存，不是一般麻将开放或无方向的状态。其他资格条件仍存在，置位不保证最终一定能入场。收包随后 140C50030 重建可用 UI 数据，调用 UIModule 相关刷新及 1400FC970；未发起比赛或修改段位分数。p2..p8/target 未读。
