# 1006 / 0x3EE SetHousingPlotState

[分类参数](../../README.md#category-03ee) · [附注索引](../README.md)

室外地块与所有者类型

- 分支地址：`0x140b3d6b5`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步室外地块状态和所有者类型。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | byte0 地块；byte1 PlotState；byte2 OwnerType；byte3 未读 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：普通地块 0..59 写 PlotDetail+0 状态及+4 OwnerType。0x80/81 为公寓特殊编号，由另一消费者更新公寓状态，不写普通地块数组；随后刷新地图。

依据：`0x140E1BF20 / 0x140E331A0 / FFCS OutdoorTerritory.PlotDetail`。
