- 分支地址：`0x140b45426`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：暂停并复位 Event 与 Battle 两个 BGM 场景。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此路径未读取 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：旧四项未知场景表现控制已明确为 BGM 操作，不涉及四种图形效果。EventFramework 存在时 1417C8D80 依次 14085C260/390 将 BGMSystem.Scenes[1]/[0].PlayState 写 0，再 14085C200/340 清两个非 Playing 场景的当前 Situation/BgmId/PlayingBgmId、自定义 fade 开关及时间等字段。因为先置 Paused，两次 reset 的 PlayState!=1 条件在相应 scene 存在时成立。全局 142AC6EF8、Scenes+C0、stride60h 与 FFCS 具名 SetBGM14085CE00 独立一致；scene0=Event、1=Battle，+50h PlayState0Paused/1Playing。它不遍历所有场景，Content/住宅等其他 scene 并非本类别直接目标。每个 helper 分别校验 BGMSystem 存在及 NumScenes 范围。当前没有网络参数或回放样本。

依据：`0x1417C8D80 ordered4calls`、`0x14085C260 scene1 PlayState+50=0`、`0x14085C390 scene0 PlayState+50=0`、`0x14085C200 reset scene1 paused fields`、`0x14085C340 reset scene0 paused fields`、`0x14085CE00 FFCS BGMSystem.SetBGM structural crosscheck`、`FFCS BGMSystem.Scene Event0/Battle1/PlayState`、[EventBattleBgmReset.md](../EventBattleBgmReset.md)。
