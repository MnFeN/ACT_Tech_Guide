# 1110 / 0x456 SetGoldSaucerReadyCount

[分类参数](../../README.md#category-0456) · [附注索引](../README.md)

金碟匹配准备人数

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步金碟内容匹配的已准备人数与所需人数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 已准备人数，写 NumberArray81[2]；准备窗口格式化显示为当前人数 |
| p2 | 所需准备人数，写 NumberArray81[3]；<=0 时不更新人数显示；萌宠之王作为分母，陆行鸟竞赛分母固定 8；p1>=p2 时显示完成指示控件 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：Agent170 GoldSaucerHud 共用准备界面。1416D3220 RaceChocoboReady 读取数组[3]/[2]并调用 1416D3040(total,current,8)；1416E6280 LovmReady 调用同助手(total,current,total)。助手在 total>0 时通过 14064AFE0 格式化 Addon19（两个整数以/分隔），并按 current>=total 切换图像节点可见性。陆行鸟准备窗口 ULD 文本 9135 明确“正在确认准备情况”。该类别是准备人数同步，不是比赛分数、名次或比赛倒计时；不由此断言所有不合法输入均被限制，助手比较使用 signed32。0455 阶段 7 主动写当前 1/所需 2 供后续界面使用。p3/p4 及其余参数未读；伪码中多出的寄存器参数是虚函数类型不准，末端仅两次数组写。

依据：`0x140E6B110 default delegate`、`0x1410A4B10/0x1410A4B60 NumberArray81[2]/[3]`、`0x1416D3220 RaceChocoboReady update`、`0x1416E6280 LovmReady update`、`0x1416D3040 shared display and visibility helper`、`0x14064AFE0 Addon19 two-number formatter`、`resources-gold-hud-ready-count.json / resources-gold-hud-ready.json`、`client/probe-RaceChocoboReady-uld.json / probe-LovmReady-uld.json`、[GoldSaucerReadinessHud.md](../GoldSaucerReadinessHud.md)。
