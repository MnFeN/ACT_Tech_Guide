| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位室内家具对象索引；byte3 为转轮台部件槽，byte2 未读；绘制槽数随台型为 1..6 |
| p2 | 低 16 位部件资源模型编号（FFFF 保留）；byte2 场景状态选择值（FF 保留）；byte3 附加缓存状态（FF 保留），未被当前即时绘制末端读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：实际资源核实：BaseId196818 为转轮台 I，196833..196837 为 II..VI，197084 为小型转轮台 VI；全部 HousingFurniture.UsageType8、CustomTalk721112 CmnDefHousingWheel_00216。140E24BC0 给出对应可绘制槽容量 1、2、3、4、5、6、6，141C6B630 要求 slot<8 且 slot<该台容量。每部件缓存 stride6，ushort 模型在+0、p2byte2 在+2、p2byte3 在+4，各自的 FFFF/FF 保留旧值。模型直接由 1406FF990 改写现有部件 SGB 资源编号，不查 GardeningSeed；p2byte2 通过 1406FFC40 作为 SGB 文件名倒数第 7 字符的十进制状态选择，另一路倒数第 4 字符固定 0。高 byte 额外缓存虽传入外层第六参数，141C6B630 不读取，不能称它是已显示的百分比/剩余小时。其确切蓄能阶段枚举仍待查。p3..p8 未读；现有回放无样本。
