# 1850 / 0x73A EurekaStep

[分类参数](../../README.md#category-073a) · [附注索引](../README.md)

同步优雷卡剧情进度、等级资格值及 32 位剧情旗标

- 分支地址：`0x140b446f8`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：剧情 ID 顺序及元素等级资格已核对；32 位旗标逐 bit 业务仍待查。
- 用途：同步优雷卡剧情进度、等级资格值及 32 位剧情旗标。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位优雷卡剧情进度 ID，写状态+1；真实先后比较先查 EurekaStoryProgress 链生成的顺序表，不以该 byte 无条件当有序数 |
| p2 | 完整 uint32，写状态+4；用于优雷卡剧情资格的元素等级缓存。同事件实际对白的 13 项明确元素等级门槛与原生比较匹配，见 EurekaElementalQualificationText.md |
| p3 | uint32 剧情/场景资格旗标，写+8；读者以 bitIndex<32 逐位检查，其中 bit20 参与 ZoneSharedGroup RequirementType4 的附加门槛 |
| p4 | 此分支未读取 |

说明：模块由 140B1F210 只在 TerritoryType 内容属性 41 或特例 276/628 相关转区时创建/维持，构造加载 EurekaStoryProgress。140B1FD10 从表行 0 沿单 byte nextRow 链接建立+30h 起 128 项顺序表。当前资源 92 行恰好 0→1→…→91→0，但代码仍使用表中顺序。p1 变更标脏 140 个对象+9Bh 的 1Ch 并刷新 ZoneSharedGroupManager 及事件状态；p2 变更只置 04h；p3 变更置 1Ch。073B/073C 分别为同一 p2/p3 的单独更新。p2 已通过后续同事件 SystemTalk 的明确元素等级文本交叉确认，逐 bit 旗标完整业务仍待查。 新增逐位消费：141A991A0 对象事件回调和 141A993E0 刷新路径，将 bit0/1/2 对应 EObj2009421/2009432/2009433，bit8..11 对应 2009562..2009565，bit12..15 对应 2009615..2009618，bit21..23 对应 2009713..2009715；这些 EObjName 本机均明确“岛内以太之光”。匹配 EventObject BaseId 且该 bit 已置时调用 SetSharedTimelineState(4,0,0)，说明它们控制对应岛内以太之光的持久场景表现；本轮不把未读到的传送权限服务端逻辑补成已证明。其他位仍有剧情图标/bit20 场景门控等用途，不将整个 uint 简化为以太之光专用位图。 补充原生 CustomTalk 注册映射与脚本：bit3→B01C0 金钱商店、bit4→B01C1 上锁宝箱鉴定、bit5→B01C2 常风武器强化、bit6→B01EC 恒冰盖罗尔特事件，分别控制其 61723 姓名牌提示图标的抑制（另有剧情门槛）；bit16 由 B021B 武器属性调整入口的布尔查询读取，其实际脚本调用 OpenEurekaWeaponAdjust。不能把这些位统一当地图传送位或仅凭图标抑制说商店不能使用。详见 EurekaCustomTalkFlagConsumers.md。 元素等级名称的新确认来自真实 CustomTalk 事件绑定、同事件 Lua SystemTalk 和本机 13 项明确等级文本，见 EurekaElementalQualificationText.md；旧说明中“尚缺独立命名”已被这组业务语义证据取代，不表示获得了原生具名 getter。p3 其余旗标仍待查，073A 不计整体完成。 bit20 的 NPC 消费现已绑定到真实 CustomTalk B0222/721442 CtsErkEureka4Ejika_00546：静态 holder1428D9350→vtable142425C30 的 slot2=141A9A420。该事件实际文本包含选择艾吉卡路线后不能推进可露儿路线的提示，但脚本未直接读取网络 bit20，故只确认为该丰水之地剧情事件的可选资格抑制位，不能据对白将 bit20 值 0/1 直接命名成两条路线。进度 86 匹配 ENpc1027115、89 匹配 1027117 且 bit20 未置才可选；85 及 90/91 的独立分支不读该位。 新增 GLBOPT2 Microcode 基本块/跨函数来源追踪，101 绑定 116 流记录、111 调用位置；复现 11 处既有位查询及 20 个已知位，独立正例校验无误，但没有新增其余位语义。非 SSA、动态/特殊参数/未知来源边界见 EurekaMicrocodeFlagFlowAudit.md。 后续 m_stx 地址寄存器标签问题已修复并重跑相关批次，按目标实际读取站点比对无新增/移除；见 MicrocodeStoreAddressFix.md。
