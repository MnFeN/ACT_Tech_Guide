# 190 / 0xBE SetQuestRedoProgress

[分类参数](../../README.md#category-00be) · [附注索引](../README.md)

新游戏加任务进度

- 分支地址：`0x140b44271`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：QuestRedo 条目索引、进度位及任务完成视角消费者已核对。
- 用途：更新 New Game+ 当前 QuestRedo 条目的进度位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 位索引，机器实际使用 p1&31，对应当前 QuestRedo 资源的 32 个 QuestRedoParam 条目 |
| p2 | 非零设位，0 清位 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：QuestRedoManager+0xC 的 32 位进度图。140EB2C00 选择下一任务时跳过已置位条目；140EB33D0 针对 QuestId 在 QuestRedo32 项中找到索引，用对应 bit 生成当前重玩视角的任务完成状态(0x101 vs1)。不写 QuestManager 全局完成位。p2 非零置位否则清位；p3..p8 未读。主入口要求 QuestRedoManager 存在；未校验 p1<32，超范围按 SHL 低 5 位折返。

依据：`0x140EB27A0`、`0x140EB4090`、`0x140EB2C00 QuestRedo32 rows / bittest manager+C chooses next unfinished`、`0x140EB33D0 QuestEventId=short|10000 →index→progress bit→return0101`、`0x140EB27A0 SHL low5 mask /manager+C`、`resources-questredo-fields.json QuestRedo row structure`。
