# 141 / 0x8D SetRepeatableQuestFlag

[分类参数](../../README.md#category-008d) · [附注索引](../README.md)

重复任务标志

- 分支地址：`0x140b426b9`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与字段已核对。
- 用途：设置重复任务标志并可刷新关联事件。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 QuestRepeatFlag 行号/位索引，要求其 byte 索引<2 |
| p2 | 非零置位，零清位 |
| p3 | 非零时根据 QuestRepeatFlag 关联 EventId 刷新任务/事件 |
| p4 | 此分支未读取 |

说明：位图以 128>>(p1&7)倒序存储；p3 只控制通知，p2 不由下游再次读取。

依据：`0x140B80300`、`EXD__QuestRepeatFlag__Row_140838620`。
