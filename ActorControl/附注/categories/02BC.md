# 700 / 0x2BC ActionRejected

[分类参数](../../README.md#category-02bc) · [附注索引](../README.md)

动作被拒绝，取消匹配动作并校正冷却

- 分支地址：`0x140b402a9`。
- 回放观察：1177 次；包族 {"ActorControlSelf": 1177}。

## 参数与行为

- 核对状态：SourceSequence、响应动作匹配及冷却单位已核对。
- 用途：动作被拒绝，取消匹配动作并校正冷却。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | BattleLog 错误/LogMessage ID |
| p2 | ActionType |
| p3 | 动作 ID |
| p4 | 冷却已流逝时间 newElapsed，除 100 转秒 |

额外参数：Self p5 为 newTotal，按 uint32 转 float 后/100 秒；p6 为 CastInfo.SourceSequence（uint32），非零且与当前值相等才调用取消施法表现。p7/p8 未读。

说明：匹配 CastInfo.ResponseActionType/ResponseActionId(+0x44/+0x48)后清响应及动作表现；p6 比较的是独立 SourceSequence(+0x08)，不是响应 GlobalSequence。p4/p5 同时 0 时走另一冷却重置路径；否则调用 SetCooldown。 本轮汇编复核：32 位 mov 写 EAX/ECX 后零扩展至 RAX/RCX，再 cvtsi2ss 以 64 位寄存器转 float，按 uint32 取数；已纠正旧伪码 signed 传播。见 FloatConversionAudit.md。

依据：`0x140B402A9`、`Client.Game.ActionManager.SetCooldown`、`Client.Game.BattleLog.AddActionLogMessage`、`FFCS CastInfo.SourceSequence+0x08 / ResponseActionType+0x44 / ResponseActionId+0x48`、`0x140B40402..56`、`client/main-float-conversion-instructions.json`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
