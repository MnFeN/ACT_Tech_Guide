# 244 / 0xF4 SetAdditionalMovementVelocity

[分类参数](../../README.md#category-00f4) · [附注索引](../README.md)

设置附加水平速度

- 分支地址：`0x140b448e3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：虚函数、float 布局与逐帧位移已核对。
- 用途：设置角色水平附加移动速度向量。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 按原始 32 位 IEEE754 float 重解释：X 方向速度 |
| p2 | 按 float 重解释：Y 分量；参与全零关闭判定并存储，本次逐帧水平消费者不使用其位移 |
| p3 | 按 float 重解释：Z 方向速度 |
| p4 | 此路径未读取 |

说明：不是整数压缩坐标：三参数原样 bit 复制为 float 向量。全零关闭，否则置 active 并存 MoveController+0x420..428。满足本机/状态条件时每帧将 X/Z 乘受上限约束的逻辑帧秒数后加到位置，因此是米/逻辑秒的速度。Y 不能直接标未用，因为参与启用判定。 当状态 bit1 成立时，时间轴选择消费者 0x141821500 会采用 ActionTimeline156/157，即 battle/knockback_start_pc / knockback_end_pc；资源与附加击退运动相符。

依据：`0x1421970E0`、`0x1418206B0`、`0x1418205B0`、`0x14181AD10`、`0x141815FE0`。
