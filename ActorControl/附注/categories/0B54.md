# 2900 / 0xB54 SetFieldRecordItem

[分类参数](../../README.md#category-0b54) · [附注索引](../README.md)

单项战果记录登记

- 分支地址：`0x140b455c9`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：单项更新战果记录道具的已登记缓存。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位分组号 group，目标索引=group*32+最低置位 bit(p2) |
| p2 | 32bit 选择掩码，只处理最低的一个 1bit；多 bit 不会批量更新；0 时扫描 32 位后写下一组首项，不是无操作 |
| p3 | 整个 32 位值恰等于 1 时置 true，其他值 false |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：UIState+19F78h 模块的+8 由构造 140C47070 固定为 32，+Ch 起 55 个 bool 供 ItemAction.Type19743 战果记录道具登记检查使用。140C471E0 以 ItemAction.Data0 直接索引此数组；当前对应 50 个战果记录道具，索引 1..50，0 与 51..54 无当前道具映射。此入口不检查 group、目标索引或零 mask，不应在定义中虚构安全边界。仅更新 bool，不自行将整个缓存标为加载完成；批量响应 0B55 另设类型 19743 状态 2。

依据：`0x140C4DFC0 wrapper / 0x140C473F0 same selector algorithm`、`0x140C47070 ctor width32 and bool55`、`0x140C47130 map keys19743 and50454`、`0x140C471E0 ItemAction type19743 checks Data0 registration bool`、`resources-itemaction-type19743.json / resources-itemaction19743-linked-items.json`、[FieldRecordRegistrationFlags.md](../FieldRecordRegistrationFlags.md)。
