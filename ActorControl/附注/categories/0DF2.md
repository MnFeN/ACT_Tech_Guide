## 参数与行为

- 核对状态：客户端子命令、参数及序列事件请求已核对。
- 用途：宇宙机甲：事件申请/控制子协议。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | WKSMechaEventData 行号 |
| p2 | 低 8 位子命令 |
| p3 | 仅 low8(p2)==2 且尚未提交申请时：完整 uint 申请驾驶员时的 ClassJob ID，写 module+105C0；其他子命令未读 |
| p4 | 本消费者未读取 |

说明：模块 ready 后按 p2 低 8 位分流；命令 2 只在 Submitted bit1 尚未置时置位并存 p3 ClassJob ID，已有 Submitted 时连 p3 也不更新；命令 5 只清 Submitted，不清职业 ID。140A7D0A0/140A7D450/140A7A870 把 module+105C0 与 PlayerState.CurrentClassJobId 比较，不等显示 Log10767“无法驾驶，与申请驾驶员时的职业不同。”；140A7D580 还以 62000+ClassJob 生成职业图标。141A6BCD0 把角色当前 ClassJob 与该值比较；p3 并非序号/错误码/数量。命令 1 按 p1 匹配当前事件后打开 Addon16870 其他任务申请冲突确认框；12 匹配当前事件后仅报名开放且地面传送未开放时清 Submitted；13 关闭事件已保存 YesNo；11 按资源+74 的 GameObject.LayoutId 及+78 的 SequentialEvent 行号请求角色序列事件；活动列表已含相同行号或当前指令关联行号时不重复入队。manager 不存在或资源任一值为 0 不请求。固定附加参数为 1、11111、null，不来自 p3/p4。命令 1 原生未在读 CurrentEvent.RowId 前判空，11/12/13 有判空，不能统一补前置检查。p4..p8/target 未用。详见 MechaApplicationClassJob.md。
