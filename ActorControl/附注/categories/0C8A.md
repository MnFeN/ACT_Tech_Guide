# 3210 / 0xC8A SetIslandLandmark

[分类参数](../../README.md#category-0c8a) · [附注索引](../README.md)

无人岛地标建设

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛地标建设状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 MJILandmarkPlace 槽 |
| p2 | 低 8 位 MJILandmark 行号 |
| p3 | 低 8 位距完工小时数 |
| p4 | 只有恰等于 1 写 UnderConstruction=true |

额外参数：Self p5 低 8 位地标旋转 0/1/2/3；p6 未用。

说明：更新对应地标场景；当前入口不显式检查槽范围。

依据：`0x140EA9730 / IslandState.LandmarkIds,HoursToCompletion,UnderConstruction,Rotation / 0x140EAD3C0`。
