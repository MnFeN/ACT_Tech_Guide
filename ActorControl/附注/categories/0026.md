# 38 / 0x26 ToggleInvisible

[分类参数](../../README.md#category-0026) · [附注索引](../README.md)

角色隐身标志

- 分支地址：`0x140b3a7d6`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对字段。
- 用途：设置角色 ActorControlFlags 最高位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零置 Character+0x1CE8 的 0x80 位，零清除 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：具体消费该位的显隐逻辑待继续追踪；不直接调用 DisableDraw。

依据：`0x140B398D0`、`FFCS Character.ActorControlFlags`。
