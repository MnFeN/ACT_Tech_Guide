# 204 / 0xCC OnInvitationTelepo

[分类参数](../../README.md#category-00cc) · [附注索引](../README.md)

接收队友传送邀请

- 分支地址：`0x140b40d2b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Aetheryte 目的地、邀请者索引与日志/对话/缓存宽度已核对。
- 用途：接收队友传送邀请。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零直接显示不能接受传送的 LogMessage441 |
| p2 | Aetheryte 资源行号；完整 uint 用于资源检查与 Log440 目的地名，邀请 Agent 缓存低 8 位 |
| p3 | 邀请者在本机 Group 的 0-based 小队成员索引，用于名字/跨服世界名查询 |
| p4 | 此分支未读取 |

说明：p1 非零只显示 Log441 无法接受传送并返回。p1=0 时按 p3 查成员，若找到就用该成员名与 p2 Aetheryte 构造 Log440 收到邀请；找不到成员仍继续后续目的地 UI 处理。EXD.Aetheryte(p2)存在且 Agent0x34 可用时设置 Telepo 邀请状态，按 Permission142 决定是否打开 SelectYesno 对话，再显示/隐藏 Telepot 邀请界面；Addon1800/1805 明确通过 Aetheryte→PlaceName 显示目的地。CE9610 格式化参数保留完整 uint，但 Agent+5C/+66 缓存为 byte，后续邀请标题使用该 byte；记录当前程序的宽度差异，不把 p2 当 TerritoryType。目的资源或 Agent 无效时发送内部命令 203 拒绝并清邀请状态。p4..p8 未读。

依据：`0x140C1B5D0`、`0x140836040=EXD.Aetheryte row`、`0x140C1B5D0 Log440/441 and destinationAgent0x34`、`resources-delivery-teleport.json Addon1800/1805 Aetheryte→PlaceName macros`、`0x140CE9610 ASM EBX=EDX fulluint /bytecache+5C`、`0x140CE9920 R15D=R8D fulluint but+5C/+66 bytecache`。
