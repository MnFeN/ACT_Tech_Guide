# 609 / 0x261 ToggleWireframeRendering

[分类参数](../../README.md#category-0261) · [附注索引](../README.md)

翻转场景线框渲染开关并同步五处渲染状态

- 分支地址：`0x140b3af6c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：翻转场景线框渲染开关并同步五处渲染状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此分支未读取 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

额外参数：p1–p8 及 Target 独立目标均未读。

说明：完全无参数的 toggle：以 RenderManager+2E0F1h 当前 byte 是否为 0 产生新 bool，并写回该 byte、+29478h、+2E668h、+370C5h，以及保留其他位仅改 DWORD+30DDCh.bit0。固定 FFCS 三个偏移精确匹配：TerrainRenderer+29D40h+Wireframe43B1h=2E0F1h；BGInstancingRenderer+10F40h+Wireframe18538h=29478h；WaterRenderer+2E390h+Wireframe2D8h=2E668h。原生 14028D1F0 和 140290D50 实际读取前两 renderer 的 Wireframe，非零时将图形上下文+874h 栅格化状态改为(halfDepthBias<<5)|6；其低 2 位 FillMode=2，与 FFCS PackedRasterizerStateDesc 以及 Microsoft D3D11_FILL_WIREFRAME=2 相符，完成从收包到绘制状态核验。剩余两处同步偏移不硬套固定 FFCS FigureRenderer/GrassRenderer 的未命名内部字段。重复收到两次会翻回原值，不能定义为 p1 启用/禁用。未动态打开线框。

依据：`0x140B3AF6C five state writes`、`FFCS Render.Manager/TerrainRenderer/BGInstancingRenderer/WaterRenderer exact field arithmetic`、`0x14028D1F0 BG read -> Context+874 packed state`、`0x140290D50 terrain read -> Context+874 packed state`、`FFCS Kernel/PackedRasterizerState.cs FillMode low2bits`、`https://learn.microsoft.com/en-us/windows/win32/api/d3d11/ne-d3d11-d3d11_fill_mode`、`client/wireframe-field-consumers.json`、[WireframeRenderingToggle.md](../WireframeRenderingToggle.md)。
