- 分支地址：`0x140b3e39d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：飞空艇部件操作结果并刷新界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位飞空艇登记标识，用于查列表索引 |
| p2 | 结果码，0 才重算当前飞空艇数据与返回界面 |
| p3 | 低 8 位值，传给部件 Agent 但当前末端未读 |
| p4 | 低 16 位值，传给 Agent 但当前末端未读 |

额外参数：Self p5 低 16 也被传给 Agent，但当前末端未读取；p6 未读。

说明：AgentAirShipParts 只刷新四个库存部件条目，并不消费转交的索引/结果/其他参数。p1 仅参与查找传参，未决定后续已选飞空艇；p2 决定是否重算。两个 category 在当前 EXE 共用同一分支。

依据：`0x140E42020 / 0x140573680 / 0x140E3EAB0`。
