## 参数与行为

- 核对状态：收包字段、实际消费者与参数身份已核对。
- 用途：记录供 Pc.IsStatus 附加事件匹配使用的状态 ID 与关联事件 ID。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 StatusId，写 QuestManager+CB4 |
| p2 | 完整 uint32 状态关联 EventHandlerId，写 QuestManager+CB8；与 Pc.IsStatus 可选事件对象+20h 的完整 ID 比较 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：实际注册 Pc.IsStatus=140B9D810：先 HasStatus(statusId,E0000000)，可选事件对象非零时再要求缓存 StatusId/EventId 二元组均匹配。省略事件条件不使用缓存。本包不添加/移除状态；p2 不是状态层数、system 参数或 buff 来源 EntityId。 p5..p8 及独立 target 未读；无回放样本。见 QuestWarpEventAndStatusAssociation.md 全部 6851 项脚本包读取 0 错误，101 份 IsStatus 匹配均反编译/反汇编成功，且全部按 SHA 映射到 100Quest+1CustomTalk 真实路径。Quest68906/66909 明确 pc:IsStatus(STATUS0,self)，另用 GetStatusSystemParam 取独立参数；与原生+20h 完整 EventId 比较构成第二证据链。
