# 315 / 0x13B DeactivateType4GatheringPoint

[分类参数](../../README.md#category-013b) · [附注索引](../README.md)

结束特殊采集点

- 分支地址：`0x140b3fa49`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：Type4 禁用门控、次数恢复及实际地图槽清理已核对。
- 用途：终止 Type4 采集点的可见/可用状态，恢复次数并清小地图槽 4。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：清 Flags+310bit1，RemainingCount=Count；末端 Agent0x28 实际是 AgentMap，调用 140FC03D0(agent,4)清第 4 个 MiniMapGatheringMarker 记录。此前“AgentGathering 回调 4”解释撤回。Type4 可见性依赖 bit1，故清后不再通过该门控。p2..p8 未读。

依据：`0x140E8B0D0`、`0x140E8B830 Type4 flagsbit1 gate`、`0x140FC03D0 AgentMap marker slot4 clear`。
