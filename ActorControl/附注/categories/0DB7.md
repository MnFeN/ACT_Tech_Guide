## 参数与行为

- 核对状态：ContentId 来源、完整 0..6 姿态映射及即时应用门控已核对。
- 用途：按 ContentId 同步宇宙赞誉全息影像的站姿/pose 编号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ContentId 高 32 位 |
| p2 | ContentId 低 32 位 |
| p3 | 完整 uint32 姿态编号 0..6；0 普通站姿，1..6 依次为 pose01..06；>=7 忽略 |
| p4 | 本消费者未读取 |

说明：以(uint64)p1<<32|p2 在 7 条 96 字节记录的+18h ContentId 查找，匹配才将 p3 低 byte 写该记录+28h。141A79A10 接收内部类型 893 资料时复制记录，并以同字段与 PlayerState.ContentId(142ADF420=PlayerState+68h)比较，确定该标识不是 EntityId。随后 141A7A7D0(self,matchedIndex,p3)按记录+20h EntityId 找角色，资格允许才即时切姿态；未能即时应用仍保留缓存编号。原生表 14241C300 为[783,13330,13331,13332,13333,7405,7407]，本机 ActionTimeline 依次 normal/idle、emote/pose01_center_loop 至 04、pose05_loop、pose06_loop。会比较当前与默认 timeline 并按需写/播放，非任意动作 ID 或展示名次。其他网络参数不读。仅 WKS 默认委派模块已加载且该链可达时生效。

依据：`0x141A79C40`、`resources-wks-hologram-controls.json`、`resources-wks-hologram-quest.json`、`0x141A79A10 PlayerState.ContentId and shared96byte records`、`0x141A7A7D0 / table14241C300 sevenActionTimeline rows`、`0x141A795B0 / 0x141A796F0 serverTime<module+320h`、`0x141A79F30 / 0x141A7A9F0 statistics-state and09UTC boundary`、`FFCS WKSManager.State+50 CurrentPlanetIndex+15 LatestPlanetIndex+16`。
