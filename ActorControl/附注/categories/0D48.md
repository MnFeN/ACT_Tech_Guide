# 3400 / 0xD48 PrepareCutscene

[分类参数](../../README.md#category-0d48) · [附注索引](../README.md)

准备过场动画

- 分支地址：`0x140b45699`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：资源命名空间及播放状态机已核对。
- 用途：准备指定过场动画的播放状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Cutscene 行号，32 位 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：同一活动 Cutscene 重复应答直接返回；已有另一编号时先清理旧状态，再设 state=1。逐帧 0x1408510D0 按本机 sheet128=Cutscene 取资源路径，要求 row+24 bit1，加载后进入 state2/3，准备标志满足后播放并进入 state4。0x1417BED70 也由 EXD__Cutscene 取同一编号，确认该字段命名空间。不是 Action 行号。

依据：`0x140851350`、`0x140851630`、`0x1408510D0 / sheet-map Cutscene=128`、`0x1417BED70 / EXD__Cutscene__Row_14083A0F0`。
