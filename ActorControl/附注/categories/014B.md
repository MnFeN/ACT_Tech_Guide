# 331 / 0x14B OpenFishingReleaseSettings

打开放生设置

- 分支地址：`0x140b3ff57`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：FishingSpot 十槽、两组尺寸位图、界面节点及应用回组已核对。
- 用途：打开钓鱼放生设置界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 有效低 20 位放生选择位图：bit0..9 一般尺寸，bit10..19 大尺寸；每位按 FishingSpot.Item 原始槽 0..9 编号 |
| p2 | FishingSpot 表行号，用于异步加载钓场信息 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：FishingEventHandler140E91030 仅在 FishRelease Agent 未开时建立 owner 并调用 140F7C1F0，p1 完整 32 位先存 Data+148。140F7C730 从 FishingSpot 最多 10 个 Item 构造界面；140F7C950 用原始 Item 槽取两组 10bit，压缩为实际列表索引后传给 Addon 前两项；UI 不存在的鱼项不占显示位，但协议位仍是原始槽。14138AA20 把第一项绑定 node6..15、第二项 node18..27；原始 fishrelease.uld 分别位于“一般尺寸”(Addon14352)和“大尺寸”(14353)两行。应用回调 140F7C460 再按原始槽重组成 low10 | high10<<10，故不是 HQ 许可、鱼种 ID 或计数；p1 高 12 位没有在此界面读取。p2 FishingSpot 行号，p3..p8 未读。

依据：`0x140E91030 / 0x140F7C1F0 / 0x14048CF50`、`0x140F7C950 protocolslot→displaylist bitremap`、`0x140F7C460 displayselection→originalslot packedlow10/high10`、`0x14138AA20 a3[0]→nodes6..15;a3[1]→nodes18..27`、`client/fish-release-uld.json text14352/14353 ordinary/large size rows`、`resources-fish-release-labels.json labelsandcannotreleaseuncaughtfishlog`。
