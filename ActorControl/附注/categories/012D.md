# 301 / 0x12D SetGatheringPoint

[分类参数](../../README.md#category-012d) · [附注索引](../README.md)

采集点活动资料

- 分支地址：`0x140b3f5cd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与结构/资源已核对。
- 用途：同步采集点槽位、事件 ID 及剩余次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 0..11 的缓存槽位，超过 11 忽略 |
| p2 | 完整 32 位写槽缓存；低 16 位 OR 0x30000 查采集事件 |
| p3 | 低 8 位写槽缓存与事件 RemainingCount |
| p4 | 此路径未读取 |

说明：p1 是槽号，p2 才是采集事件 ID；两者不可互换。

依据：`0x140E96C10`。
