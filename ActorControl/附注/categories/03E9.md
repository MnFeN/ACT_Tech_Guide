# 1001 / 0x3E9 ShowBuildPresetUI

[分类参数](../../README.md#category-03e9) · [附注索引](../README.md)

建房申请应答

- 分支地址：`0x140b3d5d0`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：建房申请应答：使用对应地块缓存进入房屋建造许可证选择，或重取资料。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low8 OutdoorHouseUnit，请求端当前选中地块标识；普通 0..59 含 division，80h/81h 为公寓编码，回包比较与缓存一致性；高 24 位未读 |
| p2 | 完整 32 位结果：0 进入成功处理；非零结束等待且不发 1104。不是 bool 低 byte |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：p1 身份由请求端闭环：Outdoor+125D8h 为当前选中 HouseUnit，复制到+125DAh 请求缓存后，1100/1101 原样发送。原生 140E1C2B0 明确接受普通 0..59 或 80h/81h 公寓编码；普通值包含 division，不是 UI 显示的 1..30 地块号。回包只比较低 byte 与请求缓存，不在此处重新做范围校验。p2 完整 32 位只判断零/非零，不存在已证实的详细错误码枚举。无回放样本。 140E1C190 通过范围/已有房屋/权限检查后缓存 mode1 并发送 1100。140E1BC50 要求 Outdoor 存在、p2=0、HouseUnit 匹配且 mode1 才调用 AgentHousing141722BB0(agent,0)；它整理背包可用槽并打开 Addon263 HousingSelectDeed。其他情况使请求缓存 FF/mode0、以参数 1 通知 Agent 结束等待；若 p2 仍为 0，再发送 1104(p1low8,0,0,0)补取资料。不能把补取过程等同立即选择建造许可证，也不是直接完成建房。

依据：`0x140E1C190 selectedHouseUnit->requestcache mode1 command1100`、`0x140E1BC50 reply gates/p2full32`、`0x141722BB0 openAddon263 HousingSelectDeed`、`client/housing-response-addon-names.json`、`client/housing-exterior-cache-plot-refs.json`、`resources-housing-exterior-request-results.json`、[HousingExteriorRequestResponses.md](../HousingExteriorRequestResponses.md)。
