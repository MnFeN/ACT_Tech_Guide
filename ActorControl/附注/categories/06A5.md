# 1701 / 0x6A5 RefreshNpcAppearanceOverrides

[分类参数](../../README.md#category-06a5) · [附注索引](../README.md)

刷新 NPC 外观覆盖

- 分支地址：`0x140b43dda`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：重新检查并请求场景中已追踪 NPC 的外观覆盖数据。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 未读取 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：14196FFC0 遍历外观缓存，仅处理状态 0/2/3；在对象表找 ObjectKind3 且 BaseId 等于缓存键的实例，找到置 4 并加载／请求，找不到置 0。ENpcResident.Map 为 5..7 时走 141A178C0 本地 ENpcDressUp 路径，其他情况发送内部命令 2300，参数为 NPC 基础 ID。普通外观数据回包 140B4BAA0→14196F7B0→141A172E0 保存武器、十项装备、26byte 捏脸及其他字段，置状态 2；若原状态 4 再触发 ENpcBase 应用。此控制不携带外观、物品或 EntityId 参数，也不为所有未追踪 NPC 创建缓存。

依据：`0x14196F840 exact key state3 / lea rcx,[node+28h] tailcall ASM`、`0x14196FFC0 visible EventNpc scan and request2300`、`0x14196F7B0 normal appearance data response / 0x141A172E0 state2`、`0x141A177B0 ENpcBase load and apply`、`0x141A17B20 state3 selects default weapons/equipment/customize`、`0x141A178C0 sheet784 ENpcDressUp / 0x141A18310 sheet783 ENpcDressUpDress`、`resources-enpc-dress-up-tables.json`、[NpcAppearanceCacheControls.md](../NpcAppearanceCacheControls.md)。
