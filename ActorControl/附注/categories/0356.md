# 854 / 0x356 PvpCurrencyMessage

[分类参数](../../README.md#category-0356) · [附注索引](../README.md)

PvP 货币奖励提示

- 分支地址：`0x140b3cc1e`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：原始 SeString 条件树、附加百分比及持有量差额已核对。
- 用途：显示对战奖励货币获得或到达上限提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Item ID，用于货币物品名 |
| p2 | 非零才显示日志并提示 HowTo141 |
| p3 | 旧持有量 |
| p4 | 新持有量 |

额外参数：Self p5 为获得奖励的附加百分比显示值：0 不显示，非 0 以“(+p5%)”原值显示；p6..p8 未读。仅 p2 非 0 且 p4!=p3 路径读取 p5。

说明：p2 非零时，新旧持有量相等显示 658 上限，唯一文本参数是 p1 物品 ID；不等显示 657，局部数值参数 1=(uint32)(p4-p3)、参数 2=p1、参数 3=p5。已逐表达式解码本机 657：lnum3==0 则空串，否则显示“(+”+num(lnum3)+“%)”，明确 p5 是附加百分比，不是倍率小数或奖励条件枚举；客户端这里不按该百分比重算差额。资源还将 lnum2 作为 Item 行号取名；658 以 lnum1 取 Item 名。最后 HowTo141 并刷新 PvP 资料；p2=0 时仍走资料刷新而不显示这些日志。

依据：`LogMessage657,658`、`resources-pvp-currency-decoded.json Log657 lnum3==0?empty:(+lnum3%)`、`resources-gearset-errors-pvp-currency.json rawSeString657/658`。
