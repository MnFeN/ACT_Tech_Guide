# 1519 / 0x5EF DispatchFrozenActionEffects

[分类参数](../../README.md#category-05ef) · [附注索引](../README.md)

冻结动作源的效果派发

- 分支地址：`0x140b43569`。
- 回放观察：1 次；包族 {"ActorControlSelf": 1}。

## 参数与行为

- 核对状态：GlobalSequence、零基 TargetIndex、动作冻结门控及回放逐目标配对已核对。
- 用途：动作源冻结时，按全局序号和目标索引立即派发缓存动作效果。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ActionEffect.Header.GlobalSequence，uint32；0 不匹配有效缓存 |
| p2 | ActionEffect 中零基 TargetIndex，取低 8 位 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：要求包头为本机/回放观察角色，且通过直播/回放路由门控。在该角色 32 条 EffectEntry 中按 GlobalSequence 和 TargetIndex 查找；记录.SourceId 必须能解析为 Character，且 Character.Representation+24 的动作冻结原因 byte 非 0。满足时将本条最多 8 个非空效果交 1408FE940 派发，并在 Action 资源存在的执行路径清缓存 GlobalSequence 及 TargetIndex；不是重新执行技能或直接重算伤害。1408FFF00 从 Header.GlobalSequence 及目标循环索引生成两键，FFCS EffectEntry 布局一致。唯一 7.57 回放样本 p1=7351,p2=6，精确匹配 1535ms 前寄生清汁 24299 的第 7 个目标 100372A9。样本不记录运行时冻结 byte，不能据此断言具体冻结原因；本文件未发现该序号/目标索引 6 的 EffectResult，亦不据此认定网络丢包。p3..p8 未读。

依据：`0x140900B10`、`0x140900C90`、`0x1408FFF00 cache producer Header.GlobalSequence and target loop index`、`FFCS ActionEffectHandler.EffectEntry source/target confirmed fields`、`0x1408D66F0 freeze OR Representation+24 and0x1408D6A20 resume clear`、`0x1409079B0 zero playback rate freezes;GPose ToggleMotionFreeze bit2`、`replay-effect-replay-pair.json seq7351 target6 object100372A9 action24299 delta1535ms`。
