# 3211 / 0xC8B SetIslandWorkshop

[分类参数](../../README.md#category-0c8b) · [附注索引](../README.md)

无人岛工坊建设

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛工坊建筑状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位工坊槽 |
| p2 | 低 8 位 MJIBuildingPlace 位置号 |
| p3 | 低 8 位 BuildingLevel（资源子行，通常比显示等级低 1） |
| p4 | 低 8 位 GlamourLevel |

额外参数：Self p5 低 8 位 HoursToCompletion；p6 恰等于 1 为 UnderConstruction。

说明：写五个平行数组并刷新指定 ENpc 及 7 个建筑位置的布局。

依据：`0x140EA9730 / IslandState.Workshops / 0x140EAD9E0`。
