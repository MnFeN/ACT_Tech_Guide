# 201 / 0xC9 ZoneInDefaultPos

[分类参数](../../README.md#category-00c9) · [附注索引](../README.md)

按压缩坐标瞬移角色并保留当前朝向

- 分支地址：`0x140b395cd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：XYZ 压缩、XMM2 当前朝向及默认瞬移控制副作用已核对。
- 用途：按压缩坐标瞬移角色并保留当前朝向。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位压缩原生 X |
| p2 | 低 16 位压缩原生 Y 高度 |
| p3 | 低 16 位压缩原生 Z |
| p4 | 此分支未读取 |

说明：p1..p3 低 16 位按 u16*2000/65535-1000 解码 XYZ。收包 ASM140B395D3 明确 XMM2=Character+0xC0 当前 rotation、R9=0 options；14181BED0 真实原型(self,position,floatrotation,options)，旧伪码把 R8 误当第三整数并遗漏朝向。默认 options mode7、reset=true；移动许可拒绝时不处理，成功则清当前目标移动状态与若干运动缓存，设置位置/原朝向，并对本机同步地面/飞行分类、强制移动 Condition70 与控制状态。它不是平滑移动插值，也不读取 p4 作为朝向。其他类型调用同一函数可传不同旋转/选项，不能把所有调用都归同一网络语义。p4..p8 未读。

依据：`0x140B395CD`、`0x14181BED0`、`0x140B395D3 ASM movss XMM2,[Character+C0];R9=0;call14181BED0`、`0x14181BED0 corrected float rotation prototype /SetPosition→SetRotation`、`0x14181BED0 defaultoptions mode7/reset1 and Condition70 clear`。
