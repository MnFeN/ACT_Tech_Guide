# 361 / 0x169 SetWeeklyTomestoneCount

[分类参数](../../README.md#category-0169) · [附注索引](../README.md)

本周神典石获得数

- 分支地址：`0x140b3d28a`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步本周期已获得的受周上限限制神典石数量。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 绝对累计数量，覆盖 InventoryManager+36C8h；不是增量或剩余额度 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140882A80 GetLimitedTomestoneCount 扫描 TomestonesItem.Tomestones==3 的行，仅查询 ItemID 匹配才返回+36C8h。1408753B0 以 Tomestones 行 3 上限减该值算剩余额度；140D934E0/140E08F00 以累计+拟获得数>周上限判断超限，另独立检查持有量 2000。固定 FFCS GetWeeklyAcquiredTomestoneCount 封装与本机消费一致。本机当前 Item49“亚拉戈记忆神典石”，资源周上限 900；定义不能固定某一货币名或 450。p2–p8 未读。

依据：`0x140B3D28A store`、`0x140882A80 GetLimitedTomestoneCount`、`0x1408753B0 remaining cap`、`0x140D934E0 / 0x140E08F00 overflow checks`、`FFCS InventoryManager.GetWeeklyAcquiredTomestoneCount`、`resources-tomestone-cache-raw.json`、`resources-tomestone-cache-typed.json`、[TomestoneCaches.md](../TomestoneCaches.md)。
