# 3203 / 0xC83 SetIslandWorkshopGroove

[分类参数](../../README.md#category-0c83) · [附注索引](../README.md)

无人岛工房干劲

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步无人岛工房干劲当前值并刷新 HUD。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位工房干劲当前值，零扩展写 MJIHud.AgentData+80Ch 的 DWORD；不在此按上限钳制 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140EA9730 case3203 明确将 p1 截为 ushort 传 1409FAE50，助手写 AgentData+2060 DWORD 并尝试刷新 HUD，不能只据存储宽度误写为全 32 位。1409FC580 以此值和 MJICraftworksTension 上限格式化 Addon15106“工房干劲：+当前/上限”。上限由当前 5 个景观槽中 LandmarkId!=0 且 UnderConstruction==0 的数量查表，0..5 分别 10/15/20/25/35/45；不是简单每处+5。刷新前还检查 HUD 数据状态与 AddonReady，不能立即刷新时保留 dirtybit1。p2..p8 及独立目标未读。

依据：`0x140EA9730 case3203 ushort p1 cast`、`0x1409FAE50 DWORD store AgentData+80C`、`0x1409FC580 current+cap ->Addon15106`、`resources-mji-hud-current-value.json explicit groove text`、`resources-mji-workshop-groove-cap.json count0..5 cap10/15/20/25/35/45`、`FFCS IslandState.LandmarkIds/UnderConstruction`、[MjiWorkshopGrooveAndActors.md](../MjiWorkshopGrooveAndActors.md)。
