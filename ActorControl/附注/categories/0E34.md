# 3636 / 0xE34 SetCosmicGatheringPointTotal

[分类参数](../../README.md#category-0e34) · [附注索引](../README.md)

宇宙采集点目标总数

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：附加目标原文、虚文本查找及总数字段消费者已核对。
- 用途：同步可采集的采集点数量目标的总数/上限。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 仅低 8 位写 Manager+E9Ah，作为该附加目标条目+7Ch 总数/上限；零会使该目标创建路径跳过 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：收包仅写 byte，不直接刷新已有目标条目；后续创建目标时使用。附加目标原文为 MassivePcContentTextData119“可采集的采集点数量”。141A72690 把调用者传入文本与 Director 虚 301(119)比较；相等且 Manager+E9Ah 非 0 时，创建类型 1 目标条目并将 E9A 写条目+7Ch 总数/上限。141A73BD0 匹配同文本时将 E9B 写条目+78h 当前数值；其他普通任务目标按 ToDo 类型另取值。不是凭同号套文本：当前虚 301 在四个相关 vtable 均指 141A23FC0，从缓存 Utf8String 按文本 ID 取值；装载 141A25560 及 141A251C0 明确使用 sheet1252 MassivePcContentTextData，内容 1/2 通用范围 100..149 包含 119。两个值仅作为当前可采集点目标的分子/分母显示，不把当前数值直接命名为已采集数量。p2..p8/target 未读，无回放样本；默认任务模块须加载且链可达。

依据：`0x141A709C0`、`FFCS WKS/WKSManager.cs`、`0x141A72690 text==vf301(119) AND E9A!=0→todo7C maximum`、`0x141A73BD0 text==vf301(119)→E9B→todo78 current`、`0x141A23FC0 cached additionaltodo text resolver`、`0x141A25560 and141A251C0 loadsheet1252 MassivePcContentTextData`、`resources-wks-additional-todo119.json`、`resources-wks-director-content-text-ranges.json`。
