# 416 / 0x1A0 SetEventObjectArgument

[分类参数](../../README.md#category-01a0) · [附注索引](../README.md)

事件对象通用参数

- 分支地址：`0x140b418b3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对字段。
- 用途：覆盖 EventObject 的通用 Arg 参数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint 写 EventObject.Arg+1B4；具体解释依对象 SubKind，不能统一称 SharedTimelineState |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：按路由 entityId 查普通 GameObject 并要求 ObjectKind==7；不同于 EventState 或 SharedTimelineState。 固定 FFCS 此字段名 Arg，说明其用途按 GameObject.SubKind 决定；这里只存储，不调用 SharedGroup.PlayTimeline 或 SetSharedTimelineState。与 DF7 命令 1 写同字段，旧“共享组状态”描述应收窄为对象通用参数。

依据：`0x140B418B3`、`FFCS EventObject.cs`、[MechaSceneObjectCommands.md](../MechaSceneObjectCommands.md)。
