# 380 / 0x17C ReplaceGatheringPointConfig

[分类参数](../../README.md#category-017c) · [附注索引](../README.md)

替换采集点配置

- 分支地址：`0x140b3fc21`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与结构已核对。
- 用途：替换采集点基础配置并保存原始配置。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 |
| p2 | 32 位 GatheringPointBase 行号，写 BaseRowId |
| p3 | 低 8 位 GatheringLevel |
| p4 | 低 8 位同时写 RemainingCount/Count |

额外参数：p5 低 16 位 GatheringPointBonus0；p6 低 16 位 GatheringPointBonus1。

说明：先保存旧 BaseRowId、等级、次数及两个 bonus，再清临时显示缓存、重建采集显示；原 BaseRowId 只保存低 16 位。六参都有有效读取。

依据：`0x140E8B260 / FFCS GatheringEventHandler.cs`。
