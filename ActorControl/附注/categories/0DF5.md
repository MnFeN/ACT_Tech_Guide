# 3573 / 0xDF5 SetCosmicMechaStoryState

机甲驾驶剧情状态

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：驾驶剧情位、零值阶段回调及全部参数边界已核对。
- 用途：同步机甲驾驶剧情进行位，零值时刷新当前阶段场景布局。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 不用于模块更新的事件筛选；后续事件层虽比较行号，但本类别无附加消费者 |
| p2 | 完整值恰 1 设 PilotCutscenePlaying；其他值清；恰 0 额外置 module+10 并调用当前事件阶段虚 8 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：模块 141A2D7F0 要求+105CA ready 且 Flags 有 PilotApplicationAccepted，否则不更新。p2 按完整 int 比较：1 设 bit3，0 或 2 等清 bit3，但仅 0 写 module+10 byte=1；当前事件及阶段 handler 存在才调用阶段虚 8。7 阶段真实虚 8 均已导出：1/2/6 仅缺省三槽 pending0→4，3 设 1/4/4，4 设 1/4/(Accepted?1:4)，5 设 2/1/(Accepted?1:4)，7 设 2/2/(Accepted?2:4)；4/5/7 还要求全局模块存在。布局 state1/2/3/4 的启用/过渡参数映射已在 141C53670 核对。此类别无 DFB 额外槽 2 覆盖。p1 不限定模块操作，所有 p1 值均可执行同一模块分支；默认事件转发匹配与否没有新增动作（scene default，7 阶段虚 9return0）。p3..p8/target 未用。详见 MechaPilotCutsceneAndArrival.md。

依据：`0x141A2D7F0 / 0x141A6ACC0`、`client/141A2D7F0_DelegatedActorControl.c cases3573/3574`、`client/mecha-stage-cleanup-virtuals.json seven slot8 targets`、`client/141C5F570_MechaStage3_slot8.c`、`client/141C5F8E0_MechaStage7_slot8.c`、`client/141C53670_mecha_scene_selection.c scene state application`、`resources-wks-mecha-time-labels.json Log10841/10842`、[MechaPilotCutsceneAndArrival.md](../MechaPilotCutsceneAndArrival.md)。
