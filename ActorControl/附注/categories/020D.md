# 525 / 0x20D SetChallengeLogProgress

[分类参数](../../README.md#category-020d) · [附注索引](../README.md)

挑战笔记五项进度

- 分支地址：`0x140b42a01`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步挑战笔记当前页的五项进度。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 当前页签/分类，只有等于 SelectedTab 才应用 |
| p2 | 进度列表第 1 项 |
| p3 | 进度列表第 2 项 |
| p4 | 进度列表第 3 项 |

额外参数：p5/p6 为第 4/5 项；分类 12 对所有匹配项目复用 p2，其余按表顺序读取列表。

说明：各项上限由 ContentsNote 表限制；写显示状态数组并设 Loaded。属于进度值，不是完成位图整字节。

依据：`0x140C2F140 / 0x140C2F1C0`。
