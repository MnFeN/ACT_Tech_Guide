# 3571 / 0xDF3 CosmicMechaParticipation

[分类参数](../../README.md#category-0df3) · [附注索引](../README.md)

宇宙机甲参与确认

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：驾驶获选/地面参与分流、对白行/子行及延迟调度已核对。
- 用途：确认当前机甲事件的驾驶获选或地面参与，地面路径可安排延后战斗对白。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 未使用；直接处理 CurrentEvent，不按此参数选择事件 |
| p2 | 完整值恰 1：设 PilotApplicationAccepted 并清 IsJoined；其他值：设 IsJoined 并清 PilotApplicationAccepted、执行地面参与初始化 |
| p3 | 仅 p2!=1 且非 0 时使用：MassivePcContentBattleTalk 完整 32 位行号；0 不安排对白 |
| p4 | 仅上述对白分支：MassivePcContentBattleTalk 完整 32 位子行号，非数量/奖励/时间 |

说明：141A2D7F0 要求 ready 及 CurrentEvent 非空，调用 141A6B680(event,p2==1,p3,p4)后直接 return1，不走通用事件转发；不要求事件 Flags&3==3。helper 另要求当前全局机甲模块及 MassivePcContentDirector 存在。驾驶分支只设模块 Accepted/清 IsJoined，不使用 p3/p4。地面分支设 IsJoined/清 Accepted，141C55260 更新场景对象交互/选择器，WKSParam1016=1421 作为 ScreenImage，设 module bit13，输出 Log10845“参加了机甲行动！此机甲行动将使用特殊热键栏上的专用技能。”；p3 非 0 时导演虚 337 传(p3,p4,5)。真实基类构造 141A24120 vt1423E2CB8、factory141A23590 的 3 种派生 vt 均槽 337=141A26BA0，按表 1253 MassivePcContentBattleTalk 行/子行读取，保留两参数完整 DWORD。查表成功且 source 存在才替换对白链并创建 5000 毫秒开始计时；无效行/子行不会清原链。计时回调 141A28B00 标记 1261/1262，Update141A25890 不递增首个子行直接 141A27B20 播放，后续按子行递增；实际显示时长另来自资源+0F 秒而不是 p4。地面路径最后发 internal3480(currentEventRow,0,0,0)。p5..p8/target 未用。详见 MechaParticipationAndDelayedBattleTalk.md。
