# 2704 / 0xA90 SetDynamicEventDeadline

[分类参数](../../README.md#category-0a90) · [附注索引](../README.md)

动态事件截止时间

- 分支地址：`0x140b45558`。
- 回放观察：117 次；包族 {"ActorControlSelf": 117}。

## 参数与行为

- 核对状态：截止时间戳、阶段时长上限及服务器秒消费已核对。
- 用途：更新动态事件阶段截止时间与战斗阶段秒数上限。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint DynamicEventContainer.Events 槽索引；数组 16 项，入口无范围检查 |
| p2 | uint 服务器截止时间戳（秒）；写 DynamicEvent+0x60。固定 FFCS 旧名 StartTimestamp 与本机消费不符 |
| p3 | uint 战斗阶段倒计时上限（秒）；写+0x64，非 0 覆盖资源 Duration 形成的默认上限 |
| p4 | 主分支及本消费者未读取 |

额外参数：Self p5..p8 未读取。

说明：140BD4490 在 ServerTime>=deadline 时返回 0，否则 remaining=deadline-ServerTime，再按 State1 登记/State2 准备/State3 战斗的各自时长上限夹紧。State3 用+0x64（p3），为 0 才退回+0x68 资源 Duration*60。因此 p2 不是开始时间，p3 不是每帧递减字段；固定 FFCS SecondsLeft 命名亦需按上下文理解。见 DynamicEvents.md。

依据：`0x140B6C830`、`FFCS ContentDirector.DynamicEvents+0xC98 / DynamicEventContainer.Events+8 / stride0x1D0`、[DynamicEvents.md](../DynamicEvents.md)、`140BD4490 deadline-Framework.GetServerTime，State3 cap+4 else+8`、`141AB9A60 resource.Duration*60→DynamicEvent+0x68`、`141AB98F0向UI返回剩余秒与进度`。
