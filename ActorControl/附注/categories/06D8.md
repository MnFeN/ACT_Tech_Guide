# 1752 / 0x6D8 CloseTrapChest

[分类参数](../../README.md#category-06d8) · [附注索引](../README.md)

关闭强欲陷阱界面

- 分支地址：`0x140b4449a`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：关闭指定宝箱关联的强欲陷阱界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 宝箱 EntityId，必须匹配 Loot+458h 的附加宝箱缓存 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：先按 p1 精确匹配 648-byte 附加宝箱缓存；不存在则直接返回。缓存+264h（十进制 612）==1 时调用 140C3AF30，取得 Agent279 TreasureHighLow，仅当其 IsAgentActive 为真调用虚槽 5 Hide 关闭界面。此类别没有额外查 Treasure，也不清 20h/40h 标志、不改剩余时间或缓存键。 Agent279 由固定 FFCS 命名 TreasureHighLow，NumberArray123 同名；140CF6770 读取 Addon11407“强欲陷阱”标题。不能混称普通 NeedGreed 战利品窗口或停止底层倒计时。

依据：`0x140C3BCC0`、`0x140C3AF30 active-gated Agent279 Hide`、`FFCS AgentModule.cs Agent279 TreasureHighLow`、`0x140CF6770 uses Addon11407 title`、`resources-treasure-highlow-text.json`、[TreasureAndLootCountdown.md](../TreasureAndLootCountdown.md)。
