# 408 / 0x198 ExitRangeResponse

[分类参数](../../README.md#category-0198) · [附注索引](../README.md)

跨区预请求应答

- 分支地址：`0x140b40d56`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：ExitRange 预请求应答、完整状态分支及附加值透传已核对。
- 用途：应答 ExitRange 跨区预请求，许可后继续发送跨区请求。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint 状态：仅 WarpInfo.State==1 处理；0 许可→State2；1 按全局分支恢复或只清临时位置控制 bit0；其他拒绝→State0 并清 BetweenAreas |
| p2 | 完整 uint 附加值，仅 p1==0 保存 WarpInfo+58；State2 后与 ExitRange.InstanceId 和 XYZ 原样发往 internal941 请求，不在客户端解释或换算 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：00D0 与 0198 在当前主 switch 共用同一入口，p3..p8 及 target 未读取。WarpInfo.State1 来源已追到 140861300：当前碰撞对象是 ExitRangeType.ZoneLine(1)，经 EventFramework140B7AAF0 发起预请求且仍存在事件交互活动时等待应答；无事件等待则直接 State2。p2 完整 32 位不作本地比较、不作坐标或时长，140860060 State2 将其与 ExitRange.InstanceId 及 ZoneLineLastHit XYZ 组成后续请求；ASM140860FD9/FE6 为+58→第 5 DWORD，internal941 描述长度 40。此值的服务端内部编码未独立证明，定义为应答附加值的原样透传，不伪称区域号、分线号、随机 nonce 或官方 token 字段。p1=1 且 BYTE13(xmmword142AF9090)==1 时，仅本机存在才清位置控制 bit0，并直接返回，WarpInfo 状态/Condition45 在该分支不被清理；其他全局分支走 140863170(reason3)，清 prefetch、恢复 WarpPos 并 State5、BetweenAreas=true。p1 其他非 0 才直接 State0、Condition45=false、清计时及+C4。p1=0 先 State2/BetweenAreas=true 再保存 p2。重复通知若状态已非 1 整包无效果。详见 ExitRangeWarpAcknowledgement.md。

依据：`0x140862330 / 0x140863170 / Conditions.BetweenAreas`、`client/140861300_area_transition_method.c ExitRangeType1 and EventFramework request→State1`、`client/140B7AAF0_sub_140B7AAF0.c range interaction pre-request`、`client/140860060_area_transition_method.c State2 sends p2 unchanged alongside InstanceId/XYZ`、`client/140860060_sub_140860060.asm 140860FD9/FE6/FFD internal941`、`client/140862330_sub_140862330.asm full p1 branches`、`sources/FFXIVClientStructs/FFXIVClientStructs/FFXIV/Client/Game/UI/WarpInfo.cs +58 remains unnamed`、[ExitRangeWarpAcknowledgement.md](../ExitRangeWarpAcknowledgement.md)。
