# 144 / 0x90 DailyQuestSeed

[分类参数](../../README.md#category-0090) · [附注索引](../README.md)

同步每日任务随机种子并刷新事件状态

- 分支地址：`0x140b42786`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：QuestManager 字段、字节宽度与事件刷新掩码已核对。
- 用途：同步每日任务随机种子并刷新事件状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位写 QuestManager.DailyQuestSeed(+0x6D8) |
| p2 | 非零时向 EventFramework 通知 512 类别状态变化 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：140BE1E50 忽略 PlayerState 接收者，转取 140B51D40 返回的 QuestManager，再写+6D8；不是 PlayerState 本身字段。p2 非零作为 EventFramework 掩码 0x200 刷新的选项；p3..p8 未读。

依据：`0x140BE1E50`、`0x140B42786`、`0x140BE1E50 →140B51D40=QuestManager142ADCE90 →byte+6D8`、`FFCS QuestManager.DailyQuestSeed+6D8`。
