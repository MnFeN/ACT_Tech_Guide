# 3202 / 0xC82 SetIslandExperience

[分类参数](../../README.md#category-0c82) · [附注索引](../README.md)

无人岛经验与等级

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛经验、等级及升级提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 本次经验增量，进入类型 15 ScreenLog |
| p2 | CurrentXP，32 位 |
| p3 | 低 8 位 CurrentRank |
| p4 | 非零对 p6 实体显示获得经验浮字 |

额外参数：Self p5 非零播放升级图像/VFX 并刷新岛屿对象；p6 为用于浮字/升级效果的 BattleChara EntityId。

说明：p1 只在 p4 非 0 时进入浮字；p2/p3 直接写 XP 与 Rank。p5 非 0 还遍历 140 个对象请求刷新。

依据：`0x140EA9730 / MJIManager.IslandState / ScreenImage1138`。
