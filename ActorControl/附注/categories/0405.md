# 1029 / 0x405 HousingActorFade

[分类参数](../../README.md#category-0405) · [附注索引](../README.md)

住宅角色渐显与渐隐

- 分支地址：`0x140b3db94`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：逐帧 Alpha 及透明度末端已核对。
- 用途：令指定住宅角色淡入或淡出。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | BattleChara EntityId |
| p2 | 非零淡入（+1/0.3），0 淡出（-1/0.3） |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：仅 Outdoor 存在，按 p1 查 BattleChara。两路径清 Character+0x236C bit2，设置 AlphaRate(+0x2320)，并解除渲染抑制 bit23。0x14090A010 按有效帧时长累加 Alpha(+0x22E8)，限制 0..1，触端点清速率；最终传 1-综合 Alpha 给 DrawObject.SetTransparency。0.3 为完整 0↔1 行程所需逻辑秒，不强制重设起始 Alpha。

依据：`0x140E1FF90 / 0x140909F00 / 0x140909F40`、`Character构造0x1408D9B30→vtable0x142197100`、`虚槽39=0x140907490→0x14089AD50；虚槽41=0x1409075B0→0x14089ADF0`、`0x14090A010 / Alpha逐帧更新与DrawObject.SetTransparency`。
