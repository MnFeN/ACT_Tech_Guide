# 176 / 0xB0 ResetFestivalQuestFlags

[分类参数](../../README.md#category-00b0) · [附注索引](../README.md)

重置节庆任务记录

- 分支地址：`0x140b433a5`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：FestivalQuestWork 注册名、三字节记录及工作位清理已核对。
- 用途：重置节庆任务工作标志的记录。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位节庆 Festival 编号，写工作记录首字节 |
| p2 | 低 8 位工作记录槽索引；入口无范围检查，当前 Lua 读写仅遍历 1 槽 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：每条 3 字节：byte FestivalId + ushort WorkFlags。140BE0AE0 将指定槽编号设 p1 并清后续 16 位 Flags。140BE0A60 查 FestivalId 与工作 bit；140BE0930 保存工作 bit，Flags bit0 用于 read-only 检查，并执行内部命令 818；Lua 注册名 GetFestivalQuestWorkFlag/SaveFestivalQuestWorkFlag 提供业务名。注意这不是 0x386 当前区域节庆显示设置，也不等于给活动 FestivalPhase 赋值。p3..p8 未读。

依据：`0x140BE0AE0`、`0x140B9F5D0 Lua register GetFestivalQuestWorkFlag→140B9BBE0 /Save→140B9BB40`、`0x140BE0A60 current1-slot lookup /16 work bits`、`0x140BE0930 strings FestivalQuestWork is not ready /read only /FlagMax over`、`0x140BE0AE0 byteID + zero ushort`。
