# 1607 / 0x647 ShowSpectatorHud

[分类参数](../../README.md#category-0647) · [附注索引](../README.md)

显示观战界面与计时

- 分支地址：`0x140b43992`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：启用观战界面显示并同步剩余逻辑秒数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 剩余逻辑秒数，数值转 float；与 0643 写同一个 SpectatorManager+88h 倒计时 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：1417884C0 先清 DAh.bit0，经 141788660 同步剩余秒数，再置 DAh.bit1 请求显示观战 UI。当前方法设置 UI 显示标志，实际界面由后续消费显示，不是本次同步调用直接创建窗口。141788170 证明计时单位为逻辑秒，并以阈值秒数除 60 生成分钟提示。p2–p8 及 Target 独立 target 均未读。

依据：`0x1417884C0 SpectatorManager.ShowSpectatorUI`、`0x141788170 SpectatorManager.Update decrements seconds`、`0x141788660 stores timer and skips already-passed warnings`、`0x1419AB8F0 selects threshold arrays`、`0x14233BE58 / 0x14233BE60 threshold int32 seconds`、`0x1417888B0 ShowLogMessageUIntUInt1532`、`resources-spectator-time-warning.json`、[SpectatorTimeAndWarnings.md](../SpectatorTimeAndWarnings.md)、[FloatConversionAudit.md](../FloatConversionAudit.md)。
