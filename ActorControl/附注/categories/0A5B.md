新月岛知识取得提示

- 分支地址：`0x140b4549b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：以 UnlockLink 投递新月岛知识取得通知。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | MKDLore.UnlockLink（完整 uint32，资源行+8），不是 MKDLore 行号、ItemId 或 ImageId；Agent 遍历行 1..60 按此字段匹配 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：主收包调用 140BCB0B0(type11,&p1,count1)，取得 Agent485 MKDLore 后 140A8FFA0 将 p1 入+200 队列。若本机当前动作 43141 则延后启动；Agent 未激活且资源未在加载时，140A90010 异步加载 MKDLore 行 1..60。回调 140A902C0 明确比较 row+8 的 UnlockLink 与队首，相等才出队；资源行号作为另外的*a5 用于标题 Addon16668/16669 及显示缓存，证明两种编号不等同。通知向 Atk 模块发送 10 项参数、首值 61，包含资源 Image 与格式化文本；随后缓存(UnlockLink,rowId)。本入口没有调用 SetUnlockLinkValue，不能直接称它本身执行实际解锁或将 p1 当作知识道具。当前 60条映射见mkd-lore-unlocklink-map.json。

依据：`0x140BCB0B0 type11 -> Agent485 MKDLore`、`0x140A8FFA0 pending UnlockLink vector / action43141 gate`、`0x140A90010 table1279 loads rows1..60`、`0x140A902C0 matches row+8 then separately uses rowId`、`resources-mkd-lore-notification.json typed MKDLore.UnlockLink`、`resources-mkd-lore-all-raw.json offset8 UInt32`、`mkd-lore-unlocklink-map.json`、[MkdLoreUnlockNotification.md](../MkdLoreUnlockNotification.md)。
