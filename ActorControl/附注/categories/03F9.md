# 1017 / 0x3F9 HousingItemMoveConfirm

[分类参数](../../README.md#category-03f9) · [附注索引](../README.md)

确认家具移动

- 分支地址：`0x140b3d857`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：按已摆放家具容器与槽号确认移动，将本地对象当前位置/朝向提交家具缓存。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low16 已摆放家具 InventoryType；bits16..23 室外 HouseUnit（地块/公寓 division 键），室内不用；bits24..31 未读 |
| p2 | low8 容器内家具槽号；高 24 位未读。室内总索引=50*(InventoryType-25003)+slot；室外每容器 40 槽换算后按地块基址定位 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取；包内没有 XYZ 或旋转字段

说明：140E19A00 优先 Outdoor，否则 Indoor。Outdoor 入口只接受表 1421CF2C0 的 25001/25200（已摆放家具），虽然后续共享换算存在 27000/27200 表路径，已被前置检查排除，不可写成此包支持储藏室。室外槽中间值以 byte 计算，未额外校验标准 40 槽上限；HouseUnit 普通 division=unit/30，80/81 为特殊 division，要求与当前场景 division+1 一致，再加地块基址，公寓特殊加 1460。Indoor 只接受 25003..25014，slot 取 low8，不把正常 50 槽容量说成入口范围检查。140E271B0 按 48 字节 record 取+24h 对象索引，141A820E0 按该索引查 ObjectArray（索引 600 取 TempObject，其他以 ObjectCount 检查）。取得对象后先调用 vf80，再从 GameObject.Position 和 Rotation 复制到 record+10h/+20h。Indoor 有对应本地 HousingObject 时再 SetPosition/SetRotation 同步；Outdoor 在 record 索引为负时可用同家具索引的本地对象。140E29570 在 40 项本地对象中查 Kind12 且 HousingFurnitureIndex+1AEh 相同。所有路径末尾置 HousingManager+E0h=1，越界总索引>=1462 只置该标记不读对象。当前 408 回放无该类样本；未将 vf80 或+E0h 独立命名为未经证实的业务事件。

依据：`0x140B3D857 packed p1/p2 route`、`0x140E19A00 Outdoor/Indoor gates`、`0x1421CF2C0 bytes a96100007062000078690000406a0000`、`0x140E234F0 indoor 50slot conversion`、`0x140E271B0 localtransform torecord`、`0x141A820E0 ObjectArray index/600temp`、`0x140E29570 local HousingFurnitureIndex lookup`、`FFCS HousingFurniture Position10/Rotation20/Index24`、`FFCS HousingObject.HousingFurnitureIndex+1AE`、[HousingMoveConfirmation.md](../HousingMoveConfirmation.md)。
