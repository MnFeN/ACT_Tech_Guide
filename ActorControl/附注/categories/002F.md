# 47 / 0x2F TetherCancel

[分类参数](../../README.md#category-002f) · [附注索引](../README.md)

取消指定连线槽，可按连线 ID 匹配

- 分支地址：`0x140b3a582`。
- 回放观察：14147 次；包族 {"ActorControl": 14147}。

## 参数与行为

- 核对状态：已核对。
- 用途：取消指定连线槽，可按连线 ID 匹配。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 槽，低 8 位 |
| p2 | 预期连线 ID，低 16 位；0 为无条件取消此槽，否则需匹配当前 ID |
| p3 | 未读取 |
| p4 | 未读取 |

说明：清理特效并把对端置为无效对象 ID。

依据：`0x1408CCE80`。
