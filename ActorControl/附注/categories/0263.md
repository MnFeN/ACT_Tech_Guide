# 611 / 0x263 HideActor

[分类参数](../../README.md#category-0263) · [附注索引](../README.md)

角色渐隐或隐藏

- 分支地址：`0x140b416e2`。
- 回放观察：3 次；包族 {"ActorControl": 3}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：按时长渐隐或立即隐藏角色。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零时以 p1*0.1 秒渐隐，零时立即将 alpha 设 0 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

依据：`0x140909F40`、`0x140909E00`。
