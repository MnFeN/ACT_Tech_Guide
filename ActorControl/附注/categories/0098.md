# 152 / 0x98 SetRetainerItemAccess

[分类参数](../../README.md#category-0098) · [附注索引](../README.md)

雇员物品访问开关

- 分支地址：`0x140b42dc3`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：雇员物品选项、跨服副本强制禁用与布尔消费已核对。
- 用途：同步雇员物品访问开关，影响投影容器选项及特定物品使用。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零保存 true 到 PlayerState+5C0；0 保存 false |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：140BE2120 若 InfoModule.IsInCrossWorldDuty 为真则强制返回 false，否则读取此字段。MiragePrism 的 140DAB360 根据它决定是否列入菜单“雇员装备中/雇员所持物品”（Addon3733）；false 时跳过此项，其他选项为物品/兵装库/装备中、投影台、收藏柜。物品使用检查 140E04C30 对特定类型也用此 getter 施加不可用 bit。收包后 EventFramework 掩码 0x1000 刷新。不是 CanFly、不是风脉开关，原先因邻近字段推断的风脉业务关联已撤回。p2..p8 未读。

依据：`0x0098`、`EventFramework掩码4096`、`0x140BE2120 InfoModule.IsInCrossWorldDuty→false else PlayerState+5C0`、`0x140DAB360 menuindex1 skipped when getter false`、`resources-glamour-menu.json Addon3732/3733/3734/3735`、`0x140E04C30 type table1421CCCC8 and unavailable bit0x40000000`。
