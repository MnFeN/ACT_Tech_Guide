# 279 / 0x117 SetFollowMountModel

[分类参数](../../README.md#category-0117) · [附注索引](../README.md)

角色跟随模型

- 分支地址：`0x140b39024`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：FollowMount 与普通 Companion 区分、模型创建/延后/清理条件已核对。
- 用途：设置或清除 FollowMount 表驱动的角色跟随模型。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FollowMount 表行号/控制 ID，0 触发清理路径 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：p1 低 ushort 查 FollowMount；表缺失或 ModelCharaId(+16)为 0 时只缓存到 CompanionContainer+1C，不立即生成。有效模型条件允许时创建/重设 CompanionObject，14174DAD0 type2 按 FollowMount 读取 ModelChara 及跟随参数；普通 Companion 表对应 type1，两者不能混作同一个 minionID。角色已骑乘、正在骑乘、变身/游泳/潜水或死亡时保存在+1A 延后应用。p1=0 仅清/移除 FollowMount 状态；如果现有对象是普通 Companion 且 FollowMount getter 返回 0，早退保留该对象。成功创建时初始化在主人位置/朝向，挂接主人指针和跟随更新；本机额外刷新事件与 UI。p2..p8 未读。无样本证明单一任务场景，定义限于资源表和模型跟随行为。

依据：`0x1408AA090 / FFCS CompanionContainer.cs`、`0x14174DAD0 type2 FollowMount vs type1 Companion,ModelChara+16`、`0x14174B600 owner attachment/current position and orientation`、`0x14174A5D0 only type2 returnsFollowMountId`、`resources-followmount-controls.json sampled FollowMount values`、`0x1408AA090 clear0 preserves ordinary Companion object`。
