## 参数与行为

- 核对状态：HouseId 身份及独立读取已核对；p3 室内类型完整枚举待查。
- 用途：同步当前室内住宅 HouseId 及附加室内类型。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | HouseId 高 32 位：低 16 为 TerritoryTypeId，高 16 为 WorldId；与 p2 拼 uint64 |
| p2 | HouseId 低 32 位：byte0 HouseUnit（地块/公寓分区），byte1 保留未命名，bits16..21 WardIndex，bits22..31 RoomNumber |

说明：此前仅记“住宅关联 64 位标识”，现已独立核实为 HouseId，不能再保留 ContentId 候选。当前 FFCS 签名唯一匹配 GetCurrentIndoorHouseId=140E1F650，直接返回 Indoor+125D0h，恰为 0418 拼 p1 高/p2 低写入的位置；GetCurrentHouseId140E1F030 与 GetOwnedHouseId140E22620 和权限列表比较提供互证。HouseId 八字节含 WorldId、TerritoryTypeId、Ward/Room、Plot/Apartment 标志，非角色 ContentId。包入口无格式合法性验证；房间号等为资源/结构逻辑表示，不能自动转 UI 一基显示编号。p3 本次不命名为 OwnerType 或 EstateType：部分同偏移候选其实来自 Outdoor（其 125D8 是地块 byte），而非 Indoor；必须分基址。Indoor 真实读取有 getter1F670、1FB60/1FBE0/1FC30 对 2 比较及 EventObj2004624..6/2008126/2011571“移动到其他房间”，Lua.IsNeedHousingAuthorityCheck 对 p3==0 和共享住宅归属返回 0/4/255；PatchMark 提示路径对 0/2 比较，但当前表没有 criteria1/2 行可提供枚举文案。先存 HouseId 及 p3，再置 Indoor+12530h=1 并调用对象刷新。p4..p8/target 未读，无回放样本。
