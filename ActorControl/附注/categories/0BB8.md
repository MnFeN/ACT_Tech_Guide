# 3000 / 0xBB8 ResumeEventCoroutine

[分类参数](../../README.md#category-0bb8) · [附注索引](../README.md)

恢复事件脚本应答

- 分支地址：`0x140b4535d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与末端字段已核对。
- 用途：恢复当前事件处理器的 Lua 协程应答。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零继续 Lua 协程；0 将当前 Handler 状态置 2 后结束处理 |
| p2 | 第 1 个 Lua 整数返回值，依 p6 数量读取 |
| p3 | 第 2 个 Lua 整数返回值，依 p6 数量读取 |
| p4 | 第 3 个 Lua 整数返回值，依 p6 数量读取 |

额外参数：Self p5 为第 4 个整数返回值；p6 为返回值数量。四个连续 uint 缓冲由 p2..p5 组成，消费者循环按 p6 读取；入口未见数量上界校验。

说明：先查事件栈当前 Handler；Handler 已处于结束状态则走结束处理。Lua 参数按有符号 int 推入。非零 p6 还登记 24byte 应答记录到管理器队列；不是普通物品更新。

依据：`0x14198A660`、`0x140B7E6F0`、`0x1405EF740`。
