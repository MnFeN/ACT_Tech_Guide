# 308 / 0x134 ShowCollectability

[分类参数](../../README.md#category-0134) · [附注索引](../README.md)

收藏价值飘字

- 分支地址：`0x140b3f970`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：本机 ScreenLog 值入队及 51/52 收藏价值类型对照已核对。
- 用途：在本机显示收藏价值数值飘字，可选暴击样式。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位采集事件 ID，OR 0x30000 后查 EventHandler |
| p2 | 收藏价值飘字显示数值，作为 ScreenLogEntry.Value1 原始 int32 |
| p3 | 非零选 CollectabilityCrit 类型 52；0 选 Collectability 类型 51 |
| p4 | 此路径未读取 |

说明：p1 用于查存在的 GatheringEventHandler，但 140E96D20 实际目标固定本机 source。AddScreenLogMessage 只把数值入队为 Value1，不修改实际收藏价值、物品数量或采集次数。类型 51/52 由 Dalamud 一级源码 FlyTextKind 对照为 Collectability/CollectabilityCrit，后者为带感叹号的较大字体/弹跳表现；这里不把动画样式等同某个服务端随机判定算法。p4..p8 未读。

依据：`0x140E96D20`、`0x1409AF260 AddScreenLogMessage→ScreenLogEntry.Value1`、`https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Game/Gui/FlyText/FlyTextKind.cs Collectability51/CollectabilityCrit52;checked2026-11-16`。
