# 3600 / 0xE10 MassiveContentPositionVfx

[分类参数](../../README.md#category-0e10) · [附注索引](../README.md)

大规模内容位置特效

- 分支地址：`0x140b45a0d`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：大规模内容 Director 的定时位置 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | VFX 行号 |
| p2 | 低 16 位压缩 X，u16*2000/65535-1000 米 |
| p3 | 低 16 位压缩 Y，同公式 |
| p4 | 低 16 位压缩 Z，同公式 |

额外参数：Self p5 按 int32*0.001 转逻辑秒强制回收时长；p6 为可选绑定 BattleChara EntityId，E0000000 为不绑定。

说明：复用 VfxLifetime 文档已核对的定时回收消费者；不是 Omen 缩放。p6 无效且查不到角色则不创建。

依据：`0x141A237B0 / 0x140B51F80`。
