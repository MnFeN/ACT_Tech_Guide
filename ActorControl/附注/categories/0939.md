# 2361 / 0x939 ShowItemGainWithRestriction

[分类参数](../../README.md#category-0939) · [附注索引](../README.md)

物品获得与收益限制提示

- 分支地址：`0x140b45158`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：显示获得物品的单件/多件日志，包含防沉迷收益限制提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 32 位 Item 标识，0 不显示；送日志本地参数 1 及 Item 表名称宏 |
| p2 | 完整 uint32 获得数量；<=1 选择 2071，>1 选择 2072；0 只在 HasAddictionRestrictions 为真时仍显示收益受限提示 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：141780D00 要求 item 非 0，且 quantity 非 0 或 PlayerState.HasAddictionRestrictions(+78h)为真；当前 PlayerState 基址 142ADF3B8，故 byte142ADF430 对应此字段。quantity uint32<=1 用 Log2071，否则 2072；本地参数 1 为 Item 编号、参数 2 为数量（仅多件路径显式加入）。完整 SeString 边界已解码，普通 gnum51=0 为获得了 Item 及数量，gnum51=1 走防沉迷收益减半，其他走无法获得收益；此函数未将传入数量再除 2。HasAddictionRestrictions 门控与模板 gnum51 是独立存储，未声称它们始终数值相同。不是交付或扣除物品，不直接改变库存。

依据：`0x141780D00 unsignedquantity branches`、`PlayerState142ADF3B8+78=142ADF430 HasAddictionRestrictions`、`FFCS PlayerState field+78`、`resources-dynamic-event-reward-templates.json`、`resources-dynamic-event-reward-decoded.json`、[DynamicEventItemRewardNotices.md](../DynamicEventItemRewardNotices.md)。
