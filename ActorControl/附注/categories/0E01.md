# 3585 / 0xE01 StopMechaReactionObjects

[分类参数](../../README.md#category-0e01) · [附注索引](../README.md)

停止机甲反应对象生成

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：停止反应对象重建、延后清理计时与全部参数边界已核对。
- 用途：锁存停止机甲反应对象生成，并在场景更新中清理现存反应对象。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 WKSMechaEventData 行号；匹配事件且 Flags&3==3、模块存在才执行 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

说明：141A6ACC0 caseE01 只置 event+82B1=1；scene 此类别 default、7 阶段虚 9return0，无隐藏参数。真实消费者 141C53670 场景更新把该 byte 作为强制进入反应对象清理路径的条件之一；遍历 scene+1AF0..1AF8 的记录，有效资源/记录、未标记清理且有已生成对象时，通过 ReactionEventObjectManager 按记录+48 index 查对象，141C42A30(obj,30)启动退场计时，并置 record+CC/+CE。141C42A80 只在 SharedGroup 非空时累积 FrameDelta*GameSpeed*30，达到 30 清计时 active；名义 1 秒，不是 30 秒或固定 30 渲染帧。141C57B20 等待该标志清除，再 141C583F0 销毁对象/释放关联，清记录并移除 vector 项，按资源键分组发 internal3476(eventRow,key,count,0)。同一函数的创建门控要求阶段 5/6/7 且该 byte 为 0、当前生成数<70，所以 E01 还阻止后续重建，不只是瞬时清一次。Setup141A6A850 将此 byte 清 0。重复 E01 只保持 1，不凭收包直接重启所有已标记计时器。p2..p8/target 未用。详见 MechaReactionObjectShutdown.md。

依据：`0x141A2D7F0 / 0x141A6ACC0`、`client/141C53670_sub_141C53670.c forced reaction cleanup`、`client/141C53670_sub_141C53670.asm 141C5391D record index;5393D timer30`、`client/141C57B20_sub_141C57B20.c block create and grouped report`、`client/141C42A30_sub_141C42A30.c timer initialization`、`client/141C42A80_mecha_reaction_cleanup_timer.c scaled30 update`、`client/141C583F0_sub_141C583F0.c reaction destroy and relations`、`client/14198A250_sub_14198A250.c index<100 lookup`、[MechaReactionObjectShutdown.md](../MechaReactionObjectShutdown.md)。
