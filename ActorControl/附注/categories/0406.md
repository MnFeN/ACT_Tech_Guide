## 参数与行为

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 有符号结果/计数：负数清临时对象；0 使用默认确认文本；正数按家具 HousingUnplacement 行格式化确认文本 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：仅 Indoor 且 TemporaryObject 有对象时；正数作为确认模板数值，分已放置或储藏室取不同 HousingFurniture 字段。p1 经尾跳转 EDX 透传，初始伪码曾误省略。
