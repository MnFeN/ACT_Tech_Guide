# 1606 / 0x646 SetContentBgm

[分类参数](../../README.md#category-0646) · [附注索引](../README.md)

副本背景音乐

- 分支地址：`0x140b43988`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：设置 Content 场景的背景音乐 BGM 行号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 BGM 资源行号，写 BGMSystem.Scenes[3].BgmId；高 16 位未读 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：14085BD90 是固定 sceneId=3 的 BGM 设置辅助函数。FFCS 独立签名唯一匹配通用 BGMSystem.SetBGM=14085CE00，两者读取同一全局 142AC6EF8/NumScenes+8/Scenes+C0。通用实现以 96*sceneId 寻址，固定辅助对 Scenes 底址+300 写 ushort，恰为 3*96+12 的 BgmId；+306=3*96+18，+336=+30h 自定义淡入淡出开关，+344/+352 为淡入淡出毫秒字段，+376=+58h 初始音量。当前包固定所有控制参数为 0，关闭自定义淡入淡出并将初始音量设 1.0。需 BGMSystem 存在且 NumScenes>3；不是未知场景图形效果，也不是直接打开观战界面。逐帧观战派生 141789FE0 亦用同 helper：状态 20/21 播放 BGM908，22 按 bit 选 909/910，23 播放 BGM1；本机资源分别 BGM_MKS01/02/03 及 BGM_Null。状态完整枚举另在 0648 待查，不影响本类别的 BGM 行号语义。无本包回放样本。

依据：`0x140B43988 p1low16 otherargs0`、`0x14085BD90 fixedscene3 fields`、`0x14085CE00 FFCS BGMSystem.SetBGM unique signature`、`client/ffcs-signature-matches.json`、`FFCS BGMSystem.Scene stride60h BgmId+0C`、`0x141789FE0 automatic spectator BGM selection`、`resources-spectator-bgm.json`、[ContentBgmScene.md](../ContentBgmScene.md)。
