# 213 / 0xD5 RecoverFromEventRange

[分类参数](../../README.md#category-00d5) · [附注索引](../README.md)

脱离指定事件范围

- 分支地址：`0x140b444a4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：EventRange、六方向受限检测、探测高度条件与固定上移 2 单位已核对。
- 用途：本机陷于指定 EventRange 范围时，在碰撞条件满足后上移 2 世界单位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | EventRange 布局实例 ID（LayoutInstanceType=49/0x31） |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：仅 p1 作为 EventRange 布局实例 ID。要求本机存在、Character+2C0 的移动状态不在 2..4、实例 active 且 Collider.ContainsPoint(当前 XYZ)。14182DBE0 对水平半径 0.2 的六个方向做移动碰撞求解，统计求解后水平离起点距离<0.18 的方向；至少 4 个方向受限才继续，原“全局模式门控”解释撤回。以当前 XYZ+(0,2,0)为探测点调用 1418186E0(self,&height,probePosition)，后者第三指针在 R8，旧伪码漏参；返回成功且 height>当前 Y 时，用 14181BED0 移到当前 XYZ+(0,2,0)，保持 Character+C0 当前朝向。查询高度只参与比较，不作为最终 Y。常量 1421A8B80 原始 16 字节 00000000000000400000000000000000，即 float[4]={0,2,0,0}；140B52B90 为向量加法。选项+8..13={7,1,0,0,0,1}，其中+13 抑制本机位置改变时的两项常规回调；其余按 callee 处理。p2..p8 未读，无网络参数控制位移量或朝向。未找到该类回放样本，不进一步指定单一玩法来源。

依据：`0x140B445B4`、`0x1418186E0`、`0x141818500`、`0x14181BED0`、`0x140B444A4..140B44635 ASM /R8 probePosition /XMM2 currentRotation`、`0x1421A8B80 bytes float(0,2,0,0)`、`0x140B52B90 Vector3 addition`、`0x14182DBE0 six probes radius0.2/result distance<0.18 count>=4`、`0x14182D950 movement collision solver`、`0x1418186E0 corrected 3-argument prototype; result+A0 float`、`0x14181BED0 position+rotation/options semantics`。
