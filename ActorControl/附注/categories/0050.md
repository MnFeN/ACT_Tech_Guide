[分类参数](../../README.md#category-0050) · [附注索引](../README.md)

伤害飘字/VFX 并同步当前 HP

- 分支地址：`0x140b3acd7`。
- 回放观察：1986 次；包族 {"ActorControl": 1986}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：伤害飘字/VFX 并同步当前 HP。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 显示伤害量 |
| p2 | 新的当前 HP 绝对值；同步角色、小队及相关 UI |
| p3 | 低 16 位可选 VFX；高 16 位可选 LogMessage，0 则使用 504 飘字 |
| p4 | 此分支未读取 |

说明：此类同时有视觉和数据同步，不是只播放受击特效。

依据：`0x140B3ACD7`、`FFCS CharacterData.Health`。
