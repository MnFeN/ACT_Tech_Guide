# 3222 / 0xC96 SetIslandEntryPermissions

[分类参数](../../README.md#category-0c96) · [附注索引](../README.md)

无人岛访客许可

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步无人岛入场许可位图：好友、部队成员、小队成员。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位完整覆盖 MJIManager+9；bit0 允许好友入场，bit1 允许部队成员入场，bit2 允许小队成员入场；高五位仍保存，但本设置窗口不读取。p1 高 24 位未读 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：140EA93D0/E0/F0 分别读 bit0/1/2；140EA9400/9450/94A0 分别按布尔改对应位并保留其他位，均发送 ExecuteCommand3252(fullByte,0,0,0)。Agent433 MJISettings 把低三位组为 AtkValue4，打开 AddonNameId849。关键新证据：窗口布局加载方法 141499DF0 使用单数资源名 MJISetting，构造 141499BD0 安装 vtable142275A30，OnSetup 虚槽 49=141499E10；布局文件实际 ui/uld/MJISetting.uld，非失败的 MJISettings.uld。OnSetup 表 14226BA00 九条记录中 node15/16/17 分别读取 AtkValue4 的 mask1/2/4 并 SetChecked；ULD 相同节点 TextId15343/15344/15345，资源原文为允许好友/部队成员/小队成员入场，标题 15342 入场许可设置。因此三位身份由原生绑定与 ULD/Addon 资源闭环，不再依靠邻近文本猜测。设置回调依次三个 setter，可能发三次完整 byte。仍区别 Manager+8 AllowedVisitors 字段。无回放样本。

依据：`0x140EA9730 case3222 storebyte+9`、`0x140EA93D0/E0/F0 readbit0/1/2`、`0x140EA9400/9450/94A0 preservebits/send3252`、`0x140A1C760 AtkValue4 /Addon849`、`0x140A1CA60 setters`、`0x141499BD0 ctor vtable142275A30`、`0x141499DF0 LoadUldResourceHandle MJISetting`、`0x141499E10 OnSetup node/AtkValue/mask table`、`client/mji-setting-checkbox-bindings.json`、`client/mji-setting-uld.json nodes15/16/17`、`resources-mji-server-setting-labels.json Addon15343/4/5`、[MjiServerSettingsBitmap.md](../MjiServerSettingsBitmap.md)。
