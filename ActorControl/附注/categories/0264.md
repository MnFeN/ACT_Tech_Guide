# 612 / 0x264 ResetActorPresentation

[分类参数](../../README.md#category-0264) · [附注索引](../README.md)

重置角色动作与武器状态

- 分支地址：`0x140b44db3`。
- 回放观察：7 次；包族 {"ActorControl": 7}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：重置角色时间轴、武器附加状态及待机动作。

| 参数 | 读取与语义 |

| p1 | 此分支未读取 |
| p2 | 此分支未读取 |

说明：清三个 DrawData 子字段并根据 Character.Mode 选择待机/采集/表情时间轴；并非单纯播放固定动画。

依据：`0x1408BEEB0`、`0x1408B0100`、`0x1408BDB00`。
