# 3576 / 0xDF8 RemoveCosmicMechaObjectGroup

[分类参数](../../README.md#category-0df8) · [附注索引](../README.md)

移除机甲反应对象组

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：PopRange 筛选、三维距离排序、处理上限及延后回收已核对。
- 用途：按 PopRange 生成组选择一批机甲反应对象退场，或按内部计数清理。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 WKSMechaEventData 行号；事件外层匹配且 Flags&3==3、模块存在，scene 再次核对同 ID |
| p2 | low8==3 按 PopRange 组筛选、排序后逆序处理；low8==4 不按组筛选且不另排序；其他值不处理 |
| p3 | 仅 low8(p2)==3：完整 uint PopRange 布局 InstanceId/生成组键，匹配动态记录+4；不是 EntityId 或资源类型 |
| p4 | 仅 low8(p2)==3：完整 uint 处理计数上限，0 提前返回且不排序；low8==4 忽略此参数，使用当前已生成计数 |

说明：141C57470 通过 LayoutWorld.GetLayoutInstanceStatic(40,payload+8,0)定位 PopRange，把同 payload+8 写动态记录+4，独立证明 p3 键类型。子命令 3 用 141C5B750 三维距离比较升序，再从 vector 末尾遍历，故正常从远到近处理；相等不保证稳定。比较器还将距 source>WKSParam1006=80 且 EObj BaseId 非 2015375 的被比较记录+CC 置 1，因此排序可额外标记别组对象清理。p4=0 在排序前直接 return，不触发这一排序副作用。子命令 4 不筛组，不重新排序，用 scene+6238 已生成数作计数；内部为 0 未做开头 guard，遇负 index 记录后减计数可 uint 回绕，不能概括总是零个。每个有 BaseId/组键的匹配记录先标+CC；index<0 或查到有效对象并启动 30 逻辑单位退场时才减上限，index>=0 但查不到对象时已标记却不减。重复包可重启退场计时；与 E01 已标记去重不同。后续 141C57B20 等待退场后回收并按组 internal3476 回报，见 E01 专题。ASM141C542FF movzx r14d,bpl、141C54390 cmp r14b,4 确认全部按 low8，不采信旧 C 伪码 v17 完整比较。p5..p8/target 未用。详见 MechaPopRangeBatchCleanup.md。

依据：`0x141C54220`、`client/141C54220_sub_141C54220.asm DF8 542FF byte narrowing /54390 filter /543C9 decrement`、`client/141C57470_mecha_scene_selection.c PopRange(40,payload8) and record4`、`FFCS LayoutEngine.ILayoutInstance InstanceType.PopRange=40`、`client/141C5B750_sub_141C5B750.c 3D sort comparator and marksideeffect`、`client/141C5BD30_sub_141C5BD30.c ascending insertion/introsort`、`resources-mecha-reaction-cleanup-radius.json WKSParam1006=80`、`client/141C57B20_sub_141C57B20.c delayed removal and3476`、[MechaPopRangeBatchCleanup.md](../MechaPopRangeBatchCleanup.md)。
