# 573 / 0x23D SetVentureTutorialFlags

[分类参数](../../README.md#category-023d) · [附注索引](../README.md)

雇员探险教程进度

- 分支地址：`0x140b3bf91`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：包宽度、当前记录选择、原生 Lua 名称及实际消费者已核对。
- 用途：覆盖探险教程进度标志（VentureTutorialFlags）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位完整覆盖全局教程 bitmask；不是按位 OR 命令 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：本机 Lua 注册 141C9AA10 明确 IsVentureTutorialFlagOn→141C9D1D0，以 Lua 第二实参与 word142ADC598 按位 AND。注册常量 1 介绍、2 重置说明、4 已设职业、8 已设主手、16 战斗说明、32 采矿说明、64 园艺说明、128 捕鱼说明、256 已接受探险、512 已完成探险、1024 探索说明（ABOUT_FORTUNE）、2048 投影说明、4096 染色说明；高 3 位未有注册名，仍原样保存。141C9DB40 依据有职业/无主手/当前 VentureId 对 4/8/256 作本地补充 OR 并发 ExecuteCommand1401；服务器回包 023D 本身是覆盖。UpdateVentureTutorialFlagOn 使用 ServerRequestCallback8，callback8 也覆盖同 word。

依据：`0x140B386F0`、`0x141C9AA10 nativeLua registration and flag constants`、`client/retainer-active-consumers.json`、`0x141C9D600 callback8/9`、`0x141C9D1D0 maskquery`、`0x141C9DB40 sticky tutorialbitupdate andmenus`。
