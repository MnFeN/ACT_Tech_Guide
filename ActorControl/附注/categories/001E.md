# 30 / 0x1E SetNpcPartState

[分类参数](../../README.md#category-001e) · [附注索引](../README.md)

设置 NPC 部件状态

- 分支地址：`0x140b3f321`。
- 回放观察：138 次；包族 {"ActorControl": 138}。

## 参数与行为

- 核对状态：已核对，纠正历史解释。
- 用途：NPC 部件状态切换及可选部件破坏日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 部件索引 0–5，必须小于 6 |
| p2 | 部件状态，低 8 位缓存；0/1/2 各有模型属性与时间轴处理 |
| p3 | 用于日志的另一个实体 ID；仅 p4 非零且对象存在时使用 |
| p4 | 非零触发 LogMessage605“坏掉了”通知；不是目标 VFX 开关 |

说明：若实体尚未登记，分支还可把 p2 写入待生成缓存对应部件槽。BNpcBase17833 引用 BNpcParts67；不能称为圣龙模型绑定。

依据：`0x1408D44E0`、`BNpcBase.BNpcParts`、`resources.json LogMessage605`。
