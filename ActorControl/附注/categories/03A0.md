# 928 / 0x3A0 SetMountGroundSpeed

[分类参数](../../README.md#category-03a0) · [附注索引](../README.md)

坐骑地面基础速度

- 分支地址：`0x140b43d86`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步非默认坐骑移动配置的地面基础速度覆盖值。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 数值转换为 float，写 PlayerState+7A4h；非零且 MoveControl 行号!=1 时覆盖 GroundSpeed，0 不覆盖默认表值 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：本机 global142ADFB5C。141827830、141828500、14182E600 及 1418378A0 均先取 Mount 行+30h 的 MoveControl 行号；无坐骑默认 1。读取 MoveControl+8 GroundSpeed 到控制器+58h；非 1 行且覆盖值>0 时才替换。141829540 在移动模式 1..6 及未选 RP 走路的路径读+58h，并乘 1408D6110 的状态速度倍率；RP 走路、后退等走相应表字段，不能说所有方向无条件改速。1418294D0 将其作为最大/目标速度供 1418297E0 逐帧加速上限使用。p1 不是 IEEE754 位重解释，不是百分比，也不是 Mount 表 ID；收包本身只写覆盖缓存，读取发生于配置初始化/刷新。 汇编复核纠正此前 signed 结论：140B43D7A mov eax,[p1]零扩展到 RAX，140B43D81 cvtsi2ss xmm0,rax，因此按 uint32 数值转换；FFFFFFFFh 成为约 4.295e9 的正 float，不能当作负数禁用。反编译中(float)(int)p1 的符号表达不可靠。

依据：`0x140B43D86 uint32→float`、`0x141827830`、`0x141828500`、`0x14182E600`、`0x1418378A0`、`0x141829540 +58h GroundSpeed consumer`、`0x1418294D0 / 0x1418297E0 speed ceiling`、`resources-gold-content-movement-typed.json MoveControl.GroundSpeed`、[MovementOverrideAndBeginnerFlags.md](../MovementOverrideAndBeginnerFlags.md)、`0x140B43D7A mov eax / 0x140B43D81 cvtsi2ss xmm0,rax`。
