# 1035 / 0x40B SetInteriorEnvironment

[分类参数](../../README.md#category-040b) · [附注索引](../README.md)

室内环境设置

- 分支地址：`0x140b3dcaf`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步室内环境设定并可显示变化提示。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 模式 0 显示变化提示；1 立即应用；其他值只同步目标缓存和 UI |
| p2 | 低 8 位亮度档位 0..5，提示显示 5-p2 |
| p3 | 非零开启家具屏幕空间环境光遮蔽 |
| p4 | 此路径未读取 |

说明：仅 Indoor；模式 0 按当前配置/状态决定亮度过渡，亮度或 SSAO 变化才显示 6117。

依据：`0x140E1D3C0 / 0x140E38760 / LogMessage4172,6115,6117`。
