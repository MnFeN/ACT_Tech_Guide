- 分支地址：`0x140b45a03`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：通知类别与点击后分类导航已核对；p2 附加 byte 业务待查。
- 用途：通知莫古莫古大收集目标达成并提示领取报酬。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 仅低 8 位写通知记录+0Ah，既作队列优先级又作点击后指南书分类索引 0..3；导航时>=4 回退 0，但排序仍用原 byte |
| p2 | 仅低 8 位保存到通知记录+10h（不是旧文档的+11h）；当前已核对导航路径不读取它，具体附加语义待查 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：属于同一 CSBonusManager；不覆盖 EventInfo 字段，构造[p1 低 8,p2 低 8]临时负载，category3455 通知订阅者。140A58F30 显示 Log1498“达成了莫古莫古大收集活动目标，请在指南书领取报酬”，将两 byte 写入 Addon15914 可获得奖励通知记录并排入 Agent452 通知队列；指南书数据存在时关闭窗口。两个 byte 分别进入通知记录+Ah/+10h，+Ah 还影响通知优先级；具体目标分类与序号映射尚未独立核对，未凭位置直接命名周常/迷你/终极。不是直接授予报酬。 后续已定位 AgentMoogleCollection452 构造 140A586B0/vtable1421A2D78；140A58B70 仅按 ServerTime-通知 timestamp 驱动 HUD 最长 30 秒倒计时，140A58A40 打开指南书前清通知队列，141AA2870 同样只 Show。现有这些消费者没有读取两个 byte 以定位目标，不能据此擅称周常/迷你/终极；140A59390 只计算周序号，已排除为通知分类 getter。 偏移纠正以 ASM140A58FC7/8FE4/8FEF/8FF3 为准：传入通知结构起点 rsp+20h，p1 写 rsp+2Ah、p2 写 rsp+30h，rsp+31h 另固定清 0，故+11h 是本地导航请求状态，不是网络 p2。新追到 HUD 通知点击入口 140FDD060 case31→140A59480，将队首+11h 置 1 再 140A63570 加载指南书。异步完成后的 140A639E0/140A63B60 读该状态和通知+8h 的 season，匹配当前可见两个 season 后以 p1byte 作分类（>=4 归 0）调用 140A5F350(data,seasonIndex,category,0,0)。后者把 category 存选定 season 记录+1E0h 并按+10h 起 4 个 WORD 选择请求；140A65AE0 用同分类查询 CSBonusMissionType，当前 0..3 映射显示模式 1..4。此前只查 Agent 构造到 59390 范围，漏了 59480 点击及 63xxx 异步导航消费者，现已补齐。不将尚无读取证据的 p2 直接命名为任务下标。
