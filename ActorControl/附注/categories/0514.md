# 1300 / 0x514 SetVerminionStage

[分类参数](../../README.md#category-0514) · [附注索引](../README.md)

萌宠之王关卡

- 分支地址：`0x140b3909c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步萌宠之王当前 MinionStage 关卡编号。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 MinionStage 表行号，直接覆盖 Director+62Dh；1 为第 1 关新手教学，9 为第 9 关铜山爆破 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：不是抽象玩法模式。独立消费者 140E75C00、140E76040 均以 Director+62Dh 直接查询 MinionStage，前者按行+4 播放背景音乐并读取+6 bit0 调整场地布置，后者据同表初始化设施 VFX。大型玩法初始化 140E76B30 从其数据+4 写相同 byte 后也查 MinionStage。当前表 0..33 共 34 行；1..24 有明确关卡名，0 及 25..33 名称为空，不能替空名行臆造玩法枚举。接收入口仅截 byte 存储，无资源行有效性检查，也不在本分支直接调用场地初始化。0516 对关卡 1 处理教程步骤、对关卡 9 处理专用演出颜色；关卡 15 另有设施路径特殊判断。p2..p8 及独立 target 均未读。无现有回放样本，未运行游戏。

依据：`0x140B39144 writeDirector+62D`、`0x140E75C00 MinionStage(Director+62D)`、`0x140E76040 MinionStage(Director+62D)`、`0x140E76B30 independent initialization stage byte`、`resources-verminion-stage-all-raw.json`、`resources-verminion-stage-identities.json`、[VerminionStagesAndTutorial.md](../VerminionStagesAndTutorial.md)。
