# 237 / 0xED CollisionMoveResponse

[分类参数](../../README.md#category-00ed) · [附注索引](../README.md)

碰撞位移请求应答

- 分支地址：`0x140b43d9f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：ContentAttributeRect 区域碰撞来源、缓存索引及确认/重发闭环已核对。
- 用途：确认或重发区域属性碰撞触发的本机位移请求。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 非零：有效请求缓存清零并清 Condition47；0：重发有效缓存，不重新启动本地轨迹 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：不依赖路由角色查找，操作全局输入控制器 142AB28B0+410h 的 24 字节请求；缓存+5byte!=FF 才有效。141835800 及 14182D230 构造来源已追到 140864460→140E12DD0：要求区域属性模块激活，碰撞材质具有指定标志，在位置查询附近 MapRange(type43)碰撞布局，其 MapRangeFlags3 bit0 置位后，用 LayoutId 和材质类别查 140846600。后者遍历当前 ContentAttributeRect 的 32 项、匹配布局 ID/类别并检查有效位图；type2 可按 Status 存在豁免，type3 可按 Character.TransformationId 相等豁免；返回 0..31 条目索引，缓存+5 正是此索引。1408464D0 原生 sheet638=ContentAttributeRect 异步加载，条目 12bytes，本机 83 行资源列 offset0 参数/4 布局 ID/8 类型/9 材质类别。141835B50 计算碰撞修正方向，141835800 先建立本地位移，再 14062BE30 写请求并置 Condition47；14182D230 的带时长变体用 14062C0A0 写同一缓存。00ED 非零仅清缓存/Condition47，不直接停止当前轨迹；零只调用 14062BCA0 用原缓存发送内部 550(size40)，不重新执行位移构造。没有 NetworkModuleProxy 则不发；录制条件满足时把相同 24 字节记录为内部 494。550/494 是本机构建内部标识，不能作线上 opcode。p2..8/独立 target 未读，不比较网络序号或再消费 p1 错误原因。Condition47 固定 FFCS 仍叫 Unknown47，此链可描述为请求等待状态但不假造官方字段名。141835B50 初始精确 framewrong 已按原 frame 参数重建后成功；原 frame 和失败诊断保留。无本类回放样本。
