# 931 / 0x3A3 BeginReplayAck

[分类参数](../../README.md#category-03a3) · [附注索引](../README.md)

副本回放开始应答

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：实况 Self 外层、开始请求配对及状态门控已核对。
- 用途：开始副本回放的应答／许可，按挂起请求进入回放播放状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 完整 uint32 非零为允许开始；仅+743h 开始挂起 bit0 置位时处理并先清 bit0，0 或当前+742h RecordingPackets.bit2 为真则不开始，否则初始化回放播放状态 |
| p2 | 开始应答处理未读取 |
| p3 | 开始应答处理未读取 |
| p4 | 开始应答处理未读取 |

额外参数：Self p5..p8 未读取；Self 没有独立 target 字段；路由 EntityId 不用于选择另一个角色

说明：实况 1418D71D0 Self 分支先调用 1408494E0，在通用 HandleActorControl 之前处理。本类旧 EndReplayAck 名称不符当前构建，03A3 实际为开始应答，03A4 为结束应答；03A2 已确认是下坐骑/坐标纠正。开始请求 140847C80 置 pending 并发 1980，成功应答置 InPlayback、重置位置/速度/头部暂存/Level 等。931/932 不通过录制白名单，解释 408 回放无本类样本，但未动态启动游戏验证。详见 ReplayActorControlOuterPaths.md。

依据：[ReplayActorControlOuterPaths.md](../ReplayActorControlOuterPaths.md)、`client/replay-outer-catalog.json：实况Self外层，非主分发默认链`、`1408494E0 C/ASM category931/932 before recording whitelist`、`140847C80 command1980 startpending bit0 /140847DA0 command1981 stoppending bit1`、`14084BEA0 excludes931/932 from recorded Self whitelist`、`14084950A category3A3 /140849535 fullDWORD p1 /14084954A TEST ECX,ECX`。
