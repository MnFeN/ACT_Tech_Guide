大鱼出现提示

- 分支地址：`0x140b3fe40`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：FishingSpot 转读宏、出现/再次出现列及时间轴资源已核对。
- 用途：显示指定钓场的大鱼出现或再次出现提示，后者播放直感恢复时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | FishingSpot 资源行号；Log3530 取该行 BigFishOnReach 列 1，Log5582 取 BigFishOnRefresh 列 3 |
| p2 | 0 为首次出现提示 3530 并播放固定音效 3；非 0 为再次出现提示 5582，本机存在时尝试时间轴 11968 fishing/int_recover |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：原先“空模板”来自去除 SeString 宏的纯文本；原始 Log3530/5582 为 sheet(FishingSpot,lnum1,1/3)，不是直接显示数值。已枚举本机 576 行 FishingSpot，75 行出现/结束字段非空、73 行再次出现字段非空，另含测试行 1；例如行 17 为“感觉到附近有比大泷太郎还要大的鱼在活动！”及“再次感觉到附近有比大泷太郎还要大的鱼在活动！”。此类只提示/表现，不在此直接写直感 Status 或鱼种解锁位。p3..p8 未读。
