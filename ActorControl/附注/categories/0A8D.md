# 2701 / 0xA8D OpenDynamicEventDuelInvitation

[分类参数](../../README.md#category-0a8d) · [附注索引](../README.md)

动态事件单挑邀请

- 分支地址：`0x140b454da`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：DynamicEvent 门控、MycDuelRequest 与单挑邀请 UI 已核对。
- 用途：打开动态事件单挑邀请窗口。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint DynamicEventContainer.Events 槽索引；数组 16 项，入口无范围检查 |
| p2 | 主分支及本消费者未读取 |
| p3 | 主分支及本消费者未读取 |
| p4 | 主分支及本消费者未读取 |

额外参数：Self p5..p8 未读取。

说明：要求 DynamicEvent.EventType+0x56==2 且容器资源分型为 1；向 Agent387 MycDuelRequest 传事件槽 byte+0x1CC。140DA6C90 打开邀请并设置服务器时间+30 秒应答期限，读取该槽的 DynamicEventSingleBattle 资源。这个 30 秒由客户端固定，与 p2..p4 无关。

依据：`0x140B6C7D0 / 0x140BCB420`、`FFCS ContentDirector.DynamicEvents+0xC98 / DynamicEventContainer.Events+8 / stride0x1D0`、[DynamicEvents.md](../DynamicEvents.md)。
