# 941 / 0x3AD SetAchievementRewardEligibility

[分类参数](../../README.md#category-03ad) · [附注索引](../README.md)

成就物品奖励领取资格

- 分支地址：`0x140b44b9c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：更新成就物品奖励领取资格辅助位图的一个字节。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 辅助位图字节索引；写 Achievement+214h+p1，入口无边界检查 |
| p2 | 低 8 位完整覆盖指定字节；逐 bit 由 Achievement 资源 Unknown1/Unknown2 选择索引和正反极性 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：读取器 140C1D5E0 按 bitIndex 测试。AgentAchievement140EDA290/140EDB3C0 在资源有 Item 奖励时，以+60 Unknown1、+61 Unknown2 作资格索引：仅前者有效要求置位，仅后者有效要求未置位；两者均有效或均 255 均不测试、资格 false。所得 flags.bit11 与主成就完成 bit0 独立；Addon141333590 对应：未完成->Addon13959 未达成；已完成且资格 true->13960 可领取；已完成且 false->13961 已领取。因此不能把底层每 bit 统一叫已领取位，也不应把 03AD 叫同步成就完成位。当前资源 266 个关联行，正向 33、反向 165、两列都有值但此路径不测试 68；完整索引、字节位置、奖励 Item 和成就名已存机器映射与专题表。

依据：`0x140C1D460 byte overwrite`、`0x140C1D5E0 bit predicate`、`0x140EDA290 / 0x140EDB3C0 Achievement Unknown1/Unknown2 -> UI800`、`0x141333590 completion/eligibility -> Addon13959/13960/13961`、`resources-achievement-reward-state-text.json`、`achievement-reward-flag-map.json`、[AchievementRewardEligibilityBitmap.md](../AchievementRewardEligibilityBitmap.md)。
