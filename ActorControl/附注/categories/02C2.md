# 706 / 0x2C2 ActionUseFailed

[分类参数](../../README.md#category-02c2) · [附注索引](../README.md)

物品或技能使用失败

- 分支地址：`0x140b405c5`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与实际日志模板已核对。
- 用途：提示道具使用中断或技能发动失败。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ActionType；2 选 LogMessage539，其他选 613 |
| p2 | Action ID/该类型对应资源 ID |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：p1==2 显示 LogMessage539“中断使用道具”，以 p2 取 Item；其他 ActionType 显示 613 发动失败，按技能类型/ID 格式化。source 为路由角色，p3/p4 未读。

依据：`FFCS BattleLog.AddActionLogMessage`。
