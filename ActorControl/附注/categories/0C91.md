# 3217 / 0xC91 SetIslandMinionSlot

[分类参数](../../README.md#category-0c91) · [附注索引](../README.md)

无人岛放养宠物槽

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步无人岛放养宠物槽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 放养槽 0..49 |
| p2 | 宠物 EntityId，E0000000 不登记 |
| p3 | Companion 行号，消费者另转换为当前可用编号 |
| p4 | 放养区域 1..14 |

说明：登记 50 项 12byte 槽，设 RoamingMinions 并刷新 MinionManagement；会复用已有宠物槽或空槽，不能把索引直接当 Companion 行号。

依据：`0x140EA9730 / 注册模块0x141A67950 / FFCS MJIPastureHandler.MinionSlots`。
