# 220 / 0xDC GimmickJump

[分类参数](../../README.md#category-00dc) · [附注索引](../README.md)

按 GimmickJump 配置启动机关跳跃

- 分支地址：`0x140b422c9`。
- 回放观察：479 次；包族 {"ActorControl": 479}。

## 参数与行为

- 核对状态：分支、汇编与表布局核对。
- 用途：按 GimmickJump 配置启动机关跳跃。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 高 16 位原生 X，低 16 位原生 Y 高度；不是打包的两个地面坐标 |
| p2 | 低 16 位原生 Z |
| p3 | 低 8 位 GimmickJump 行号；bit16 传入移动标志，其他高位未见使用 |
| p4 | 移动确认序号，写入移动控制器；受限状态可能发送命令 602 确认 |

说明：当前 479 条全部是普通 ActorControl，不能描述成通常 Self 作为此样本事实。坐标解码同 B7。

依据：`0x1418147B0`、`0x14181F250`、`resources.json GimmickJump`。
