# 348 / 0x15C MateriaMeldFailureEffect

[分类参数](../../README.md#category-015c) · [附注索引](../README.md)

魔晶石镶嵌失败表现

- 分支地址：`0x140b3c048`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：失败分支及资源宏参数已核对。
- 用途：魔晶石镶嵌失败的动画、日志和委托界面响应。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 装备 Item ID，LogMessage1202 文本参数 1 |
| p2 | 魔晶石 Item ID，文本参数 2 |
| p3 | 损失魔晶石数量，文本参数 3 |
| p4 | bit1 控制委托后续模式；bit0 虽传入消费者但消费者未读 |

说明：按职业/潜水/角色模式播放不同失败 VFX 及动作；距本机<5 时显示 1202；本机时更新 MateriaAttach。本机 1202 宏分别以 lnum1/2 取 Item，以 lnum3 显示化成粉末的个数。

依据：`0x1418F0240 / LogMessage1202 / AgentMateriaAttach`。
