# 2368 / 0x940 SetFateMapMarker

[分类参数](../../README.md#category-0940) · [附注索引](../README.md)

FATE 地图标记位置

- 分支地址：`0x140b450cd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：设置 FATE 自定义地图标记位置。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FateId |
| p2 | uint32/1000 得到 X 米 |
| p3 | int32/1000 得到 Y 米 |
| p4 | int32/1000 得到 Z 米 |

说明：p2 在当前主入口确为无符号转换，p3/p4 有符号。使用 FATE 名字、MapIconId 和当前 TerritoryType 构建标记，不直接改 FATE 中心位置。

依据：`0x141780BA0 / MapMarkerData.SetData`。
