# 200 / 0xC8 ZoneIn

[分类参数](../../README.md#category-00c8) · [附注索引](../README.md)

角色入场/复活相关显现表现

- 分支地址：`0x140b39590`。
- 回放观察：18358 次；包族 {"ActorControlSelf": 2165, "ActorControl": 16193}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：角色入场/复活相关显现表现。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 等于 1 时从 alpha0 开始以 1 秒渐显；其他值走立即设置 alpha1 的路径 |
| p2 | 非零时执行复活动作时间轴 77 及 LogMessage560 |
| p3 | 低 16 位可选 ActionTimeline |
| p4 | 低 16 位可选 VFX，播放后登记到 VfxContainer 槽 13 |

说明：同时处理坐骑子对象显现和本机相关 UI；不是无参数的普通入场开关。

依据：`0x140862A00`。
