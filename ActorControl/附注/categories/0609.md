## 参数与行为

- 用途：同步驯兽师一号、二号、三号兽笛选定的魔兽。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位 XBMPet 行号，写 ActionManager+184h 的槽 0，对应 Action44881 一号兽笛；0 为空选择 |
| p2 | 低 8 位 XBMPet 行号，写+185h 的槽 1，对应 Action44892 二号兽笛；0 为空选择 |
| p3 | 低 8 位 XBMPet 行号，写+186h 的槽 2，对应 Action44894 三号兽笛；0 为空选择 |
| p4 | 此路径未读取 |

说明：1408EF0B0 无资源范围/解锁/重复检查，直接覆盖三个 byte；同时把截 byte 后的无符号数写全局文本数值参数 109/110/111，并将 Agent500 XBMMonsterNotebook 的+5E/+5F/+60 三项重建标志置 1。固定 FFCS 标为 selected Battlehorn pets，XBMPet RowIds；本机 getter1408EF2E0 对槽 0..2 返回该 byte，其他槽返回 0。GetExtraParamForSummonAction140B2C680 对 44881/44892/44894 分别选 0/1/2 槽，非 0 才用该 XBMPetId 查询 XBMNoteModule 的 PetMirage；注意返回的是外貌选项，不是再次把 ID 本身当 extraParam。140AAAE30 在 ClassJob43 时将三槽复制进图鉴；本机 ClassJob43 正文为驯兽师，三个 Action 名称为一/二/三号兽笛，直接证实业务归属。当前 XBMPet 表 0..50，0 为空，1..50 有数据；范围只是当前资源事实，收包仍可保存 51..255 而未验证。不是三条召唤兽 EntityId 或 Companion 宠物编号，不直接召唤/遣散场上实体，也不设置魔兽解锁、大小或变种。p5..p8 及独立 target 未读，现有回放无样本。
