# 1020 / 0x3FC SetOutdoorGardenState

[分类参数](../../README.md#category-03fc) · [附注索引](../README.md)

室外园艺种子与生长

- 分支地址：`0x140b3d8ee`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：同步室外园艺家具部件的种子与生长状态。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | byte0 家具对象索引；byte1 地块；byte3 部件槽；byte2 未读 |
| p2 | low16 GardeningSeed 行号；byte2 生长状态；byte3 附加缓存状态 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：每部件缓存 stride6，种子 FFFF 及状态 FF 为不更新哨兵。场景 BaseId131126..131128 将种子映射 GardeningSeed+8 模型，byte2 驱动部件状态；byte3 仍写缓存，但此园艺即时绘制链不使用该附加值。不能叫染色。

依据：`0x140E1F690 / 0x140E28890 / 0x141AC58C0 / 0x141C6B630`。
