# 3561 / 0xDE9 ShowCosmicAchievementRewards

探索成果奖励档位

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：普通成果与五档位独立队列、DailyDefine 资源及奖励通知消费已核对。
- 用途：排入单项探索成果及最多五个日常成果奖励档位通知。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位成果 WKSAchievement 行号，140A7EA60 排入普通成果通知；FFFF 为队列消费者的日常档位分支哨兵 |
| p2 | 先完整 32 位非零才入队，再截低 8 位作 WKSAchievementDailyDefine 奖励档位行号 |
| p3 | 同 p2：下一项独立日常成果奖励档位行号 |
| p4 | 同 p2：下一项独立日常成果奖励档位行号 |

额外参数：Self p5/p6 各按完整非零检查后截低 8 位排入另一个日常奖励档位通知；p7/p8/target 不用

说明：纠正旧“分类 byte”命名。先 140149350→140A7EA60 以 p1low16 排一项；再顺序检查 p2..p6 完整 uint，非 0 则 1401493A0→140A7EB10 排入默认 achievementIdFFFF、dailyTier=low8 的项。不会去重，不把完整 256 当 0 跳过，256 会入队档位 0。Agent 更新 140A7EE10 逐项调用 140A80960：成果 ID 非 FFFF 取 WKSAchievement 名称及 RewardItem、研究工具图标/奖励；FFFF 则按 tier 查 WKSAchievementDailyDefine 门槛和 141A761B0 按玩家任务进度选出的奖励，Addon16930 显示“日常成果：N 点”。本机有效奖励档位 1/2/3 门槛 50/100/200，0 为占位；消费者不是星球分类列表。140A80C50 提交带文本、图标和数值的展示通知并将队列项置完成，队列随后删除。收包本身不向库存发奖励；无额外验证 p1 范围或非零 tier 有效性。默认模块须加载且链可达，无回放样本。

依据：`0x141A762B0`、`0x141A76190 uint32base8C+86400`、`0x140A80480 deadline→Addon16923 withServerTime`、`0x1401493F0 activeAgent471 Hide andLog11153`、`0x140A7EE10 notificationqueue consumer`、`0x140A80960 FFFF→DailyDefine and16930 elseWKSAchievement`、`0x140A80C50 notification completedstate2`、`resources-wks-achievement-reset-deadline.json`、`resources-wks-daily-achievement-reward-notices.json`。
