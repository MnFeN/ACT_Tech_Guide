角色行为控制

- 分支地址：`0x140b3aec7`。
- 回放观察：1040 次；包族 {"ActorControl": 1040}。

## 参数与行为

- 核对状态：基础/覆盖控制码优先级、低值清理与 Behavior 执行边界及回放分布已核对。
- 用途：更新角色基础 Behavior 控制码；变化时重置执行状态，按有效编号选择是否执行 Behavior 表。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位写 Character+1DF4h 的基础行为控制码；相同值不操作。场景覆盖码 controller+106h 非 0 时优先；有效码>30000 才请求/执行 Behavior 表，<=30000 不以同号加载 ActionTimeline。低值仍参与零/非零及变化清理，30000 在>=资格判断与>表执行判断间有明确边界 |
| p2 | 只读 bit0；仅 p1 低 16 变化时把执行 dirtybit0 置位，bit0 非 0 另置 dirtybit4 以抑制对应位置恢复；旧基础码>=30000 且路由对象被识别为本机时可立即推进控制器。p2 不是覆盖行为编号 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：目标 Character+0x1CF0 的行为控制器+260（绝对+0x1DF4），变化置 dirtybit0；p2 bit0 追加 dirtybit4。旧值>=30000 且路由角色被识别为本机时立即推进控制器。逐帧 0x14194BCB0 以有效编号>30000 加载本机 sheet7=Behavior，控制时间轴、移动、渐变、表情等；30000 为特殊边界，不在此处作为普通表行执行。回放常见小编号在 ActionTimeline 表均有对应资源，但小编号到最终时间轴的完整路径继续核对，不能称所有值都是 Behavior 行号。 继续沿全.text ushort+0x104/+0x106 访问者和 Character+0x1DF4 读取者核对：14194B4A0 的完整汇编只对低编号做状态清理/门控，返回后 14194BCB0 明确 cmp<=30000 跳到 ret；未发现该路径直接将低编号传给时间轴播放。早期“低值与 ActionTimeline 相关”仅来自同号资源匹配，应视为未证实假设，现已撤回。还需核对别名/复制字段消费者，不能把低编号直接定义为 ActionTimeline。 补查此前 word-only 扫描遗漏的 dword/qword/LEA 访问：全.text 对 104h/106h/1DF4h/1DF6h 得到 1054 个候选位移点，均不能脱离基址当作本字段访问。行为模块范围及 Character 绝对偏移选出的 13 个函数中，新增 14194BB30 用 DWORD 清 controller+104h（同时清主/覆盖两个 ushort）；1408D70B0/73D0 从场景对象虚函数取得覆盖编号并写+106h。未由此发现低编号到动画播放的独立消费者；仍保持部分状态，不把候选扫描总数当已核实读者数。回放 1040 条中 p1=0 有 518 条，p2 全部 0；其余低编号与 ActionTimeline 同号只是数值相合，不能构成语义证明。 完成条件复核：低编号在已核对的客户端消费者中没有独立逐 ID 解码表，应记录其变化/非零/范围门控及清理效应，而非等待为 1051/5257 等编写不存在证据支持的逐号动画名称。14194B4A0 先取覆盖非 0 则覆盖、否则基础为有效码；dirty 时清标志、重置 14194BBD0 的执行缓存，PlayerKind1 下有效码非 0 还会终止相关 Emote 状态，并按基础>=30000 且无不同覆盖等条件处理场景控制/位置恢复。14194BCB0 仅有效码>30000 且其他执行条件满足才请求 sheet7 Behavior，低值没有时间轴 ID 查表。14194DD90 的资格是基础>=30000 或覆盖非 0，因此 30000 不能与 29999 无条件混为一类。全.text 补扫 packed 读取：221 个位移读点/154 函数，唯一关键词候选是 0x3000000 掩码误匹配；8 个反编译失败函数的 9 处指令已保留 ASM 上下文，分别为批量复制、随机数移位状态、全局渲染上下文或 float 值，不提供低编号到时间轴的映射证据。扫描不宣称穷尽任意未解析间接别名，但完整控制器/已识别主覆盖读者和复制恢复路径已核对。1040 条普通 ActorControl 中基础 0 为 518 条、非零<30000 为 519 条、35529 为 3 条，p2 全 0；当前 Behavior35529 确有 9 子行。这里确认的是本版收包控制效果，不声称还原服务器为每个不参与逐号解释的低值取名的意图。
