# 575 / 0x23F SetRetainerPendingVenture

[分类参数](../../README.md#category-023f) · [附注索引](../README.md)

雇员保留探险任务

- 分支地址：`0x140b3bf71`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：包宽度、当前记录选择、原生 Lua 名称及实际消费者已核对。
- 用途：设置当前雇员结束保留中的探险任务 ID（SightPendingTaskId）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 RetainerTask.RowId 写当前 Retainer+0x42；0 表示无结束保留任务 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：14110D550 按 LastSelectedRetainerId 选中雇员；无选中或无匹配忽略。141C9AA10 注册 GetSightPendingTaskId→141C9D540，返回此 ushort 任务 ID，并在任务行存在时返回 Task 引用值为 0 的辅助 bool。14110DFE0 判断该字段非 0，141C9DB40 据此添加 Addon2403“查看雇员探险情况 [结束保留中]”，对应 Lua 枚举 RETAINER_MENU_SIGHT_PENDING_TASK=7。装备资格 1408880B0/1408883A0 与普通 VentureId 同时检查，非 0 报 Log3904 无法更换装备；140CC3150/140CC72C0 设错误 mask0x20，Addon2361 提示有进行中或已归来的探险。它与+38 普通 VentureId 是两个独立字段，不是经验、完成时间或普通探险状态枚举。

依据：`0x14110D550`、`0x141C9AA10 nativeLua registration and flag constants`、`client/retainer-active-consumers.json`、`0x141C9D600 callback8/9`、`0x141C9D540 GetSightPendingTaskId→RetainerTask`、`0x14110DFE0 pending!=0`、`resources-retainer-sight-pending.json Addon2403`、`resources-retainer-state-menus.json Log3904 Addon2361`。
