# 183 / 0xB7 PositionVFX

[分类参数](../../README.md#category-00b7) · [附注索引](../README.md)

位置特效

- 分支地址：`0x140b43fc4`。
- 回放观察：134 次；包族 {"ActorControlSelf": 134}。

## 参数与行为

- 核对状态：入口、记录及逐帧回收已核对。
- 用途：副本控制器管理的固定位置 VFX。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | VFX 行号 |
| p2 | 游戏原生 X 压缩坐标，低 16 位 |
| p3 | 原生 Y 即高度，低 16 位 |
| p4 | 原生 Z 压缩坐标，低 16 位 |

额外参数：p5 为 uint32 毫秒数，数值转 float×0.001 得到强制回收倒计时（游戏逻辑秒）；0 不启用该倒计时。p6 可选关联角色 EntityId，E0000000 允许无角色；有效 ID 须能查到 BattleChara。p7/p8 未读。

说明：坐标解码 u16*2000/65535-1000；134 条均为 Self，1 条 p5=3000，其余 0。逐帧 remaining-=FrameDeltaTime*GameSpeedMultiplier，降至 0 请求停止并清记录；0 不保证特效无限存在，见 VfxLifetime.md。 网络整数先零扩展再转 float，不能发送 FFFFFFFFh 作为负寿命禁用；只有 0 关闭本项计时。内部 float 管理器仍以 remaining>0 决定是否扣减。

依据：`0x140B43FC4–0x140B4404A`、`0x140B6CE50`、`0x140B51F80`、`0x140B51EE0`、`0x140B70D10`、[VfxLifetime.md](../VfxLifetime.md)、`0x140B44009..42`、[FloatConversionAudit.md](../FloatConversionAudit.md)。
