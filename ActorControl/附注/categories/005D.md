# 93 / 0x5D AutoRepairResponse

[分类参数](../../README.md#category-005d) · [附注索引](../README.md)

自动修理应答

- 分支地址：`0x140b3c748`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：RepairManager、AgentRepair 自动修理发起与队列继续/中断应答已核对。
- 用途：处理自动修理应答：继续下一类装备或中断自动修理队列。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零表示继续；0 中断自动修理并显示 Log11291 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：全局 142AD9760 为 RepairManager，AgentRepair 发起自动流程的 14088D360 设置+113 模式及回调。只有+113 非零时处理本类。p1 非零且未请求取消(+114=0)、下一项索引未越界且队列值不为 7 时，推进+104 索引，置+115 及+116=0x40000000，回调 virtual3(0,下一项)继续；否则回调 virtual4(取消标志)，清回调与队列。+114 已有取消请求时亦显示 11291。p1=0 直接清队列、显示 11291“自动修理已中断。”、回调 virtual4(true)。队列值来自修理库存类别选择，并非网络 p2。收包自身不遍历道具写耐久，也不把非零 p1 当成修理件数。p2..p8 未读。

依据：`0x14088DA80`、`LogMessage11291`、`resources-queue-progress.json Log11291=自动修理已中断`、`FFCS RepairManager.Instance /AgentRepair Unk28 callback`、`0x140CA8580 AgentRepair event a5=3→14088D360`、`0x14088D360 automatic queue init`、`0x14088DA80 next category/stop callback and clear`。
