# 70 / 0x46 PlayVoiceLine

[分类参数](../../README.md#category-0046) · [附注索引](../README.md)

播放语音台词

- 分支地址：`0x140b39702`。
- 回放观察：2489 次；包族 {"ActorControl": 2489}。

## 参数与行为

- 核对状态：语音资源路径、编号范围及空间位置已核对。
- 用途：在角色位置播放本地化语音台词。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | VoiceLine 资源编号，入口只接受 8201000..8299000（含端点） |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：0x140418590 检查编号后按当前语音语言构造 sound/voice/Vo_Line/%07d_%s.scd，再以角色 XYZ 播放；传入角色潜水状态。不是任意 Sound 表/SFX 行号，也不是 LogMessage 文本 ID。录制模式有音频抑制门控；无效范围直接返回 0。调用类型已按 XMM2/XMM3 和栈上 Z 恢复，避免把 position 指针错误当成音频参数。

依据：`0x1408CE2D0`、`0x140605660`、`0x140418590`、`0x140418590 / sound/voice/Vo_Line/%07d_%s.scd / asm unsigned(id-8201000)<=98000`。
