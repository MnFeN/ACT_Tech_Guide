# 290 / 0x122 Emote

[分类参数](../../README.md#category-0122) · [附注索引](../README.md)

表情动作播放及事件通知

- 分支地址：`0x140b3f0a9`。
- 回放观察：248 次；包族 {"ActorControlTarget": 248}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：表情动作播放及事件通知。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Emote 行号，仅表中指定允许标志非零时处理 |
| p2 | 此分支未读取 |
| p3 | bit0 关闭日志；bit1 写 PlayEmoteOption.Flags 的 bit1（上游未命名）；bit3 禁用坐下初始动画 |
| p4 | 此分支未读取 |

额外参数：独立 targetId 参与动作及事件通知

说明：保存独立 64 位 targetId 至 PlayEmoteOption.TargetId；p3 其他位不在这里转发。

依据：`FFCS EmoteController.PlayEmoteOption`、`0x140B3F0A9`。
