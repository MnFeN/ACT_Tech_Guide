# 1514 / 0x5EA SetDutyActionPresent

[分类参数](../../README.md#category-05ea) · [附注索引](../README.md)

设置五个 DutyAction 条目与各条目的存在标志

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：默认委派链字段核对。
- 用途：设置五个 DutyAction 条目与各条目的存在标志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | DutyAction1 的 ActionId，同时按非零推导可用标志 |
| p2 | DutyAction2 的 ActionId |
| p3 | DutyAction3 的 ActionId |
| p4 | DutyAction4 的 ActionId |

额外参数：p5 是 DutyAction5 的 ActionId；组 24 使用 PhantomAction 槽

依据：`0x1409041B0`。
