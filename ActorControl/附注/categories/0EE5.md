小游戏运行状态

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：模块与参数读取明确，细分业务待查。
- 用途：同步匹配小游戏的运行状态值。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 小游戏 ID，必须等于对象虚槽 20 返回值 |
| p2 | 写对象+72 的 32 位状态 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：该共用处理器即使成功写入也返回 false，外层继续派发；未匹配 ID 不写。不能以返回 false 推断类别未使用。 本机 LiveMinigamesTerritoryType[1,1]明确场地 1336，地名 5445“睡莲湖附近”；配套 Action45127/42039/42038 分别转圈割草/突进割草/大转圈割草，可确认为割草玩法。结果 Addon795 原生名 EasterMowingResult，仍不凭名称推定具体运营活动年份。

依据：`0x14198E950 / LiveMinigames registered virtual6`、`0x141C46130`、`resources-live-minigames-all-raw.json`、`resources-live-minigames-territory-actions.json`、`resources-live-minigames-placename.json`、client/live-minigame-update-methods.json virtual0..10 / [MowingResultActualAddonAndRewardQuantity.md](../MowingResultActualAddonAndRewardQuantity.md) actualAddon795。
