# 44 / 0x2C MercyStrokeHealMessage

[分类参数](../../README.md#category-002c) · [附注索引](../README.md)

慈悲杀恢复体力提示

- 分支地址：`0x140b3abfa`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：慈悲杀动作、恢复体力数值与模板参数排列已核对。
- 用途：慈悲杀恢复 HP 的战斗日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 必须等于 36（Action 慈悲杀）才处理 |
| p2 | uint32 恢复体力显示数值，作为 BattleLog.value1 进入日志模板；不是 Status 行号 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：仅 p1==36(Action 慈悲杀)处理；source=target=包头角色，固定 ActionType1、Action36、LogMessage601。140C51C70 依次压入动作文本与 value1..4，p2 进入 value1，即 601 模板的体力数值；其余 value2..4 全 0，模板百分比项因 value2=0 为空。此项只加日志/相关飘字，不直接写角色 HP，不能把显示值当本机 HP 赋值或 StatusId。p3..p8 未读。

依据：`LogMessage601`、`Action36`、`0x002C`、`0x140C51C70 AddActionLogMessage packsactionstring thenvalue1..4 asformatargs`、`resources-winded-mercy.json LogMessage601 rawSeString`、`FFCS BattleLog.AddActionLogMessage value1..4 names,not StatusId`。
