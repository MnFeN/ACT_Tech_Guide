# 2359 / 0x937 SetFateInitiator

[分类参数](../../README.md#category-0937) · [附注索引](../README.md)

FATE 发起目标与备用位置

- 分支地址：`0x140b4507e`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：实体与备用 BNpcName 双路径、signed 坐标及 EntityId 变化门控已核对。
- 用途：同步 FATE 发起目标 EntityId 及离线备用 BNpcName、坐标标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 FateId |
| p2 | MotivationNpc EntityId，E0000000 可清 |
| p3 | uint32 BNpcName.RowId：实体不存在/不可用时，作为目标地图标记的备用名称，与包内坐标配合 |
| p4 | int32/1000 得到 X 米 |

额外参数：Self p5/p6 按 int32/1000 为 Y/Z 米。

说明：141780840 仅匹配 FateId 且 Context.Flags bit80 已置、旧 MotivationNpc 与 p2 不同时处理；EntityId 相同会整项忽略，p3 及坐标也不更新。改变时旧/新有效 EntityId 对应对象标记+9Bh bit2 刷新，写 Context.MotivationNpc 及第三个 FateMapMarker 记录(kind2,EntityId=p2,BNpcNameId=p3,备用 X/Y/Z)。p2 不是 E0000000 或 p3 非零则保留该目标记录；二者都无效则重置记录。当前 14177B590 逐帧遍历 37 个 D0h 记录调用 14177B090，kind2 先按 EntityId 找存在且满足 140899B10 的对象，用对象虚 6 取名和真实 GetPosition；否则 p3 非零时明确 EXD_BNpcName_1408352A0 查本机 sheet47，并从 BNpcName 取备用名、沿记录保存的包内坐标生成 MapMarkerData。p3 零或备用行无效则清可用标志，不凭 p3 创建/生成 NPC。坐标主收包 ASM140B45033..7E 用 cvtdq2ps 把 p4/p5/p6 的 signedint32 除 1000 为米；不是 uint 坐标或直接 floatbits。p7/p8 和 target 未读，无回放样本。

依据：`0x141780840 / FFCS FateContext.MotivationNpc`、`0x14177B590 loops37 FateMapMarkers fromBB0 strideD0`、`0x14177B090 kind2 EntityId→live object name/position elseBNpcName(row+8)`、`0x1408352A0 native sheet47=BNpcName`、`0x14177B090 fallback coordinates record+94/+98/+9C`、`HandleActorControl ASM140B45033..7E signedcvtdq2ps p4/p5/p6 /1000`、[FateMotivationFallbackName.md](../FateMotivationFallbackName.md)。
