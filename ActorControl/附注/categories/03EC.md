# 1004 / 0x3EC DemolishHouseResponse

[分类参数](../../README.md#category-03ec) · [附注索引](../README.md)

拆房申请应答

- 分支地址：`0x140b3d645`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：拆房申请应答：缓存匹配时显示拆除房屋确认，否则重取资料或结束等待。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | low8 OutdoorHouseUnit，与 Outdoor+125DAh 请求缓存比较；普通 0..59 含 division、80h/81h 为公寓编码；高 24 位未读 |
| p2 | 完整 32 位结果：0 允许成功处理或缓存不匹配时补发 1104；非零结束等待且不补发。当前路径不细分其他原因码 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

额外参数：p5..p8 及独立 target 未读取

说明：不是外装编辑应答。发起 140E1C410->140E2E370 检查当前地块已有房屋、背包空格、操作权限与额外房屋状态后，将选中 HouseUnit 复制到请求缓存、mode3，发送 1103。140E1BE20 要求 Outdoor 存在、p2=0、p1 与缓存匹配、mode3，才调用 AgentHousing141722DA0(agent,0)，使用 Addon6313 确定要拆除房屋吗/返还房产证书但废弃装潢与 6404 拆除房屋，141727A50 dialogevent24。非匹配/非零清请求缓存 FF/mode0 并以参数 1 通知 Agent 结束等待；只有 p2=0 再发送 1104(p1low8,0,0,0)。本包只推进确认，不直接拆除房屋，不携外装物品编号。无回放样本。

依据：`0x140E2E370 mode3/1103 request`、`0x140E1BE20 HouseUnit/p2/cache gate`、`0x141722DA0 Addon6313/6404 dialogevent24`、`resources-housing-demolition-confirmation.json`、[HousingDemolitionAndBuildResults.md](../HousingDemolitionAndBuildResults.md)。
