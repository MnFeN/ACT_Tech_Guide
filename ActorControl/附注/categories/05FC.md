# 1532 / 0x5FC SetTargetHudStatus

[分类参数](../../README.md#category-05fc) · [附注索引](../README.md)

目标 HUD 补充状态

- 分支地址：`0x140b3a1cd`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：新增或更新 HUD 按目标实体补充显示的状态与剩余时间。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Status 表 RowId，低 16 位；0 为空槽标记 |
| p2 | IEEE754 float32 位模式，直接作为剩余逻辑秒数保存；不是整数转 float，也不乘 0.001 |
| p3 | 状态显示所属目标 EntityId，作为缓存匹配键；HUD 按当前被处理实体 ID 筛选，并非状态来源 EntityId |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：PlayerState+7C0h 有十个 12-byte 槽：+0 ushort StatusId、+4 float 剩余秒、+8 uint 目标 EntityId。140BE3AE0 先找相同 StatusId 和目标 EntityId，没有则找 StatusId==0 空槽，满十项且无匹配时不更新。140BE3CA0 只对非空且剩余>0 槽逐帧减 FrameDeltaTime*GameSpeedMultiplier 并在<=0 时将时间钳 0；不自动清 StatusId/EntityId，0 或负数入参也不在此递减。HUD ProcessStatuses140FDBA60 先按目标 EntityId 取得这十项，验证 Status 资源且未设行+22h 的 04h 过滤位，以 int(remaining+0.5)形成显示秒数，再与常规 StatusManager 最多 60 项合并、排序、按界面上限截断。补充项参数/层数写 0，内部来源标记置 1，槽索引 0..9；常规状态索引偏移 10，不把这十项真正加入 StatusManager。显示行为及实际战斗状态效果应区分。

依据：`0x140BE3AE0 ten-slot match/upsert`、`0x140BE3CA0 logical-seconds decrement`、`0x140BE3C40 target-filtered StatusId getter`、`0x140BE3C70 float time getter; corrected float return prototype`、`0x140FDBA60 HudStatus.Status.ProcessStatuses merges extra10 and ordinary60`、`0x140FEC010 passes displayed entityId and PlayerState`、`client/extra-status-hud-callers.json`、[ExtraStatusHudCache.md](../ExtraStatusHudCache.md)。
