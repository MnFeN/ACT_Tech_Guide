# 18 / 0x12 ClearProcTimer

[分类参数](../../README.md#category-0012) · [附注索引](../README.md)

清除条件技能触发窗口

- 分支地址：`0x140b3a106`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：ProcTimers、Miss/格挡/招架触发与动作可用性消费已核对。
- 用途：清除指定的条件技能触发窗口计时器。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | signed int ProcTimers 槽索引；仅检查<5。1=本机攻击被回避/未命中，2=本机格挡，3=本机招架，4=本机回避；0 保留槽 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：ActionManager+0x7C8 五 float。1408FE940 处理 ActionEffect：type1 源为本机置槽 1=5 秒、目标为本机置槽 4=5 秒；type5 格挡置槽 2=5，type6 招架置槽 3=5。1408E73C0 每帧扣有效逻辑秒并夹紧 0；1408E4FF0 按 Action 资源+44 选择槽，计时<=0 时返回动作不可用 572。因此 0x12 是撤销对应条件技能触发窗口，不是通用冷却组清零。槽 0 没有上述触发赋值。

依据：`0x1408EF300`、`FFCS ActionManager.ProcTimers+0x7C8`、`1408FE940→globals1428BC68C/690/694/698=5.0`、`1408E4FF0 Action+44索引ProcTimers，<=0返回572`、`ActionManager.Update1408E73C0逻辑帧秒扣时`。
