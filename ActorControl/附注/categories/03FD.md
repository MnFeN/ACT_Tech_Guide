# 1021 / 0x3FD OutdoorGardenHarvestResult

[分类参数](../../README.md#category-03fd) · [附注索引](../README.md)

室外园艺收获结果

- 分支地址：`0x140b3d944`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：显示园艺收获结果。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 收获 Item ID |
| p2 | 收获数量 |
| p3 | 低 16 位 GardeningSeed 行号，用于关联产物 |
| p4 | 第二组收获 Item ID；需 p4 与 p5 均非 0 |

额外参数：Self p5 为第二组收获数量；本消费者未读 p6。

说明：一件用 750，多件用 751；第一组另从 GardeningSeed+4 取得关联产物传给 UI；第二组关联产物为 0。

依据：`0x140E1F700 / 0x140E31AA0 / LogMessage750,751`。
