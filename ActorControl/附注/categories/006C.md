# 108 / 0x6C RemoveLeveMapMarker

[分类参数](../../README.md#category-006c) · [附注索引](../README.md)

移除理符地图标记

- 分支地址：`0x140b40c1c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：理符地图 LevelId 匹配与完整移除链已核对。
- 用途：移除当前理符任务中 Level 匹配的地图标记。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | Level 资源行号，与 ActiveLevequestMarker.MarkerData 每条首 DWORD LevelId 匹配 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：遍历 Map+1B18..1B20 的 0x50 字节 MapMarkerData 向量，找到首个 LevelId 匹配项后移除该项的地点索引，通知当前 Director 虚 293(LevelId)，将后续 0x50 字节记录前移并缩短向量。找不到则不处理。与 0x6B 对称；p2..p8 未读。

依据：`0x140C14C50`、`0x140C14C50 vector Map+1B18..1B20 / record0x50 / Director virtual293`、`FFCS Map.ActiveLevequestMarker and MapMarkerData.LevelId`。
