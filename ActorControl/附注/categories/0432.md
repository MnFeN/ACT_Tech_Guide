刷新飞空艇与探索结果

- 分支地址：`0x140b3e3fa`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：刷新飞空艇部件及当前探索结果界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位飞空艇登记标识，只用于查索引后转交 Agent |
| p2 | 值原样转交部件 Agent，当前末端未读取 |
| p3 | 低 8 位值，转交 Agent 但当前末端未读 |
| p4 | 低 16 位值，转交 Agent 但当前末端未读 |

额外参数：Self p5 低 16 转交 Agent 但未读取。

说明：无 p2=0 门控；ActiveAirshipId 有效且对象存在则刷新探索结果 UI。各参数在包装中有读取/传参，但部件 Agent 当前实现不消费它们，不能按名称猜它们控制界面。

依据：`0x140E42200 / 0x140573680 / 0x140E40B90`。
