# 1301 / 0x515 SetVerminionPhase

[分类参数](../../README.md#category-0515) · [附注索引](../README.md)

萌宠之王阶段

- 分支地址：`0x140b3909c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：设置萌宠之王阶段与计时/界面。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 阶段值；3 准备、4 提交召唤队列、5 计时阶段、6 结果显示分支 |
| p2 | p1==5 时按 signed32 整数转 float 秒，写+65Ch 剩余召唤等待和+660h 初始召唤等待；p1==6 时为 ScreenImage 行号 |
| p3 | p1==5 时按 signed32 整数转 float 的 HUD 比赛剩余秒数，写+6BCh；p1==6 时非零值为 LogMessage 行号 |
| p4 | 此路径未读取 |

说明：阶段 3 清选择队列并显示选择开局宠物提示，将 HUD 计时+6BCh 设 20 秒；阶段 4 提交队列并关闭召唤选择；阶段 5 写召唤等待剩余/初始与比赛剩余两个独立计时器，并显示 ScreenImage359；阶段 6 用 p2 显示 ScreenImage，p3 非零时输出 LogMessage。+65Ch 和+6BCh 都按 Framework.FrameDeltaTime 秒递减并钳 0，后者阶段 6 停止递减，均未在此乘 GameSpeedMultiplier。140E77D20 将+65Ch>0 作为暂缓召唤条件，140E73E30 也在此时间归零后检查队列自动发起召唤；+660h 初始副本不递减。转换与 051F 不同：140E78968/973 及 986/98A 使用 movd+cvtdq2ps，明确 signed32，不能套用主收包 uint32 规则。

依据：`0x140E829D0 / GoldSaucerDirector类型0x800A且内容7 / 0x140E788F0 / LogMessage4829`、`0x140E73E30 update raw assembly`、`client/verminion-update-windows.json`、`0x1410D1650 NumberArray98 minute/second digits`、`0x140E77D20 summon eligibility wait`、`0x140E788F0 stage5 signed32 conversions`、[VerminionClocksAndSummonDelay.md](../VerminionClocksAndSummonDelay.md)。
