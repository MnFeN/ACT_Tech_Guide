# 229 / 0xE5 ReleaseRemoteSpecialMove

[分类参数](../../README.md#category-00e5) · [附注索引](../README.md)

解除远端特殊移动

- 分支地址：`0x140b4231a`。
- 回放观察：3235 次；包族 {"ActorControl": 3235}。

## 参数与行为

- 核对状态：移动清理及渲染位方向已核对。
- 用途：释放远端角色特殊移动并解除渲染抑制 bit22。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 此分支未读取 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：0x141820330 检查 MoveController+1081 bit5 和远端等条件，重置移动子对象，并可能先施加 RenderFlags bit22；随后 0x141820460 无条件清移动 bit5 并调用角色 vf39(22)，实际清 RenderFlags bit22。不是全局 Conditions[22]。四参未读取；特殊移动子类型仍以门控记录。

依据：`0x141820330`、`0x141820460`。
