# 95 / 0x5F SetLootGreedOnly

[分类参数](../../README.md#category-005f) · [附注索引](../README.md)

战利品仅限贪婪

- 分支地址：`0x140b3c766`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：宝箱双键、RollState 与分配模式及消息模板已核对。
- 用途：将宝箱中的指定战利品改为仅限贪婪分配模式。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 宝箱实体 ID，匹配 LootItem.ChestObjectId；0xE0000000 直接跳过 |
| p2 | 该物品在宝箱中的索引 ChestItemIndex，不是全局 16 槽的索引 |
| p3 | 写 LootItem.RollState(+0x20)的 32 位值，当前客户端按该状态控制可选 Need/Greed/Pass |
| p4 | 此分支未读取 |

说明：UIState+0x4960=Loot；16 条 LootItem，每条 0x44 字节。找到 ChestObjectId/ChestItemIndex 双键后，仅当 LootMode(+0x38)不等于 3 才设置 RollState=p3、LootMode=3，用 ItemId(+8)/ItemCount(+0xC)显示 Log5184 的“分配方式变更”文字，并刷新已打开的 AgentLoot(0x29)。若当前模式已相等则连 p3 也不更新。p4..p8 未读。

依据：`0x140C3B680`、`FFCS UIState.Loot+4960 / LootItem offsets0,4,20,38`、`resources-request-state.json Log5184/5185`、`0x140C397C0 Agent0x29 visible refresh`。
