# 708 / 0x2C4 ShowActorNumberMessage

[分类参数](../../README.md#category-02c4) · [附注索引](../README.md)

指定角色单数值日志

- 分支地址：`0x140b40695`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：以指定角色显示一个数值参数的通用日志。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | source BattleChara EntityId |
| p2 | LogMessage 行号 |
| p3 | 文本数值参数 1 |
| p4 | 此路径未读取 |

说明：须 p1 角色存在；该日志接口第二控制常量固定 1，不能把它归到 p4。

依据：`FFCS BattleLog.AddLogMessage3Params`。
