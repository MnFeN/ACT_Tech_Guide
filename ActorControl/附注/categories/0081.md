# 129 / 0x81 SetProvisionSeed

[分类参数](../../README.md#category-0081) · [附注索引](../README.md)

军队筹备任务与交付数据

- 分支地址：`0x140b41ecf`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步军队筹备任务随机种子及当日已交付屏蔽位图。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 32 位任务随机种子；140C1E5C0 用于生成 11 个职业的条目选择与额外奖励判定 |
| p2 | 位图字节 0，最高位对应职业索引 0，随后向最低位排列（索引 0..7） |
| p3 | 位图字节 1；bit7/6/5 对应职业索引 8/9/10 |
| p4 | 保存位图字节 2；当前 11 职业生成循环不消费此字节 |

额外参数：Self p5 低 8 位保存位图字节 3；当前 11 职业循环不消费；p6..p8 未读

说明：职业索引 i 对应 ClassJob8+i（刻木至捕鱼）。140C1E5C0 生成 11 项：位图 bit 为 0 且 ItemId 非零时，条目+27 置 1；bit 为 1 禁止该条目。该位是已交付条目的屏蔽状态，界面独立证据见后文。seed 驱动固定整数 PRNG，选择职业候选项并与 GCSupplyDefine1 阈值比较设置额外奖励标记。FFCS 附近旧注释不足以精确命名，现以实际消费者为依据。 独立界面链已补齐：141003260 把 GCSupply 条目+27 的可交付 bool 取反写 Agent 列表条目+155；141001CD0 将+155 非零条目从显示列表跳过，141000E50 同样跳过它们来解析界面选择。当前标签页有已学职业条目但无可显示条目时，141001CD0 使用 Addon4588“今天的份额已经筹备完毕。”；没有相应职业条目则用 4604“还没有学会相应职业，无法获得筹备任务的经验值。”。结合位图的反向条件，可将这些已存在职业条目的网络位命名为当日已交付/筹备完成屏蔽位。ItemId 为 0 也会隐藏，但这是另一个条件，不等同网络完成位。现有 408 回放无 0080/0081，属于静态收包、界面与本机资源交叉核实，未实际交付。

依据：`0x0081`、`0x140C1E5C0 11 iterations / GCSupplyDefine1 / PRNG seed142ADF6B4`、`0x140C1E5C0 bit=(128>>(i&7)) & byte_142ADF6A4[i>>3]`、`resources-gcsupply.json ClassJob8..18`、`0x141003260 source+27 -> AgentItem+155 inverted`、`0x141001CD0 excludes155 and chooses Addon4588/4604`、`0x141000E50 selection excludes155`、`resources-gcsupply-completion-ui.json`、[GrandCompanySupplyCompletionBitmap.md](../GrandCompanySupplyCompletionBitmap.md)。
