无人岛工坊活动角色组

- 分支地址：`0x140b456cb`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：建筑活动角色组切换已核对；开关完整业务名待查。
- 用途：选择无人岛工房建筑周围的常规或替代活动角色组。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位写 MJIManager+414h；在已建成工房路径中仅按 0/非 0 选择 MJIBuilding 行+18h 或+17h 的 MJILivelyActor 组，非逐 bit 旋转值 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：140EAD9E0 不是移动/旋转控制：先按 MJIBuildingPlace 定位建筑，再按类型和等级查 MJIBuilding 子行。非建造中且建筑接口 type==1（工房）时，低 byte 为 0 选行+24 替代角色组，非 0 选+23 常规组；其他类型不受此选择影响。组变化则撤旧组，并以建筑场景变换位置创建 MJILivelyActor 组；141A7BF70 异步读 sheet1090=MJILivelyActor，不是 VFX 或建筑朝向。例工房 II 子行 1/1 常规 group9、替代 73，均含 ENpc1043467；Behavior 分别 33397/33413，替代组含 event_talk1 聊天时间轴。可推测与工房工作/休息表现有关，但服务器开关完整业务名未独立证实，故保留待查。包到达后刷新 7 个有效建筑位置；p2..p8 及独立目标未读。 补全 414h byte 访问扫描：全.text 仅 6 个同位移 byte 访问点且均反编译成功；除收包 140EA9730 和场景读者 140EAD9E0 外，新确认 140EAB260 是本机写者。AgentMJICraftSchedule 确认回调 1409FF3B0 从 14bit 选择掩码分别提取本周/下周各最多两个序号，传给 140EAB260；后者检查前两项 0..6、后两项 7..13，并将 byte414h 写为(managerByte3A8!=firstDay)&&(secondDay==0)，随后发内部 Execute3261 四个 day。ASM140EAB285/28D/298 明确是与 firstDay 比较后 test 第二项是否 0，不是与两个休息日都不相等的公式；不按常识修正。该路径只写缓存并发送请求，没有调用本包的七建筑刷新。它证明与休息日确认流程有关，但不能仅据此将网络 p1 等同是否正在生产，完整业务名继续保留缺口。相同 414h 偏移的其他基址候选不当作 MJIManager 消费者。
