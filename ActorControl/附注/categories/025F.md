# 607 / 0x25F ActorVisualControl

[分类参数](../../README.md#category-025f) · [附注索引](../README.md)

指定角色显示与动作

- 分支地址：`0x140b415da`。
- 回放观察：10717 次；包族 {"ActorControl": 10717}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：按显式 EntityId 执行渐隐、VFX 或时间轴子命令。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 目标 EntityId；0xE0000000 立即返回 |
| p2 | 子命令：1 渐隐；2 播放 VFX 后渐隐；3 执行 ActionTimeline；4 重置时间轴；5 普通 GameObject.PlayTimeline |
| p3 | 子命令 2 为 VFX ID，3 为 ActionTimeline ID，5 为虚函数参数 |
| p4 | 子命令 1/2 渐隐时长，除 100 为秒 |

说明：2 的 VFX 以该对象为源和目标；无 Character 时仍可执行普通对象可用的路径。

依据：`0x025F`、`0x140909F40`、`0x1408BDCB0`、`0x1408BEA90`。
