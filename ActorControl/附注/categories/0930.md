# 2352 / 0x930 RemoveFateStartNpc

[分类参数](../../README.md#category-0930) · [附注索引](../README.md)

移除 FATE 开始 NPC

- 分支地址：`0x140b44f80`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：从 FATE 开始 NPC 列表移除一个对象。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 32 位对象标识，按列表元素低 DWORD 匹配 |
| p2 | 此路径未读取 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：列表元素为 8byte GameObjectId，查找只比较低 32 位，移除整项并压紧；不能叫删除 FATE 上下文（那是 0x935）。

依据：`0x1417816C0 / FFCS FateManager.FateStartNPCs`。
