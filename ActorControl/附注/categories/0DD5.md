# 3541 / 0xDD5 SetCosmicMissionReacceptance

[分类参数](../../README.md#category-0dd5) · [附注索引](../README.md)

宇宙任务再次受理限制

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步放弃临时探索任务后的再次受理限制。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位宇宙职业索引，0 起 |
| p2 | 低 16 位 WKSMissionUnit ID |
| p3 | 非零设再次受理限制，0 解除；界面提示放弃后必须先完成其他任务才能再次领取 |
| p4 | 本消费者未读取 |

说明：在 p1 低 8 位职业索引对应 JobState.ProvisionalMissions 中，按 p2 低 16 位 MissionUnit ID 查首匹配条目，写其+Ah bool；未找到不新增。140A72650 GetProvisionalMissions 将该 byte 转为 MissionEntry.Flags.bit7（ConditionLocked），140A73E10 选中条目时读取同 bit 并附加 Addon16807：放弃临时探索任务导致不可再次领取，完成其他任务后才能再次领取。故不是任务完成/奖励领取标志，也不是泛天气或时间条件。列表同时包含天气/时段条目，但该位指放弃后的再受理限制；各天气/时段条件由其他字段表达。入口未检查职业索引是否<=10，不能把协议合法范围误写成本地保护。p4 及额外参数未读。

依据：`0x141A6F260 case0DD5 indexed job vector and byte+A write`、`0x141A6F2E6 ASM cmp [rax],bx low16 missionId`、`0x140A72650 GetProvisionalMissions byte+A -> flags80`、`0x140A73E10 SelectedMissionFlags.bit7 -> Addon16807`、`resources-wks-condition-lock-text.json explicit abandonment/reacceptance text`、`FFCS AgentWKSMission.MissionFlags.ConditionLocked`、[WksProvisionalMissionReacceptanceLock.md](../WksProvisionalMissionReacceptanceLock.md)。
