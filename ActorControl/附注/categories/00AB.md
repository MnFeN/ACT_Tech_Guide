# 171 / 0xAB SetAvailableActions

[分类参数](../../README.md#category-00ab) · [附注索引](../README.md)

生成可用技能列表

- 分支地址：`0x140b43336`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与字段已核对。
- 用途：按职业与等级构建可用 Action 列表。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 打包三个职业 byte：bits16..23 主职业、bits8..15 基础职业、bits0..7 附加职业 |
| p2 | 低 8 位主职业等级 |
| p3 | 入口转交低 8 位，但当前列表构建 callee 未读取 |
| p4 | 低 8 位附加职业等级 |

额外参数：p5 低 8 位被转交但当前构建函数未读取；校正 8 项原生参数后消除了伪码多出的未初始化实参。

说明：遍历 Action 表，依据 ClassJob/Category、等级与 Action 标志收集条目；不应因附近 FFCS 偏移碰到 Emj 结构就命名为麻将。

依据：`0x140C50950`、`0x140C450C0`。
