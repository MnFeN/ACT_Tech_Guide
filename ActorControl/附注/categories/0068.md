理符任务等级显示

- 分支地址：`0x140b3f57b`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：任务等级 byte、仅变化刷新及 HUD 等级显示已核对；上游 MaxDifficulty 名称/类型不采纳。
- 用途：设置理符 Director 的等级显示字段并触发 UI 刷新。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位写 LeveDirector+478；被当前任务 HUD 按“n 级”显示 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：从 EventFramework 中选 BattleLeve8001/GatheringLeve8002/CompanyLeve8007 Director。141A08350 仅值变化时写 byte+478 并 140C11740 刷新，getter141A08330 返回该 byte。140C11870 在理符 Director 时选此 getter，非理符选虚 270；140FEFF90 及 140FF0E70 使用 Addon35“n 级”等格式显示。固定 FFCS 将+478 声明为 int MaxDifficulty，但当前程序初始化/读写均 byte，且此链证明是任务等级显示值；不能仅依 FFCS 名称称作难度星数上限。p2..p8 未读。

依据：`0x140B811F0`、`0x141A075E0 ctor byte+478=0 /141A08330 getter /141A08350 setter`、`0x140C11870 leve vs Director.virtual270`、`0x140FEFF90 /140FF0E70 FormatAddonText2Int Addon35`、`resources-booster-items.json Addon35/1093/16606`、`client/leve-difficulty-references.json`。
