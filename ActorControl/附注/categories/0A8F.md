单挑抽选与勇气值

- 分支地址：`0x140b45528`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：DynamicEvent 资源与单挑抽选/勇气值日志已核对。
- 用途：显示动态事件单挑抽选结果与勇气值通知。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint DynamicEventContainer.Events 槽索引；数组 16 项，入口无范围检查 |
| p2 | 非零显示 Log9671 获选参加并重算勇气值；0 显示 Log9670 未获选但勇气值+1 |
| p3 | 主分支及本消费者未读取 |
| p4 | 主分支及本消费者未读取 |

额外参数：Self p5..p8 未读取。

说明：仅 DynamicEvent.EventType==2；条目+0x74 的 DynamicEventId 作为文本参数，模板明确查 DynamicEvent 资源。此包分支只显示结果，不在此直接写勇气值。

依据：`0x140B6C810 / 0x141AB9880`、`FFCS ContentDirector.DynamicEvents+0xC98 / DynamicEventContainer.Events+8 / stride0x1D0`、[DynamicEvents.md](../DynamicEvents.md)。
