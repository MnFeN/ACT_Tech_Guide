# 187 / 0xBB TimeZoneResponse

[分类参数](../../README.md#category-00bb) · [附注索引](../README.md)

本地时区计算应答

- 分支地址：`0x140b44133`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与参数已核对，部分业务字段待查。
- 用途：按时间戳计算本地时区并发送命令 820。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 无符号 32 位 Unix 时间戳（秒），用于 gmtime/localtime 并原样转交命令 |
| p2 | 原样转交命令 820 第三参数，业务待查 |
| p3 | 原样转交命令 820 第四参数，业务待查 |
| p4 | 此路径未读取 |

说明：以传入时间戳计算本地/UTC 差异，换算分钟并按 15 分钟取整、处理 DST，最终以计算结果+1440 作为命令 820 第一数值。不能仅据日期函数就把 p2/p3 判未用。

依据：`0x140B44124`、`0x140B386F0`。
