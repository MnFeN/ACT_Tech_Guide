# 31 / 0x1F SetModelAppearance

[分类参数](../../README.md#category-001f) · [附注索引](../README.md)

更新组合模型表现

- 分支地址：`0x140b3f3a1`。
- 回放观察：440 次；包族 {"ActorControl": 440}。

## 参数与行为

- 核对状态：模型状态、缩放、属性、动画索引与全槽清理选项已核对。
- 用途：一次更新模型状态、缩放、属性和两组动画索引。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | bit31 先清理全部 14 个 ActionTimeline 槽；低 31 位 ModelState 行号（缓存最终存低 8 位） |
| p2 | ModelScale 行号，最终存低 8 位 |
| p3 | 模型属性值与使能位掩码，同 0x31 |
| p4 | 低 8 位打包两个 0..15 的动画选择索引 |

说明：bit31 只门控初始 0x1408C44F0→0x140606FE0：对 ActionTimelineSequencer 槽 0..13 清请求/引用/速度/掩码并通知调度器停止，再更新 ModelState、ModelScale、属性与打包动画索引。不是单纯忽略状态相同检查，也不是强制重建整个模型。p4 低/高 4 位分别索引 0x1421979A0/0x1421979C0 表；对应索引与缓存不同时才请求 ActionTimeline。0x1408BD6C0 真实只有 self 和 packedIndices 两个参数，旧 variadic 反编译错误已按汇编修正，p1bit31 不在此再次消费。

依据：`0x140909B50`、`0x1408BD5B0`、`0x1408D3BF0`、`0x1408D3C50`、`0x1408BD6C0`、`0x1408C44F0→0x140606FE0 slots0..13`、`0x140607B30 / 0x140607C70清理槽与时间轴请求`。
