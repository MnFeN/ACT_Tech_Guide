# 3810 / 0xEE2 RemoveMowingReactionObjects

[分类参数](../../README.md#category-0ee2) · [附注索引](../README.md)

批量移除割草反应对象

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：布局实例 ID 筛选、三维距离排序、Timeline1 及延时回收闭环已核对。
- 用途：批量移除割草小游戏反应对象，先播放时间轴 1，再延时回收。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 布局实例 ID，与对象记录+4 匹配；p2==1 时忽略 |
| p2 | 完整 uint32 恰等于 1 为全体模式，使用模块当前对象数；其他值按 p1/p4 筛选 |
| p3 | 非全体模式的目标处理数；0 不进入筛选，非 0 按记录中位置到本机的三维距离从近到远排序，仅找到场景对象才递减 |
| p4 | uint32 生成组过滤键，与记录+4Ch 比较；记录值 0 也通过；全体模式忽略 |

说明：模块已激活且默认委派链可达。141C61140 构造记录首 DWORD 为 EObj.RowId、+4 为布局实例 ID（同一值调用 GetLayoutInstanceStatic(type40)）；+4Ch 来自输入生成记录第三 DWORD。141C61A00 把首二字段送 ReactionEventObjectManager.CreateObject(baseId,layoutId)，确认 p1 不是 ReactionEventObject.RowId 或 EntityId。比较器 141C62CC0 对记录+10h/+14h/+18h 和本机 GetPosition 作 XYZ 三维距离比较；排序 141C630F0 解引用 vector 指针后调用比较器。选中对象先设记录待处理及 Timeline=1，通过 ObjectIndex 取对象、虚 20 播放 Timeline1，并设 141C42A30(obj,30)计时。ReactionEventObject 构造 141C427F0 写 vtable142454FC0，虚 20=141C42E20 实际 PlayTimeline；仍受原生场景/对象状态门控。Update141C42A80 每帧 elapsed += FrameDeltaTime*GameSpeedMultiplier*30，达到 30 才清计时标志，名义 1 游戏逻辑秒，不是 30 秒或固定 30 渲染帧；没有 LayoutInstance 则不推进计时。141C61700 等待标志清除后，按记录 ObjectIndex 调用 14198A120 移除对象、减少当前数、清记录并从 vector 摘除。ASM141C6186F..81 证 EDX=record+A0h 避免伪码漏第二参数。负 ObjectIndex 且 record+AC 预留标志已置时，会清该标志并标记待处理，此支不检查 p1/p4；不能把所有副作用都说成严格只匹配筛选键。p5..8/独立 target 未读，无回放样本。
