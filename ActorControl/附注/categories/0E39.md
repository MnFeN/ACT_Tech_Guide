# 3641 / 0xE39 SetCosmicGoldStarChain

[分类参数](../../README.md#category-0e39) · [附注索引](../README.md)

宇宙任务金星连锁

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：ConsecutiveGoldCount 字段与金星连锁确认文案数值消费者已核对。
- 用途：同步探索任务当前金星连锁次数。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 先截低 8 位；0..5 写 WKSManager+EC0h 金星连锁次数，6..255 忽略；高 24 位不参与范围检查 |
| p2 | 本消费者未读取 |
| p3 | 本消费者未读取 |
| p4 | 本消费者未读取 |

说明：低 8 位先检查<=5 才取 Manager 写+EC0h，0 有效表示无连锁；例如完整 p1=256 会写 0，不是整 uint 超过 5 就忽略。FFCS State+E70h ConsecutiveGoldCount 加 Manager.State+50h 与当前偏移一致。原生 140A75E90 接受任务确认和 140A78740 放弃确认均将此 byte 作为 Addon17168/17170“当前金星连锁”的数值参数；并分别显示 17169“开始低于 A 类的探索任务会导致金星连锁重置”、17171“放弃探索任务会导致金星连锁重置”。确认文案另有当前任务标志/等级条件，此包仅同步计数，不直接给予加成、不发起放弃也不在接包内刷新 UI。p2..p8/target 未读，默认模块须加载且链可达；无回放样本。

依据：`0x141A709C0`、`FFCS WKS/WKSManager.cs`、`FFCS WKSManager.State+E70 ConsecutiveGoldCount`、`0x140A75E90 count→Addon17168; lowerA warning17169`、`0x140A78740 count→Addon17170; abandon warning17171`、`client/wks-mission-aux-readers.json`、`resources-wks-consecutive-gold-warnings.json`。
