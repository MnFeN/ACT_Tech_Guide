# 3300 / 0xCE4 SetVariantDungeonRecord

多变迷宫探索记录

- 分支地址：`0x140b45900`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：同步多变迷宫探索记录的完成位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | VVDNotebookContents.RowId-1 的零起始 bit 索引；当前有效资源映射 0..48，入口自身不检查边界 |
| p2 | 非零设为已完成，0 清除完成位；不是只接受 1 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5–p8 及 Target 独立 target 未读。

说明：位图 142ADFA48=PlayerState+690h，固定 FFCS 已命名 CompletedVVDNotebookContents，撤回此前“固定 FFCS 未命名”的过时说明。141A43720 按 VVDRouteData(group,subrow)取得 ushort NotebookContents 行号，非零时减 1 并查该位；140A53B60/140AFA5E0 调用它生成路线完成掩码。当前 VVDRouteData 四组映射记录 1..12、13..24、25..36、37..49，对应包索引 0..11、12..23、24..35、36..48；完整 49项标题及映射见vvd-notebook-bit-map.json。此为取得/完成记录，区别于 UIModule.VVDNotebookModule 用户文件的 SeenNotes 已阅读标记。没有在本收包直接输出日志、打开界面或刷新所有模块。

依据：`0x140BE5210 generic bit write`、`FFCS PlayerState.cs +690 CompletedVVDNotebookContents`、`0x141A43720 VVDRouteData first ushort minus1 then bit lookup`、`0x140842400 EXD VVDRouteData table1111 getter`、`0x140A53B60 / 0x140AFA5E0 route completion mask readers`、`resources-vvdnotebookcontents-raw.json / resources-vvdroutedata-raw.json`、`vvd-notebook-bit-map.json`、[VariantNotebookCompletion.md](../VariantNotebookCompletion.md)。
