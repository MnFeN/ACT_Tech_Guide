# 123 / 0x7B DutyQuestScreenMsg

[分类参数](../../README.md#category-007b) · [附注索引](../README.md)

指定接收者的屏幕提示

- 分支地址：`0x140b41e22`。
- 回放观察：1 次；包族 {"ActorControlSelf": 1}。

## 参数与行为

- 核对状态：ScreenImage 资源、接收主体筛选与 64 位比较已核对。
- 用途：向指定本机显示主体发送 ScreenImage 屏幕通知。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ScreenImage 资源行号 |
| p2 | 接收主体 GameObjectId 低 32 位；0xE0000000 无条件显示，否则须等于当前显示主体的完整 GameObjectId |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：140B7FC60 比较零扩展 p2 与 140627470 返回的 64 位 GameObjectId。1406273E0 通常返回本机角色 source，但特定目标模式使用 TargetSystem+98 GPoseTarget 或+A0 IdleCamTarget；不能将所有模式简化为硬目标或包头 EntityId。匹配后调用 1417CEEF0→1400F19A0 查询 ScreenImage。本批唯一样本 p1=1447，p2=0x10069019 等于包头实体；本机 ScreenImage1447 的 Image=128404、Jingle=159、Type=37。p3..p8 均未传入。

依据：`0x140B7FC60`、`0x140B7FC60 ASM lea RCX=0x142AAB990 TargetSystem; p2 zeroextend vs RAX`、`0x140627470 → 0x1406273E0 → GameObject virtual1 GetGameObjectId`、`FFCS TargetSystem GPoseTarget+98 / IdleCamTarget+A0 / TargetModes+6E60`、`resources-screenimage-7b.json`。
