# 378 / 0x17A PlayerCurrency

[分类参数](../../README.md#category-017a) · [附注索引](../README.md)

同步特殊货币的物品和持有数量

- 分支地址：`0x140b3d2a4`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：同步特殊货币的物品和持有数量。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | specialId，按有符号低 8 位解释 |
| p2 | Item 行号 |
| p3 | 允许的最大持有数量 |
| p4 | 当前持有数量 |

额外参数：p5 非零表示无数量上限；不是交易增量

说明：由 CurrencyManager 初始化状态门控。

依据：`FFCS CurrencyManager.SetItemData`。
