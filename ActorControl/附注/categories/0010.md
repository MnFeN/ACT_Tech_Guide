# 16 / 0x10 RecastDetails

[分类参数](../../README.md#category-0010) · [附注索引](../README.md)

设置冷却计时

- 分支地址：`0x140b3a157`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：汇编与被调函数已核对。
- 用途：设置冷却组已过时间和总时长。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | ActionManager 冷却组索引 |
| p2 | 已过时间，unsigned 转 float 后除 100，单位 0.01 秒 |
| p3 | 总时长，uint32 数值转 float 后除 100，单位 0.01 秒 |
| p4 | 未读取 |

说明：写 RecastDetail.Elapsed(+8)、Total(+12)、IsActive(+0)。初次 IDA 输出漏 XMM 参数，已以汇编纠正。

依据：`0x140B3A125–0x140B3A157`、`0x1408EDDD0`、`float常数0x14211BF98=100`、`0x140B3A125..157 zero-extended p2/p3 conversions`。
