# 59 / 0x3B SetOverrideTimeline

[分类参数](../../README.md#category-003b) · [附注索引](../README.md)

设置覆盖动作时间轴

- 分支地址：`0x140b43dfc`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支与被调函数已核对。
- 用途：设置/清除角色覆盖时间轴。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 非零作为进入 ActionTimeline；0 时按 p2 或清除路径执行 |
| p2 | 低 16 位保存为 TimelineContainer+742 的覆盖时间轴 ID；也是退出/后续时间轴 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：p1 非零同时播放进入/退出组合；p1=0,p2 非零直接执行 p2；两者零时停止已存 ID 并清字段。

依据：`0x003B`、`Client.Game.Character.TimelineContainer.PlayActionTimeline`、`0x1408BE910`。
