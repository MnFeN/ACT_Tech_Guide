# 240 / 0xF0 TurnToDirection

[分类参数](../../README.md#category-00f0) · [附注索引](../README.md)

转向指定朝向

- 分支地址：`0x140b447da`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：p1 压缩朝向、当前位置轨迹与旧状态优先级清理已核对。
- 用途：本机通过移动门控后，在当前位置建立朝向 p1 的转向轨迹。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位压缩朝向，换算 u16*2π/65535−π弧度 |
| p2 | 此分支未读取 |
| p3 | 此分支未读取 |
| p4 | 此分支未读取 |

说明：主分支 ASM140B447E7 明确 EDX=p1；141819DB0 保存 EDI、取 DI 并经浮点缩放，XMM2 传给 141819E90，目标 XYZ 为当前位置、options 默认。旧原型遗漏第二参而误判无参，已纠正。1418168A0(self,4)实际是按优先级 4 清理/取消旧运动，不是“进入模式 4”：它比较 4 与当前+3F2 优先级并在允许时清+3EC..3F3。此前该命名亦撤回。门控排除 MovementState1..3、机关跳跃 3、某活动路径模式 2 和高优先级运动。无参数控制新 XYZ 或持续时间，p2..p8 未读。

依据：`0x141819DB0`、`0x140B447E7 mov EDX,p1 /0x140B447F2 call`、`0x141819DC1 EDI=EDX /0x141819E45 ECX=DI`、`0x141819E58..9E70 angle decode→XMM2→141819E90`、`0x1418168A0 a2 is cancellation priority;compare+3F2 then zero+3EC..3F3`。
