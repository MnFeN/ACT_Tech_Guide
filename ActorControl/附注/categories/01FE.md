# 510 / 0x1FE UnlockChocoboTaxi

[分类参数](../../README.md#category-01fe) · [附注索引](../README.md)

解锁陆行鸟运输站

- 分支地址：`0x140b40b0f`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：分支、结构或资源已核对。
- 用途：设置陆行鸟运输站解锁位。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 运输站解锁索引，当前入口允许 0..95 |
| p2 | 非零设 bit，0 清 bit |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：写 UIState+0x1A0DF 十二字节位图，固定 FFCS 声明 93bit，本入口按 12byte 允许至 95。另通知 EventFramework 事件 16 刷新。

依据：`0x140C4B6E0 / FFCS UIState.UnlockedChocoboTaxiStands`。
