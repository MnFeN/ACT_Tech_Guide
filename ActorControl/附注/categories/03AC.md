# 940 / 0x3AC SetFashionAccessory

[分类参数](../../README.md#category-03ac) · [附注索引](../README.md)

装备时尚配饰

- 分支地址：`0x140b4499c`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：模式分支、初始化／复制／恢复调用及姿态条件已核对。
- 用途：为角色装备或清除时尚配饰。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 16 位 Ornament 行号 |
| p2 | 完整 uint32 模式：0 常规装配并处理本机自动撑伞状态；1 角色复制装配；2 请求条件性保留姿态；3 角色初始资料装配；4 解除抑制后恢复并请求条件性保留姿态。0/1 参与收刀，2/4 的保留受时间轴和 EmoteCategory4 限制，其他数值走共同逻辑而无专用分支 |
| p3 | 此路径未读取 |
| p4 | 此路径未读取 |

说明：角色存在才处理；p1 仅 low16 Ornament 行号；p3..p8 和 target 未读。同 ID 可直接返回，0 移除，受抑制可仅暂存。mode1 由 CopyFromCharacter.CopyFlags.Ornament 独立传入；mode3 由 1408CEA20 在 1408CFC7C 明确传入，并读取初始资料+6Ah 的配饰号；mode4 由多个解除抑制调用者恢复暂存 ID。1408B7040 实际识别普通／配饰基础移动时间轴；140614F20 实际查当前 Emote.EmoteCategory==4，并非任意循环表情。装配与移除的姿态保留边界详见 OrnamentModeCallersAndPoseConditions.md，2/4 不是无条件保留。模式名称采用行为描述；未声称官方枚举名或服务器选择条件。SetupOrnament 伪码仍有 local allocation 警告，模式判断核对完整 ASM；没有本类回放样本。
