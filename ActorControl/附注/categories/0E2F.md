# 3631 / 0xE2F SetCosmicMissionCompletionFlags

[分类参数](../../README.md#category-0e2f) · [附注索引](../README.md)

宇宙任务完成与金牌记录

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：本机分支与结构已核对。
- 用途：宇宙探索：同步任务完成或金牌位图的一个字节。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | 低 8 位，完整位图字节值 |
| p2 | 低 16 位字节索引，须小于 213 |
| p3 | 非零选 MissionGoldFlags，否则 MissionCompletionFlags |
| p4 | 本消费者未读取 |

说明：地址分别为 WKSManager+0xFA6/+0xED1。不是单个任务 ID/单 bit 开关；完成位图出现非零时设置模块+8 加载标志。 路由：WKSManager 默认模块链，需对应模块已加载。

依据：`0x141A6F260`、`FFCS WKS/WKSManager.cs`。
