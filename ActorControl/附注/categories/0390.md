# 912 / 0x390 SetWeeklyLotteryTimeBase

[分类参数](../../README.md#category-0390) · [附注索引](../README.md)

周彩票时间基准

- 分支地址：`主分发器未显式列出，默认委派链或其他入口尚未匹配`。
- 回放观察：0 次；包族 {}。

## 参数与行为

- 核对状态：已核对。
- 用途：更新金碟周彩票时间基准（WeeklyLotOffsetTime）。

| 参数 | 读取与语义 |
| --- | --- |
| p1 | uint32 秒尺度时间基准，完整写 GoldSaucerManager+50h；不是已证明的下一开奖时刻 |
| p2 | 未读取 |
| p3 | 未读取 |
| p4 | 未读取 |

额外参数：Self p5..p8 未读取；该委托分支不使用目标 ID

说明：原生 Lua 注册 140DFD5A0 将 GetGsWeeklyLotOffsetTime 绑定 140DFC6A0；后者返回 manager+50h，无实例回退 1285056000。与固定 FFCS 字段 WeeklyLotOffsetTime 交叉一致。WeeklyLottery 界面多处读取该值；未把字段直接解释为下一开奖 Unix 时间。

依据：`默认链0x140E6B110`、`0x140E6B110 GoldSaucerManager delegated handler`、`client/gold-manager-direct-consumers.json`、[GoldSaucerTimeAndFlags.md](../GoldSaucerTimeAndFlags.md)、`0x140DFD5A0 Lua registration`、`0x140DFC6A0 GetGsWeeklyLotOffsetTime`。
