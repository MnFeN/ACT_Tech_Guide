# 无人岛庭具编辑应答：0CA6/0CA7

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

## 0CA6：保留或清除槽

p1 低 16 位是庭具索引；p2 完整 32 位按 0/非 0 分支，其他参数未读。

- p2 非零：先取关联对象，清当前编辑预览及临时对象，然后对目标布局解除编辑标记并更新状态；对应庭具槽保留。
- p2 为 0：仅索引<90 时，移出活动记录列表，清动态对象与绑定，重置该槽的 ID、位置、旋转等。

最后两分支均标记 HousingMenu 刷新。保留路径 141C137F0 允许关联对象查找失败时，按 HousingObject 索引回退；因此不能把整条类别概括成只接受<90。清槽路径 141C13630 则明确限制<90。p2 只按实际保留/清槽定义，不把它凭空命名成通用成功/失败码。

141C13D70 清的是模块+2970h 当前编辑预览记录，不是清除全部 90 个槽。1406F4560(0,layout)会清目标布局运行字段 byte+3 的 0x10 位（bit4），并调用 1406FE730；具体渲染字段不强套未确认名称。

## 0CA7：提交本地变换与区域编号

p1 低 16 位为庭具索引，p2 低 8 位为 MJIMinionPopAreas 区域行号；其他参数未读。对于 slot<90 且记录+39h 未置的条目，141C13480 从本地编辑对象读取 XYZ 和旋转，写入槽+10h/+14h/+18h/+20h；再写+36h 标志 12，以及+38h 区域 byte，变化时置模块+29C0h dirty，并同步已有对象变换。坐标和角度来自本地编辑状态，不是包内 p3/p4。

区域的独立消费 1418EA5A0：16 直接返回允许；其他值在需要 MJI 检查的状态下要求资源存在、编号非 0、行+9bit0 为 1，再执行场景放置判定。相关 141C142E0/143F0 把区域 16 对应到特殊对象索引 90。16 不是资源行，实际表只有 0..15；这里保留“特殊旁路值”描述，未给它编造地名。
