# 03E9／03EA：住宅建造及外装编辑申请应答

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

两类别参数相同：p1 低 8 位 OutdoorHouseUnit；p2 完整 32 位结果，只区分零/非零。p1 高 24 位、p3..p8 和独立 target 不读取。

## HouseUnit 身份来自请求端

140E1C190（建造）和 140E1C2B0（外装）从 Outdoor+125D8h 当前选中 HouseUnit 取 byte，复制到+125DAh 请求缓存，分别写 mode1/2 到+125DCh 并发送 1100/1101，HouseUnit 原样作为第一参数。140E1C2B0 明确检查普通 0..59 或 80h/81h 公寓编码；普通值包含 division，并非界面 1..30 地块号。建造端还要求未已有房屋；文本 3318 明确“土地上已有房屋建设完成”，外装端 3321 明确“土地上没有建设房屋”。

## 应答处理

| 类别 | 内容 |
| --- | --- |
| 03E9 | **可直接使用缓存的条件**：Outdoor 存在、p2=0、p1 匹配缓存、mode1<br>**行为**：141722BB0(agent,0)整理背包可用槽，打开 Addon263 HousingSelectDeed，选择建造许可证 |
| 03EA | **可直接使用缓存的条件**：Outdoor 存在、p2=0、p1 匹配缓存、mode2<br>**行为**：1406F3580 复制对应场地外装记录，再 141722E40(agent,0)→14171F150 打开 Addon258 HousingEditExterior |

不符合可用缓存条件时，两者均把请求 HouseUnit 设 FF、mode0，并向对应 Agent 处理函数传 1 结束当前等待；若 p2 仍为 0，则发送 1104(p1 低 8 位,0,0,0)补取资料。p2 非零不补发，当前消费者没有细分该值业务原因，不能虚构详细错误码枚举。

1406F3580 对 60 个 40byte 场地外装记录索引，p1>=60 返回错误；03EA 调用不检查返回值。因此虽请求编码检查容许 80h/81h，也不能据此承诺公寓按同样外装复制路径有效。

本包不携外装物品 ID/染色值，也不直接建成房屋或更换装潢。当前无回放样本；请求端、应答端和实际 Addon 名三路静态证据核对。
