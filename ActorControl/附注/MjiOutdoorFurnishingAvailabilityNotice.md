# 无人岛庭具投影可用提示：0CAA

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

本类别全部控制参数未读，只将 MJIManager+438h（十进制 1080）待提示 byte 置 1。原“接收完成／数据加载完成”业务名撤回。

140EA8F80 更新循环读取该位，等待以下条件允许：1408436D0 的 UI 低 2 位阻塞状态不成立、140EAFB40 的事件阻塞状态不成立、全局布局状态(dword142AAB79C&FFFFFFFD)==0，且 UIModule 可用。然后先清 byte，再显示 Log10218：

> 可以使用“无人岛庭具”进行投影了，具体操作请使用“查看说明”阅读“关于无人岛庭具投影”一栏的介绍。

因此这是延迟提示调度，不在此加载庭具列表、设置解锁位或打开投影编辑器。条件不满足时保留待提示状态。多次收包在消费前合并为一位；消耗后再次收包仍可排队，不能把客户端 byte 说成永久记录首次解锁的旗标。

偏移扫描另命中 141A4AA80 的+438h，但其基址是网络 JSON 响应对象，读取后查 return_code，与本 MJIManager 字段无关。没有把相同位移当作同一消费者。

实际原文为 resources-mji-caa-delayed-notice.json；收包、更新及条件助手 C/ASM 已保存。现有回放无该类别样本，未动态触发投影提示。
