# 03AC：配饰模式的调用身份与姿态条件

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

补足模式 3 的独立调用者，以及此前仅记录地址的两个姿态条件。按实际效果给出描述性名称；不假称官方枚举名称。当前无 03AC 回放样本。

| p2 完整 uint32 | 描述性用途及精确差异 |
| --- | --- |
| 0 | 常规装配／移除。装配时参与收刀；本机还执行 AutoUmbrellaOrnamentId 匹配、天气结果处理。 |
| 1 | 角色复制装配。CharacterSetupContainer.CopyFromCharacter 在 CopyFlags.Ornament=400000h 且源当前配饰非 0 时显式传 1；装配参与收刀，不执行模式 0 专用自动撑伞状态处理。 |
| 2 | 请求保留非基础动作姿态的装配／移除；受下述时间轴和表情条件限制，不主动进入 0/1 收刀分支。没有找到给它另一官方用途名称的证据。 |
| 3 | 角色初始资料装配。1408CEA20 读取资料+6Ah 的非零 ushort 配饰号，于 1408CFC7C 置 R8D=3，1408CFC89 调用 SetupOrnament。跳过 0/1 收刀分支，亦不启用 2/4 的特殊保留条件。 |
| 4 | 解除抑制后的恢复装配。1408AC960、1408B54C0、1408B5BA0、1408B5C00 从暂存+20h 取配饰号后传 4；装配／移除与 2 同组请求保留姿态。不限于自动雨伞。 |
| 其它值 | 不拒绝；没有额外专用分支，跳过 0/1、2/4、0 三组判断，保留共同装配／移除行为。 |

主入口 p1 只用 low16 Ornament 行号，p3..p8 和 target 不读，必须路由角色存在。相同配饰号可直接返回，0 可移除；抑制期间可能仅暂存，并非每次都立即创建显示对象。

## 模式 1 与 3 独立调用证据

1408D2360 CopyFromCharacter 的 1408D2D6F..80：读取 source.OrnamentContainer.OrnamentId，R8D=1。FFCS CopyFlags.Ornament 同为 400000h；完整 C/ASM 保存。

1408CEA20 的 1408CFC6F..99：资料+6Ah 非 0 即传 3；函数由 1408CE890（个人资料前缀后偏移 20h）及 1408D00E0（另一资料前缀后偏移 10h）共同调用。上层 140B4F2A0 按资料 tag1/2/3 挑对应初始化包装，来自角色资料队列。此处只据实际初始化链称“角色初始资料装配”，不依赖猜测包结构版号。普通模式 3 的语义不等于本网络类别只在出生时发送。

## 特殊保留条件的真实含义

1408B7040 取角色（必要时取挂载的角色对象）的 slot0 ActionTimeline。若 1408B6DC0 会将当前普通移动时间轴转换为配饰移动时间轴，返回 true；也检查 1428BBD90 的 14 个配饰移动时间轴及 1428BBDC8 的单独 13372。资源现已逐行提取：

- 普通 3/783 normal/idle，7/8 转向，13..16 走路，22..27 跑步及起跑，30 冲刺、31..33 跳跃。
- 映射至 7367..7380 ornament/idle、转向、走路、跑步、冲刺、跳跃；13372 为 ornament_sp/m6016/onm_sp01。

因此这个条件检查基础移动／配饰动作时间轴；不是任意“正在表情”判断。

140614F20 读取 EmoteController+14h EmoteId，调用 140836970 真实 Emote 表，要求资源+26h byte==4。原始 EXH 列 11、Offset38、UInt8 与 typed EmoteCategory 互证。当前 20 个匹配行包括 91/92/93/95..100/107/108/117/218/219/243/244/253..255/325；218/219 真实名为“改变姿势”，类别 4 名称本身为空。不将该类别命名为所有循环表情或 EmoteMode4。

装配的 1408B4B66..BC9：只有 mode2/4 且上述两条件均 false，才置“保留”临时值。角色武器状态 bit40 本身也可绕过该清理段；否则不满足保留条件时调用 140616A20 清 CPose，并重置动作槽。140616A20 把 CurrentPoseType/CPoseState 所在 WORD 写 00FFh；本机旧 pose 有效且 CPoseState 非 0 时还发内部 command507。

移除 1408B4CF0 额外检查 1408B6B70：其判断当前 slot0 时间轴是否匹配当前配饰角色缓存的 6 个非零时间轴之一；匹配时不走 2/4 的特殊保留路径。其后仍有武器状态与基础动作／表情判断，不能概括为“2/4 必保留，其他必清”。完整分支保存在 C/ASM。

## 结论边界

全部 p2 数值按三个精确比较组覆盖；模式 1/3/4 另有独立原生调用身份，模式 2 按条件效果描述。官方模式名、服务器为何选择某模式、每个时尚配饰外观并非本次静态参数定义的依据。先前“未命名 3”缺口现由显式初始化调用补足。

资源：resources-ornament-emote-all-raw.json（全部 Emote 原始列）、resources-ornament-pose-timelines.json（真实 ActionTimeline 键、EmoteCategory4 与代表 Emote 行）。当前 CN 地址和字段来自 ASM，FFCS 只提供 EmoteId/CPose 字段与复制 flag 辅助身份。SetupOrnament 原伪码仍有 local allocation 警告，模式控制流一律以已存完整 ASM 为准。
