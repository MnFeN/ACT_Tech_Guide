# 宇宙任务窗口与目标结束控制：0DDA/0DDB/0DDC

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

三者全部控制参数未读，效果不同，不能统一称为放弃任务或关闭界面。

| 类别 | 实际效果 |
| --- | --- |
| 0DDB | 仅关闭已激活的 Agent466 任务选择窗口 |
| 0DDC | 标记目标结束，切换任务信息为结束后的显示并显示完成提示 |
| 0DDA | 清理 CurrentMission 与任务条目缓存，关闭任务信息和配方本等相关界面 |

## 0DDB：任务选择窗口

141A709C0 在 WKSManager 存在时调用 1401489D0，后者只取 Agent466 交 140495000；仅 Agent 存在且 IsAgentActive 为 true 时调用 Hide。未清当前任务、分数、评级，也未发起放弃命令。

## 0DDC：目标结束与待汇报显示

设置 CurrentMission+38h（manager+EB8h）=1，调用 140148C10(3)。该助手更新 Agent467 任务信息，调用 Agent204 任务物品状态标记及 Agent468 配方本重置，然后显示/聚焦任务信息。评级 1/2/3 还触发 Agent463 HUD 通知 2 及 Log10766“完成了探索任务的目标”。其他评级也可能走 UI 更新，但没有该成功日志。

结束标记有实际读取者：140A78150 在计时目标使用 0DD7.p2 结果耗时进行剩余时间显示；141A710A0 抑制临近截止提示。因此它表示目标结束后的阶段，尚未清除 CurrentMission，不能称为任务完全删除或已经发放报酬。

## 0DDA：任务缓存与相关 UI 清理

141A75710 清任务 ID、阶段、deadline、分数、评级、附加计数、结果值与状态，并释放 CurrentMission+20h 容器节点。141A74520 清任务追踪/显示条目的类型、进度和附加缓存。之后 140148A10 关闭 Agent467、468 的已激活窗口，重置 Agent204 任务物品，并对 Agent40 地图调用 140FC18C0(agent,1)。参数 1 由 ASM140148AA4 固定设置；旧伪码遗漏参数不意味着沿用任何控制参数。

140FC18C0 只有地图已激活、内部匹配类型 1 及当前打开状态 3 时清对应状态，再按缓存 MapId 重新打开地图。这里不从地图内部枚举猜地名或场景。

0DDA 与 0DD9 的任务数据重置相同。0DD9 另有非失败情况下的功能解锁提示；两者分别调用 140148A10／140148AD0，这两个 UI 助手的已核对动作相同，均关闭任务信息与配方本、清任务物品界面并按固定类型 1 刷新地图，不能仅因地址不同就说 UI 效果不同。虽然任务放弃可能触发这条清理应答，不能只从无参清理效果就声称每一次都由玩家手动放弃。

证据均为 141A709C0 默认链及对应 C/ASM；Log10766本机原文存resources-wks-mission-completion-messages.json。现有回放无这三类样本，未在游戏动态放弃或汇报任务。

## 0DD9 的功能解锁提示门控已核对

此前未命名的 JobStateModule+8 字段已查明为“本模块已观察到任意任务完成记录”的单向锁存。构造 141A6E960 设 0；整包位图接收 141A6EA60/141A70040、单字节更新 141A6F260 case0E2F/141A700F0，以及扫描助手 141A703D0，均在尚为 0 时遍历 manager+ED1h 的 213-byte 任务完成位图，任意 byte 非零则设 1。普通数据更新不会因随后位图全零而将其清 0。

0DD9 先保存旧评级，再清任务与显示缓存；旧评级!=5 且该锁存为 0 时，输出 Log10932..10937 的三组功能解锁提示与说明，然后执行与 0DDA 等效的 UI 清理。这个门控基于客户端已观察到的完成位图，不能声称它在所有异步时序下都严格等于“玩家历史上第一次完成任务”，也不把三条文字提示说成此处实际设置了服务器解锁状态。现已保留完整构造／接收／读取链，类别状态更新为已核对。
