# 多变迷宫探索记录完成位：0CE4

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

0CE4 操作的 142ADFA48 等于 PlayerState+690h。固定 FFCS 将其命名 CompletedVVDNotebookContents；本次读者链进一步核实为多变迷宫探索记录的完成位，纠正此前“未知辅助解锁”的保留描述。

| 参数 | 定义 |
| --- | --- |
| p1 | VVDNotebookContents 行号减 1，零起始 bit 索引 |
| p2 | 非零置位，0 清位 |
| p3／p4／额外参数／Target 目标 | 未读 |

140BE5210 按 byte=p1>>3、mask=1<<(p1&7)修改位图，没有入口范围检查。当前资源有 50 行（含空行 0），有效 49 项，故当前有效协议索引为 0..48；不能把资源范围误写成程序已有防越界检查。

141A43720 以路线组及子行调用 VVDRouteData getter140842400，读取行首 ushort NotebookContents 行号，非零则减 1 查同一位图。140A53B60 和 140AFA5E0 按路线调用该读者，生成对应完成掩码。原始反编译曾漏推此方法的两个传入参数；修正函数原型、重新导出后明确为(group,subrow)，机器指令也保持 RCX／RDX 直接调用资源 getter。

这组服务器完成位与 UIModule.VVDNotebookModule 保存的 SeenNotes 不同：后者是用户文件内四组、每组 13 byte 的已阅读记录。本包不直接修改 SeenNotes，也不应命名为“已阅读某篇”。本包没有回放样本；当前资源和静态读写链互证，未做游戏动态验证。

原始资源分别保存在 resources-vvdroutedata-raw.json和resources-vvdnotebookcontents-raw.json；便于程序复用的 49项映射为vvd-notebook-bit-map.json。
