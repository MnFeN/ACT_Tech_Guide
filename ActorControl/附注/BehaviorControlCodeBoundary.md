# 0052：基础 Behavior 控制码、覆盖编号与低值边界

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

本类别更新角色基础行为控制码，不能统一定义为“播放 ActionTimeline”。p1 取低 16 位；p2 只读 bit0；p3..p8 及 target 不读。角色不存在时忽略。

## 收包与去重

14194D4C0 将 p1 低 16 位与 controller+104h（Character+1DF4h）比较，相同就返回，包括不采纳新的 p2 选项。不同则保存 p1 并置 dirtybit0；p2 bit0 置位时另置 dirtybit4。旧基础编号>=30000 且路由角色被识别为本机时，后者还可立即调用逐帧控制器。其他 p2 位未在该入口使用。

场景覆盖编号位于 controller+106h，由 1408D70B0/1408D73D0 等路径选择场景对象并写入，非本包 p2。14194B4A0 先计算有效编号：覆盖非 0 优先，否则取基础。

## 有效编号的实际消费

dirty 时，14194B4A0 清 dirty 并调用 14194BBD0 重置执行缓存、计时及目标等状态。PlayerKind1 路径在有效编号非 0 时会终止相关 Emote 状态，并清理相关时间轴排队状态；另一组基础>=30000 且有效值等于基础的条件控制场景状态，退出时可恢复已保存位置，dirtybit4 抑制其中的位置恢复。非 PlayerKind1 不应套用整组玩家 Emote 副作用。

14194BCB0 只在其他执行条件满足且有效编号严格>30000 时请求 sheet7=Behavior；读取到同一有效行后继续执行 Behavior 命令。<=30000 直接离开该表执行分支，不以同号查询或播放 ActionTimeline。

| 数值边界 | 已证行为 |
| --- | --- |
| 基础低 16 与旧值相同 | 不更新、不因 p2 不同重新触发 |
| 有效值 0 | 不走非零有效值的 Emote 取消条件，不执行 Behavior 表 |
| 有效值 1..29999 | 可触发值变化/非零清理；不执行 Behavior 表 |
| 30000 | 不执行 Behavior 表；但基础>=30000 的资格门控已成立，须区别 29999 |
| 有效值>30000 | 通过其他条件后请求并执行 Behavior 行 |
| 基础为低值但覆盖非 0 | 仍以覆盖为有效编号，不能断言必停止覆盖行为 |

14194DD90 进一步明确资格判断为基础>=30000 或覆盖非 0。因此不能仅以表执行是否发生代表所有控制状态。

## 读取路径补查与证据限制

除此前 word 读取及 Character 绝对偏移读者外，本轮按指令 operand 类型补扫 DWORD/QWORD 读取，排除 LEA 和纯写入，得到 221 处/154 函数。关键词过滤唯一候选是 0x3000000 掩码的字符串误匹配。8 个反编译失败函数中的 9 处已保存 ASM 上下文：批量复制、随机数状态移位、全局渲染状态与 float 读取均没有提供低值到 ActionTimeline 的映射。主/覆盖控制器、已识别复制恢复消费者与资源请求边界的判断结合原始机器指令。

这不是对全程序任意未解析间接别名的数学证明，也没有据此声称还原服务端为低编号赋予的全部名称。完成的定义是本版客户端如何控制、读哪些参数及怎么执行；低值只作上述数值门控/变化处理的部分，不要求凭同号资源编造逐 ID 动画含义。

## 回放交叉核对

1040 条均为普通 ActorControl：518 条 p1=0，519 条非零低值小于 30000，3 条 p1=35529；p2 全部 0。当前 Behavior35529 有 9 条子行，属于可执行范围。小编号恰好在 ActionTimeline 中有同号行不构成播放该时间轴的证据，旧假设已撤回。
