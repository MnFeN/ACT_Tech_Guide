# 0136 / 013E：选择对象生成键；0139：撤销服务器许可

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

此前把选择键的业务缺口描述为“时段/天气枚举待查”，容易让读者以为它一定是时间或天气。新追到真实生成者后，能精确定义为按对象生成附加字节选择实例；不能把它加上没有证据的时间单位。

## 查询 DWORD 的来源

本机 140B49140 ObjectSpawn 按 Kind6 创建采集点对象，将 payload+2C 和+30 的两个完整 DWORD 交 141759180；该函数写入 GatheringPointObject.Impl+10/+14。141757D50 对象更新把 Impl+10 作为 EDX 传 handler 虚 278。这里已验证接收对象是采集点 handler；全.text 扫描得到的其他+8B0 间接调用还可能属于其他类/子集合，不能一概当成采集调用。

所以 140E8B830 里的 BYTE2(query)是生成包 payload+2E 字节。该函数对普通 Type 还把 BYTE1(query)用于周期记录索引、BYTE3(query)用于分组数量检查；本专题不把这些其他字节套成 0136 或 013E 额外参数。

Setup140E8B610 从第二个 DWORD 的 byte2，即 payload+32，给 handler 缓存的选择键赋初值；对 Type2/5 还由 payload+30 和+31 组合设活动 bit。这说明“对象自己的键”与“handler 当前选中的键”是两个独立位置，不能因它们在某个生成包中恰相等就混成一个字段。

## 0136

p1 低 16 位与 30000h 合成 EventId，找既有 handler；p2 低 8 位置 handler+304，Flags+310 bit0 置 1；p3..p8 和 target 不读。setter 不自行检查 Type，但可用性消费者仅在 Type2/5 使用这组字段：活动 bit 必须为 1，并且选择键与对象 payload+2E 完全相等。

这就是启用对应类型并选择哪些已生成对象可通过此项资格检查。p2 不是默认 bool，也不表示采集次数。它保留全部 byte 值 0..255，没有 20/24 小时等校验。

## 013E

p1 同样查 handler；仅 Type8 处理 p2：low8 写+305，并将 RemainingCount+30A 恢复为 Count+30B。其他 Type 完全不写。p3..p8 和 target 不读。

该类型比较存在重要符号边界：ASM140E8B894 以 movsx 把缓存 byte 扩成有符号 int；140E8B89E 以 movzx 把 query byte 扩成 0..255，然后 cmp 两个 32 位寄存器。因此缓存 0..127 可匹配相同对象键，128..255 变成负数后不能匹配任何对象键。特别 FF 对应无选择/禁用的实际效果，不能当成键 255 仍可显示。

无论选择值可否匹配，setter 仍恢复 RemainingCount。这不是删除对象，不是只清图标；实际显示还需后续资格判断。现有 Type8 资源 12 行全 Territory901，但地名范围不能证明这个字节是天气枚举。

## 最终显隐和可选中

141757D50 在资格为真时继续用 handler 另一虚方法取得可选中状态，交 140898020 设置 GameObject.TargetableStatus.IsTargetable，再走对象显示路径；资格为假则清可选中位并走隐藏路径。还保留 Type5 采集类型的特效更新分支。许可、探知状态、等级、次数/虚 280 例外等没有被这个选择键绕过。

因此这些收包改变实际对象的资格和表现，而不只是记录一个以后无人读取的字节。缺少对应回放样本，不宣称已动态看见特定对象出现。

## 0139 与 0138 闭合

0139 仅 p1 低 16 位查既有 handler，140E8B250 只清+312；不清 Count/RemainingCount，不改资源+311、不删除对象，其余参数未读取。Type0 拒绝、Type3 通过发生在许可门控前；其他类型只在资源+311 非零时受+312 影响。最终对象更新使用的正是上述资格结果。

官方未命名的资源 bool 可以准确描述为要求服务器许可；服务器根据什么玩法条件授予它并未在客户端本包中判断，不能编造“任务已接取”。与 0138 的开启、Setup 的初始化、0180 的独立写入及最终消费者合看，0139 客户端行为与全部参数用途闭合，转为已核对。

0136 和 013E 的键来源、位宽、匹配规则、Type 约束及最终对象表现现也闭合，均转为已核对；保留键值由服务器分配，不给每个任意 byte 值强造一个天气或时段名称。
