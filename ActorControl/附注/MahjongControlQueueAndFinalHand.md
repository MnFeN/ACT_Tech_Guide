# 07D0：麻将内部控制队列与最终局提示（部分确认）

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

本轮补查该类别四个子命令。外层要求 InstanceContentDirector 类型 14，内部 141A20020 还要求 Agent328 Emj 存在。p4..p8 及独立 target 不读，无回放样本。本类别保持待查，不因补齐时间和队列就声称所有子命令业务已命名。

## 正确的内部接口

1410D9C00 在 Emj Agent 激活时，取 AgentData+F80h 的包装对象，再取包装对象+8 作为核心接口；未激活返回 0。末尾的 141ADC820 被自动库识别成 CRT file_name，实际机器码只是返回 this+8 的 qword，不能据错误名称将结果当字符串。

1410E1AB0 创建 AgentData 和 16 字节包装对象；141ADB700 创建 1248 字节核心并调用 141ADD6F0；构造明确安装 vtable142449640。由此证实子命令 1 调用的 slot5 是 141AE19B0，子命令 2 调用的 slot8 是 141AE18A0，不能套 AgentInterface 同槽 Hide/IsActivatable 定义。

| 子命令 p1 | 参数与真实效果 |
| --- | --- |
| 1 | p2 按 unsigned32 检查<4，符合才入内部事件 4，携带席位索引；>=4 不入队 |
| 2 | 完整 p2!=0 转 bool，入内部事件 6 |
| 3 | p2 完整 32 位写 Director+21B0h |
| 4 | p2 完整 32 位写 Director+21B4h，p3 完整 32 位写+21B8h |

141ADEC40 消费内部队列：事件 4 把核心+4A8h[席位]置 1，并在列表计数<4 时将席位追加到+498h 四 DWORD 列表。事件 6 把 bool 写核心+4DDh，核心+4D8h 阶段置 2，然后弹出队首。内部事件 4/6 不是 ActorControl 类别号，也不是网络子命令号。更具体的“已准备／已响应／断线”等含义没有独立文字证据，暂不命名。

## 子命令 4：最终局提示与时间

Director 字段的 getter 分别为 141A212F0(+21B0h)、141A21300(+21B4h)、141A21310(+21B8h)。1410DAA60 和 1410DAFA0 在联网模式下同步 NumberArray141 和 StringArray121：

| p2 模式 | 内容 |
| --- | --- |
| 0 | **NumberArray141[9]**：绝对秒差/60 >=1 时 0，否则 1<br>**实际显示**：0 取动态 EmjAddon201“距离新一局的开始时间还有 n 分钟”；1 取 202“不足 1 分钟”全文 |
| 1 | **NumberArray141[9]**：2<br>**实际显示**：EmjAddon203“下一局将是最终局” |
| 2 | **NumberArray141[9]**：3<br>**实际显示**：EmjAddon204“此局为最终局” |

p3 始终保存，只有模式 0 的这条计时分支使用。算法为 uint32(p3-GetServerTime())/60，ASM 的 32 位 SUB 后用无符号 MUL/SHR 完成除 60；没有 max(deadline-now,0)，逾期可按 32 位回绕产生大值。不能将 p3 误认为剩余秒或分钟，也不以正常服务器输入假设替代实际边界。模式 1/2 不计算倒计时；其它非零模式没有该 UI 分支，不能编造额外模式名称。

AddonEmj 真实 vtable1422C8640 已由构造 1416E7500/析构 1416E7910 核对。OnRequestedUpdate(slot52)1416EAD60 读取 NumberArray141[9]；0 取 StringArray121[0]，其它值从对象的表项选文案。初始化 1416ED0C0 将 values39/40/41 保存到+F28h/+F30h/+F38h；初始数据生产者 1410DB600 恰以 EmjAddon202/203/204 构造这三个槽。故上述模式名来自实际显示链，不是按相邻资源行猜测。

实际资源原句保存于 resources-mahjong-limit-notices.json。该计时与最终局提示相关；它不直接发牌、不保证到时自动开局，也不在此扩展成未经验证的服务器赛制规则。

## 剩余缺口

子命令 3 状态会参与退出资格：0、1、4、5 走一组受限路径，其它值不同；5 还在一项初始菜单配置中区别处理，但具体状态名未确认。子命令 1/2 的内部事件业务仍需接续 UI/牌局消费者。已检查的 35 个核心消费者候选及 65 个包装方法保存在独立 manifest，避免下轮重复从虚槽猜起。
