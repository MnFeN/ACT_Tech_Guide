# 064B 成员属性：全局 312 步长补查

[ActorControl 分类与参数](../README.md) · [附注索引](README.md)

在整个.text 按真实指令查找立即数 312，而不只扫 141A3D000..141A43000 的 word+F0 访问。得到 463 个候选站点、236 个函数；候选包括栈帧大小、UI 资源号等同值，不能都称为观战记录。225 函数成功反编译，11 失败已逐项记录，不写 None 伪码。

真实同布局链新增确认：14178A9D0 为 vector 扩容搬迁，复制同一字段+F0h 到新记录，不是属性解释消费者；1419D80F0 构造该 312byte 记录并将+F0h 清 0。141789280（观战）及 141A3E360/141A3FEC0（实战）从完整成员资料+18h ushort 保存同+F0h；064B 随后按槽覆盖它。多个 reset 和名单重建路径同样清 0。

记录两项 Utf8String 位于+0/+68h、EntityId 位于+E0h、属性位于+F0h。独立 getter141A3DF80 按 EntityId 找到成员并返回该 ushort，但当前没有代码调用 xref。两字符串和后面的 52byte 资料块不构成给该 ushort 命名为段位、等级或 HP 的证据。14178A9D0 的整项搬迁也不证明界面显示该值。

失败 11 项中 7 项的 312 命中仅是 rsp 栈帧调整；14091B1D0、140936530、14126FC00、141287120 另有普通对象指针+138h 等候选（有些函数同时多种命中），不能靠失败本身排除所有别名。此扫描也不穷尽没有 312 常数的访问器、预先计算的记录指针或其它基址变换。

文件：client/spectator-stride-global-consumers.json（全部站点、文件名和失败）、各*_spectator_stride_global_candidate.c；已有 064B setter 与 141A3DF80 C/ASM 保留。结论仍为“成员属性名待查”，没有为了计数把拷贝者当语义证明。
